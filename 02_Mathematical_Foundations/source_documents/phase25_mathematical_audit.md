## 1. 정의의 정리 (F의 D1–D4 수정판)

이하 A는 끌개(콤팩트, 흐름 불변), μ는 A 위의 불변 확률측도, O_𝔅는 패턴 𝔅의 관측 사상이다.

| # | 개념 | 정의 | 무엇의 성질인가 |
|---|---|---|---|
| I1 | 주변공간 식별 | O_𝔅가 M (또는 ℝ³) 위에서 단사 | 패턴 |
| I2 | 끌개 위 전역 식별 | O_𝔅가 A 위에서 단사 | 패턴 |
| I2′ | **점별 전역 식별** | 섬유 C_𝔅(s) = {s' ∈ A : O_𝔅(s') = O_𝔅(s)} = {s} | (패턴, 상태) |
| I3 | 주변공간 계수 | rank D O_𝔅(s) = 3 (ℝ³에서의 미분) | (패턴, 상태) |
| I4 | 끌개 조각 위 몰입 | A ⊇ S (매끄러운 조각)일 때 rank D O_𝔅(s)\|_{T_s S} = dim S | (패턴, 상태) |
| I5 | 안정적 식별 | 역사상이 섬유 근방에서 L-Lipschitz: ‖s−s'‖ ≤ L‖O_𝔅(s)−O_𝔅(s')‖ (국소 또는 전역) | (패턴, 영역) |
| I6 | 대상 식별 | O_𝔅(s) = O_𝔅(s') ⇒ g(s) = g(s') (A 위) | (패턴, 대상) |
| I6′ | 점별 대상 식별 | g가 섬유 C_𝔅(s) 위에서 상수 | (패턴, 대상, 상태) |

관계:
- I2 ⇔ (모든 s에서 I2′).
- I1 ⇒ I2.
- I3 ⇒ I4 (조각이 있을 때).
- **I3, I4 ⇏ I2** (계수는 국소, 단사는 전역).
- **I2 ⇏ I4**. 예: t ↦ t³은 단사지만 0에서 몰입이 아니다.
- 잡음이 있을 때 의미 있는 것은 I5다. I2(단사)만으로는 안정적 추정이 보장되지 않는다.
- box-counting 차원 d_A(Lorenz ≈ 2.06)는 **정리의 충분조건**(m > 2d_A)에 쓰인다. 위상차원은 "연속 단사가 가능한가"에 쓰인다. 둘은 다른 양이다.

## 2. 명제별 감사

### P0 — 단조성
- **원래 명제:** 𝔅 ⊆ 𝔅'이고 𝔅가 g를 식별하면 𝔅'도 식별한다.
- **가정:** O_𝔅 = Π∘O_𝔅' (좌표 투영). 마스크는 상태와 무관.
- **증명:** 정확하다. I2, I2′, I3, I4, I6에 모두 성립한다 (행을 더해도 계수는 줄지 않음).
- **숨은 가정:** I5(안정성)에도 성립하지만, Lipschitz 상수는 좋아지기만 한다 (같거나 작아짐).
- **"P(𝔅 ∈ I_g)가 r에 대해 감소"의 근거:** 결합(coupling) 논증에 MCAR **그리고 항목별 독립 Bernoulli**가 필요하다 (`prepare`는 만족).
- **판정: Valid.**
- **AIM 관계:** 관측이 많을수록 일관성 요구가 정당화되는 패턴이 늘어난다.

### P1 — 완전한 단일 view의 충분성
- **원래 명제:** F_i가 A에서 단사이면 모든 대상이 식별되고, G_{j←i} = F_j∘F_i⁻¹는 연속이다.
- **가정:** F_i 연속, A 콤팩트 → F_i⁻¹: F_i(A) → A 연속 (콤팩트-하우스도르프). 그러면 G 연속.
- **증명:** 정확하다.
- **숨은 가정:**
  - "T2(Sauer–Yorke–Casdagli)에 의해 F_i가 단사"는 **prevalent h**에 대한 결론이다. 특정 좌표함수 x, y에 대해서는 **가정**이다.
  - "미분동형"은 결론에 없다. 연속(위상동형)까지만 나온다.
- **판정: Valid with additional assumptions** (F_i 단사는 가정 A1로 명시).
- **AIM 관계:** AIM의 "each variable's delay embedding is diffeomorphic to the others"는 A1(그리고 매끄러움 조건)이 있을 때만 참이다. z에서는 거짓이다 (P2).

### 과거·미래 지연 관계 (F §1)
- **원래:** F_i^+ = F_i ∘ φ_{(m−1)τ}.
- **오류:** 좌표 순서 뒤집기가 빠졌다.
  - F_i(φ_{(m−1)τ}s) = (h(φ_{(m−1)τ}s), …, h(s))이고, 이것은 F_i^+(s) = (h(s), …, h(φ_{(m−1)τ}s))의 역순이다.
  - **수정:** F_i^+ = P_rev ∘ F_i ∘ φ_{(m−1)τ} (P_rev: 좌표 역순 치환).
- **결론에 미치는 영향:** P_rev는 선형 동형이고, φ_t는 A 위의 위상동형이다 (흐름 불변 집합, φ_t(A) = A). 그러므로 단사성과 몰입성은 보존되고 결론은 그대로다.
- **판정: 표기 오류 (Incorrect as written, conclusion unaffected).**

### P2 — Lorenz 대칭과 Bayes 하한

다섯 층위를 분리한다.

**(a) 결정론적 비식별** [증명]
- Γ(x, y, z) = (−x, −y, z)는 Lorenz 벡터장과 교환한다: f(Γs) = Γf(s) (직접 대입).
- 따라서 φ_t∘Γ = Γ∘φ_t이고, h_z∘Γ = h_z이므로 z만 관측하는 모든 패턴 𝔅에서 O_𝔅(Γs) = O_𝔅(s).
- 추가 가정: **Γ(A) = A**. 문헌상 고전 Lorenz 끌개는 원점의 불안정다양체의 폐포로 기술되고, Γ는 원점과 그 불안정다양체를 보존하므로 성립할 것으로 보지만 **세부 문헌을 확인하지 않았다**.
  - [수치] 우리 test 구간의 2,119개 상태 모두가 거리 0.5 안에 거울상 Γs를 가진 표본 상태가 있었다 (`pair_consistency.py`).
- 그리고 s ≠ Γs ⇔ (x, y) ≠ (0, 0).
- 결론: z-only 패턴은 I2를 만족하지 않는다. 점별로는 (x, y) ≠ 0인 모든 s에서 I2′가 실패한다.
- **이 층위에는 측도가 필요 없다.**

**(b) 대상의 범위**
- g∘Γ = −g인 대상(Γ-홀: x, y, xz, yz, …)은 z-only로 점별 식별되지 않는다 (g(s) ≠ 0일 때).
- Γ-짝 대상(z, x², xy, …)은 **결정되지 않는다**. 식별 여부는 z 지연사상이 A/Γ에서 단사인지에 달려 있고, 이것은 **Unresolved**다.

**(c) 측도의 대칭성**
- 하한에는 μ의 Γ-불변성이 필요하다.
- 근거: 고전 매개변수에서 물리적(SRB) 측도가 유일하다는 결과 (singular-hyperbolic 끌개 이론, Tucker 2002 이후) + Γ가 Lebesgue 측도를 보존하고 흐름과 교환 → Γ_*μ도 물리적 측도 → Γ_*μ = μ.
- **문헌 결론에 의존하고, 여기서 재증명하지 않았다.**

**(d) MSE 하한 — 정확한 진술**
- **명제 P2(d).** μ가 Γ-불변이고, 대상 g가 Γ-홀이며 g ∈ L²(μ)라 하자. 임의의 가측함수 u: (z-only 관측 공간) → ℝ에 대해

    E_{s∼μ}[(u(O_𝔅(s)) − g(s))²] = E_μ[g²] + E_μ[u²] ≥ E_μ[g²]

  등호는 u = 0 μ-a.s.일 때다.
- **증명:** E_μ[u·g] = E_μ[u∘O_𝔅∘Γ · g∘Γ] = −E_μ[u·g] ⇒ E_μ[u·g] = 0. ∎
- **적용 범위:**
  - (i) 기댓값은 **μ 아래의 모집단 기댓값**이다. 유한한 test 구간의 경험분포는 Γ-대칭이 아니므로 그 위의 RMSE는 하한보다 작을 수 있다. 과거에 3,000점 smoke에서 ρ ≈ 0.79가 나온 것이 그 예다.
  - (ii) **원래 단위**의 Γ-홀 대상에 대한 것이다. train 평균으로 정규화한 x' = (x − m)/s는 Γ-홀이 아니다. 하한은 원래 단위로 E_μ[x²]이고, 이를 s²로 나누면 Var_μ(x)/s² (E_μ x = 0일 때)다.
  - (iii) "nRMSE ≥ 1"은 모집단에서 정규화 분모가 Var_μ(x)^{1/2}일 때만이다.
  - (iv) 관측 잡음이 Γ와 무관하게 독립이면 그대로 성립한다.
  - (v) **모든 대상이나 모든 데이터 분포로 일반화할 수 없다.** z 대상, x², 비대칭 측도 등에는 해당하지 않는다.

**(e) 수치 결과와의 관계**
- [수치] z 기준 FPRM nRMSE 0.998–1.383, C/E/F의 z view 1.01–1.10 — 모집단 하한과 **일치하는 정황**이다.
- 증명의 대체물은 아니다. 유한 test 구간과 정규화 분모가 다르다.

- **판정: Valid with additional assumptions** (Γ(A) = A와 μ의 Γ-불변성은 문헌에 의존, 대상은 Γ-홀, 기댓값은 μ 아래).
- **AIM 관계:** "모든 변수의 지연 임베딩이 미분동형"은 Lorenz에서 **거짓**이다. 그러므로 AIM 문장을 수학적 진술로 쓰려면 "식별 가능한 view(조합)에 한해"라는 조건을 붙여야 한다. AIM 원문은 바꾸지 않고, 구현과 주장의 범위를 조건부로 한정한다.

### P3 — 대상은 식별되는데 상태는 식별되지 않는 경우
- **원래:** O_x = (x, ẋ, ẍ)는 x = 0에서 몰입이 아니고 (det = −σ²x), 그래도 y = x + ẋ/σ는 식별된다. 그래서 "상태 전체가 국소 식별되지 않는 x = 0에서도"라고 썼다.
- **문제 1 (과장):** det D O_x = 0은 **주변공간 계수(I3) 부족**만 뜻한다.
  - 단사성(I2′) 실패를 뜻하지 않는다 (t³ 예).
  - 끌개 조각 위 몰입(I4) 실패도 뜻하지 않는다. A의 매끄러운 조각이 2차원이면, 주변 계수 2로도 조각 위 계수는 2일 수 있다.
- **문제 2 (범위):** 미분 좌표 사상이지 지연 사상이 아니다. 유한 τ의 지연 사상에서는 y(t)가 (x(t), x(t−τ), x(t−2τ))의 정확한 함수라는 것이 F_x의 단사성 없이는 보장되지 않는다.
- **수정 명제 P3′:**
  - 미분 좌표 사상 O_x에 대해, y는 O_x의 매끄러운 함수다 (모든 점, 증명 그대로).
  - O_x는 평면 {x = 0}에서 ℝ³ 기준 계수가 2다.
  - 그러므로 **"대상 식별(I6)은 상태의 주변공간 계수 조건(I3)보다 약하다"** 가 증명되는 내용이다.
  - 상태가 실제로 I2′ 또는 I4 의미에서 비식별인지는 **Unresolved**다.
- **판정: Overstated** → P3′로 축소.
- **AIM 관계:** 낮은 대치 오차가 상태 복원을 뜻하지 않는다는 주장은 P3′로도 지지된다 (대상 식별 조건이 더 약하므로). 하지만 "x = 0에서 상태가 국소 비식별"이라는 표현은 지운다.

### P4 — 각 view는 불충분, 결합하면 식별
- **원래:** 현재값 하나씩(B_i = {0}): 단일 view는 끌개 위상차원 ≥ 2 때문에 단사가 아니고, (x, y, z)는 항등이다.
- **문제:** "Lorenz 끌개의 위상차원 ≥ 2"(2차원 중심-불안정 조각 포함)는 문헌 확인 없이 쓴 주장이다.
- **더 간단하고 엄밀한 대체 증명 P4′:**
  - A가 평형점이 아닌 궤도 γ를 포함하고, γ를 따라 x(t)가 어떤 구간에서 단조가 아니라고 하자. 그러면 중간값 정리에 의해 x(t₁) = x(t₂)인 t₁ ≠ t₂가 있다.
  - γ가 비주기이거나, |t₂−t₁|이 주기보다 작게 고를 수 있으면 s(t₁) ≠ s(t₂)다. 그러므로 x 하나는 A에서 단사가 아니다. y, z도 같다.
  - 이 조건은 우리 궤적에서 직접 확인된다: x가 양 날개를 오가므로 부호가 바뀜.
  - 결합 (x(t), y(t), z(t)) = s는 항등사상이라 단사다. ∎
- **숨은 가정:** 위의 궤도 조건 하나 (수치로 쉽게 확인 가능).
- **판정: Valid** (P4′의 증명으로 교체. 위상차원 논증은 삭제).
- **AIM 관계:** 완전 관측 변수가 없어도 **불완전한 view들의 결합**으로 식별할 수 있는 경우가 존재한다. AIM의 핵심 동기를 지지하는 엄밀한 예다. 단, 예가 "현재값 3개 = 상태 자체"라는 Lorenz의 특수 구조를 쓴다는 점은 명시한다.

### P5 — 결합해도 비식별
- **원래:** (i) z-only, (ii) |𝔅| < 3이면 국소 몰입 없음, (iii) |𝔅| = 1이면 전역 단사 아님.
- (i) **Valid** (P2(a)).
- (iii) **Valid** (P4′ 논증: 스칼라 하나는 A에서 단사가 아님).
- (ii) **Overstated.** |𝔅| < 3이면 **주변공간 계수(I3)** 가 3이 아닌 것은 맞다. 하지만 A가 국소적으로 2차원 조각을 가지면 좌표 2개로도 조각 위 몰입(I4)이 가능하다. 끌개 위 전역 단사(I2)가 좌표 2개로 불가능한지는 **Unresolved**다.
  - d_box(A) ≈ 2.06 > 2이므로 **Lipschitz 역사상을 갖는** ℝ²로의 단사는 불가능하다. Lipschitz 사상은 box 차원을 늘리지 않기 때문이다. 이것은 **I5(안정적 식별)의 부정**이지 I2의 부정이 아니다.
- **수정 명제 P5′:** z-only와 |𝔅| = 1은 비식별 (I2 실패). |𝔅| = 2는 Lipschitz 안정 식별(I5)이 전역적으로 불가능하다. I2 자체는 Unresolved.
- **판정: (ii)는 Overstated, 나머지는 Valid.**

### P6 — 식별가능성은 (패턴, 상태)의 성질
- **문제:** F의 D1은 **패턴의 성질**(I2)인데, P6는 (패턴, 상태)의 성질이라고 했다. 정의 불일치다.
- **수정:** 점별 정의 I2′, I4, I6′는 (패턴, 상태) 성질이고 I2, I6은 패턴 성질이다. I2 ⇔ ∀s I2′.
  - "같은 상태에 다른 마스크를 주면 같은 잠재가 나와야 한다"는 요구는 두 패턴이 그 상태에서 **점별 식별(I2′)** 할 때만 정당하다.
- **판정: Valid with additional assumptions** (정의를 I2′로 통일하면 Valid).

### P7 — 무조건적 점 일관성의 붕괴
- **원래:** 𝒫에 전체 관측과 z-only가 있고 모든 s에서 정확한 등식 Φ(O_𝔅(s)) = Φ(O_𝔅'(s))를 강제하면, 전체 관측에서도 s와 Γs를 구분할 수 없다.
- **증명:** 정확하다. Φ_full(s) = Φ_z(s) = Φ_z(Γs) = Φ_full(Γs). 디코더가 공유 코드의 함수이므로 x̂(s) = x̂(Γs), 그리고 P2(d)에 의해 MSE ≥ E_μ[x²].
- **숨은 가정:**
  - (i) **정확한 제약**이다. 유한 가중치의 벌점(λ‖Φ_z − Φ_full‖²)은 붕괴를 "강제"하지 않고 상충을 만든다.
  - (ii) s와 Γs가 모두 A에 있음 (P2(a)).
  - (iii) 디코더가 공유 코드만 본다.
- **일반화** ("가장 거친 분할로 붕괴"): 𝒫 안 패턴 섬유들의 합집합으로 생성되는 동치관계의 각 동치류에서 Φ가 상수가 된다. **Valid**.
- **판정: Valid with additional assumptions** (정확한 제약일 때). 소프트 벌점에 대해서는 "붕괴 방향으로 압력"이라고만 말할 수 있다.
- **AIM 관계:** 모든 view에 같은 잠재를 무조건 요구하는 식으로 AIM을 구현하면 안 된다.

### P8 — 평균 융합 (범위 재조정)

사용자가 구분한 주장 A–E별로 정리한다.

| 주장 | 내용 | 판정 | 근거 |
|---|---|---|---|
| A | 식별 여부와 무관하게 모든 마스크에 같은 잠재를 강제하는 것은 불가능 (정보 보존과 양립 불가) | **Valid** (P7 그 자체) | – |
| B | 식별 가능한 마스크들 사이에서도 잠재 일치가 불가능 | **Incorrect** (일반 융합에서) | 반례: 오라클 융합 ζ = ψ(s) (𝔅 ∈ I이면 O_𝔅⁻¹이 존재). 학습 융합(F형)은 원리상 가능 |
| C | 고정 가중치 단순 평균의 한계 | **Valid** (아래 P8′, 고정 가중치는 특수 경우) | P8′ |
| D | 마스크 의존 가중치 평균의 한계 | **Valid, 단 가중치가 각 view 자신의 마스크에만 의존하고 관측되면 양수일 때** (C의 실제 구조: w_i = 관측 개수) | P8′ |
| E | 모든 평균 기반 융합의 불가능성 | **Incorrect** | P8″ (행렬 가중 평균의 반례), 교차 view 게이팅으로 w_z = 0 가능 |

**P8 원래 증명이 실제로 뒷받침하는 범위:** "단일 view 패턴 {i}, {j}와 결합 패턴 사이의 불변" → "e_i = e_j = ζ" → "z view가 있으므로 P7 붕괴". 이 추론은 비식별 패턴 {z}에도 일관성을 요구하므로 **주장 A만** 뒷받침한다. "평균 융합은 일관성과 정보 보존을 함께 만족할 수 없다"는 원래 결론은 **Overstated**다.

**P8′ (C의 스칼라 가중 평균에 대한 정확한 불가능성) [증명]**
- **가정:**
  - 융합 ζ_𝔅 = Σ_i w_i e_i / Σ_i w_i.
  - e_i는 view i의 입력(값과 마스크)에만 의존한다.
  - w_i는 view i의 마스크에만 의존하고, view i가 관측되면 w_i > 0이다.
- **명제:** 패턴 {x}(x 창 완전, 나머지 없음)와 {x, z}(x, z 창 완전)에 대해, 모든 s에서

    max( ‖ζ_{x,z}(s) − ζ_x(s)‖, ‖ζ_{x,z}(Γs) − ζ_x(Γs)‖ ) ≥ (w_z/(w_x+w_z)) · ‖e_x(s) − e_x(Γs)‖ / 2

- **증명:**
  - ζ_{x,z}(s) − ζ_x(s) = (w_z/(w_x+w_z)) (e_z(s) − e_x(s)).
  - e_z(s) = e_z(Γs)이므로 삼각부등식에서 ‖e_z − e_x(s)‖ + ‖e_z − e_x(Γs)‖ ≥ ‖e_x(s) − e_x(Γs)‖. ∎
- **해석:**
  - 하한이 0이 되려면 x-view 코드가 s와 Γs를 구분하지 않아야 한다. 그러면 x-view는 x의 부호도 디코딩할 수 없다.
  - 그러므로 **C 구조에서는 "x-view가 정보를 가짐"과 "{x}, {x,z} 사이 잠재 일치"가 양립할 수 없다.** 두 패턴이 모두 식별 가능하더라도(x가 식별하면 P0에 의해 x+z도 식별) 그렇다.
  - 식별 가정 자체는 증명에 필요 없다.
- **수치 확인** (`pair_consistency.csv`, 기존 C 체크포인트 9개, 2,119개 거울 쌍):
  - 하한 위반 0건. 정리이므로 당연하고, 구현 점검 수준의 의미다.
  - 그런데 실제 불일치(시간 척도로 정규화)는 하한보다 훨씬 크다: {x}|{x,z} 0.65–1.48 vs 하한 0.22–0.37.
  - **Γ와 무관한 쌍 {x}|{x,y}도 0.47–1.38로 크다.**
  - → C의 잠재 불일치는 **주로 P8′의 대칭 장애 때문이 아니다.** 더 일반적인 원인이 지배한다.
  - 유력한 설명 (P11 감사 참조): C의 디코더는 ℝ¹⁶ → ℝ³이라 어떤 열린 집합에서도 단사가 될 수 없다. 출력에 영향을 주지 않는 방향(국소적으로 13차원)으로 코드가 마스크마다 움직여도 손실이 변하지 않는다. **이것은 가설이며 학습 실험으로 검증해야 한다** (문서 D의 최소 실험).

**P8″ (행렬 가중 평균은 대칭 장애를 피할 수 있음) [존재 증명, 학습 가능성 아님]**
- **가정:**
  - z view의 기여가 행렬 가중치 Λ_z(o_z) (반양정치)이고, 융합이 ζ = (Σ Λ_i)⁻¹ Σ Λ_i e_i 꼴이다 (가우스 PoE의 평균과 같은 대수 형태).
  - 섬유 쌍 {s, Γs}가 o_z로 결정된다. 이것은 z 지연사상이 A/Γ에서 단사라는 가정이고 **Unresolved**다.
- **명제:** Λ_z(o_z)의 영공간이 ψ(s) − ψ(Γs) 방향을 포함하고, e_z(o_z)가 두 점의 중점이면, P⊥ψ(s) = P⊥ψ(Γs)이므로 z의 기여는 두 점이 공유하는 성분만 바꾼다. 따라서 {x}, {x,z} 사이 정확한 일치가 가능하다 (x 기여가 ψ(s)이고 Λ_x가 가역일 때).
- 의미: **스칼라 가중**(C)은 불가능, **방향별 가중**(정밀도 행렬)은 가능. 이것은 정밀도 가중 융합을 쓸 **구조적** 이유다. 확률적(PoE가 참 사후라는) 정당화와는 별개다 (P9 감사).
- **판정 요약:** 원래 P8은 **Overstated**. P8′ (C 구조 한정, Valid)과 P8″ (존재, Valid with assumption)로 대체한다.
- **AIM 관계:** "평균 융합이라서 불가능"이 아니다. "**스칼라·자기 마스크 의존 가중 평균**은 Γ형 비식별 view가 있으면 일치할 수 없다"가 정확한 진술이다.

### P9 — 조건부 독립과 전문가의 곱
- **원래:** MCAR이므로 view 관측들은 s가 주어졌을 때 조건부 독립이고, p(s | o_1..o_n) ∝ p(s)^{1−n} Π p(s | o_i)다. 그리고 AC는 가우스 PoE 융합을 "P9에서 유도"했다고 썼다.
- **문제:**
  1. **MCAR만으로는 조건부 독립이 나오지 않는다.** MCAR은 "결측이 값과 무관"이지 "view 간 마스크가 서로 독립"이 아니다. 예: 센서 정전으로 모든 변수가 동시에 빠지는 결측도 MCAR이지만 마스크는 강하게 상관된다.
  2. **관측 잡음**이 view 간 상관되면 깨진다.
  3. **학습된 잠재 ζ**가 s의 정보를 잃으면 (ψ 비단사), o_i들은 ζ가 주어졌을 때 조건부 독립이 아니다. ζ가 담지 못한 s의 정보를 공유하기 때문이다.
  4. **결정론적 관측**에서는 p(o_i | s)가 디랙이고 사후는 특이측도다. 밀도 수준의 곱 공식이 정의되지 않는다. 사후는 μ를 섬유 교집합에 제한한 정규 조건부확률이고, 지지집합 수준에서는 supp(결합 사후) ⊆ ∩ supp(개별 사후)만 말할 수 있다.
  5. **가우스 PoE의 전문가는 참 우도가 아니다.** 학습된 가우스 인자들의 정밀도 합이 Fisher 정보의 합과 같을 이유가 없다. 선형-가우스 모형에서만 정확하다.
  6. **사후 전문가 vs 우도 인자:** 사후들의 곱에는 p^{1−n} 보정이 필요하다. 우도 인자들의 곱에는 사전 하나만 곱한다. AC가 쓴 ℓ_i(우도 인자)는 **신경망 출력일 뿐 정의상 우도가 아니다.**
- **수정 명제 P9′ [증명]:**
  - **가정:** (i) 패턴 (B_1, …, B_n)이 서로 독립이고 s와 독립 (`prepare`의 항목별 독립 Bernoulli가 만족). (ii) 관측 잡음이 view 간 독립이고 s가 주어졌을 때 마스크와 독립. (iii) 잡음 밀도가 존재.
  - **결론:** o_1, …, o_n은 s가 주어졌을 때 조건부 독립이고, p(s | o) ∝ p(s) Π_i p(o_i | s) ∝ p(s)^{1−n} Π_i p(s | o_i).
  - ζ = ψ(s)이고 ψ가 μ-a.s. 가역이면 ζ 공간으로 그대로 옮겨진다. 그렇지 않으면 성립하지 않는다.
  - 잡음이 없는 극한에서는 섬유 교집합 위 정규 조건부확률로 해석한다.
- **판정: Overstated** → P9′. **"MCAR이 가우스 PoE의 정확성을 보장한다"는 주장은 철회한다.**
- **AIM 관계:** PoE는 **설계 선택**(정밀도 가중 융합, P8″의 구조적 이점)으로 쓸 수 있다. 하지만 "참 사후"라는 근거로 쓸 수는 없다.

### P10 — tower 일관성
- **원래:** 𝔅 ⊆ 𝔅'일 때 Q_𝔅(· | o_𝔅) = E[Q_𝔅'(· | o_𝔅') | o_𝔅].
- **증명:** 조건부 기댓값의 tower 성질로 정확하다. 단, **우변의 기댓값은 o_𝔅가 주어졌을 때 가능한 여러 o_𝔅'(즉 섬유 위 여러 상태)에 대한 평균**이다.
- **구분해야 할 네 개념:**

| 개념 | 정의 | 언제 성립해야 하나 |
|---|---|---|
| 같은 상태 마스크 섭동 | 같은 s에 대해 Q_𝔅(o_𝔅(s))와 Q_𝔅'(o_𝔅'(s)) 비교 | 두 패턴이 s에서 점별 식별(I2′)할 때만 같아야 함. 일반적으로는 **지지집합 포함**만: ψ(s) ∈ supp Q_𝔅(o_𝔅(s)) (참 사후는 μ-a.s. 만족) |
| 사후 평균 일관성 | E[mean Q_𝔅' \| o_𝔅] = mean Q_𝔅 (마팅게일) | 참 사후에서 항상 |
| 사후 분포 일관성 | Q_𝔅 = E[Q_𝔅' \| o_𝔅] (혼합 등식) | 참 사후에서 항상 (= tower) |
| tower 일관성 | 위와 같음 | – |

- **AC의 평가 설계 점검:**
  - AC §6 B의 "(식별, 비식별) 쌍: ψ(s)가 비식별 쪽 사후의 고밀도 영역에 포함되는가"는 **같은 상태 지지집합 포함 검사**로 정당하다.
  - AC의 "tower 검사"는 "완성은 같은 섬유의 이웃으로 몬테카를로 근사"라고 써서 방향은 맞다. 하지만 같은 상태 섭동과 섞어 쓴 표현(§5.2 표 (ii)의 "확률적으로는 Q_j = E[Q_{i,j} | o_j]")은 **tower 등식을 같은 상태 비교처럼 읽히게 했다.** 수정한다.
- **시뮬레이션 추정 절차 (설계):**
  1. 학습에 쓰지 않은 **긴 별도 궤적**(또는 여러 초기값 궤적)으로 참조 풀 𝒮를 만든다. μ에서의 근사 표본이다.
  2. 평가 시점 s₀, 패턴 𝔅 ⊂ 𝔅'에 대해, 𝒮에서 ‖O_𝔅(s) − O_𝔅(s₀)‖ ≤ ε인 상태 {s_k}를 고른다 (섬유의 ε-근방).
  3. 우변 ≈ (1/K) Σ_k Q_𝔅'(· | O_𝔅'(s_k)). 이 혼합과 Q_𝔅(· | O_𝔅(s₀))의 거리를 잰다 (평균 차이, MMD, 또는 표본 기반 에너지 거리).
  4. **편향:** (a) ε-근방은 섬유가 아니라 관측 공 위의 조건부다 → O(ε × 사후의 관측 민감도) 편향. ε → 0이면 표본 수가 줄어든다. (b) 시계열 표본은 상관되어 있어 유효 표본 수가 줄어든다 (궤적을 띄엄띄엄 추출). (c) 관측 차원이 큰 패턴에서는 ε-근방이 희박하다 (차원의 저주). 패턴별로 ε를 정하고 K를 보고한다.
  5. 기준선: 참 사후는 수치적으로 알 수 없으므로, **같은 절차를 "참 상태 디코더"(s ↦ δ_{ψ(s)})에 적용한 값**을 추정 잡음의 하한으로 함께 보고한다.
- **판정: Valid** (수학). AC의 해석과 검증 프로토콜은 **수정 필요**.

### P11 — 단사 디코더와 공유 잠재
- **정확한 판본 [증명]:**
  - **가정:** (i) R: K → ℝ^{nm} 연속 단사, K ⊆ Z 콤팩트. (ii) 𝔅, 𝔅' ∈ I(s)에서 Φ_𝔅(s), Φ_𝔅'(s) ∈ K. (iii) R(Φ_𝔅(s)) = R(Φ_𝔅'(s)) = F_all(s).
  - **결론:** Φ_𝔅(s) = Φ_𝔅'(s).
  - 더 나아가 F_all이 A에서 단사이고 F_all(A) ⊆ R(K)이면, ψ = R⁻¹∘F_all: A → K는 연속 단사다. 그러므로 위상동형 (R⁻¹는 콤팩트 위에서 연속).
  - **얻는 것은 위상적 상태 표현이다.** 미분동형이려면 추가 가정이 필요하다: R이 C¹ 몰입이고 단사, F_all이 A를 포함하는 매끄러운 다양체의 매장, 그리고 A의 매끄러운 조각에 대한 해석.
- **근사 판본 P11′ [증명]:**
  - **가정:**
    - (i) **점별** 복원 오차: ‖R(z_𝔅) − F_all(s)‖ ≤ ε, ‖R(z_𝔅') − F_all(s)‖ ≤ ε. 평균 오차가 아니다. 평균만 알면 Markov 부등식으로 "표본의 일부 비율에서"로 약해진다.
    - (ii) **전역 역-Lipschitz**: 모든 z, z' ∈ K에서 ‖z − z'‖ ≤ L‖R(z) − R(z')‖. K는 두 코드를 모두 포함하는 집합.
  - **결론:** ‖z_𝔅 − z_𝔅'‖ ≤ L‖R(z_𝔅) − R(z_𝔅')‖ ≤ 2Lε. ∎
- **구분:**
  - **전역 단사성**은 (ii)의 L < ∞를 위해 필요하지만 충분하지 않다. 콤팩트 K에서는 연속 단사 ⇒ R⁻¹ 연속이지만, Lipschitz는 아니다.
  - **국소 몰입**(DR 계수 = k) 또는 **Jacobian 최소 특이값 σ_min(DR) ≥ 1/L₀**은 국소 역-Lipschitz만 준다. 전역 L은 R(K)가 "자기 자신에 가깝게 접히는" 정도에 좌우되므로, **σ_min이 커도 전역 L은 클 수 있다** (예: 거의 닫히는 곡선).
  - **추정:** L은 표본 쌍 sup ‖z−z'‖/‖R(z)−R(z')‖로 경험적 **하한**만 얻는다. 표본 밖의 접힘은 놓친다.
  - 데이터가 차지하는 잠재 지지집합 K에서의 성질만 필요하다. 전체 ℝ^k에서의 단사성은 필요 없다.
- **C에 대한 함의 [증명]:**
  - 현재값 디코더 R: ℝ¹⁶ → ℝ³는 (불변영역 정리에 의해) **어떤 열린 집합에서도 단사가 아니다.**
  - 그러므로 K가 열린 조각을 포함하면 P11의 가정 (i)이 깨진다. 이것이 C 불일치의 유력한 구조적 원인이다 (가설, P8 수치).
  - FDR(ℝ¹⁶ → ℝ²⁴)이나 잠재 차원 ≤ 출력 차원이면 단사가 **가능**해진다. 그래도 **보장되지는 않는다.**
- **판정: Valid with additional assumptions.** "D와 C가 함께 성립"은 **위상적 의미**로 한정한다.
- **AIM 관계:** "일관성을 손실로 강제하지 않고 복원의 결과로 얻는다"는 방향은 유지된다. 실제로는 (ε, L) 두 양을 **측정해야** 일관성 주장이 가능하다.
