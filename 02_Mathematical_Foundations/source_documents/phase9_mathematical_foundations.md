## A1. 수학적 대상과 실제 모델의 대응

**정의**
- 상태: S_t ∈ 𝒮 ⊂ R⁶. 흐름 φ^t는 상(image)으로 가는 해석적 미분동형이다(Phase 8 L2).
- 관측 함수: h_j ∈ {x1, z1, x2, z2}(좌표 사영, 고정 상수로 정규화)
- view j의 지연 관측: Φ_j(S_t) = (h_j(S_t), h_j(φ^{−τ}S_t), …, h_j(φ^{−(m−1)τ}S_t)) ∈ R⁸
- 전체 지연 관측: Φ(S_t) = (Φ_1, …, Φ_4) ∈ R³². 과거만 쓴다.
- 마스크: 창 안의 원래 관측 마스크 O ∈ {0, 1}^{4×8}, 인코더 입력 마스크 M ≤ O(항목별)
- 사영: π_M Φ(S)는 M = 1인 항목만 남기고 나머지를 0으로 둔 값이다.

**실제 코드와의 대응 [Verified (code/data)]** (`experiments/phase5/core.py:75–104`, `experiments/phase8/train8.py:32–39`, `experiments/fdr/loss.py`)
- **인코더:** E(π_M Φ, M) = fuse([E_i(V_i ⊙ M_i, M_i) ⊙ a_i]_i, w)
  - E_i는 view별 group MLP(2m → 64 → latent)다.
  - a_i = 1{view i에 관측 lag가 있음}, w_i는 관측 비율이다.
  - 마스크 M이 입력이므로 **마스크 조건부 인코더 E_M**이다.
- **디코더:** D(Z) ∈ R^{4×8}. view별 group MLP가 각 view의 **전체 지연 벡터**를 출력한다.
  - lag-0 출력이 시각 n의 대치값이다.
- **학습 입력:** B = O − H. H는 관측 항목 중 비율 h = 0.2를 독립적으로 숨긴 것이다. 따라서 **M = B ≤ O**이고, 이미 A1의 형태다.
- **학습 손실(FDR):** 숨겨진 관측 항목 H에서만 계산한다. 원시 위치 u마다 중복도 1/c(u)로 가중한다.
- **평가 입력:** test 시 입력은 O 자체다. 대치 대상은 O = 0인 위치다.

## A2. 불완전 마스크에서의 복원 불가능성

**명제 A2.1 [Verified (math)]**
- 진술: 같은 마스크 m에서 두 상태 s ≠ s′가 π_m Φ(s) = π_m Φ(s′)이면, (π_m Φ, m)만 받는 어떤 결정론적 인코더 E와 디코더 D도 두 상태를 구별하지 못한다. 즉 E(π_m Φ(s), m) = E(π_m Φ(s′), m)이고 D∘E도 같다.
- 확률 판(Phase 8 L4′): 대응 사상 s ↦ π_m Φ(s)가 μ_P-양의 측도에서 단사가 아니면 R*_m > 0이다.
- 증명: E가 (π_m Φ, m)의 함수이므로 입력이 같으면 출력이 같다. 확률 판은 L4′이며, 식별 불가하면 σ(W)-가측 추정기의 Bayes 위험이 양수다. ∎

**반례 (모두 Verified (math))**
- **(a) 완전 결측 창(m = 0):** π_0 Φ ≡ 0이다. 따라서 E는 상수이고 Bayes 위험은 Var(S̃)다.
- **(b) Lorenz 부호반전**
  - X0 = {창 안에 x1, x2가 모두 결측}에서 W∘γ₁₂ = W다(z는 γ₁₂-불변).
  - 그러나 s ≠ γ₁₂ s다(x = y = 0인 측도 0 집합 제외).
  - 따라서 X0에서는 모든 상태가 자기 반전상과 구별되지 않는다.
  - E_P[x, y | W] = 0(N1-X0)이고, 정보 하한은 LB_X0 = 0.6679(κ = 1, Phase 8 감사)다.
- **(c) 관측 차원 부족:** n_obs(m) < 6이면 P에서 비단사다(Phase 8 L4; A-ac 가정, 크기 정보 없음). ν에서는 Unresolved다.

**정리 A2.2 (전역 cross-mask 정렬의 불가능성) [Verified (math)]**
- 가정: 다음이 모두 성립하는 마스크 집합 𝓜가 있다고 하자.
  - (i) 어떤 m₀ ∈ 𝓜에 대해 서로 다른 s, s′가 π_{m₀}Φ(s) = π_{m₀}Φ(s′)를 만족한다.
  - (ii) 모든 m ∈ 𝓜에서 E(π_m Φ(s), m) = T(s)다(마스크 불변).
- 결론: T는 단사일 수 없다. 특히 상태를 구별하는 마스크 m₁ ∈ 𝓜가 있어도, 그 마스크의 표현까지 비단사가 된다.
- 증명: T(s) = E(π_{m₀}Φ(s), m₀) = E(π_{m₀}Φ(s′), m₀) = T(s′)다. (ii)에 의해 m₁에서도 T(s) = T(s′)다. ∎
- 결론의 의미
  - **모든 결측 패턴에서 같은 상태를 같은 잠재로 보내라는 무조건적 정렬은 상태 구별성과 양립하지 않는다.**
  - (b)에 의해 X0는 양의 확률을 가진다(p = 0.7에서 0.0033). 따라서 무조건 정렬을 강제하면 해는 둘 중 하나다.
    - X0의 대칭 궤도를 전체 마스크에서도 붕괴시킨다(구별성 상실).
    - 정렬 손실을 양수로 남긴다.
  - 이것이 무조건적 Latent Alignment가 원리적으로 실패할 수 있는 이유다.

**대치가 불가능하다는 뜻은 아니다 [Verified (math)]**
- 모든 마스크 m과 위치 u에 대해 Bayes 대치 f*_u(W) := E[X_u | W_m]는 잘 정의된다.
- 그 위험은 E Var(X_u | W_m) ≤ Var(X_u)다.
- 비식별 마스크에서도 조건부 기댓값은 유용한 대치를 준다. 예: X0의 z 대치는 z의 관측 lag들로 정확할 수 있다(Phase 8 C3).

## A3. 공유 잠재 상태의 충분조건 (조건부 정리)

**정리 A3.1 [Verified (math)]**

가정:
- (H1) 𝒮는 C¹ 다양체다.
- (H2) Φ: 𝒮 → R^q는 C¹ 임베딩이다(단사 immersion이며, 상으로의 위상 동형).
- (H3) 마스크 집합 𝓜(전체 마스크를 포함하지 않아도 된다)와 C¹ 사상 E_m(m ∈ 𝓜)가 있어서 모든 m ∈ 𝓜에서 E_m∘π_mΦ = T다. T: 𝒮 → R^k는 m에 무관하다.
- (H4) C¹ 사상 D: R^k → R^q가 있어서 D∘T = Φ다.

결론:
1. **T는 단사다.** T(s) = T(s′)이면 Φ(s) = D(T(s)) = D(T(s′)) = Φ(s′)이고, (H2)에 의해 s = s′다.
2. **dT_s는 단사다.** dΦ_s = dD_{T(s)}∘dT_s이고 dΦ_s가 단사이므로 dT_s도 단사다.
3. **T는 상으로의 위상 동형이다.** 왼쪽 역사상 T^{−1} = Φ^{−1}∘D|_{T(𝒮)}가 연속이다. D는 연속이고, Φ^{−1}: Φ(𝒮) → 𝒮는 (H2)에 의해 연속이다. **콤팩트성은 필요 없다.** D가 연속 왼쪽 역을 제공하기 때문이다.
4. **T는 C¹ 임베딩이다.** 1–3에서 따른다. T(𝒮)는 R^k의 매장 부분다양체이고, T: 𝒮 → T(𝒮)는 C¹ 미분동형이다(임베딩의 표준 성질).
5. **따름정리:** 모든 m ∈ 𝓜에 대해 π_mΦ는 단사다. T = E_m∘π_mΦ가 단사이기 때문이다. **그러므로 (H3)은 𝓜가 식별 마스크로만 이루어질 때만 가능하다.** A2.2와 정합한다. ∎

**명제 A3.2 (근사판: 양적 단사성) [Verified (math)]**
- 가정
  - Φ가 상 위에서 L-Lipschitz 역을 가진다: d(s, s′) ≤ L‖Φ(s) − Φ(s′)‖.
  - D는 Λ-Lipschitz다.
  - ‖D∘E_m∘π_mΦ(s) − Φ(s)‖ ≤ ε(m, s)다.
- 결론: d(s, s′) ≤ L(Λ‖Z_m(s) − Z_{m′}(s′)‖ + ε(m, s) + ε(m′, s′))
- 증명: 삼각부등식이다. ∎
- 해석
  - **디코더의 전체 지연 벡터 오차 ε이 작은 마스크에서는, 잠재 거리가 상태 거리를 통제한다.** 이것이 cross-mask 상태 검색이 성공할 수 있는 수학적 조건이다.
  - 비식별 마스크에서는 A2.1에 의해 ε(m, ·)의 기댓값이 0으로 갈 수 없다.

**학습 모델에 적용하려면 필요한 추가 조건 (모두 Unresolved 또는 Hypothesis)**
1. (H2)가 우리 시스템에서 성립하는가
   - Takens와 SYC는 **generic/prevalent한 관측 함수**에 대한 결과이고, 고정된 좌표 사영에 대한 보장이 아니다(A5).
   - 결합 Lorenz의 끌개는 다양체가 아니다. SYC는 끌개 위의 단사와 끌개 안 매끄러운 다양체 위의 임베딩까지만 준다.
   - Lipschitz 역 상수 L은 알려져 있지 않다.
2. (H3)의 정확한 등식은 학습으로 얻을 수 없다. 근사 오차를 통제해야 하며, 비식별 마스크에서는 불가능하다.
3. **"전체 마스크"의 목표 Φ(S)는 자료에 존재하지 않는다.** 완전 관측 창의 확률은 (1 − p)^{32}로, p = 0.7에서 약 2e-17이다. 따라서 (H4)를 직접 목표로 학습할 수 없고, 관측 항목의 손실로만 간접 학습한다(A4).

**현재 B-full에 적용할 수 없는 이유 [Verified (code/data) + 논리]**
- (a) B-full의 학습 목적은 숨긴 관측 항목의 MSE다. 모집단 최소화자는 **조건부 기댓값**이며(A4.1), Φ(S)의 정확한 복원이 아니다. 따라서 (H4)의 등식이 비식별 마스크에서 원리적으로 성립하지 않는다.
- (b) 마스크 간 표현을 묶는 항이 없다. 서로 다른 마스크에서 E_m∘π_mΦ = T를 요구하거나 유도하는 어떤 손실도 없다.
- (c) B-full 잠재의 단사성이나 Lipschitz 역은 측정된 적이 없다. Phase 8 잠재 NN 진단은 근사적 근방 보존만 서술했다.
- (d) Phase 8의 경험적 사실
  - B-full의 readout 수준 마스크 분산이 Fact8보다 크다(+0.0050, κ = 1, p = 0.7).
  - 대치도 p = 0.7에서 Fact8보다 나쁘다.
  - 즉 같은 상태의 서로 다른 마스크에 대한 출력이 덜 일관적이다.

## A4. 실제 결측만으로 학습할 수 있는가

**설정**
- 창 단위 확률변수: X ∈ R^{4×8}(전체 지연 관측의 정규화 값; 학습에서 미관측 항목은 쓰지 않는다)
- 원래 관측 마스크 O, 학습 시 숨김 H ≤ O, 입력 B = O − H
- 예측기 f(w, b) ∈ R^{4×8}
- **(MCAR)** O ⊥ X이고, O의 항목은 i.i.d. Bernoulli(1 − p)다.
- **(HOLD)** O가 주어졌을 때 H는 O의 1 항목마다 독립 Bernoulli(h)이고, X와 독립이다.

**정의 (관측 holdout 위험)**
- L_rec(f) := E[ Σ_u H_u ω(B, H) (X_u − f_u(W_B, B))² ]
- ω ≥ 0은 마스크만의 가중이다. FDR의 1/c(u), 구간별 정규화 1/Σ H 등이다.
- 목표는 숨겨진 **관측** 항목뿐이다. 완전 관측 참조 변수가 필요 없다.

**정리 A4.1 (Fisher 일관성과 양성 조건) [Verified (math)]**
- 가정: (MCAR), (HOLD), 그리고 **양성 조건** 0 < h, p < 1. 그러면 b와 u ∉ b마다
  - π(b, u) := E[H_u ω(B, H) | B = b] > 0 (P1)
- 결론: L_rec의 (가측 함수족 위의) 최소화자는 u ∉ b에서 다음과 같다(a.s.).
  - **f_u(W_B, b) = E[X_u | X_b]**
  - 같은 함수가 test 입력 패턴 O = b에도 그대로 적용된다.
- 증명
  1. 조건부로 쓰면 L_rec = E Σ_u E[H_u ω (X_u − f_u)² | W_B, B]다.
  2. B = b가 주어졌을 때, b 밖의 위치가 H에 속하는지는 (O, H) ⊥ X에 의해 X와 독립이다. 그러므로 E[H_u ω (X_u − f_u)² | W_B, B] = π(B, u)·E[(X_u − f_u)² | W_B, B]다.
  3. π > 0이면 점별 최소화자는 E[X_u | W_B, B = b] = E[X_u | X_b]다. 둘째 등호는 MCAR에서 B ⊥ X이므로 성립한다.
  4. 이 조건부 기댓값은 마스크 패턴이 B에서 왔는지 O에서 왔는지와 무관하다. ∎
- (P1)의 구체적 값: P(H_u = 1 | B = b, u ∉ b) = (1 − p)h / (p + (1 − p)h)
  - p = 0.7, h = 0.2이면 **0.079**다.
  - **이것이 "P(O_u = 1 | M = m) > 0" 조건의 정확한 형태다.**
  - 위반 예
    - 어떤 view가 한 번도 관측되지 않는 경우: 그 view의 f_u는 손실로 식별되지 않는다.
    - 앞쪽 패딩처럼 구조적으로 결측인 위치

**마스크 의존 표집 편향 [Verified (math)]**
- 학습 입력 패턴의 법칙은 Bernoulli((1 − p)(1 − h))이고, test 입력 패턴의 법칙은 Bernoulli(1 − p)다. **공변량 이동**이다.
- 양성 조건 아래에서 (가측 함수 수준의) 최소화자는 같다(정리 A4.1).
- 그러나 **유한 용량에서는 패턴 가중이 다르므로 근사 우선순위가 달라진다.** test 밀도의 패턴은 학습에서 상대적으로 덜 나온다. 이것은 추정 효율의 문제이지 일관성의 문제가 아니다.

**MAR/MNAR에서의 실패 [Verified (math)]**
- O가 X에 의존하면 (HOLD)만으로는 부족하다.
- 이때 최소화자는 E[X_u | X_b, O_u = 1, B = b]다.
- 이것이 E[X_u | X_b]와 같으려면 O_u ⊥ X_u | (X_b, B)가 필요하다(원래 결측의 조건부 무시 가능성).
- 실제 자료의 원래 결측이 이를 만족한다는 보장은 없다(E2에서 명시).

**명제 A4.2 (관측 위험과 전체 위험의 관계) [Verified (math)]**
- 전체 위험: R_full(f) := E Σ_{u ∉ B} (X_u − f_u)² = Σ E Var(X_u | X_B) + E Σ_{u ∉ B} (f_u − f*_u)²
  - 둘째 항이 초과위험이다.
- 관측 위험의 초과분: L_rec(f) − L_rec(f*) = E Σ_{u ∉ B} π(B, u)(f_u − f*_u)²
- 따라서 π_min := inf_{b, u ∉ b} π(b, u) > 0이면 **R_full(f) − R_full(f*) ≤ (L_rec(f) − L_rec(f*)) / π_min**이다.
- 관측 항목만으로 학습해도, 전체 지연 관측(미관측 위치 포함) 대치의 초과위험이 통제된다. ∎

**조건부 Bayes 예측기와 정확한 상태 복원의 차이 [Verified (math)]**
- f*_u = X_u가 a.s. 성립 ⇔ X_u가 σ(X_b)-가측이다(식별 가능).
- 그렇지 않으면 남는 원리적 오차 E Var(X_u | X_b) > 0이 생긴다. A2의 (a)–(c)가 그 예다.
- 숨은 상태 y도 마찬가지다. 대치가 정확해도 y 복원이 함의되지 않는다(Phase 8 C3).

**명제 A4.3 (중첩 마스크 tower 일관성 목적의 고정점) [Verified (math)] — Phase 9 후보 메커니즘의 기초**
- **목표 정의:** 학습 표본마다 student 입력은 B, teacher 입력은 O다(B ≤ O). student의 비입력 위치 u ∉ B마다 목표를 다음과 같이 둔다.
  - Y_u := X_u (u ∈ H, 즉 관측됐지만 숨김; 참값)
  - Y_u := sg[f_u(W_O, O)] (u ∉ O, 원래 결측; teacher 예측, gradient 차단)
- **목적함수:** L_P9(f) = E Σ_{u ∉ B} ω_u (Y_u − f_u(W_B, B))². λ = 1은 두 종류 항목에 같은 가중을 준다는 뜻이다(§B 설계).
- **진술:** (MCAR), (HOLD), 0 < h, p < 1, 그리고 λ > 0이 유한하다고 하자. 무한 용량의 반-경사(semi-gradient) 고정점 방정식, 즉 "teacher f를 고정했을 때 student 최소화자가 다시 f"인 f는 **유일하며 f = f*(조건부 기댓값)**다.
- **증명**
  1. teacher를 f로 고정하면 student 문제는 점별 최소화이고, b와 u ∉ b마다 해는 다음과 같다.
     - f_u^{new}(w, b) = r·E[X_u | X_b = w] + (1 − r)·E[f_u(W_O, O) | W_B = w, B = b, u ∉ O]
     - r = r(b, u) := P(u ∈ H | B = b, u ∉ b) ∈ (0, 1)이다(가중 λ를 반영한 정규화 비율).
  2. **tower 성질:** MCAR에서 E[f*_u(W_O, O) | W_B, B, u ∉ O] = E[E[X_u | X_O] | X_B, u ∉ O] = E[X_u | X_B]다. u ∉ O라는 사건이 X와 독립이고 B ⊂ O이기 때문이다. 따라서 f*는 고정점이다.
  3. **유일성:** g := f − f*라 하자. 고정점에서 g_u(w, b) = (1 − r)·E[g_u(W_O, O) | W_B = w, B = b, u ∉ O]다.
  4. 우변의 g는 다시 "u가 입력 밖인" (패턴, 위치)에서의 값이다. 모든 패턴이 학습 법칙에서 양의 확률을 가지므로, 같은 정의역 위의 sup 노름에서 ‖g‖_∞ ≤ (1 − r_min)‖g‖_∞다.
  5. r_min > 0이면 g = 0이다. 반복 사상이 축약이므로 고정점 반복도 f*로 수렴한다. ∎
- **따름정리 (식별 적응적 마스크 간 일관성)**
  - 고정점에서 student와 teacher의 출력은 f(W_B, B) = E[f(W_O, O) | W_B, B]를 만족한다. 마스크 간 출력이 **마틴게일 일관성**을 가진다.
  - **식별 마스크 B(f*(W_B) = X)에서는** 두 출력이 같다. 디코더가 단사이면 잠재도 같아야 한다. 이것은 정리 A3.1의 (H3)를 그 마스크에서 유도한다.
  - **비식별 마스크에서는** 같지 않아도 되고, 조건부 평균만 맞으면 된다. 예: X0에서 x, y 출력은 0 쪽으로 간다.
  - **어떤 마스크 적격성 규칙도 필요 없다.** L_j ≥ 2 같은 가정을 쓰지 않는다.
- **붕괴 반례:** 같은 목적에서 참값 항목을 빼면(λ → ∞, 또는 r = 0) 모든 상수 f가 고정점이 된다. 따라서 **r_min > 0, 즉 숨김 관측 항목의 참값 손실이 붕괴를 배제하는 필요조건**이다(증명의 축약 상수 1 − r_min).
- **보장하지 않는 것**
  - 유한 용량과 유한 표본에서 f가 f*에 가까워지는지는 보장하지 않는다.
  - teacher 오차의 전파(확증 편향)가 있다. 축약 상수 1 − r_min(p = 0.7에서 약 0.92)은 1에 가깝다. 오차 감쇠가 느릴 수 있다는 뜻이며, **경험적 위험**이다.
  - 잠재의 단사성, 미분동형을 보장하지 않는다.

## A6. 모델 설계에 반드시 필요한 조건 (Gate A 결론)

1. 무조건적 cross-mask 잠재 등식은 금지한다(A2.2).
2. 학습 목표는 관측 항목 holdout을 포함해야 한다. **r_min > 0이 붕괴 배제의 필요조건**이다(A4.3).
3. 일관성 목표는 **조건부 기댓값을 보존**해야 한다. 정리 A4.3의 tower 형태(teacher ⊇ student, teacher gradient 차단, 원래 결측 위치에서만 teacher 목표)가 그 조건을 만족하는 최소 형태다.
4. 마스크 적격성(식별 여부) 규칙은 쓰지 않는다. 식별 여부에 대한 적응은 조건부 기댓값이 자동으로 수행한다.
5. 잠재 수준의 주장은 A3.2의 조건(작은 디코더 오차, Φ의 Lipschitz 역)에 묶인 경험적 가설로만 한다.

**Gate A 판정: 통과.** 위 조건을 만족하는 단일 메커니즘(A4.3)이 존재하며 그 수학적 보장 범위가 명시됐다. 그 밖의 성질(유한 표본 이득, 잠재 일관성, 상태 검색)은 Hypothesis로 분리한다.
