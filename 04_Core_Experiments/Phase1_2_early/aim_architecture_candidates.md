# Architecture Design Candidates for the AIM (Phase 2, 2026-10-27)

이 문서는 설계 검토다. **구현과 학습은 하지 않았다.**

- 수학 기반과 명제 번호(P0–P11, 개념 A–D)는 `results/notes/aim_mathematical_foundation.md`를 따른다.
- FPRM, Lag FPRM 관련 내용은 `results/notes/fprm_verification_phase2.md`를 따른다.
- 목표: RMSE를 낮추는 것이 아니다. AIM이 요구하는 성질을 학습하는 구조를 정하는 것이다.

**AIM이 요구하는 성질 (doc 2 §4의 정식 번역)**
1. 모든 식별 패턴 𝔅 ∈ I에서 공유 잠재 Φ(O_𝔅(s), 𝔅) = ψ(s) (개념 D).
2. 디코더 R_j ∘ ψ = F_j (지연 정합). 그러면 R_j ∘ Φ_i = G_{j←i}.
3. 비식별 패턴에서는 ψ(섬유) 위의 분포를 출력한다. 하나의 잘못된 상태를 강제하지 않는다.

## 1. Model A–F의 근본적인 한계

| 모델 | 구조 | AIM 관점의 한계 |
|---|---|---|
| A | 현재값만 사용하는 MLP | 지연 임베딩이 없다. 기준선 |
| B | view 하나의 지연 AE | view 간 정보가 없다. P4형 결합 식별을 쓸 수 없다 |
| C | view별 인코더, 관측 수 가중 평균 융합, 현재값 디코더 | (1) **P8**: 평균 융합은 일관성과 정보 보존을 함께 만족할 수 없다. z view가 같은 공간에 섞인다.<br>(2) 디코더가 현재값만 복원한다. 일반 계에서는 P11의 전제(F_all 복원)가 없다. Lorenz는 현재값 = 상태라서 예외.<br>(3) 점 추정이다. 비식별 패턴에서 조건부 평균(예: x ≈ 0)으로 흐려지고 불확실성을 표현하지 못한다.<br>(4) 학습 목표 L_mask는 E[x \| o, 𝔅]의 추정만 보장한다. A 이상의 성질은 보장하지 않는다 |
| D | C + 잠재 동역학 (RK4) | 동역학 손실이 없고 C의 융합 문제를 그대로 갖는다 |
| E | C + view-dropout | 학습 마스크 분포만 바뀐다. 점 추정 하나로 모든 패턴을 맞추려 해서 단일 view 정확도와 다변수 정확도가 상충했다 [수치]. P7·P8과 같은 구조적 원인이다 |
| F | 이어붙인 view 코드를 MLP로 융합 | view별 좌표 일관성을 포기한 공동 인코더다. "일관성 지표" 개선이 D를 뜻하지 않는다. 비식별 처리와 불확실성 문제는 C와 같다 |

**공통:** 식별가능성 개념이 없다. 평가가 RMSE와 단순 코드 거리뿐이다. 낮은 RMSE가 상태 복원을 뜻하지 않는다는 것은 P3이 보여준다.

## 2. 후보 아키텍처

세 후보 모두 다음을 공통으로 가정한다.
- C와 같은 입력: view별 과거 창 m = 8, τ = 1, 결측 0 + 마스크.
- 같은 데이터 분할과 정규화.
- 학습 입력 마스크 = 관측 마스크 M에서 추가로 숨긴 H를 뺀 것 (현재 `src/train.py` 방식).

숨긴 값은 어느 창에도 나타나지 않는다. 지연벡터를 마스킹 **후에** 만들기 때문이다.

### 후보 1. Shared Latent + Full Delay Reconstruction (FDR-AE)

**구성**
- 인코더: C와 같은 view별 E_i: (v_i ⊙ m_i, m_i) → e_i ∈ ℝ^k.
- 융합: C의 평균 융합을 그대로 둔 버전 (1a)과 F의 학습 융합 버전 (1b). 융합 효과를 분리하기 위해서다.
- 디코더: **view별 R_j: ℝ^k → ℝ^m**. 현재값이 아니라 view j의 지연벡터 전체 F_j(s_t)를 출력한다.

**목적함수:** 학습 중 숨긴 항목(H)에 대한 마스크 MSE. 대상 위치는 모든 view, 모든 지연 위치다. 관측된 입력 항목을 그대로 복사하는 해를 막기 위해 입력에 남긴 항목은 손실에 넣지 않는다. 기존 L_mask의 대상 범위만 넓힌 것이고 **새 손실 항은 없다.**

**검토**
- *View 간 대응 학습에 도움이 되나:*
  - P11의 전제 하나("공유 디코더가 F_all을 복원")를 만족시키는 구조다.
  - 디코더가 단사이면 식별 패턴 사이의 잠재 일관성이 따라 나온다.
  - 그러나 **디코더 단사성은 강제되지 않는다.** 그리고 융합이 평균이면 P8의 딜레마가 그대로 남는다.
- *식별가능성이 보장되나:* 아니다.
  - 완전 지연벡터 복원은 잠재가 상태를 담아야 할 이유를 준다 (F_all이 단사이면 개념 B).
  - 하지만 비식별 패턴에서 조건부 평균을 내는 점 추정이라는 점은 C와 같다.
- *퇴화 가능성:*
  - (a) **같은 view 안의 보간**: 숨긴 x_j(t−k)를 같은 view의 인접 관측 x_j(t−k±1)로 복원할 수 있다. dt = 0.01에서 lag-1 자기상관 ≈ 0.997이라 매우 쉽다. 그러면 잠재가 view 간 정보를 담을 필요가 없다.
  - (b) **디코더 비단사**: 마스크마다 다른 ζ가 같은 출력을 낼 수 있다.
  - (c) 시간 경계: 창의 가장 오래된 지연은 창 밖 정보 없이 복원해야 하므로 불확실성이 크다.

**최소 검증 실험**
1. C(현재값 디코더) vs 1a vs 1b. 조건 B, dt ∈ {0.01, 0.05}, seed 5.
2. 식별 패턴 쌍의 잠재 일관성 (§6 B).
3. 디코더 단사성 진단: 잠재 근방 vs 출력 근방 보존, 디코더 Jacobian 최소 특이값.
4. 보간 퇴화 진단: 대상 view를 입력에서 통째로 뺐을 때 그 view 복원 오차 (cross-view 기여의 상한).

### 후보 2. Mask-aware Cross-view Reconstruction (XV-AE)

**구성:** 후보 1과 같은 인코더와 디코더. 차이는 **학습 마스크 분포**다. 각 배치에서 view 부분집합 S를 뽑고, S 밖 view의 입력을 전부 숨긴 뒤 그 지연벡터를 복원한다. S 안 view의 일부 항목도 기존처럼 숨긴다.

**목적함수:** 후보 1과 같은 마스크 MSE. 새 손실은 없고, 어떤 조건부 분포 E[F_j | o_S]를 배우게 할지를 **마스크 분포로 지정**한다.

**검토**
- *Cross-view 매핑을 직접 학습하나:* 예.
  - R_j ∘ Φ(o_S)가 E[F_j(s) | o_S]를 추정한다.
  - S = {i}이고 view i가 완전하고 식별하면 이것은 G_{j←i} = F_j ∘ F_i⁻¹다 (FPRM의 다변수 버전).
- *입력 정보가 불충분할 때:* 점 추정이므로 조건부 평균을 낸다.
  - z-only → x ≈ 0이 되고, 그때의 잠재 ζ는 "평균 상태"다. 그런 상태는 존재하지 않는다.
  - 같은 인코더가 식별 패턴에서는 정확한 ψ(s)를 내야 하므로 **E에서 관찰된 상충이 구조적으로 재현될 것**으로 예상한다 (P7·P8).
- *강건성:* view-dropout 형태의 마스크 변화는 이 후보의 정의 자체다. 학습 마스크 분포와 평가 분포의 대응을 명시해야 한다.
- *복사와 cross-view 활용의 구분:* 대상 view j ∉ S이므로 j의 값은 입력에 없다. 복사가 원천 차단된다. 같은 패턴에서 입력 view를 하나씩 제거하는 기여도 분석으로 어떤 view를 썼는지 측정한다.

**최소 검증 실험**
1. S의 종류별(단일 x, y, z / 쌍 / 전체) 복원 오차를 FPRM-GP(같은 정보)와 비교. 조건 A의 "정보 맞춘 비교"를 확장한 것이다.
2. 식별 패턴과 비식별 패턴에서의 정확도-일관성 상충 측정. E의 상충이 재현되는지.

### 후보 3. Identifiability-aware Probabilistic Shared State (PoE-FDR)

**구성**
- **인코더 (view별 전문가):** E_i(o_i) → 잠재 공간의 가우스 인자 (η_i, Λ_i). 정밀도 Λ_i ⪰ 0.
  - 관측이 없는 view는 Λ_i = 0, 즉 정보가 없다.
  - 혼합 전문가는 확장 옵션이다 (Γ 이봉성).
- **융합 (P9에서 유도):**

    q(ζ | o) ∝ p(ζ) · Π_i ℓ_i(ζ; o_i),   Λ = Λ_0 + Σ_i Λ_i,   μ = Λ⁻¹ Σ_i η_i

  ℓ_i는 view i의 **우도 인자**이고 사후분포가 아니다. 그래서 p(ζ)^{1−n} 보정이 필요 없고 Λ가 항상 양정치다 (MVAE 방식).
  - 정보가 없는 view는 자동으로 무시된다.
  - 서로 다른 섬유를 가리키는 전문가들은 교집합에 집중된다 (경우 iii).
  - **이것이 "식별가능성을 아는 융합"이다.**
- **디코더:** 후보 1처럼 view별 완전 지연벡터 R_j(ζ). 가우스 우도이고 view별 잡음분산은 학습한다.
- **마스크 분포:** 후보 2의 view-subset 숨김 + 기존 항목 숨김.

**목적함수:** 숨긴 항목 o_H의 ELBO 하나.

    L = E_{q(ζ | o_in)} [ log p(o_H | ζ) ] − KL( q(ζ | o_in) ‖ p(ζ) )

- o_in은 입력에 남긴 관측이다.
- 가중치를 임의로 정하는 항은 없다 (β = 1).
- 일관성 손실은 **추가하지 않는다** (§3에서 그 이유를 설명).

**검토**
- *식별성 정보의 반영:*
  - 전문가의 정밀도 Λ_i가 view의 정보량을 근사한다.
  - 정답 Fisher 정보 (D Π_B F_i)ᵀ(D Π_B F_i)/σ²와 비교해 검증할 수 있다. Lorenz에서는 `src/observability.py`로 계산 가능하다.
- *잘못된 상태 하나를 강제하지 않는 방법:* 비식별 패턴에서 사후분포가 넓어진다.
  - 단, **단봉 가우스는 Γ의 두 점 {ψ(s), ψ(Γs)}를 표현할 수 없다.** 두 점 사이를 덮는 넓은 분포가 되고, 평균에서 디코딩하면 x ≈ 0이 나온다. 불확실성은 정직하게 보고된다.
  - 이봉성을 정확히 표현하려면 혼합 전문가 또는 흐름(flow) 기반 사후가 필요하다.
- *점 추정 vs 확률적 표현:*
  - 점 추정은 단순하고 결정론적이다. 하지만 비식별 패턴에서 P7·P8 문제를 피할 수 없다.
  - 확률적 표현은 P10 일관성을 정의할 수 있게 한다. 대가는 ELBO 학습의 불안정성(사후 붕괴, PoE 과신)과 비용이다.
- *식별가능성이 불확실할 때 일관성의 정의:* 분포 수준의 tower 조건(P10)이다.
  - 식별 패턴이면 사후가 점으로 수렴하고 점 일치로 환원된다.
  - 비식별 패턴이면 분포 일치만 요구한다.

**최소 검증 실험** (§6의 B, C를 이 후보에 맞춘 것)
1. 식별 패턴 쌍의 사후 평균 일치와 사후 폭.
2. z-only 패턴에서 디코딩한 x의 예측분포가 ±x를 덮는지 (coverage). 혼합 버전이라면 이봉성.
3. 전문가 정밀도 vs Fisher 정보의 순위 상관.
4. 대치 RMSE (사후 평균)와 예측구간 coverage.

### (참고) 검토했지만 추천하지 않는 구조

- **쌍별 cross-map 신경망 G_{j←i}** (공유 잠재 없음): Lag FPRM의 신경망 버전이다. n² 개의 매핑이 필요하고, AIM의 "shared latent"를 구현하지 않는다. 비교용 기준선으로만 둔다.
- **모든 view 쌍에 ‖E_i − E_j‖² 정렬 손실을 단순 가중합으로 추가:** P7에 의해 Lorenz에서 정보가 붕괴한다. 제안하지 않는다.

## 3. 손실 함수 분석 (요구된 6단계)

### 3.1 후보 3의 ELBO (후보 1, 2의 마스크 MSE는 이것의 결정론적 극한)

1. **학습하려는 성질:** 모든 패턴 𝔅에서 q(ζ | o_𝔅) = ψ_* μ(· | O_𝔅 = o)이고 R_j ∘ ψ = F_j. 즉 doc 2의 AIM 번역 1–3.
2. **성립 조건:**
   - MCAR (P9의 조건부 독립).
   - F_all이 A 위에서 단사 (T3, 잠재 좌표 ψ = R⁻¹ ∘ F_all이 존재하기 위해).
   - 관측 잡음 모형이 가우스로 근사 가능.
   - 학습 마스크 분포가 평가 패턴들을 지지(support)에 포함.
   - 변분 분포족과 신경망 용량이 충분.
3. **손실과 성질의 연결:**
   - ELBO의 최적점에서 q는 모델 p(ζ) p(o | ζ)의 참 사후와 같다 (분포족이 충분할 때).
   - 데이터 우도가 최적이면 R이 사전 p(ζ)를 F_all(A) 위의 분포로 밀어 보낸다.
   - R이 단사이면 ζ ↔ F_all(s)가 일대일이고 ψ = R⁻¹ ∘ F_all이다. 그러면 사후 q(ζ | o_𝔅)는 섬유의 상 ψ(C_𝔅(s)) 위의 분포다.
   - 이것은 식별 패턴에서 점 일치(D), 모든 패턴에서 P10을 함의한다.
4. **손실이 최소에 가까울 때**
   - 보장하는 것: 숨긴 지연 좌표의 조건부 분포를 맞힌다.
   - **보장하지 않는 것:**
     - (a) R의 단사성. 따라서 잠재 일관성은 측정해야 한다.
     - (b) ψ의 매끄러움 (미분동형).
     - (c) 분포족 밖의 사후 형태 (가우스 → 이봉 불가).
     - (d) 창 밖의 동역학 (시간 구조는 지연벡터에 담긴 만큼만).
     - (e) 학습 마스크 분포 밖 패턴(예: 긴 동시 결측 구간)에서의 성질.
5. **퇴화해와 반례**
   - (i) **디코더 비단사**: 같은 F_all을 내는 서로 다른 ζ가 존재하면, 손실 최적이어도 마스크마다 잠재가 다를 수 있다 (P11 반례).
   - (ii) **같은 view 안의 보간 지름길**: 항목 단위 숨김만 쓰면 view 간 정보 없이 손실을 낮출 수 있다. view-subset 숨김으로 완화하고 진단 실험으로 측정한다.
   - (iii) **사후 붕괴**: 디코더가 ζ를 무시한다. 대상이 숨긴 값이므로 그대로는 손실이 크다. 일어날 가능성은 낮지만 KL 항 크기를 감시해야 한다.
   - (iv) **PoE 과신**: 오보정된 전문가 여럿을 곱하면 사후가 너무 좁아진다. 예측구간 coverage로 측정한다.
   - (v) **MNAR**: 결측이 값에 의존하면 P9가 깨진다. 실제 데이터에서 주의해야 한다.
   - (vi) **잠재 좌표의 재매개변수화**: ψ는 미분동형 h에 대해 h ∘ ψ로 바꿔도 같은 우도를 준다. 이것은 문제가 아니다. D는 "하나의" ψ만 요구한다.
6. **실제 형태:** §2 후보 3의 L. 마스크 분포는 (항목 숨김률 0.2, view-subset 숨김 확률 q) 하나로 정한다. q는 val 우도로 고른다. **새 가중 합은 없다.**

### 3.2 (선택) tower 일관성 항 — 추가를 권하지 않음

1. 성질: P10. 𝔅 ⊂ 𝔅'일 때 q_𝔅 = E[q_𝔅' | o_𝔅].
2. 조건: doc 2 P10 (항상 참인 등식).
3. 연결: KL(q_𝔅 ‖ mixture of q_𝔅')를 몬테카를로로 근사하는 항.
4. 0일 때 보장: 학습한 사후들이 서로 정합적이다. **정답과 정합적이라는 보장은 없다.** 상수 사후, 즉 모든 패턴에서 사전분포를 내면 이 항은 0이다.
5. 반례: 위의 상수 사후. 이 항만으로는 정보 보존을 보장하지 못한다.
6. 판단: §3.1의 ELBO 최적점에서는 자동으로 성립하므로 **추가하지 않는다.** 용량이 부족해 실제로 깨지는 것이 관찰되면 그때 다시 검토한다. 대신 **평가 지표로 측정한다** (§6 B).

**관측 복원 손실과 잠재 일관성의 역할 분리.** 이 설계에서 학습 신호는 관측(숨긴 지연 좌표)의 우도 하나뿐이다. 잠재 일관성은 P11의 결과로 **기대**하고, 별도로 **측정**한다. 일관성을 손실로 직접 강제하지 않으므로 P7의 붕괴 위험이 없다.

### 식별가능성 라벨링 (B, C 평가의 전제)

평가 위치마다 (패턴, 상태)를 다음으로 분류한다.
1. **Γ 검사:** 관측된 좌표가 전부 z이면 "비식별 (Γ)".
2. **국소 계수:** `src/observability.py`로 D O_𝔅의 최소 특이값 σ_min. 임계값 아래이면 "국소 비식별".
3. **경험적 섬유 지름:** train 상태들 중 관측공간 O_𝔅에서 k-최근접 이웃을 찾는다. 그 이웃들의 참 상태 거리 최댓값 δ_𝔅(s)를 끌개 지름으로 나눈다. 크면 "모호". 패턴마다 관측 차원이 달라서 패턴별로 계산한다.

라벨: {식별, 국소 비식별, 전역 모호 (Γ 포함)}.

### A. 결측값 대치

- 비교 대상: C, F, 후보 1a, 1b, 2, 3. FPRM-T, FPRM-I, Adapted FPRM, Lag-FPRM-paper, Lag-FPRM-multi (`fprm_verification_phase2.md` §6.6), linear, locf.
- 조건 A와 조건 B를 분리한다. 조건 A에서는 **정보를 맞춘 비교**(단일 완전 view 입력)를 반드시 같이 보고한다.
- 지표:
  - 통합 RMSE와 대상별 RMSE.
  - **식별 라벨별 RMSE** (식별 / 비식별을 섞어 평균하지 않음).
  - 확률적 모델은 예측구간 coverage와 NLL.

### B. 공유 상태 일관성

- 같은 상태 s에 서로 다른 마스크 𝔅, 𝔅'를 준다. 쌍은 라벨 조합별로 층화한다.
- **(식별, 식별) 쌍:** 잠재 거리 / 시점 간 거리 스케일. 확률적 모델은 사후 평균 거리와 2-Wasserstein. **0에 가까워야 성공.**
- **(식별, 비식별) 쌍:** 식별 쪽 코드 ψ(s)가 비식별 쪽 사후의 고밀도 영역에 포함되는가 (포함률).
- **(비식별, 비식별) 쌍:** 분포 일치만 본다. **잠재가 다르다는 것만으로 실패라고 판정하지 않는다.**
- **tower 검사 (P10):** 𝔅 ⊂ 𝔅'에서 q_𝔅와, 𝔅' 완성들의 혼합 q 사이의 KL. 완성은 데이터에서 같은 섬유의 이웃으로 몬테카를로 근사.

### C. 동역학 구조 보존 (Lorenz, 참 상태를 아는 경우)

좌표값을 직접 비교하지 않는다. 잠재와 참 상태는 다른 좌표계일 수 있다.

1. **상태 구별력 (식별성):**
   - 잠재 → 참 상태로의 비선형 탐침(kNN 회귀)을 train으로 적합하고 test 오차를 잰다.
   - 근방 보존 지표: trustworthiness / continuity, 잠재 공간의 false nearest neighbors 비율.
   - 이 지표들은 좌표계와 무관하다.
2. **View 간 대응:** 완전 view i 하나를 입력하고 R_j ∘ Φ_i로 F_j를 복원한다. 참값, FPRM-GP 추정값과 비교한다 (G_{j←i}의 일관성).
3. **관측가능성과 오차의 관계:** 대치 오차와 σ_min, `amp`(doc 2와 `math_review.md` §3)의 순위 상관.
4. **시간 구조:**
   - 잠재 궤적의 한 스텝 예측가능성: kNN으로 ζ_t → ζ_{t+1}.
   - 잠재 궤적에서 추정한 최대 Lyapunov 지수 (참값 ≈ 0.906)와 상관 차원 (≈ 2.05).
   - 대조군: 시간을 섞은 잠재.
5. **Γ 처리:** z-only 패턴에서 디코딩한 x의 예측분포가 +x와 −x를 모두 덮는지. 점 추정 모델은 x̂ ≈ 0과 nRMSE ≈ 1이 **올바른** 행동이다 (P2(c) 하한). 이것을 실패로 세지 않는다.

대조군: 무작위 초기화 인코더, 단일 view 모델 B, linear 보간. 대조군으로 지표의 기준선을 잡는다.

## 8. 구현 전에 해결해야 할 이론적 문제

1. **디코더 단사성 확보 방법:** P11의 핵심 전제다. 측정만 할지, 구조적으로 보장할지(가역 디코더, 하한이 있는 Jacobian), 정칙화로 유도할지 정해야 한다.
2. **잠재 차원 k:** F_all(A)를 담으려면 k > 2d_A가 충분조건이다 (Lorenz ≥ 5, 현재 16). 차원이 크면 단사성은 쉽지만 일관성 측정이 어려워진다.
3. **사후 분포족:** 가우스(단봉) vs 혼합. Lorenz Γ처럼 **알려진 대칭**이 있는 경우의 처리를 정해야 한다.
4. **식별 라벨링의 기준:** σ_min 임계값과 섬유 지름 기준은 임의성이 있다. 결론이 기준에 민감한지 확인해야 한다.
5. **창 길이와 표본 간격:** m = 8, τ = 1(dt = 0.01)은 시간 폭 0.07로 매우 짧고 조건수가 나쁘다 (855). 지연 좌표가 상태를 구별할 만큼 시간 폭이 충분해야 P11의 F_all 단사성이 수치적으로 의미가 있다. dt와 τ를 함께 정해야 한다.
6. **T3 (Deyle–Sugihara)의 정확한 적용 조건:** 원문을 확인해 우리 불규칙 마스크 패턴에 무엇을 보장하는지 정리해야 한다.
7. **실제 데이터의 가정 (저차원 결정론, MCAR):** 위반될 때(MNAR, 잡음, 비정상성) P9 융합과 P11 일관성이 어떻게 깨지는지 정리해야 한다.
8. **FPRM 기준선의 GP 정체 국소해 처리:** 새 비교 실험 전에 기준선 수치 절차를 확정해야 한다 (`fprm_verification_phase2.md` §3.3, §6.6-7).
