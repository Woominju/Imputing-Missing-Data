## 요약 (먼저 읽을 것)

1. **FPRM 공식 MATLAB 코드를 Python으로 이식**하고 테스트 13개를 통과했다. 원 논문 수치는 **재현하지 못했다**. 공식 절차로
   재생성한 데이터에서는 논문보다 훨씬 정확하다. 표본 간격을 dt≈0.15로 성기게 하면 논문 값과 비슷해져
   (y ρ 0.899 vs 0.90, z ρ 0.777 vs 0.81) "논문 데이터가 더 성겼다"는 가설과 일치하지만, 이 원인은 확정되지 않았다.
2. **조건 A (기준 변수 1개 완전 관측)**: FPRM은 z 기준에서 x, y를 전혀 복원하지 못함 (nRMSE ≥ 0.998, ρ≈0).
   이는 우리가 도출한 대칭 하한(명제 1)과 정확히 일치한다. Coupled Lorenz에서도 x1 하나로는 다른 하위계를
   복원하지 못한다 (개별 실행 nRMSE 0.91–1.08). **"완전 기준 변수 하나"라는 FPRM 전제의 한계를 직접 보였다.**
3. **조건 B (AIM: 모든 변수 MCAR)**: 원래 FPRM은 적용할 수 없다. Adapted FPRM(기준 변수 보간 후 FPRM)과 비교하면
   Model C가 통합 RMSE에서 1.6–12배(dt=0.01), 3.1–16배(dt=0.05), 2.6–16배(dt=0.1) 낮다 (p가 클수록 격차가 줄어듦). 단 dt=0.01의 y 대상만은 Adapted FPRM(x 기준)이 더 낫다.
4. **동역학 정보 vs 통계적 보간**: dt=0.01에서는 미래를 쓰는 선형보간이 C와 비슷하거나(p≤0.5) 더 낫다(p=0.7).
   **dt=0.05에서는 과거만 쓰는 C가 선형보간보다 4.0–16배, dt=0.1에서는 3.6–25배 낮은 오차.** (그림 1)
5. **Consistent State Representation**: C의 view별 경로는 단일 view로 다른 변수를 거의 복원하지 못한다
   (x view → 다른 변수 RMSE 0.23–0.46, 같은 정보의 FPRM-GP 0.053–0.059). 이것은 식별 불가능성 때문이 아니다 (x view는 y를 거의 결정함).
   View-dropout(E)은 단일 view 성능·잠재 일관성을 개선하지만 시험한 모든 Q에서 **다변수 정확도와 상충**했다.
   평균 융합을 학습 융합으로 바꾼 F(dropout 없음)는 dt=0.01/0.05/0.1 모두에서 다변수 평균 오차가 C 이하이고 잠재 일관성이
   더 좋다. 다만 개선 폭이 작고(1–23%) seed 일관성은 일부 조건(dt=0.01 p=0.7, dt=0.05 p=0.3·0.5, dt=0.1 p=0.5)에서만 확인됐다.
6. **실제 데이터**: Exchange에서 C가 나쁜 이유는 심한 분포 이동으로 보인다 (test 항목의 42.6%가 train 범위 밖).
   ENSO는 선형보간이 가장 좋다.

## C. 수학적 분석

### C.1 기존 문헌의 정리
1. Takens(1981): generic 흐름·관측함수, m > 2d 에서 지연사상은 임베딩.
2. Sauer–Yorke–Casdagli(1991): prevalence 판본, 끌개 box-counting 차원 d_A, m > 2d_A 이면 거의 모든 관측함수에서 단사.
3. 두 지연사상이 **모두** 임베딩이면 그 사이의 대응 F_j∘F_i⁻¹ 은 상 사이의 미분동형. AIM의 "각 변수 임베딩이 서로 미분동형"은
   이 조건부 명제이며 특정 관측함수(아래 z)에서는 성립하지 않는다. 결측된 지연벡터는 정의역이 달라지므로 정리를 그대로 적용할 수 없다.

### C.2 우리가 도출한 결과 (간단한 증명 포함)
- **명제 1 (z 관측 비식별성)**: Lorenz는 Γ(x,y,z) = (−x,−y,z) 등변 → φ_t∘Γ = Γ∘φ_t, z∘Γ = z → 모든 지연에서
  F_z(Γu) = F_z(u). 관측 분포가 Γ-불변이면, z 지연벡터만의 함수 g로 x를 추정할 때 E[(g−x)²] ≥ E[x²] (쌍 (u, Γu)에서
  (g−x)²+(g+x)² ≥ 2x²). 즉 nRMSE ≳ 1, ρ ≈ 0.
- **명제 2 (정렬 손실의 부적절성)**: Γ-쌍에서 v_z 는 같고 v_x 는 다르므로, ‖e_z − e_x‖² 형태의 강제 정렬은 e_x가 부호 정보를
  지우도록 압박한다. 부분집합 S 복원 손실의 최소화는 E[x | v_S] 를 추정하므로 식별가능성을 자동으로 반영한다.
- **명제 3 (평균 융합의 조건)**: z = Σ w_i z_i / Σ w_i 가 상태의 일관된 표현이려면 모든 view 코드가 같은 좌표계 함수여야 한다.
- **따름 (z view 일관성 하한)**: 전체 view 코드가 Γ-쌍을 구별하면 (c(u) ≠ c(Γu)), z view 코드 c_z 는 두 점에서 같으므로
  삼각부등식에서 max(‖c_z − c(u)‖, ‖c_z − c(Γu)‖) ≥ ‖c(u) − c(Γu)‖/2. **z view의 일관성 지표는 0이 될 수 없다.**
- **x → y의 명시적 관계**: ẋ = σ(y − x) → y = x + ẋ/σ. x 지연벡터(유한차분)가 y를 거의 결정한다.
- **Coupled Lorenz, k=0**: 계가 곱공간이므로 x1의 지연사상은 하위계 1 상태에만 의존 → 결합 끌개에서 단사일 수 없다 →
  x1 하나로는 하위계 2를 복원할 수 없다 (FPRM 전제 실패).

### C.3 수치 실험으로 확인한 사실
- 명제 1: z 기준 FPRM, C·E·F의 z view 모두 nRMSE ≥ ≈1, 상관 ≈0. (모든 E,τ, p, seed)
- 따름 (z 일관성 하한): 시험한 모든 모델·p에서 z view 일관성 0.44–1.87; x, y view는 F q=0.15에서 0.20까지 내려감.
- x→y: FPRM(E=5,τ=3) RMSE 0.0002–0.0004.
- Coupled k=0: FPRM x1 → 하위계 2 nRMSE 0.97–1.03 (개별 실행). k=0.5, 2.0 에서도 0.91–1.08: E=3 지연으로는 결합을 통한 정보 전달이 거의 쓰이지 않음.
- 성긴 표본에서 C는 선형보간보다 훨씬 정확 (dt=0.05: 4.0–16배, dt=0.1: 3.6–25배).

### C.4 아직 검증되지 않은 가설
- C/E/F가 지연 임베딩 사이의 미분동형 대응을 학습했다 → **근거 없음** (decoder는 현재 값만 출력; F_j∘F_i⁻¹를 직접 학습하지 않음).
- 학습 융합(F)이 "일관된 공유 상태"를 만든다 → 자연 마스크에서 코드 안정성은 크게 좋아졌으나 (0.008–0.13), 단일 view와의
  일관성은 여전히 큼. 상태 좌표와의 대응(diffeomorphic chart)을 확인하지 않음.
- Exchange 성능 저하의 원인이 분포 이동이다 → 강한 정황 (42.6% 범위 밖), 인과 검증은 안 함.
- 논문 재현 차이의 원인이 표본 간격이다 → 가설과 일치하는 결과만 있음.

## E. 다음 연구 방향

1. **현재 모델의 핵심 한계**: 다변수 정확도는 높지만, 각 view가 같은 상태를 독립적으로 표현하지 못한다 (단일 view 경로 오차가
   같은 정보의 GP-FPRM보다 2.7–8.8배 큼). view-dropout·학습 융합 모두 다변수 정확도와 상충했다. 현재 decoder는 현재 값만 복원하므로
   "지연 임베딩 사이 대응"을 직접 학습하지 않는다.
2. **AIM에 더 가깝게 하려면 검증·변경할 것**:
   (a) decoder가 각 변수의 **지연벡터 전체**(과거 m개)를 복원하도록 하여 F_j∘F_i⁻¹ 형태의 대응을 직접 학습시키는 변형과,
   그 대응의 단사성·국소 Jacobian 조건수 진단;
   (b) 학습 융합 F를 기본 후보로 삼아 seed 수를 늘려(≥5) 효과를 확정하고, F + view-dropout의 상충이 용량(latent 16,
   hidden 64) 때문인지 분리하는 대조 실험;
   (c) 식별 불가능 view(z)에 대한 다봉 출력(혼합분포 또는 Γ-불변 표적)으로 조건부 평균의 한계를 명시적으로 다루기.
3. **다음 실험에서 가장 먼저 할 일**: 성긴 표본(dt=0.05–0.1) Lorenz와 Coupled Lorenz에서 C·F의 조건 A 재학습과 단일 view
   평가를 같은 프로토콜로 반복 — 동역학 정보가 실제로 차이를 만드는 영역에서 FPRM(GP)과 같은 정보로 비교하기 위함.
   (dt=0.01은 선형보간이 이미 거의 완벽해서 방법을 구별하기 어렵다.)
