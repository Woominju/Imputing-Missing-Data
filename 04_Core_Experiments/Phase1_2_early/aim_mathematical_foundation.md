## 1. 문제 설정

- 흐름 φ_t: M → M (M ⊂ ℝ^d), 끌개 A ⊂ M (콤팩트 불변 집합). box-counting 차원 d_A (Lorenz: d = 3, d_A ≈ 2.06).
- 관측 함수 h_i: M → ℝ, i = 1, …, n. 변수 x_i(t) = h_i(s_t).
- **지연사상** (우리 코드의 과거 방향):

    F_i(s) = ( h_i(s), h_i(φ_{−τ}s), …, h_i(φ_{−(m−1)τ}s) ) ∈ ℝ^m

  FPRM의 미래 방향 지연 F_i^+(s) = (h_i(s), h_i(φ_τ s), …)은 F_i^+ = F_i ∘ φ_{(m−1)τ}이므로 같은 성질을 갖는다. φ는 A 위에서 위상동형이기 때문이다.
- **결측 패턴:** 시점 t에서 view i의 관측된 지연 색인 집합 B_i ⊆ {0, …, m−1}. 전체 패턴 𝔅 = (B_1, …, B_n).
- **마스크된 관측:**

    O_{i,B}(s) = Π_B F_i(s),   O_𝔅(s) = ( O_{1,B_1}(s), …, O_{n,B_n}(s) )

  Π_B는 좌표 투영이다. 모델 입력은 (O_𝔅(s), 𝔅)다.
- **MCAR 가정:** 𝔅는 s와 독립이다. 조건 B의 `prepare(p, seed)`는 변수·시점별로 독립이고 상태와 무관하므로 이 가정을 만족한다.
- **복원 대상:** 결측된 x_j(t−kτ) = h_j(φ_{−kτ}s). 일반적으로 g: A → ℝ.

**표기 정리**

| 기호 | 뜻 |
|---|---|
| F_all(s) = (F_1(s), …, F_n(s)) ∈ ℝ^{nm} | 모든 view의 완전한 지연벡터 |
| μ | A 위의 불변 확률측도 (Lorenz: 물리적/SRB 측도) |
| Γ(x, y, z) = (−x, −y, z) | Lorenz 대칭 |

## 2. Takens 정리의 적용 조건과 결측 관측에서의 한계

### 2.1 정리들 [문헌]

**T1 (Takens 1981)**
- M이 d차원 콤팩트 매끄러운 다양체이면, **generic한 쌍 (φ, h)** 에 대해 m ≥ 2d+1일 때 지연사상은 매장(embedding)이다.
- 여기서 genericity는 (흐름, 관측함수) 쌍에 대한 C² 위상의 열린 조밀 집합이다.

**T2 (Sauer–Yorke–Casdagli 1991)**
- 고정된 흐름과 콤팩트 집합 A (box 차원 d_A)에 대해 다음을 가정한다.
  - m > 2 d_A.
  - 주기 ≤ mτ인 주기궤도에 관한 조건: 그런 주기점이 유한하고 선형화 고유값 조건을 만족.
- 결론: **prevalent한 h** (측도론적 "거의 모든")에 대해 지연사상은 A 위에서 단사이고, A에 포함된 매끄러운 다양체의 콤팩트 조각 위에서 몰입(immersion)이다.

**T3 (Deyle–Sugihara 2011, 다변수 일반화)**
- 여러 관측함수의 지연 좌표를 섞은 사상도, 좌표의 총 개수 > 2d (또는 > 2d_A)이면 **관측함수 집합 전체에 대해 generic하게** 매장이다.
- 출처: Deyle & Sugihara, *PLoS ONE* 6(3): e18295. 적용 조건(차원 정의, generic의 의미)은 원문을 다시 확인해야 한다.

### 2.2 이 정리들이 말하지 **않는** 것

1. **"모든 변수"가 아니다.** genericity와 prevalence는 "거의 모든 h"에 대한 주장이다. 특정 좌표함수는 예외일 수 있다. Lorenz z가 그 예다 (P2). AIM의 "the delay embedding of each variable is diffeomorphic to the others"는 **각 F_i가 매장일 때만** 참이다.
2. **두 지연상 사이의 미분동형:** F_i와 F_j가 모두 A 위에서 단사이면 G_{j←i} = F_j ∘ F_i⁻¹: F_i(A) → F_j(A)는 위상동형이다 (콤팩트 집합에서 연속 단사 → 위상동형). "미분동형"이라는 말은 A를 포함하는 매끄러운 다양체 위에서 둘 다 매장일 때만 성립한다. 프랙탈 A 자체에서는 매끄러운 조각 위의 몰입이라는 의미로 제한된다 (T2).
3. **결측 관측 O_{i,B} = Π_B F_i는 정리의 대상이 아니다.** 투영은 단사성과 몰입성을 깰 수 있다. 불규칙한 지연 집합에 대한 generic 결과는 T3 형태로 있을 수 있지만, **어떤 특정 패턴 B가 매장인지는 정리가 말해 주지 않는다.**
4. **유한 표본, 잡음, 표본 간격:** 정리는 정확한 무한 정밀도의 연속시간 사상에 대한 것이다.
   - 작은 τ에서는 사상이 나쁜 조건수를 갖는다. [수치 `math_review.md` 2(c)]: x-only, τ = dt에서 조건수 중앙값 855.
   - 정리는 "단사"만 보장하고, 역사상의 **Lipschitz 상수**(잡음 증폭)는 보장하지 않는다.
5. **차원 조건과 패턴 크기:** |𝔅| = Σ_i |B_i| (관측된 좌표 수)라 하자.
   - |𝔅| < d이면 국소 몰입이 불가능하다 (계수 ≤ |𝔅|).
   - |𝔅| ≤ 2d_A는 정리의 충분조건을 만족하지 않는다. 그렇다고 실패한다는 뜻은 아니다. 2d_A는 충분조건일 뿐이다.

## 3. 부분 관측에서의 식별가능성

### 3.1 정의

**D1. 상태 식별 (전역):** 패턴 𝔅가 상태를 식별한다 ⇔ O_𝔅가 A 위에서 단사.

**D2. 상태 식별 (국소):** s가 A의 매끄러운 조각 S 위의 점일 때, D O_𝔅(s)를 접공간 T_s S에 제한한 계수가 dim S. 계산은 흐름 Jacobian으로 한다.

    ∂ h_i(φ_{−kτ}s) / ∂s = ∇h_i(φ_{−kτ}s)ᵀ · DΦ_{−kτ}(s)

  이 계산은 `src/observability.py`에 이미 구현돼 있다.

**D3. 대상 식별:** 대상 g가 𝔅로 식별된다 ⇔ 모든 s, s' ∈ A에 대해 O_𝔅(s) = O_𝔅(s') ⇒ g(s) = g(s'). 동치로, A 위에서 g = ĝ ∘ O_𝔅인 함수 ĝ가 존재한다.

**D4. 식별 집합과 확률:** I = {𝔅 : 𝔅가 상태를 식별}. MCAR 하에서 P(𝔅 ∈ I)는 결측률 r의 함수다. 대상별로 I_g를 같은 방식으로 정의한다.

국소 식별(D2)은 전역 식별(D1)을 함의하지 않는다. 예: Γ로 서로 대응하는 두 점에서 계수는 각각 꽉 차 있어도 관측값이 같을 수 있다. 반대로 전역 단사여도 계수가 떨어지는 점이 있을 수 있다 (몰입 실패). 잡음이 있으면 실제로 중요한 양은 국소 조건수와 Lipschitz 상수다.

### 3.2 명제

**P0 (단조성) [증명].** 𝔅 ⊆ 𝔅' (𝔅'이 더 많이 관측)이고 𝔅가 g를 식별하면, 𝔅'도 g를 식별한다.
- 증명: O_𝔅 = Π ∘ O_𝔅'이다. O_𝔅'(s) = O_𝔅'(s')이면 O_𝔅(s) = O_𝔅(s')이고, 따라서 g(s) = g(s'). ∎
- 따름: P(𝔅 ∈ I_g)는 결측률 r에 대해 단조 감소한다 (결합 논증, MCAR).

**P1 (완전한 단일 view의 충분성) [문헌 조건부].** F_i가 A 위에서 단사이면 (T2의 조건 하에서 prevalent h_i), 모든 대상 g가 view i 하나로 식별된다. G_{j←i} = F_j ∘ F_i⁻¹는 F_i(A) 위에서 잘 정의된 연속 사상이다.
- 이것이 FPRM의 이론적 근거다. 논문 Eq. 7–12의 "partial reconstruction도 미분동형"이라는 주장은 필요 없다. FPRM이 실제로 쓰는 것은 F_i^+의 단사성과 스칼라 대상 h_j뿐이다.

**P2 (Lorenz z-only 패턴의 비식별성과 Bayes 하한) [증명; μ의 대칭성은 문헌].**
- (a) Γ는 Lorenz 벡터장과 교환한다: f(Γs) = Γ f(s). 그러므로 φ_t ∘ Γ = Γ ∘ φ_t이고 h_z ∘ Γ = h_z다. 따라서 **z만 관측한 모든 패턴** 𝔅 (모든 m, τ, 지연 부분집합)에서 O_𝔅(Γs) = O_𝔅(s)다.
  - Γ는 A를 A로 보낸다 (끌개의 대칭성. [수치 `math_review.md` 2(b)]).
  - s ≠ Γs (x ≠ 0 또는 y ≠ 0)이므로 z-only 패턴은 **어떤 것도** 상태를 식별하지 못한다.
  - 이것은 T2의 prevalence 결론이 특정 관측함수에서 실패하는 예이고, 정리와 모순되지 않는다.
- (b) **Γ-홀함수 대상은 식별 불가.** g ∘ Γ = −g이고 g ≢ 0인 대상(x, y, xz, …)은 z-only 패턴으로 식별되지 않는다.
- (c) **Bayes 하한.** μ가 Γ-불변이라고 하자. Lorenz 고전 매개변수에서 물리적 측도가 유일하다는 결과[문헌: Tucker 2002와 singular-hyperbolic 이론]가 있으면, Γ_*μ도 같은 끌개의 물리적 측도이므로 Γ_*μ = μ다.
  - 이때 z-only 관측의 임의의 가측함수 u(O_𝔅)에 대해 E_μ[(u − x)²] = E_μ[x²] + E_μ[u²] ≥ E_μ[x²]이다.
  - 증명: u(O_𝔅(Γs)) = u(O_𝔅(s))이고 x(Γs) = −x(s)이므로, μ의 Γ-불변성에서 E[u·x] = 0. ∎
  - 따라서 nRMSE ≥ √(E[x²]/Var x) ≈ 1이다 (E[x] = 0). [수치]: z 기준 FPRM에서 nRMSE 0.998–1.383 (192 실행). C/E/F의 z view에서 1.01–1.10.
- (d) **Γ-짝함수 대상은 식별될 수 있다** [가설]. x², xy, |x|, z(t − kτ) 등. z 지연사상이 몫공간 A/Γ 위에서 단사이면 식별된다. 이 단사성은 확인하지 않았다.

**P3 (상태는 국소적으로 비식별이지만 대상은 식별되는 경우) [증명].**
- 미분 좌표 사상 O_x(s) = (x, ẋ, ẍ)는 det D O_x = −σ²x다 [수치/SymPy `math_review.md` 2(a)]. 그러므로 평면 x = 0에서 몰입이 아니다.
- 그런데 Lorenz 식 ẋ = σ(y − x)에서 y = x + ẋ/σ이고, 이것은 O_x의 매끄러운 함수다. 따라서 y는 **모든 점에서** (O_x로) 식별된다. 상태 전체가 국소 식별되지 않는 x = 0에서도 그렇다. ∎
- 함의: 대치의 성공은 상태 식별보다 약한 조건으로 일어날 수 있다. **낮은 대치 오차 ⇒ 상태 복원**은 성립하지 않는다.
- 유한 τ 지연에서도 τ → 0 극한에서 같은 현상이 근사적으로 성립한다 [가설, 수치: FPRM x→y RMSE 0.0002–0.0004 (E5τ3)].

**P4 (어느 view도 단독으로 식별하지 못하지만 결합하면 식별하는 경우) [증명; 끌개 위상차원은 문헌].**
- 패턴: 각 view에서 현재값 하나만 관측 (B_i = {0}).
- view 하나: O_{i,{0}}: A → ℝ. 단사라면 콤팩트 A에서 위상동형이 되어 A의 위상차원 ≤ 1이어야 한다. 그러나 Lorenz 끌개는 2차원 중심-불안정 다양체 조각을 포함한다 (singular-hyperbolic 끌개는 자기 점들의 불안정 다양체를 포함함) [문헌]. 따라서 위상차원 ≥ 2이고, **단사가 아니다.**
- 결합: (x(t), y(t), z(t)) = s 자체이므로 항등사상이고, **단사다.** ∎
- 주의: "단일 view가 불충분"이라는 판정은 패턴 B_i에 따라 다르다. 완전한 x view는 (T2가 x에 적용된다면) 단독으로 충분할 수 있다.

**P5 (결합해도 식별하지 못하는 경우) [증명].**
- (i) 모든 관측이 z뿐인 패턴 (P2).
- (ii) |𝔅| < 3이면 국소 몰입이 없다.
- (iii) |𝔅| = 1이면 전역 단사가 아니다 (P4 논증).
- 이런 패턴에서 단일 상태를 출력하는 모든 추정기는 P2(c)형 하한을 갖는다. 대상이 Γ-홀이면 그렇고, 일반적으로는 비식별 섬유 위의 조건부 분산만큼의 하한을 갖는다.

**P6 (마스크와 식별) [증명].** 식별가능성은 상태의 성질이 아니라 **(패턴, 상태) 쌍의 성질**이다.
- 같은 s라도 𝔅가 바뀌면 식별 여부가 바뀐다 (P0, P4).
- 국소 식별(D2)은 s에도 의존한다 (x = 0 근처에서 실패).
- 그러므로 "같은 상태에 다른 마스크를 주면 같은 잠재 벡터가 나와야 한다"는 요구는 두 패턴이 모두 식별할 때만 정당하다.

## 4. Shared Latent State의 정의

인코더 Φ: (o, 𝔅) ↦ ζ ∈ Z (Z ⊆ ℝ^k). 디코더 R_j: Z → ℝ^m (view j의 지연벡터) 또는 ℝ (현재값). 다음 네 개념을 구분한다.

| 개념 | 정의 | 함의 관계 |
|---|---|---|
| **A. 예측용 특징 벡터** | 학습 마스크 분포 하에서 디코더 R이 R∘Φ로 대상을 잘 예측 (즉 E[g \| o, 𝔅]를 근사) | 가장 약함 |
| **B. 상태 정보를 보존하는 표현** | 각 𝔅에서 Φ(·, 𝔅)가 관측 O_𝔅(s)의 상태 정보를 잃지 않음: Φ(O_𝔅(s), 𝔅) = Φ(O_𝔅(s'), 𝔅) ⇒ O_𝔅(s) = O_𝔅(s') (O_𝔅(A) 위에서 단사). 확률적으로는 I(ζ; s) = I(O_𝔅(s); s) | B ⇒ (적절한 디코더가 있으면) A |
| **C. 상태 복원** | 𝔅 ∈ I이고, 매장 ψ: A → Z가 있어 Φ(O_𝔅(s), 𝔅) = ψ(s). "미분동형"이려면 ψ가 매끄러운 조각 위에서 몰입이고 Φ가 매끄러워야 함 | C ⇒ B (식별 패턴에서) |
| **D. View 간 일관된 공유 잠재 표현** | **하나의** ψ(𝔅와 무관)가 있어, 모든 𝔅 ∈ I에서 Φ(O_𝔅(s), 𝔅) = ψ(s). 𝔅 ∉ I이면 Φ는 섬유 C_𝔅(s) = {s' : O_𝔅(s') = O_𝔅(s)}의 상 ψ(C_𝔅(s)) 위의 분포를 나타냄 (§5의 사후 일관성) | D ⇒ C (모든 식별 패턴에서, 같은 좌표로) |

세 성질은 서로 다른 조건이다.
- **좌표 일치** (D에서 ψ가 𝔅와 무관), **상태 정보 보존** (B), **미분동형성** (C의 매끄러운 버전).
- 예: 패턴마다 다른 매장 ψ_𝔅를 쓰는 표현은 B, C를 만족하지만 D는 아니다.
- 예: 상수 ψ는 좌표가 "일치"하지만 B도 아니다.

**AIM 문장의 정식 번역 (제안).** 다음을 만족하는 매장 ψ: A → Z, 인코더 Φ, 디코더 {R_j}가 존재하고 이를 학습하는 것.
1. (D) 모든 𝔅 ∈ I에서 Φ(O_𝔅(s), 𝔅) = ψ(s).
2. (지연 정합) 모든 j에서 R_j ∘ ψ = F_j (A 위에서).
3. (비식별 패턴) 𝔅 ∉ I이면 Φ가 ψ(C_𝔅(s)) 위의 사후분포를 출력한다 (§5).

그러면 view i가 완전하고 F_i가 단사일 때 R_j ∘ Φ(F_i(s), {i 완전}) = F_j(s)이므로, **R_j ∘ Φ_i = F_j ∘ F_i⁻¹ = G_{j←i}** 다. 이것이 AIM이 말하는 "각 변수의 지연 임베딩이 서로 미분동형"을 학습 모델 안에서 구현하는 방식이다.

**현재 Model C의 위치**

| 개념 | C가 만족하나 | 근거 |
|---|---|---|
| A | 예 (경험적) | 조건 B RMSE |
| B | 미검증. 부분적 증거만 있음 | Lorenz에서는 디코더 출력 (x, y, z)(t)가 곧 상태 s_t다. 그래서 다변수 정확도가 높은 패턴에서는 ζ가 상태 정보를 담고 있다. 일반 계(coupled, 실제 데이터)에서는 현재값이 상태를 결정하지 않을 수 있다 |
| C | 미검증 | ψ의 단사성과 매끄러움을 시험하지 않음 |
| D | **아니오** | [수치] 단일 view 코드와 전체 view 코드의 거리 / 시점 간 거리 = 1.54–1.87 (p = 0.1). x와 y view는 식별력이 있는데도 큼 |

## 5. View Consistency의 정의

### 5.1 무조건적인 점 일관성은 부적절하다

**P7 (점 일관성 손실의 붕괴) [증명].**
- 가정: 인코더 Φ가 어떤 패턴 집합 𝒫의 모든 쌍 𝔅, 𝔅' ∈ 𝒫와 모든 s ∈ A에서 Φ(O_𝔅(s), 𝔅) = Φ(O_𝔅'(s), 𝔅')를 만족한다. 그리고 𝒫는 전체 관측 패턴 𝔅_full과 z-only 패턴 𝔅_z를 포함한다.
- 결론: Φ(O_full(s)) = Φ(O_z(s)) = Φ(O_z(Γs)) = Φ(O_full(Γs))다. 그러므로 **완전 관측에서도** 공유 코드가 s와 Γs를 구분하지 못한다. 어떤 디코더도 x를 복원할 수 없고, P2(c)의 하한 E[x²]이 완전 관측에서도 적용된다. ∎
- 일반화: 점 일관성을 강제하면 공유 코드는 𝒫 안의 모든 패턴 섬유를 합친 가장 거친 분할 위에서 상수가 된다. 즉 **가장 정보가 적은 패턴의 수준으로 붕괴**한다.
- 따라서 E_i(F_i(s)) = E_j(F_j(s))를 모든 view 쌍에 무조건 강제하는 손실은 Lorenz에서 **틀린 목표**다. 이번 단계에서 그런 손실은 제안하지 않는다.

**P8 (평균 융합의 딜레마) [증명].**
- C의 융합: ζ = Σ_i w_i e_i / Σ_i w_i. e_i는 view i의 코드, w_i는 관측 개수.
- (a) ζ가 단일 view 패턴 {i}, {j}와 결합 패턴 사이에서 같은 s에 대해 불변이면, e_i = e_j = ζ여야 한다. 단일 view 패턴에서는 ζ = e_i이기 때문이다. 그러면 **P7의 붕괴**가 일어난다 (z view가 있으므로).
- (b) 반대로 붕괴를 피하면 ζ는 마스크마다 달라진다 (C의 실제 상태).
- 그러므로 **평균 융합은 "일관성"과 "정보 보존"을 동시에 만족할 수 없다.** 식별력이 없는 view에 가중치 0을 주는 융합, 즉 **식별가능성을 아는 융합**이 필요하다.

### 5.2 네 가지 경우와 요구할 수 있는 조건

ζ의 좌표를 ψ로 고정하고, 패턴 𝔅에서 이상적인 출력을 사후분포 Q_𝔅(· | o) = ψ_* μ(· | O_𝔅 = o)로 둔다.

| 경우 | 수학적 상황 | 정당한 일관성 조건 |
|---|---|---|
| (i) 두 view 모두 식별 | Q_{i}과 Q_{j}가 같은 점 δ_{ψ(s)} | **점 일치**: Φ_i(o_i) = Φ_j(o_j) = ψ(s) |
| (ii) view i만 식별 | Q_{i} = δ_{ψ(s)}, Q_{j}는 섬유 ψ(C_j(s)) 위의 분포 | **포함**: ψ(s) ∈ supp Q_{j}(· \| o_j). 확률적으로는 Q_{j}(· \| o_j) = E[ Q_{i,j}(· \| o_i, o_j) \| o_j ] |
| (iii) 각자 불충분, 결합하면 식별 | supp Q_{i} ∩ supp Q_{j} = {ψ(s)} (μ-거의) | **결합 규칙**: 결합 사후 = 개별 사후의 곱 (P9) |
| (iv) 결합해도 비식별 | Q_{i,j}가 여러 점 (예: {ψ(s), ψ(Γs)}) 위의 분포 | **분포 일치**만 요구. 점 일치는 요구할 수 없음 |

**P9 (조건부 독립에서 나오는 결합 규칙) [증명].**
- 상태 s가 주어지면 view 관측 o_i = (O_{i,B_i}(s), B_i)는 s의 결정적 함수와 s와 독립인 마스크의 결합이다 (MCAR). 그러므로 o_1, …, o_n은 **s가 주어졌을 때 조건부 독립**이다.
- 관측 잡음이 있어 밀도가 존재한다면 Bayes 정리에 의해

    p(s | o_1, …, o_n) ∝ p(s) · Π_i p(o_i | s) ∝ p(s)^{1−n} · Π_i p(s | o_i)

  이것은 사전분포를 보정한 **전문가의 곱**(product of experts) 형태다. ∎
- 단서:
  1. 잡음이 없으면 우도가 지시함수가 되고, 결합 사후는 섬유들의 교집합 위로 제한된 μ가 된다.
  2. μ는 Lebesgue에 대해 특이하므로 밀도는 ψ 좌표계에서 정의해야 한다.
  3. MNAR(결측이 값에 의존)이면 조건부 독립이 깨진다.

**P10 (사영 일관성, tower 조건) [증명].** 𝔅 ⊆ 𝔅'이면 참 사후는 다음을 만족한다.

    Q_𝔅(· | o_𝔅) = E[ Q_𝔅'(· | o_𝔅') | o_𝔅 ]

- 증명: 조건부 기댓값의 tower 성질. 𝔅 ⊆ 𝔅'이면 o_𝔅는 o_𝔅'의 함수다. ∎
- 이 조건은 (i)–(iv) **모든 경우에서 성립**하고, 양쪽 패턴이 식별하면 점 일치로 환원된다.
- 그러므로 view 일관성의 **일반적인 정의로 제안**한다. 학습 가능한 형태는 doc 3에서 다룬다.

**P11 (공유 디코더의 단사성 ⇒ 잠재 일관성) [증명].**
- 가정:
  - 공유 디코더 R = (R_1, …, R_n): Z → ℝ^{nm}가 잠재 집합 K ⊆ Z 위에서 연속 단사.
  - 모든 𝔅 ∈ I에서 R(Φ(O_𝔅(s), 𝔅)) = F_all(s) (완전한 다중 view 지연벡터를 정확히 복원).
- 결론: Φ(O_𝔅(s), 𝔅) = R⁻¹(F_all(s))이고, 이것은 𝔅와 무관하다.
  - 더 나아가 F_all이 A 위에서 단사이면 (T3 조건), ψ := R⁻¹ ∘ F_all은 A → K의 연속 단사다. A가 콤팩트이므로 위상동형이다.
  - 즉 **D와 C가 함께 성립**한다. ∎
- 반례 (가정이 빠지면):
  1. R이 단사가 아니면, 같은 출력을 내는 서로 다른 ζ가 있다. 그러면 마스크마다 다른 ζ가 나와도 복원 손실은 0일 수 있다.
  2. 디코더가 **현재값 h(s_t)만** 복원하면 F_all 대신 h를 쓰게 된다. h가 A 위에서 단사가 아닌 계(일반적인 부분 관측 계, 예: 실제 데이터의 일부 변수만 관측)에서는 ψ가 정의되지 않는다. Lorenz에서는 h = 항등이라 현재값으로도 충분하다.
- 함의: **명시적인 정렬 손실 없이도**, "공유 디코더가 완전한 다중 view 지연벡터를 정확히 복원"하고 "디코더가 단사"이면 식별 패턴 사이의 잠재 일관성이 **따라 나온다.** 비식별 패턴에서는 이 등식이 정확히 성립할 수 없으므로 아무것도 강제되지 않는다. 이것은 P7의 붕괴를 피하는 방식이다.

## 8. 아직 검증되지 않은 주장

1. Lorenz x, y의 지연사상(사용하는 m, τ)이 A 위에서 단사라는 것. T2는 prevalent h에 대한 결론이므로 특정 x, y에 대해서는 확인이 필요하다. x = 0에서 몰입이 실패한다는 것은 이미 안다 (det = −σ²x).
2. z 지연사상이 A/Γ 위에서 단사인지 (P2(d)).
3. T3 (Deyle–Sugihara)의 정확한 가정이 우리 마스크 패턴(불규칙 지연, 변수 섞음)에 적용되는지.
4. 우리 실제 데이터(ENSO, EEG, 환율, wind, transportation)가 저차원 결정론적 끌개로 근사된다는 것. FPRM 논문도 이 가정을 둔다.
5. P(𝔅 ∈ I)를 결측률 r의 함수로 정량화하는 것. 국소 계수 기준 수치는 일부 있음 (§3.3). 전역 단사성 기준은 없음.
6. 잡음 하에서의 정량적 식별 (역사상의 Lipschitz 상수, 조건수)과 대치 오차 사이의 관계. 기존 `amp` 지표와 오차의 상관 분석이 필요하다.
7. C/E/F가 "D" 또는 "C"를 만족하는지. 현재 증거는 부정적이거나 미검증이다.
