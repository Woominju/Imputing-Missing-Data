## 1. 기존 Model C/E/F의 한계 재평가 (새 증거 포함)

| 항목 | 기존 해석 (Phase 2) | 재평가 |
|---|---|---|
| C의 잠재 불일치 원인 | "평균 융합은 일관성과 양립 불가" (P8) | **과장이었다.** 정확한 불가능성은 P8′: 스칼라·자기 마스크 가중에서 {x} vs {x,z}에만 해당 |
| 실측 [`pair_consistency.csv`] | – | Γ와 무관한 쌍 {x}\|{x,y}에서도 잠재 불일치가 시간 척도의 0.47–1.38배. P8′ 하한(0.22–0.37)보다 훨씬 크다 → **주원인은 대칭이 아니다** |
| 유력 원인 (가설) | – | C의 디코더는 ℝ¹⁶ → ℝ³(현재값)라 어떤 열린 집합에서도 단사가 될 수 없다 (P11 감사). 출력에 영향 없는 방향(국소 13차원)으로 코드가 마스크마다 움직여도 손실이 0이다. 또 다른 후보: 단일 view 입력의 복원 자체가 부정확함 (x-view만으로 다른 변수 RMSE 0.23–0.46 vs FPRM 0.05). 이것은 P11′의 ε를 키운다 |
| E (view-dropout) | 상충 → 구조적 원인 (P7·P8) | P7은 **정확한 제약**에만 적용된다. E에는 일관성 손실이 없다. 상충의 원인은 용량, 마스크 분포 가중 (Knockout 정리: 학습 손실 = 패턴별 위험을 마스크 확률로 가중한 합), 디코더 섬유 중 무엇인지 **미확정** |
| F (학습 융합) | view 의미를 포기한 공동 인코더 | 유지. 다만 P8의 주장 B는 틀렸으므로, F형 융합은 식별 패턴 간 일관성을 **원리상 막지 않는다** |
| 공통 | 식별가능성 개념 없음, RMSE 중심 | 유지. 추가로, Lorenz에서는 현재값 = 상태이므로 **C의 목표 자체는 상태 복원과 같다**. 문제는 목표가 아니라 디코더의 비단사성과 일관성의 측정 방식일 가능성이 크다 |

## 2. Architecture A — Deterministic Shared-state FDR

- **수학적 목표:** 방법 C, L_C (1/다중도 가중 마스크 MSE, 숨긴 관측 항목만). 추정 대상 = E[F_all 좌표 | x_in, m_in] (O4).
- **Encoder:** view별 E_i(v_i ⊙ m_i, m_i) → e_i (C와 같은 형태).
- **Fusion (통제 요인으로 비교):**
  1. 스칼라 관측 수 가중 평균 (C 그대로). P8′에 의해 {x}/{x,z} 불일치 하한이 있다.
  2. **행렬(정밀도) 가중 평균** ζ = (Σ Λ_i)⁻¹ Σ Λ_i e_i, Λ_i = Λ_i(o_i) ⪰ 0. P8″에 의해 대칭 장애를 원리상 피할 수 있다. **확률적 해석 없이 구조로만 쓴다.**
  3. 학습 MLP 융합 (F). 일관성을 막지는 않지만 view별 의미가 없다.
- **Decoder:** view별 완전 지연 디코더 R_i: ℝ^k → ℝ^m. 출력 차원 n·m ≥ k이므로 단사가 **가능**하다 (보장은 아님).
- **잠재 차원 k (통제 요인):** Lorenz에서 k ∈ {3, 8, 16}. A ⊂ ℝ³이므로 k = 3이면 매장이 존재한다 (감사 §3의 수정).
- **학습 신호:** 숨긴 관측 항목의 L_C 하나. 일관성 손실 없음.
- **식별가능성 가정:**
  - 식별 패턴 집합 I가 비어 있지 않다.
  - (Lorenz) x 또는 y의 완전 창이 식별 (가정 A1, Unresolved). 현재값 (x,y,z) 패턴은 항등이므로 확실히 식별 (P4′).
- **검증 가능한 예측:**
  - E1 (P11′): 식별 쌍의 잠재 불일치 ≤ 2·L̂·ε̂. L̂는 디코더 역-Lipschitz 경험적 하한, ε̂는 점별 복원 오차 분위수.
  - E2 (P8′): 스칼라 융합에서 {x}/{x,z} 불일치는 하한 이상. 행렬 융합에서는 그 하한이 사라질 수 있다.
  - E3: k를 줄이거나 출력 차원을 늘리면 식별 쌍 불일치가 줄어든다 (디코더 섬유 가설).
- **실패 모드:**
  - R이 단사가 아님 (L̂ 큼).
  - 같은 view 안의 보간 지름길 (dt = 0.01, lag-1 자기상관 0.997) → view 간 정보 미학습.
  - lag>0 출력의 미래 정보 혼입 (보고 분리로 통제).
  - 행렬 융합의 수치 불안정 (Λ 특이).
- **비식별 패턴:** 조건부 평균을 출력한다 (불확실성 없음). 일관성을 요구하지 않는다.

## 3. Architecture B — Cross-view Reconstruction

- **결론: 독립 아키텍처가 아니라 A(또는 C)의 학습 마스크 분포 요인으로 다룬다.** 구조와 목적함수가 A와 같고, 다른 것은 "view 통째 숨김" 확률 q_v뿐이다.
- **진짜 cross-view 매핑이 학습되나:** 대상 view j가 입력에 전혀 없으면 R_j∘Φ(o_S)는 E[F_j | o_S]를 추정한다. S = {i}이고 view i가 식별하면 이것은 G_{j←i}다.
  - Knockout 정리(문헌 §3): 마스크가 데이터와 독립이면, 학습 손실은 패턴별 위험을 패턴 확률로 가중한 합이 된다. q_v는 **어느 패턴에 용량을 배분할지**를 정한다.
- **자기 변수 보간 배제:** 숨긴 view의 출력에는 같은 view의 이웃 관측이 없으므로 원천 배제된다. 항목 단위 숨김에서는 배제되지 않는다.
- **평가 환경(모든 변수 랜덤 MCAR)에서의 유용성:**
  - MCAR p ≤ 0.5에서는 view 통째 결측 확률이 p^m (m = 8)으로 거의 0이다. 평가 분포와 다른 패턴을 학습하는 셈이다.
  - 그래서 q_v는 (i) G_{j←i} 평가와 정보를 맞춘 FPRM 비교를 가능하게 하고, (ii) 단일 view의 정확도(P11′의 ε)를 높이는 대신, (iii) 평가 분포의 위험 가중치를 줄인다.
  - E의 상충은 (iii)로도 설명된다. **q_v는 val 기준으로 정하고 0도 후보에 둔다.**

## 4. Architecture C — Probabilistic Shared-state Model

- **수학적 목표:** 방법 A (관측 데이터 생성 ELBO, 입력 부분표본; MoPoE Eq. 4와 같은 꼴). 대안은 방법 B (CVAE). **L_old는 쓰지 않는다** (O1).
- **Encoder/Fusion 대안:**

| 융합 | 장점 | 한계 |
|---|---|---|
| 가우스 PoE | 정밀도 가중 (P8″의 구조적 이점), 결측 view 자연 처리 (Λ = 0) | 전문가는 참 우도가 아니다 (P9′). 과신 (MMVAE가 지적한 정밀도 오보정) |
| 학습 융합 → 가우스 | 유연함 | view별 의미 없음 |
| 혼합 사후 (MoE/MoPoE) | 다봉 잠재 | MMVAE식 교차 재구성은 완전 데이터를 요구한다 (문헌 §4b). 우리 설정에는 MoPoE식 부분집합 형태만 적용 가능 |
| 정규화 흐름 사후 | 임의 형태 | 비용, 학습 불안정 |

- **가우스 PoE 7개 점검:**
  1. **전문가의 의미:** 신경망이 출력하는 가우스 인자다. 우도 인자가 아니며, Λ_i의 합이 Fisher 정보의 합이라는 보장은 없다.
  2. **사전과 우도 인자:** q ∝ p(ζ) Π ℓ_i 형태 (MVAE). 사후들의 곱이 아니므로 p^{1−n} 보정은 필요 없다. 다만 ℓ_i가 "무엇의 근사인지"는 목적함수의 최적점에서만 정의된다.
  3. **조건부 독립:** P9′의 가정(독립 마스크, 독립 잡음, ζ 가역)이 있어야 곱 구조가 참 사후의 구조와 맞는다. 그렇지 않으면 PoE는 설계 선택일 뿐이다.
  4. **과신:** 전문가가 많을수록 정밀도가 합산되어 좁아진다. coverage로 측정한다.
  5. **사후 붕괴:** 목표에 숨긴 좌표가 있으면 디코더가 ζ를 무시하기 어렵다. KL 항의 크기를 감시한다.
  6. **다봉 사후:** 잠재 공간에서 두 점 {ψ(s), ψ(Γs)}를 정확히 표현할 수는 없다. 그러나 **비선형 디코더를 거친 출력 분포는 이봉일 수 있다** [`elbo_toy.log`: 0.65 vs 참값 0.69]. 대신 잠재가 "상태 좌표"라는 해석은 약해진다 (넓은 가우스가 어떤 상태에도 대응하지 않는 영역을 덮음).
  7. **식별가능성과의 관계:** 식별 패턴에서 사후가 좁아지고, 비식별 패턴에서 넓어지는 것이 기대되는 행동이다. 이것은 검증 대상이고 보장되지 않는다.
- **Daunhawer et al. 2022의 한계:** 부분표본 학습은 log p(x)와의 간극 Δ(숨긴 좌표의 조건부 엔트로피)를 닫지 못한다. 비식별 패턴 비율이 높을수록 생성 적합이 나빠진다.
- **실패 모드:** 위의 2–6 + 복합 우도 과신 (창 중첩).
- **검증 가능한 예측:** 식별/비식별 라벨별 사후 폭, coverage, tower 검사 (감사 §P10의 절차), z-only의 x 예측분포 이봉성.

## 5. Architecture D — 추가 대안: 시간 결합 잠재 (보류)

- 아이디어: 잠재 사전에 시간 구조를 넣는다. 예: GP-VAE의 시간 GP 사전, 또는 ζ_{t+Δ} ≈ T(ζ_t).
  - 여러 창을 결합하면 실질적으로 더 긴 지연 창이 되어, 단일 창이 비식별인 패턴을 식별 가능하게 만들 수 있다.
- 수학적 근거: ψ가 매장이면 유도 동역학 T_Δ = ψ∘φ_Δ∘ψ⁻¹이 존재한다. 그래서 시간 결합은 "같은 상태 궤적"이라는 추가 제약이 된다.
- **보류 이유:** Level 2(공유 상태)가 확인되기 전에 동역학 항을 넣으면 실패 원인을 구분할 수 없다. 복잡성이 기여의 증거도 아니다. A/C에서 Level 3 검증이 실패할 때만 검토한다.

## 6. Dynamics-informed의 세 수준

| 수준 | 정의 | 판정에 필요한 증거 | 함의 관계 |
|---|---|---|---|
| L1 지연 정보 복원 | 지연 창이 대치 성능에 기여 | 같은 모델에서 m = 1 (현재값만) vs m > 1, 그리고 B(자기 view) vs C. 정보량을 맞춘 비교 | L1 ⇏ L2 (P3′: 대상 식별만으로 가능) |
| L2 공유 상태 표현 | 식별 패턴들이 같은 잠재로 사상되고, 잠재가 상태를 결정 | 식별 쌍의 잠재·출력 일치 (P11′ 경계와 비교), 참 상태 탐침 (Lorenz) | L2(정확, ψ 매장) ⇒ 유도 동역학 T_Δ **존재**. 하지만 학습된 표현이 그것을 **근사한다**는 보장은 없음 (오차 누적) |
| L3 동역학 구조 보존 | ζ_t 열이 T_Δ와 일관되게 움직임 | ζ_t → ζ_{t+Δ}의 예측가능성 (참 상태에서의 예측가능성과 비교), 잠재 근방에서의 미래 예측, 잠재 궤적에서 추정한 동역학 불변량 (보조) | L3 ⇒ 예측에 유용. 좋은 예측 성능 ⇏ L2 (예측은 상태 없이도 가능) |

구분할 것:
- 지연 좌표를 **사용함** (입력에 있음).
- 상태 정보를 **보존함** (탐침).
- 동역학적으로 **일관된 표현** (L3 지표).
- 잠재 **전이 모델을 학습함** (명시적 T가 있음 — 현재 후보에는 없음, D 모델만 해당).
- **예측 성능이 좋음.**

명시적 동역학 손실이 필요하다고 미리 결론 내리지 않는다. L2가 성립하고 L3 지표가 참 상태 수준이면 필요 없다. L3가 실패할 때 D(시간 결합)를 검토한다.

## 7. 후보 비교

| 기준 | C (현재) | A: 결정론적 FDR | B: Cross-view (= A + q_v) | C′: 확률적 (방법 A 목표) |
|---|---|---|---|---|
| AIM: 완전 관측 변수 없음 | 예 | 예 | 예 | 예 |
| AIM: 공유 잠재로의 일관된 사상 | 측정상 아니오 | P11′ 조건 하에서 (식별 패턴) | A와 같음 + 단일 view 경로 | 생성모형으로 정의됨. 일관성은 근사 품질에 의존 |
| AIM: 지연 임베딩 간 대응 (G_{j←i}) | 평가 불가 (현재값만) | 평가 가능 | **직접 학습** | 평가 가능 |
| 이론적 정당성 (목적함수) | 조건부 평균 (현재값) | 조건부 평균 (FDR, O4) | 같음 | log p(x_O) 하한 (O2) |
| 비식별 패턴 | 조건부 평균 | 조건부 평균 | 조건부 평균 | 분포 |
| 구현 난이도 (C 대비) | – | 작음 (디코더 출력, 가중, 융합 옵션) | 작음 (마스크 샘플러) | 중간 |
| 주요 실패 위험 | – | 디코더 비단사, 보간 지름길 | 평가 분포와의 불일치 | 사후 붕괴, 과신, Daunhawer 간극 |
| 선행연구 대비 새로움 | – | 낮음: 지연 AE의 완전 지연 복원은 Bakarji et al. (단일 완전 관측 변수) | 낮음: view-dropout, Knockout | 낮음: MoPoE/MIWAE의 형태 |

**새로움에 대한 정직한 평가:** 구성 요소(완전 지연 디코더, PoE, view-dropout, 부분표본 ELBO, 마스크 입력)는 모두 기존 연구에 있다. 가능한 기여는 다음과 같다.
1. 완전 관측 변수가 **없는** 동역학 복원에 이들을 결합하는 것.
2. 그 결합이 **식별 가능한 패턴에서 공유 상태를 실제로 학습함**을 수학(P11′, P8′/P8″)과 실험(식별 라벨별 일관성, 참 상태 탐침)으로 보이는 것.
3. 식별 불가능성(Lorenz Γ)을 정직하게 다루는 평가 체계.

문헌 검토에서 이 조합을 직접 다룬 선행연구는 **찾지 못했다**. 다만 이것은 부재의 증거가 아니다. 응용 수준에서 가장 가까운 Lv et al. 2025 (Mathematics)는 원문을 확인하지 못했다.

## 8. 최종 추천

**추천: Architecture A (결정론적 FDR)를 먼저 하되, 융합 방식(스칼라 vs 행렬)과 잠재 차원 k를 통제 요인으로 둔다. Architecture C′ (확률적, 방법 A 목표)는 A의 결과로 조건부 결정한다. B는 A의 마스크 분포 요인으로 흡수한다.**

근거:
1. **수학적 핵심 가설은 P11′이다** ("정확한 복원 + 역-Lipschitz 디코더 ⇒ 식별 패턴 간 잠재 일관성"). 확률 모형 없이 A에서 가장 직접 시험된다. A가 이 가설을 지지하지 못하면 C′도 같은 디코더 문제를 안는다.
2. Phase 2의 PoE-FDR 추천은 두 가지 틀린 근거에 기대고 있었다.
   - "MCAR ⇒ PoE가 참 사후" → P9 감사로 철회.
   - "ELBO 최적점에서 q = 참 사후" → L_old는 조건부 ELBO가 아님 (O1).
   - 남는 정당한 근거는 **정밀도 가중 융합의 구조적 이점(P8″)** 뿐이다. 이것은 결정론적 A에서도 행렬 가중 융합으로 시험할 수 있다.
3. 비용이 가장 작고 실패 원인이 가장 잘 분리된다.

**C′로 갈 조건:** A에서 식별 패턴 일관성이 확인되고 (Level 2), 비식별 패턴의 불확실성 표현이 연구 질문(예: 하류 인과 분석)에 필요하다고 사용자가 판단할 때.

**잠깐 멈춰야 할 사실:** Lorenz에서는 현재값 = 상태라 FDR 없이도 "디코더 단사"가 가능하다 (k = 3인 현재값 디코더). 그래서 **최소 실험은 FDR 구현 이전에** 기존 C 코드에서 k만 바꾸는 것으로 시작할 수 있다 (문서 D §5). FDR의 필요성은 현재값이 상태를 결정하지 않는 계(Coupled Lorenz의 일부 변수만 관측, 실제 데이터)에서 시험한다.
