## 1. 설정과 표기

- 시점 t의 **창**: 모든 view의 지연 좌표 x_t = {x_{i,t−kτ} : i = 1..n, k = 0..m−1} (n·m개).
- 관측 집합 O_t (M = 1인 좌표). 결측 좌표 Mis_t = 나머지.
  - 결측에는 원래 결측(M_orig = 0)과 평가용 인위 결측(eval_mask = 1)이 있다.
- 학습 시 추가로 숨긴 좌표 H_t ⊆ O_t, 입력 in_t = O_t \ H_t. 그래서 x_in = x_{in_t}, x_H = x_{H_t}.
- 실제 결측값(Mis_t)은 어떤 목적함수에서도 **목표로 쓰지 않는다** (값이 없거나, 평가 정답이므로).
- 잠재 ζ_t ∈ ℝ^k. 디코더 R: ℝ^k → ℝ^{n·m} (FDR). R_{i,k}는 좌표 (i, k)의 출력이다.

### 1.1 네 가지 확률적 목표

| 목표 | 수식 | AIM에서의 역할 | 한계 |
|---|---|---|---|
| A | log p_θ(x_O) | 관측된 지연 좌표 전체를 하나의 잠재가 생성한다는 **생성모형**의 적합. "모든 변수의 지연 임베딩이 하나의 공유 잠재로 사상된다"를 가장 직접 표현 | 모형 가정(조건부 독립, 잡음, 창 독립)에 의존. 동역학을 직접 모형화하지 않음 |
| B | p_θ(F_all) | 완전한 다중 view 지연벡터의 분포 = 끌개 위 μ의 상 F_all*μ | 완전한 F_all은 관측되지 않음. A를 통해 간접 학습 |
| C | p_θ(x_H \| x_in) | 대치에 직접 필요한 **조건부 예측분포** | 잠재가 상태일 필요가 없음. 낮은 조건부 오차 ≠ 공유 상태 복원 (P3′) |
| D | p_θ(s \| x_in) | 상태 사후 (Lorenz에서만 정답 상태로 평가 가능) | s는 학습에 쓰지 않음. 잠재 ζ가 s와 대응한다는 것은 P11/P11′의 조건 하에서만 |

**낮은 조건부 복원 오차(C)와 정확한 공유 상태(D와 개념 C/D)는 같은 목표가 아니다.** C는 대상 식별(I6)만으로 달성될 수 있다 (P3′).

## 2. 기존 목적함수 L_old의 정확한 의미

    L_old(φ, θ) = E_{q_φ(ζ|x_in)} [ log p_θ(x_H | ζ) ] − KL( q_φ(ζ|x_in) ‖ p(ζ) )

### 2.1 L_old는 무엇의 하한인가

**(a) 숨긴 좌표만의 무조건 주변우도의 하한.** 생성모형 p(ζ) p_θ(x_H | ζ) (x_in은 모형에 없음)에 대해, 임의의 분포 q에 대해

    log p_θ(x_H) = log ∫ p(ζ) p_θ(x_H|ζ) dζ
                 = E_q[log p_θ(x_H|ζ)] − KL(q ‖ p(ζ)) + KL(q ‖ p_θ(ζ | x_H))
                 ≥ L_old

q가 x_in에 의존해도 성립한다. 간극은 KL(q_φ(ζ|x_in) ‖ p_θ(ζ|x_H))다.
→ L_old는 **x_in과 무관한 모형의 log p(x_H)** 의 하한이다. 이 모형에서 x_in과 ζ를 잇는 확률적 관계는 없다. 연결은 인코더 q를 통해서만 생긴다.

**(b) 인코더로 정의한 조건부 모형의 하한 (느슨함).** 조건부 모형을 p_{θ,φ}(x_H | x_in) := ∫ q_φ(ζ|x_in) p_θ(x_H|ζ) dζ로 정의하면, Jensen에 의해

    log p_{θ,φ}(x_H | x_in) ≥ E_{q_φ(ζ|x_in)}[log p_θ(x_H|ζ)] ≥ E_q[log p_θ(x_H|ζ)] − KL(q ‖ p(ζ)) = L_old

- 첫 부등식의 간극은 Jensen 간극이다.
- 둘째 간극은 KL(q‖p(ζ)) ≥ 0이다. 이 항은 하한을 조이는 데 아무 역할을 하지 않는 **정칙화**다.
- 즉 L_old = **Variational Information Bottleneck**(β = 1) 형태다: 예측 항 − β·KL(인코더 ‖ 고정 사전).

**결론:** L_old는 log p(x_H | x_in)의 **표준 조건부 ELBO가 아니다.** Phase 2 문서(AC §3.1)의 "ELBO 최적점에서 q는 참 사후와 같다"는 주장은 **틀렸다.** L_old에는 x_H를 보는 사후 q(ζ | x_in, x_H)도, 조건부 사전 p(ζ | x_in)도 없기 때문이다.

### 2.2 L_old가 조건부 다봉성을 배우지 못하는 이유

**명제 O1 [증명].** 디코더가 가우스이고 분산이 등방·고정(또는 x_H와 무관하게 학습)이라고 하자: p_θ(x_H|ζ) = N(x_H; R_H(ζ), σ²I). 그러면 학습 데이터에 대한 기댓값

    E_{x_H|x_in}[L_old] = −(1/2σ²) E_q[ ‖E[x_H|x_in] − R_H(ζ)‖² ] − tr Cov(x_H|x_in)/(2σ²) − KL(q‖p) + const

는 조건부 분포 p(x_H | x_in)에 **평균과 총분산을 통해서만** 의존한다.
- 증명: E‖x_H − R‖² = ‖E x_H − R‖² + tr Cov(x_H). ∎
- 따라서 L_old의 최적 (q, R)는 조건부 평균을 맞추는 회귀와 KL 정칙화로 정해진다. **이봉 조건부(Lorenz z-only에서의 ±x)를 구별할 수 없다.**

**수치 확인** (`elbo_toy.log`). x_H = ±1 (각 1/2), σ = 0.1, 사전 N(0,1), q = N(m, s²)를 격자 탐색했다.

| 디코더 | argmax L_old | 그때 참값 ±1에서의 예측 로그밀도 | argmax 조건부 로그우도 | 그때 예측 로그밀도 |
|---|---|---|---|---|
| R(ζ) = ζ | m = 0, s = 0.10 | **−23.75** | m = −0.35, s = 3.0 (격자 끝) | −1.12 |
| R(ζ) = tanh(5ζ) | m = 0, s = 0.02 | **−26.01** | m = −0.35, s = 3.0 | **0.65** |
| 참 혼합분포 | – | – | – | 0.69 |

- L_old 최적해는 조건부 평균(0)으로 붕괴해 정답에 거의 0의 확률을 준다.
- 같은 가우스 잠재 분포족이라도 **조건부 로그우도**로 학습하면, 비선형 디코더를 통해 이봉 출력을 거의 정확히 표현한다 (0.65 vs 0.69).
- 이것은 "가우스 잠재가 단봉이라 대칭 불확실성을 표현할 수 없다"는 Phase 2의 서술이 **과장**이었음도 보여준다. 문제는 분포족이 아니라 **목적함수**였다.

### 2.3 대리 손실로서의 가치

L_old는 점 대치 측면에서는 "KL 정칙화된 조건부 평균 회귀"로 쓸모가 있을 수 있다. 하지만:
- (i) 확률적 의미(보정된 불확실성)를 주장할 수 없다.
- (ii) 결정론적 FDR(방법 C)에 비해 이점이 불분명하다.

**AIM 구현의 확률 목적함수로는 쓰지 않는다.**

## 3. 방법 A — 관측 데이터 생성 ELBO

### 3.1 생성 가정

1. ζ_t ~ p(ζ) = N(0, I_k).
2. 관측 좌표는 ζ가 주어지면 조건부 독립: x_{i,t−kτ} | ζ_t ~ N(R_{i,k}(ζ_t), σ_i²). 분산은 view별로 학습하고 하한을 둔다.
3. 결측 과정은 **무시 가능(ignorable)**: 마스크가 x와 ζ와 독립 (MCAR)이고 매개변수가 분리됨 (Rubin). 그러면 관측 우도 p(x_O, mask) ∝ p_θ(x_O)이므로 마스크 모형이 필요 없다.

이때 관측 좌표의 주변우도는

    p_θ(x_O) = ∫ p(ζ) Π_{(i,k)∈O} N(x_{i,t−kτ}; R_{i,k}(ζ), σ_i²) dζ

### 3.2 ELBO (입력 부분표본 포함)

**명제 O2 [증명].** 임의의 입력 부분집합 in ⊆ O와, 그것만 보는 인코더 q_φ(ζ | x_in, m_in)에 대해

    L_A = E_{q_φ(ζ|x_in, m_in)} [ Σ_{(i,k)∈O} log p_θ(x_{ik}|ζ) ] − KL(q_φ ‖ p(ζ)) ≤ log p_θ(x_O)

- 증명: 표준 ELBO 분해 log p(x_O) = L_A + KL(q ‖ p_θ(ζ|x_O)). q가 무엇에 의존하든 성립한다. ∎
- **L_old와의 차이:** 재구성 대상이 **x_H만이 아니라 관측 전체 x_O**(입력 포함)다. 이 하나의 차이로 L_A는 명확한 확률량 log p(x_O)의 하한이 된다.
- 간극: KL(q(ζ|x_in) ‖ p(ζ|x_O)). x_in ⊂ x_O이므로 인코더가 x_H 정보 없이 사후를 근사해야 한다 (amortization 간극). in = O(부분표본 없음)이면 표준 partial-VAE / MIWAE형 목적이다.
- **선행연구 (`phase25_literature_review.md`):** "부분집합을 인코딩하고 전체를 디코딩"하는 형태는 MoPoE(Sutter et al., ICLR 2021) Eq. 4와 같다. MIWAE와 Partial VAE도 log p(x_O)를 하한으로 삼는다. **방법 A는 새로운 목적함수가 아니다.**
- **Daunhawer et al. (ICLR 2022) Thm 1:** 부분표본 기반 다중모달 VAE는 log p(x)와의 간극 Δ = Σ_A ω_A H(X_{\A} | X_A)를 닫을 수 없다. 우리 설정에서 Δ는 입력이 주어졌을 때 숨긴 좌표의 조건부 엔트로피다. 식별 패턴(입력이 끌개를 매장)에서는 작고, 비식별 패턴(z-only)에서는 크다. 따라서 **입력 부분표본은 식별 패턴의 비율에 따라 생성 적합을 체계적으로 해친다.** 부분표본 확률을 val 우도로 정하고, 부분표본 없는 항(in = O)을 함께 두는 것을 검토해야 한다 (구현 전 결정 사항).
- **입력과 목표:** 입력 = x_in, 목표 = x_O. 입력 좌표를 재구성하는 것은 생성모형 우도의 일부이고 누수가 아니다. 다만 정보가 병목 ζ를 거치므로, k가 크면 일부를 그대로 복사하는 해가 생길 수 있다. 부분표본(x_H를 입력에서 뺌)이 인코더가 보지 못한 좌표를 예측하도록 강제한다.
- **마스크 조건:** 인코더는 (값·0, 마스크)를 입력받아 어떤 패턴에서도 동작한다. 생성모형 자체는 무시 가능성 덕분에 마스크를 조건으로 할 필요가 없다.

### 3.3 대치

    p(x_Mis | x_O) = ∫ p_θ(ζ | x_O) Π_{(i,k)∈Mis} p_θ(x_{ik}|ζ) dζ ≈ ∫ q_φ(ζ | x_O) Π p_θ(x_{ik}|ζ) dζ

- q = 참 사후일 때 정확하다. importance weighting(MIWAE식)으로 근사 오차를 줄일 수 있다.
- 시간 정보: 과거 창이고 lag-0 좌표를 출력하면 "과거만"이다 (문서 A §0).

### 3.4 한계와 숨은 가정

| 항목 | 내용 |
|---|---|
| 중첩 창 | 창들을 독립 표본으로 더하면 **복합(composite) 우도**가 된다. 원시 관측 하나가 최대 m번 우도에 들어간다. 정상·에르고딕이면 창-주변분포의 매개변수 추정은 일관적일 수 있으나, 불확실성은 과신된다 (대략 m배 정보 과대계산). 원시 관측별 1/다중도 가중은 점추정에 무해하고 과신을 줄인다 |
| 결정론적 동역학 | ζ ≅ s이면 창 좌표는 s의 결정론적 함수다. 조건부 독립은 자명하게 성립한다 (디랙). σ_i는 관측 잡음과 근사 오차를 흡수하는 매개변수다. σ → 0이면 우도가 특이해진다 → 하한 필요 |
| 잠재의 시간 구조 | 모형은 ζ_t를 시점별 독립 사전에서 뽑는다. 동역학 ζ_{t+Δ} = T(ζ_t)는 **모형에 없다** (Level 3은 측정 대상, 문서 C §5) |
| MNAR | 무시 가능성이 깨지면 마스크 모형이 필요하다 |
| 공유 상태와의 연결 | 적합이 완전하고 (사전 분포가 R을 통해 F_all*μ를 재현), R이 지지집합에서 단사이면 ψ = R⁻¹∘F_all이다. 그러면 q(ζ | x_O)는 ψ(섬유) 위의 분포를 근사한다. **R의 단사성은 목적함수가 보장하지 않는다** (P11′) |

## 4. 방법 B — 조건부 잠재변수 모형 (CVAE)

### 4.1 모형과 하한

- 조건부 사전 p_θ(ζ | x_in, m_in). view별 인코더 + 마스크 인식 융합으로 매개변수화한다. 융합은 PoE, 학습 융합, 행렬 가중 평균 중 선택 (문서 C).
- 디코더 p_θ(x_H | ζ). **x_in을 디코더에 넣지 않을 것을 권한다.** 넣으면 ζ는 x_in이 설명하지 못한 잔차만 담아도 되어 "공유 상태"의 의미를 잃는다.
- 학습용 사후 q_φ(ζ | x_in, x_H, m).

**명제 O3 [증명].**

    log p_θ(x_H | x_in) ≥ E_{q_φ(ζ|x_in,x_H)}[log p_θ(x_H|ζ)] − KL(q_φ(ζ|x_in,x_H) ‖ p_θ(ζ|x_in))

증명: log ∫ p(ζ|x_in) p(x_H|ζ) dζ에 q로 Jensen. ∎

### 4.2 구현 명세

| 항목 | 내용 |
|---|---|
| 사후가 쓸 수 있는 정답 | 학습 시 **인위적으로 숨긴 관측값 x_H**만. 원래 결측과 평가 정답은 절대 쓰지 않는다 |
| 추론 시 | 조건부 사전 p_θ(ζ | x_in = x_O)만 쓴다. 사후 네트워크는 쓰지 않으므로 숨긴 정답에 접근하는 경로가 없다 |
| 원래 결측 vs 인위 결측 | 원래 결측은 입력에서 0 + 마스크로만 존재하고 목표가 아니다. 인위 결측 H는 학습 신호 |
| 계산 가능성 | 가우스 사전과 가우스 사후면 KL이 닫힌 형식이다. 기댓값은 재매개변수화 표본 1개 이상 |
| 실제 결측의 복원 근거 | 학습 패턴 (in, H)의 분포가 평가 패턴 (O, Mis)의 분포와 같다는 가정. MCAR + 결측률 맞춤 필요. 현재 C의 학습 입력 결측률 1−(1−p)(0.8)과 평가 p의 차이는 이 가정을 어긴다 → 인위 은닉률을 표본화하거나, 평가 마스크 분포에 맞게 조정 |
| 학습/추론 간극 | 사후와 조건부 사전 간 차이로 추론 품질이 떨어질 수 있다 (CVAE의 알려진 문제). GSNN 혼합 목적 (q = 사전으로 둔 항)으로 완화한다 |
| L_old와의 관계 | q := p_θ(ζ|x_in)로 두면 O3은 E_{p(ζ|x_in)}[log p(x_H|ζ)]가 된다 (GSNN, 유효한 하한). L_old는 이것에서 KL(p(ζ|x_in) ‖ N(0,I))를 더 뺀 것이다 |
| 공유 상태 | 목표가 조건부 예측이라서, ζ가 상태여야 할 이유는 디코더가 x_in을 보지 않는다는 설계와 다중 view 디코딩에서만 나온다. **마스크 간 잠재 일관성을 직접 유도하지 않는다** |

## 5. 방법 C — 결정론적 FDR

### 5.1 목적함수

    L_C = Σ_{세그먼트} Σ_{원시 숨김 항목 e=(i,t')} (1/c_e) Σ_{창 t: e ∈ 창 t} ( x_e − R_{i,(t−t')/τ}(Φ(x_in,t, m_in,t)) )²

- c_e는 세그먼트 안에서 항목 e가 목표로 등장하는 창의 수 (다중도, 1–8; 문서 A L5). 1/c_e는 원시 항목마다 총가중을 1로 맞춘다.
- 또는 lag별 출력을 평균한 하나의 예측으로 항목당 한 번만 셀 수도 있다.
- 목표 = 숨긴 관측 항목만. 입력 항목은 목표에서 제외해 복사 해를 막는다.

### 5.2 무엇을 추정하나

**명제 O4 [증명].** 학습 마스크 분포 아래에서 L_C의 기대값을 최소화하는 (Φ, R) 함수는, 각 창과 lag에 대해

    R_{i,k}(Φ(x_in)) = E[x_{i,t−kτ} | x_in, m_in]

을 만족한다 (용량이 충분할 때; 조건부 평균의 L² 최적성). ∎

- **식별 패턴** (I2′): 조건부 분포가 퇴화하므로 출력 = 참값 F_all(s)이다. 그러면 P11′의 ε가 작아지고, R이 역-Lipschitz이면 잠재 일관성이 2Lε 이내로 따라온다.
- **비식별 패턴:** 출력 = 조건부 평균 (z-only면 x̂ ≈ 0). 잠재는 어떤 상태에도 대응하지 않는 점일 수 있다. 불확실성 정보가 없다. 일관성을 요구하지 않는 것이 맞다 (P7).
- **보장하지 않는 것:** R의 단사성, ψ의 존재와 매끄러움, 시간 동역학.

### 5.3 누수와 시간 정보

| 위험 | 통제 |
|---|---|
| 숨긴 값이 다른 창으로 재유입 | 현재 코드처럼 세그먼트 단위로 H를 정하고 마스킹 후 창을 구성 (L3로 검증된 경로 재사용) |
| **lag>0 출력의 미래 정보** | 창 t의 lag k 출력은 t−kτ 이후 관측을 쓴다. 대치에 lag-0만 쓰면 "과거만", lag>0을 모으면 "양방향(smoothing)". **두 버전을 이름을 구분해 보고** |
| 평가 정답 | eval_mask 항목은 M = 0이라 입력·목표 어디에도 없다 (L1 검증 경로) |
| 학습/평가 분할 | 학습 세그먼트는 train 구간 안에서만 (현재 코드) |
| 다중도 | 1/c_e 가중 (5.1) |

## 6. 세 방법 비교

| 기준 | 방법 A: 생성 ELBO | 방법 B: 조건부 모형 | 방법 C: 결정론적 FDR |
|---|---|---|---|
| 완전 관측 변수 불필요 | 예 | 예 | 예 |
| 수학적으로 정당한 목표 | 예: log p(x_O)의 하한 (O2). 모형 가정 하에서 | 예: log p(x_H \| x_in)의 하한 (O3) | 예: 조건부 평균의 L² 추정 (O4) |
| 공유 상태 학습 근거 | **가장 직접적**: 하나의 ζ가 모든 view의 지연 좌표를 생성. R 단사 시 ψ (P11) | 간접적: 디코더가 x_in을 안 볼 때만 | 식별 패턴에서 P11′ (R 역-Lipschitz일 때) |
| View 일관성 | 사후가 ψ(섬유)를 근사 → tower 일관성을 기대할 수 있음 (근사 정도에 따름) | 조건부 사전의 융합 설계에 의존 | 식별 패턴의 점 일관성만 (P11′) |
| 비식별 패턴 처리 | 사후 분포 (비선형 디코더로 출력 다봉 가능) | 조건부 사전 분포 | 조건부 평균 (불확실성 없음) |
| 데이터 누수 위험 | 낮음 (목표 = 관측된 것만) | 사후 네트워크가 x_H를 봄 → 추론 시 사용 금지를 코드로 보장해야 함 | 낮음 (L3 경로) + lag>0 출력의 미래 정보 명시 |
| 계산 비용 | 중간 (표본화, KL; IWAE면 더 큼) | 중간 (네트워크 2개) | 낮음 (현재 C + 디코더 출력 확장) |
| 실험 검증 가능성 | NLL, coverage, 일관성, 탐침 | 조건부 NLL, coverage | RMSE, 일관성, 탐침 (분포 지표 없음) |

**네 가지 판단을 분리하면:**

| 판단 | A | B | C |
|---|---|---|---|
| 1. 이론적으로 정당한가 | 예 (명시된 생성 가정 하에서) | 예 | 예 (조건부 평균 추정으로서) |
| 2. AIM에 적합한가 | **가장 높음** (공유 잠재가 모든 지연 좌표를 생성) | 중간 (예측 목표 중심) | 중간 (점 추정, 식별 패턴에서만 공유 상태 근거) |
| 3. 구현 가능한가 | 예 (VAE + 마스크) | 예 | **가장 쉬움** |
| 4. 원하는 성질을 실제로 얻을 가능성 | 불확실: 사후 붕괴, 복합 우도 과신, R 단사성 | 불확실: 사전-사후 간극, ζ가 상태가 아닐 수 있음 | 불확실: R 단사성, 같은 view 안 보간 지름길 |

손실 항 개수로 타당성을 판단하지 않았다. 셋 다 하나의 원리(우도, 조건부 우도, L² 위험)에서 나온다.

## 7. 최소한의 올바른 학습 목표 제안

1. **L_old는 쓰지 않는다.** 표준 조건부 ELBO가 아니고 (§2.1), 조건부 평균만 본다 (O1).
2. **첫 단계: 방법 C (결정론적 FDR, L_C).** 목표가 명확하고 (조건부 평균), 구현이 작으며, 핵심 가설 P11′(복원 → 잠재 일관성)을 직접 시험한다. 확률적 주장은 하지 않는다.
3. **확률 모형이 필요하다고 판단되면: 방법 A (관측 데이터 생성 ELBO, 입력 부분표본).** AIM 문장에 가장 직접 대응한다. 방법 B는 보정된 예측분포 자체가 주목표일 때의 대안이다.
4. 어떤 단계에서도 **일관성 손실은 추가하지 않는다** (P7). 일관성은 측정한다 (문서 C·D).
5. 구현 시 필수 통제: 1/다중도 가중, lag-0 대치(과거만)와 양방향 대치의 분리, 원래 결측과 평가 정답을 목표에서 배제, 학습/평가 결측률 정렬.
