## 2. 아직 가설인 주장

| # | 가설 | 시험 방법 |

## 3. 가장 중요한 미해결 문제

1. **공유 잠재 일관성이 왜 실패하는지 (H1 vs H2).** 이후 모든 설계 결정이 이것에 달려 있다.
2. 학습된 디코더의 역-Lipschitz 상수를 신뢰성 있게 추정하는 방법 (U6). 이것이 P11′를 실용적으로 만든다.
3. 식별 라벨링 (U1, U8): "식별" 라벨을 어떤 패턴에 붙일 수 있는가.
4. 확률 모형이 연구 질문에 필요한가 (사용자 결정).

## 4. 실험 프로토콜 (공통)

### 4.1 대치 (Missing-value Imputation)

**비교 대상과 명명 규칙**
- Model A–F와 새 후보.
- FPRM:
  - **FPRM-T(faithful)**, **FPRM-I(faithful)**: 현재 v2 이식 코드 (스냅샷 b5b8754f).
  - **FPRM-T(stab)**: §6의 안정화 버전. faithful과 반드시 이름을 구분한다.
- Adapted FPRM (AF-interp, AF-complete).
- **Lag-FPRM(paper-regime)**: SI Fig. S15에서 재구성. 동시 결측 구간에만 적용.
- **Lag-FPRM-MCAR(ours)**: 우리 일반화. 원 논문의 방법이 아님을 명시.
- linear, locf. 필요하면 GP-VAE나 SAITS 같은 학습형 대치기 하나 (선택).

**조건:** 조건 A(완전 기준 변수 1개)와 조건 B(모든 변수 MCAR)를 분리한다. 추가로 (S) 동시 결측 구간 체계 (Lag FPRM 원 조건).

**통제**

| 항목 | 규칙 |
|---|---|
| 데이터 분할 | 기존 `prepare`의 시간순 분할 |
| 마스크와 평가 위치 | 같은 (p, seed) 마스크, 같은 평가 위치. 어떤 방법이 정의되지 않는 위치는 따로 집계하고, coverage도 보고 |
| 정규화 | train 관측값 통계 |
| 정보 접근 표 | 방법마다 {과거만 / 양방향, transductive / inductive}. FDR은 lag-0(과거만)과 lag 통합(양방향)을 분리 |
| 정보를 맞춘 비교 | 단일 완전 view 입력에서 C 계열 vs FPRM-GP |
| 반복 | seed ≥ 5. seed별 짝 차이와 그 범위를 보고 |

### 4.2 상태 식별가능성 라벨 (Lorenz)

세 등급:
1. **확실히 비식별:** z만 관측된 패턴 (P2), 관측 좌표 1개 (P5′).
2. **충분조건 충족:** 같은 시점의 현재값 x(t), y(t), z(t)를 모두 관측 (항등, P4′). 그 밖에 증명된 경우만.
3. **수치 판단 (불확실):** 나머지 전부. 다음 세 지표를 따로 기록한다. 하나로 합치지 않는다.
   - (a) 주변 Jacobian 최소 특이값 σ_min (I3, 국소).
   - (b) 조건수 / `amp` (I5).
   - (c) 유한 표본 섬유 지름 δ: 별도 긴 궤적에서 관측공간 k-NN을 찾고, 그 참 상태 거리 최댓값을 끌개 지름으로 정규화. 전역 모호성의 근사다.
   - Jacobian만으로 전역 식별 라벨을 만들지 않는다.

**민감도 분석:** σ_min 임계값 {10⁻³, 10⁻², 10⁻¹} × δ 임계값 {0.02, 0.05, 0.1} × k-NN의 k {5, 20}. 주요 결론(식별 라벨별 일관성)이 격자 전체에서 유지되는지 보고한다.

### 4.3 공유 잠재 일관성

식별 쌍 (𝔅, 𝔅') (등급 2, 또는 등급 3의 같은 라벨)에 대해 같은 시점 s의 값을 비교한다.

| 지표 | 좌표 불변성 | 비고 |
|---|---|---|
| 잠재 일치 ‖z_𝔅 − z_𝔅'‖ / 시간 척도 | 상사변환만 | 보조 |
| **디코더 출력 일치** ‖R(z_𝔅) − R(z_𝔅')‖ | 재매개변수화에 불변 | 주지표 |
| **P11′ 경계 점검**: 불일치 ≤ 2·L̂·ε̂ | – | L̂는 경험적 하한임을 명시 |
| 참 상태 탐침 (z → s, kNN과 MLP, train/test 분리) | 탐침 함수족이 넓으면 근사 불변 | Lorenz |
| 마스크 섭동 안정성 (항목 하나를 지웠을 때 출력 변화) | 출력공간 | – |
| 국소 근방 보존 (trustworthiness, continuity) | 국소 쌍-Lipschitz에 근사 불변 | 위상 보존의 증명 아님 |
| 사후 일관성 (확률 모형): 같은 상태 지지집합 포함, tower 검사 (감사 §P10의 ε-근방 절차와 편향 보고) | – | – |

**비식별 쌍(등급 1)에서 점 불일치는 실패로 세지 않는다.** 확률 모형이면 사후가 섬유를 덮는지 (z-only에서 ±x 이봉성, coverage) 본다.

### 4.4 동역학 구조 (Lorenz)

| 지표 | 내용 |
|---|---|
| 상태 탐침 | z_t → s_t 복원 오차 |
| 근방 보존 | 잠재 k-NN과 상태 k-NN의 겹침 |
| 전이 일관성 | kNN 회귀 ζ_t → ζ_{t+Δ}의 오차 vs 같은 방법의 s_t → s_{t+Δ} 오차 (Δ ∈ {1, 5, 20} 스텝) |
| 잠재 근방 미래 예측 | 잠재 이웃들의 미래 상태 분산 (유사체 예측) |
| 유도 동역학 대응 | 위 전이 지도를 상태 탐침으로 옮긴 오차 |
| (보조) Lyapunov 지수, 상관 차원 | 표본 수, 잡음, 매개변수(이웃 반경, 시간 지연)에 대한 추정 편향을 함께 보고. **신경망의 미분동형성 증명으로 쓰지 않는다** |

### 4.5 불확실성 (확률 모형만)

- 조건부 NLL, 예측구간 coverage (50/90/95%), calibration 곡선, sharpness (구간 폭).
- z-only 패턴의 x 예측분포.
- 관측량 증가에 따른 사후 폭 변화 (P0 단조성의 확률판: 기댓값에서 감소해야 함).
- **점 추정 모델과는 RMSE끼리만 비교**한다. 분포 지표와 섞지 않는다.

## 5. 다음에 할 단 하나의 최소 실험 — "디코더 섬유 시험"

**질문:** C의 공유 잠재 불일치는 디코더 비단사성(H1) 때문인가, 단일 view 복원 오차(H2) 때문인가?

**왜 가장 중요한가:**
- Architecture A(FDR)의 이론적 근거는 P11′ ("복원 정확 + 역-Lipschitz 디코더 ⇒ 일관성")이다.
- H1이 맞으면 A는 올바른 방향이다.
- H2가 맞으면 디코더를 바꿔도 소용없고, 학습 마스크 분포(q_v)나 단일 view 정확도가 먼저다.
- 확률 모형(C′)도 같은 디코더 문제를 안으므로, 이 결과가 모든 후보의 우선순위를 정한다.

**설계 (기존 Model C 코드 그대로, 설정 값만 변경)**
- 데이터: Lorenz dt = 0.01 (`results/data/lorenz_20000.npz`). Lorenz에서는 현재값 디코더의 출력이 상태 자체(ℝ³)이므로 **k = 3이면 디코더가 단사일 수 있다.**
- 요인:
  - 잠재 차원 k ∈ {3, 16}
  - p ∈ {0.3, 0.7}
  - seed 0–4
  - → 20 학습. 기존 k = 16 체크포인트는 seed 0–2만 있으므로 같은 코드 경로로 모두 다시 학습한다. **GPU 예약 필요.**
- 하이퍼파라미터: 기존 `--tau 1 --m 8 --epochs 150 --patience 15`, hidden 64. k만 변경.
- 평가 (CPU, `pair_consistency.py`를 확장한 별도 진단 스크립트):
  - 패턴 {x}, {y}, {z}, {x,y}, {x,z}, {y,z}, {x,y,z} (완전 창). 그리고 현재값만 관측 패턴.
  - 패턴별 ε̂ = ‖R(z_𝔅) − s‖의 분위수 (참 상태와 비교 가능).
  - 쌍별 잠재 불일치와 출력 불일치.
  - L̂ = 표본 쌍에서 max ‖z−z'‖/‖R(z)−R(z')‖ (하한).
  - P11′ 경계 2L̂ε̂ 점검.
  - P8′ 하한 점검.
  - 조건 B test RMSE.

**예측과 판정**

| 결과 | 해석 | 다음 결정 |
|---|---|---|
| k = 3에서 {x}\|{x,y} 출력·잠재 불일치가 크게 감소 (예: 잠재 중앙값 ≤ 0.2 시간 척도), ε̂ 비슷, RMSE는 seed 변동 범위 안 | **H1 지지** | **Go:** Architecture A (FDR + 융합 요인)를 Coupled Lorenz 부분 관측(현재값 ≠ 상태)에서 구현 |
| k = 3에서도 불일치가 크고, {x}의 ε̂가 큼 (단일 view 복원 오차 0.2 이상) | **H2 지지** | 디코더보다 **학습 마스크 분포**(q_v, 단일 view 패턴 비중)를 먼저 시험. FDR 구현 보류 |
| ε̂는 작은데 불일치가 큼 | P11′의 L̂가 큼 (디코더 역함수 불안정) | 디코더 정칙화 설계와 이론 재검토 (U6) |
| {x}\|{x,z} 불일치가 하한 아래 | 수학 오류 또는 코드 오류 | 즉시 중단하고 점검 |

**성공 기준과 별개의 판정:** k = 3에서 RMSE가 나빠지면, 용량과 일관성의 상충으로 보고한다. 일관성만 좋아진 것을 "개선"이라 부르지 않는다.

## 6. FPRM 비교 검증 계획 (대규모 재실험 없이 설계만)

1. **이름 분리:**
   - `FPRM-faithful` = 현재 이식 (b5b8754f). D1–D9 차이를 문서화한 공식 충실 이식.
   - `FPRM-stab` = 최적화만 바꾼 버전: **성공 판정과 무관하게** 고정 다중 시작점 (MATLAB 초기점 + 고정 대체점 + 고정 seed 무작위 시작점 N개) 중 최소 NLL을 고른다.
   - 둘은 같은 표에 나란히, 구분된 이름으로 보고한다.
2. **기록:** 적합마다 JSON 한 줄. 초기점 목록, 각 시작점의 NLL·종료 메시지·σ_L·σ_F·σ, 선택된 시작점, jitter, 활성 집합 seed. 정체 해 플래그 (σ_L > 100). 조건 B, coupled, real에도 같은 열을 저장한다.
3. **원본 보존:** v2 결과는 그대로 둔다. 새 결과는 `results/extra/fprm_comparison/v3/`에 저장하고, 스크립트에 기존 파일 덮어쓰기 거부를 유지한다. 코드 스냅샷 해시를 결과에 기록한다.
4. **공정 비교:** 주표에는 faithful을 쓴다 (원 논문 방법에 대한 공정성). stab은 "구현 문제를 제거했을 때의 FPRM 상한"으로 함께 보고한다. faithful과 stab의 차이가 우리 결론을 바꾸면 그 사실을 명시한다.
5. **Lag FPRM:**
   - (S) 체계의 Lag-FPRM(paper-regime)은 원 논문 조건의 기준선이다.
   - Lag-FPRM-MCAR(ours)는 조건 B에서 **FPRM 계열의 가장 강한 확장**이다. 이것을 빼면 FPRM을 허수아비로 만들 위험이 있다. 비교할 가치가 있다고 판단한다.
   - 다만 우선순위는 §5의 최소 실험 다음이다. Lorenz에서만 먼저 시행한다 (GP 비용).
   - 원래 FPRM이 직접 지원하지 않는 조건(조건 B)과 우리가 확장해서 적용하는 조건을 표에 명시한다.

## 7. 확장 기준

| 단계 | 진입 조건 | 이 단계에서 주장할 수 있는 것 |
|---|---|---|
| Lorenz (dt 0.01, 0.05) | 현재 | L1–L3 전부 (참 상태 있음) |
| **Coupled Lorenz** | Lorenz에서 식별 쌍 일관성(§4.3 주지표)이 P11′ 경계 안에 있고 RMSE 손실이 없음 | 부분 관측(현재값 ≠ 상태)에서 FDR 필요성 (H3). k = 0의 하위계 독립성은 "결합해도 비식별"의 자연스러운 시험 |
| 실제 데이터 | Coupled에서 H3 지지 + FPRM 비교 (faithful/stab/Lag-MCAR) 완료 | **L1과 불확실성만.** 참 상태가 없으므로 L2·L3 주장은 하지 않는다. 마스크 섭동 안정성과 출력 일치만 보고 |

## 8. 중단 또는 방향 전환 기준

1. Lorenz에서 Architecture A의 변형(융합 × k × q_v) 어느 것도 식별 쌍 일관성을 P11′ 경계 수준으로 얻지 못할 때 → AIM의 "consistent shared latent" 부분은 **미달성으로 보고**한다. 기여를 "완전 관측 변수 없는 지연 기반 대치(L1) + 식별가능성 인식 평가 체계"로 재정의할지 사용자와 논의한다.
2. 정보를 맞춘 조건 B에서 FPRM-stab 또는 Lag-FPRM-MCAR이 C 계열과 동등하거나 더 나을 때 → 우리 방법의 성능 우위 주장은 하지 않는다. 기여를 이론과 평가로 한정한다.
3. 식별 라벨 결론이 민감도 격자에서 뒤집힐 때 → 라벨 기반 주장을 철회하고 등급 1·2(증명된 경우)만으로 보고한다.

## Decisions Requiring Discussion with ChatGPT and the User

1. **§5 최소 실험 승인 여부와 GPU 예약.** 20회 학습, Lorenz, 기존 코드에서 k만 변경.
2. **AIM 문장의 수학적 해석 범위:** "the delay embedding of each variable is diffeomorphic to the others"를 "식별 가능한 view(조합)에 한해, 위상적(필요 시 매끄러운) 대응"으로 한정해 보고하는 데 동의하는지. AIM 원문은 바꾸지 않는다.
3. **확률 모형(C′)이 연구 질문에 필요한가.** 불확실성이 하류 분석(인과, 예측)에 필요하면 방법 A(생성 ELBO), 보정된 예측이 목표면 방법 B. 아니면 결정론적 A로 충분하다.
4. **FDR 대치의 시간 정보 규칙:** 주 결과를 lag-0(과거만)으로 할지, 양방향(lag 통합)도 별도 결과로 낼지.
5. **FPRM 비교 정책:** faithful을 주표로, stab을 보조로 하는 데 동의하는지. Lag-FPRM-MCAR(우리 확장)을 조건 B 기준선에 넣을지.
6. **식별 라벨링 기준과 민감도 격자의 범위.**
7. **새로움의 주장 범위:** 구성 요소는 기존 기법이다. 기여를 "완전 관측 변수 없는 동역학 복원에서 공유 상태 학습을 이론적 조건과 함께 검증"으로 둘지. Lv et al. 2025 같은 응용 연구는 원문 확인이 필요하다.
8. **실험 규모:** seed ≥ 5, dt ∈ {0.01, 0.05}부터. dt = 0.01은 선형보간이 매우 강해 방법 간 구별력이 낮다는 기존 관찰을 반영할지.
