# Phase 3A — Decoder Fiber Diagnostics on Existing Checkpoints (2026-10-27)

**목적:** 기존 Model C (및 E)의 잠재 불일치가 무엇으로 설명되는지, 반증 가능한 진단으로 확인한다. 후보는 다섯 가지다.
1. 전체 잠재공간에서의 디코더 비단사.
2. 학습된 잠재 support에서의 비단사.
3. 출력상 구별되지 않는 서로 다른 잠재 (Case A).
4. 단일 view의 정보 부족.
5. 학습 마스크 분포 밖(OOD) 입력에 대한 일반화 실패.

**코드와 산출물** (CPU 전용, 학습 없음, 기존 파일 미변경):
- `results/extra/phase3a_decoder_diagnostics/fiber_diag.py` → `patterns.csv`, `pairs.csv`, `decoder_jacobian.csv`, `near_collisions.csv`, `fiber_diag.log`
- 체크포인트: Model C (`results/checkpoints/lorenz_C_p{0.3,0.7}_s{0,1,2}.pt`), Model E Q=0.5 (`aim_autonomous_20261027/model_E_viewdrop/checkpoints/`). 총 12개.

**Phase 2.5 주장의 수정:** "C의 디코더 R: ℝ¹⁶ → ℝ³는 전체 공간에서 단사일 수 없다"는 참이다 (불변영역). 하지만 **관련 있는 것은 학습된 잠재 support(저차원일 수 있음) 위의 단사성**이다. 이 문서는 support 위에서 측정한다. 그리고 ℝ³ → ℝ³로 바꾼다고 단사성이 보장되지 않는다는 점도 파일럿에서 확인됐다 (문서 2).

## 1. 설정

- **평가 단위:** Lorenz test 구간의 과거 창 (m = 8, τ = 1)과 그 시점의 참 상태 s_t (정규화 단위 x, y, z). 모든 패턴은 **같은 t**에서 비교한다.

**패턴**

| 계열 | 이름 | 정의 |
|---|---|---|
| ART (인위적 view 제거) | x, y, z, xy, xz, yz, xyz | 남긴 view는 8개 lag가 전부 관측됨, 나머지 view는 비움 |
| NAT (자연 마스크) | NATe1, NATe2 | 평가 결측률 p에서 새로 뽑은 독립 MCAR 두 개 |
| | NATt | 학습 입력 결측률 (1−p)·(1−0.2)로 뽑은 MCAR |
| | NATe1−1 | NATe1에서 관측 항목 하나를 더 지움 (중첩) |
| NATV (자연 마스크 + view 제거) | x\|nat, xy\|nat, xz\|nat | NATe1의 해당 view 관측만 남김. 관측 위치는 자연 마스크 그대로 |

**기록 항목**
- e_B = ‖R(z_B) − s_t‖ (3차원 상태 오차, 정규화 단위).
- view별 관측 lag 수.
- **학습 마스크 분포에서 그 마스크 유형(view별 관측 수 벡터)이 나올 확률.** C: 항목별 Bernoulli(q_tr), q_tr = (1−p)·0.8. E: 위 분포와 view-subset 탈락(Q = 0.5)의 혼합. 해석식으로 계산.
- 잠재 OOD 정도: 그 패턴의 잠재에서 학습형 마스크(NATt) 잠재 구름까지의 최근접 거리 / 척도.
- **척도:** 같은 체크포인트 안에서, 자연 마스크 잠재의 임의 두 시점 간 거리 중앙값 (ART 쌍은 xyz 잠재 기준). **다른 모델의 잠재 좌표는 직접 비교하지 않는다.**

**Case 정의** (두 기준으로 민감도 확인)

| | 정확 (e) | 출력 유사 (d_R) | 잠재 상이 (d_z/척도) |
|---|---|---|---|
| strict | ≤ 0.10 | ≤ 0.10 | ≥ 0.30 |
| loose | ≤ 0.25 | ≤ 0.25 | ≥ 0.50 |

- **A:** 둘 다 정확, 출력 유사, 잠재 상이.
- **B:** 하나 이상 부정확, 잠재 상이.
- **C:** 둘 다 정확, 잠재 일치.
- **D:** 관측이 더 많은 패턴의 오차가 e 기준 이상 더 큼.

## 2. 학습 마스크 분포 분석

| 질문 | 답 (해석식, `patterns.csv`의 `train_prob_of_type`) |
|---|---|
| 1. C의 학습 중 view 조합 | 항목별 독립 Bernoulli(q_tr). p = 0.3이면 q_tr = 0.56, view당 관측 lag 수 평균 4.5. p = 0.7이면 q_tr = 0.24, 평균 1.9. view가 통째로 빈 창은 (1−q_tr)⁸ = 0.0014 (p = 0.3), 0.11 (p = 0.7) |
| 2. 관측 지연 좌표 수 분포 | view별 Binomial(8, q_tr)의 곱 |
| 3. x-only, x+y 입력의 빈도 | **완전한 x-only(8 lag) + y, z 없음**: C에서 q_tr⁸(1−q_tr)¹⁶ ≈ 10⁻⁸ (p = 0.3), 10⁻⁷ (p = 0.7). 표 값은 0.0000. x+y 완전도 마찬가지다. 자연 마스크에서 view만 지운 NATV:x도 p = 0.3에서 ≈ 0 (C) |
| 4. 인위적 view 제거의 OOD 정도 | 마스크 유형 확률 ≈ 0. 잠재 공간에서도 C의 ART:x 잠재는 학습형 잠재 구름에서 **척도의 0.67배** 떨어져 있다 (p = 0.3). xyz는 0.15배, 자연 마스크는 0.10–0.15배. **OOD가 측정상으로도 확인된다** |
| 5. Model E의 완화 정도 | E(Q = 0.5)는 단일 view 유형 확률을 C의 ~0에서 0.0008 (ART:x, p = 0.3)과 0.014–0.024 (NATV:x)로 올린다. 잠재 OOD 거리 ART:x 0.67 → 0.37 (p = 0.3). p = 0.7에서는 E에서도 완전 8-lag view가 드물어 (q_tr⁸ ≈ 10⁻⁵) 완화가 작다 |

## 3. 패턴별 상태 복원 오차 (중앙값, 3 seed 평균, `patterns.csv`)

| 패턴 | C p = 0.3 | E p = 0.3 | C p = 0.7 | E p = 0.7 |
|---|---|---|---|---|
| NAT:NATe1 (평가 분포) | **0.034** | 0.083 | **0.095** | 0.137 |
| NAT:NATt (학습형) | 0.033 | 0.084 | 0.104 | 0.142 |
| ART:xyz (완전 관측, OOD) | 0.045 | 0.096 | 0.220 | 0.247 |
| ART:x | 0.337 | **0.132** | 0.400 | 0.390 |
| ART:y | 0.693 | **0.259** | 0.571 | 0.582 |
| ART:z (Γ 비식별) | 0.930 | 0.949 | 0.943 | 0.914 |
| ART:xz | 0.060 | 0.115 | 0.218 | 0.235 |
| ART:xy | 0.166 | 0.131 | 0.319 | 0.369 |
| NATV:x (자연 + view 제거) | 0.449 | **0.128** | 0.442 | **0.305** |

관찰:
1. **같은 정보량에서도 분포 안·밖에 따라 오차가 크게 다르다.** C p = 0.7에서 완전 관측 ART:xyz(OOD, 24개 좌표)의 오차 0.22가 자연 마스크(평균 7개 좌표) 0.095보다 **2.3배 크다.** 관측 정보가 더 많은데 나빠졌으므로 정보 부족으로 설명할 수 없다 → **OOD 일반화 실패의 직접 증거.**
2. **E가 단일 view 오차를 크게 줄인 조건은, E의 학습 분포에 그 패턴이 실제로 들어간 조건과 일치한다.**
   - p = 0.3: ART:x 0.34 → 0.13, ART:y 0.69 → 0.26.
   - p = 0.7: 거의 변화 없음. E에서도 완전 view가 드물기 때문이다.
   - 자연 마스크 위의 view 제거(NATV:x)는 p = 0.7에서도 0.44 → 0.31로 줄었다 (E에서 유형 확률 0.024).
   → **단일 view 실패의 상당 부분은 정보 부족이 아니라 학습 분포 문제**다.
3. **정보 부족이 지배하는 경우도 있다.** ART:z는 어떤 모델에서도 ≈ 0.93 (Γ 비식별, P2). 그리고 E로 분포에 넣은 뒤에도 남는 ART:x 0.13 (p = 0.3)은 FPRM-GP (x→y,z 0.05)보다 크다. 이 잔여분이 정보 부족인지 용량 문제인지는 이 진단으로 구분되지 않는다.
4. **대가:** E는 평가 분포 오차를 키운다 (0.034 → 0.083). 학습 손실이 패턴별 위험을 패턴 확률로 가중한 합이기 때문이다 (Knockout 정리, 문헌).

- **Case A (출력은 같고 정확한데 잠재가 다름)는 실제로 존재한다.**
  - 가장 뚜렷한 예: C p = 0.3 ART:xz | ART:xyz. 출력 차이 0.055, 두 오차 0.060 / 0.045인데 잠재 차이가 척도의 0.70배. strict 기준 80%, loose 기준 99.5%의 창이 Case A다.

- **Case B (부정확 + 잠재 상이)는 인위적 단일 view 쌍에서 지배적이다** (C에서 94–100%). E는 p = 0.3에서 이를 50–60%로 낮춘다. 위 §3과 합치면, 이 Case B는 주로 OOD 일반화 실패로 설명된다.
- **Case C (정확 + 일치):** 분포 안 쌍에서 다수다 (C p = 0.3 loose 92%). 항목 하나 차이(NATe1 | NATe1−1)는 98%가 Case C다. **분포 안의 작은 마스크 섭동에는 일관적이다.**
- **Case D (관측 추가 시 악화):** C p = 0.3 ART:x → ART:xy에서 12%, p = 0.7에서 21%. 그리고 ART:xyz(OOD)가 자연 마스크보다 나쁜 것(§3-1). 융합 방식만의 문제인지 학습 분포의 문제인지는 이 데이터로 구분되지 않는다. 다만 xyz의 악화는 정보가 늘었는데도 생기므로 **분포 문제 쪽 증거가 더 강하다.**

## 5. 디코더의 국소 구조 (support 위, `decoder_jacobian.csv`, `near_collisions.csv`)

support = 자연 마스크(NATt, NATe1) 잠재.

| 지표 | C 0.3 | C 0.7 | E 0.3 | E 0.7 |
|---|---|---|---|---|
| 디코더 Jacobian 특이값 (중앙값) σ₁ / σ₂ / σ₃ | 1.80 / 1.41 / 0.71 | 1.69 / 1.13 / 0.48 | 1.52 / 1.07 / 0.50 | 1.96 / 1.21 / 0.58 |
| σ₃ 5% 분위 | 0.44 | 0.27 | 0.25 | 0.30 |
| support의 PCA 95% 차원 | 4.7 | 5.3 | 3.0 | 4.3 |
| support의 TwoNN 내재차원 | **4.9** | 2.7 | **6.1** | 3.0 |
| 출력 최근접 쌍의 잠재 거리 / 척도 (중앙값) | 0.27 | 0.36 | 0.17 | 0.32 |
| near-collision 비율 (출력 < 0.05, 잠재 > 0.3) | **0.27** | 0.26 | 0.10 | 0.19 |

해석 (과장하지 않기 위해 분리):
- 16 → 3 디코더 Jacobian의 계수는 support 위에서 3이다 (σ₃ > 0.25). 출력 방향으로 **국소적으로는 비특이**다. 계수만으로는 support 위 비단사를 결론 낼 수 없다.
- 그러나 support의 내재차원(TwoNN 2.7–6.1, PCA 3–5)은 상태 끌개의 차원(≈ 2.06, 3차원 공간)보다 크다. 그리고 출력이 거의 같은 이웃 쌍의 10–27%가 잠재에서 멀다. 이는 **support가 상태 외의 성분(마스크 의존 성분)을 포함하고, 디코더가 그 방향을 무시한다**는 것과 부합한다. 즉 support 위의 근사적 다대일 (Case A의 기하학적 형태)이다.
- 역-Lipschitz 경험적 하한 (잠재 거리 / 출력 거리의 최댓값)은 260–400으로 크다 (`near_collisions.csv`). P11′의 L이 크면 출력이 정확해도 잠재 일치를 보장하지 못한다.
- 이 진단은 모두 **support 표본**에서 했다. 임의 잠재 벡터는 쓰지 않았다. ART 패턴의 잠재는 support에서 떨어져 있어 (§2-4) 디코더 진단 표본에 넣지 않았다.

## 6. 가설별 증거와 반례

| 가설 | 지지 증거 | 반대 증거 / 한계 |
|---|---|---|
| H1: 전체 ℝ¹⁶에서의 디코더 비단사 | 수학적으로 참 | 관련 없음. support는 저차원 |
| H1′: support 위 근사 다대일 (Case A) | support 내재차원 > 상태 차원. near-collision 10–27%. 분포 안 쌍의 Case A 8–31%. ART:xz\|xyz의 80% | strict/loose 기준에 민감. 잠재 차이가 출력에 영향이 없으면 대치 성능에는 무해 |
| H2: 단일 view 정보 부족 | z-view는 확실 (P2). E로 분포에 넣어도 남는 x-view 오차 0.13 > FPRM 0.05 | x-view 오차 대부분(0.34 → 0.13)은 학습 분포만 바꿔서 사라짐 |
| H3: 학습 마스크 분포 / OOD | 단일 view와 완전 관측 패턴의 학습 확률 ≈ 0. 잠재 OOD 거리. **완전 관측(정보 최대)이 자연 마스크보다 나쁨 (C p = 0.7: 0.22 vs 0.095)**. E가 분포에 넣은 조건에서만 개선 | E의 개선도 FPRM 수준에는 못 미침. 용량과 상충이 섞임 |

**결론의 한계:**
- Lorenz dt = 0.01만 봤다. seed 3개, p 두 개.
- Case 임계값에 따라 비율이 크게 변한다 (예: NATe1 | NATe2의 Case A 31% vs 8%).
- 잠재 거리 척도는 체크포인트별 정규화라 모델 간 직접 비교는 근사다. 좌표 불변 지표는 d_R와 e_B다.
- E와 C는 학습 목표 분포도 다르므로, E–C 차이를 순수한 "분포 커버리지" 효과로 해석할 수 없다.
