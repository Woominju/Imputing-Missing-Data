## 1. 진단이 FDR 설계에 주는 제약

1. 단일 view와 view 조합 실패의 상당 부분은 **학습 마스크 분포 밖 입력** 때문이다 (문서 1 §3, §6). FDR은 이것을 고치지 않는다. 그래서 **학습 마스크 분포를 FDR 설계의 일부로 명시해야 한다.**
2. 분포 안에서는 출력이 일치하는데 잠재가 다른 경우(Case A)와, 상태 차원보다 큰 support 내재차원이 관찰된다. 디코더 출력을 24차원(완전 지연)으로 늘리면 "출력에 영향 없는 잠재 방향"을 줄일 **가능성**이 있다. 이것이 FDR이 겨냥하는 효과다. 아직 가설이다.
3. 잠재 차원을 출력과 같게 줄이는 것(k = 3)은 안정적 역함수를 주지 않았다 (σ_min ≈ 0.05). **k를 줄이는 것으로 일관성을 얻으려 하지 않는다.**

## 3. Full Delay Reconstruction Target과 Masked Loss의 정확한 정의

**기호**
- 세그먼트 X ∈ ℝ^{W×n}, 관측 M, 학습 은닉 H ⊆ M (세그먼트 단위로 한 번 뽑음), 입력 B = M − H.
- 창은 현재 코드처럼 **마스킹 후에** 만든다 (`delay_embed(X·B, B)`). 이것은 Phase 2.5 L3로 검증된 경로다.
- anchor t ∈ {span, …, W−1}, span = (m−1)τ. 출력 Ŷ[t, i, k] ≈ x_i(t − kτ), k = 0, …, m−1.

**원시 위치의 중복도**

    c(u) = #{(t, k) : t − kτ = u, span ≤ t ≤ W−1, 0 ≤ k ≤ m−1}

**손실 (원시 항목 단위 평균):**

    L = Σ_{u,i} H[u,i] · 1{c(u) > 0} · (1/c(u)) Σ_{(t,k): t−kτ=u} (x_i(u) − Ŷ[t,i,k])²  /  Σ_{u,i} H[u,i] · 1{c(u) > 0}

- 원시 항목마다 총가중이 1이 된다. 그래서 세그먼트 경계 근처 항목이 과소가중되거나, 중앙 항목이 m배로 과대가중되지 않는다.
- 각 창의 예측을 **개별적으로** 훈련한다 (제곱오차의 평균).
- 대안 "lag 예측들을 먼저 평균한 뒤 제곱오차"는 다른 목적함수다. 개별 창 예측이 부정확해도 평균만 맞으면 손실이 작아서, P11′가 요구하는 창별 ε를 줄이지 않는다 → **채택하지 않는다.**

**중복도 실측** (`fdr_multiplicity.log`)

| (m, τ, K) | W | c(u) 범위 | c = m인 위치 |
|---|---|---|---|
| (8, 1, 64) (현재) | 71 | 1–8 | 57/71 |
| (8, 5, 64) | 99 | 1–8 | **29/99** |
| (8, 5, 16) | 51 | 1–4 | **0/51** (c = m 위치 없음) |
| (4, 10, 64) | 94 | 1–4 | 34/94 |

- τ > 1이면 같은 원시 위치가 τ 간격의 anchor들에서만 반복된다. K < (m−1)τ이면 c = m인 위치가 없다.
- **K ≥ (m−1)τ를 요구**하고, 위치별 c(u) 분포를 결과에 기록한다.
- 1/c 가중은 세그먼트 안의 공정성을 맞춘다. 하지만 학습 세그먼트가 무작위로 뽑히므로, 시계열 전체 기준으로는 각 원시 시점의 기대 가중이 거의 같다 (경계 효과는 세그먼트 단위).

**원시 시점별 평가 vs 창 좌표별 평가:**
- **주지표는 원시 시점별 평가다.** 평가 정답 위치마다 하나의 대치값으로 RMSE를 낸다 (§4 프로토콜).
- 창 좌표별 평가(모든 (t, k) 출력에 대한 오차)는 P11′의 ε 진단용 보조지표다. 같은 정답을 여러 번 세므로 주지표로 쓰지 않는다.

## 4. 과거 전용 vs 양방향 평가

| 프로토콜 | 대치값 x̂_i(u) | 쓰는 관측 | 비교 대상 (같은 정보) |
|---|---|---|---|
| **Causal / past-only** | anchor t = u의 lag-0 출력 Ŷ[u, i, 0] | 시점 ≤ u | C, B, locf, FPRM-I(과거 방향 창으로 바꾼 경우만) |
| **Bidirectional / offline (지평 h)** | anchor t ∈ [u, u+h]의 lag (t−u)/τ 출력들의 평균 (h ≤ (m−1)τ) | 시점 ≤ u + h | linear 보간, FPRM-T (미래 방향 창 + transductive) |

- `impute_fdr(model, X, M, mode="past"|"bidir", h)`로 구현한다. 결과 표의 열 이름에 프로토콜과 h를 넣는다.
- AIM이 온라인 인과 대치만을 요구하지는 않으므로 양방향도 정당하다. 다만 **같은 정보 접근끼리만** 비교한다.

## 5. P11′과 실제 학습 목표의 간극

| # | 양 | 학습에서 직접 최소화되나 | 측정 가능성 |
|---|---|---|---|
| 1 | 학습 중 숨긴 일부 좌표(H)의 오차 | 예 (L) | 학습/검증 손실 |
| 2 | 입력에 남긴 관측 좌표의 복원 오차 | **아니오** (복사 방지를 위해 손실에서 제외) | 시뮬레이션과 실제 모두 측정 가능 |
| 3 | 전체 지연벡터 F_all의 복원 오차 (창별) | 아니오. 1의 기대값을 통해 간접적 | **시뮬레이션에서만** (참값 있음) |
| 4 | P11′의 ε: **식별 패턴, 점별** 전체 F_all 오차 | 아니오 | 시뮬레이션에서만. 분위수로 보고 |
| 5 | 실제 데이터 | – | 원래 결측의 정답이 없음. 인위 은닉 항목으로만 1을 추정. 4는 측정 불가 |

- 마스크 MSE의 최소화는 **조건부 평균**을 추정한다 (O4). 식별 패턴에서는 그것이 참값이므로 기대 의미에서 ε → 0을 지향한다. 하지만 **점별 ε가 작다는 보장도, 역-Lipschitz L이 작다는 보장도 없다.**
- 그러므로 "FDR을 출력하면 P11′의 가정이 충족된다"고 주장하지 않는다. 시뮬레이션에서 ε(분위수)와 L̂(경험적 하한)를 측정해 **경계 2L̂ε̂와 관찰된 잠재 불일치를 비교하는 것**이 검증이다.
- 문서 1에서 C의 L̂ 하한은 260–400으로 컸다. FDR에서 이 값이 줄어드는지가 핵심 관찰 대상이다.

## 7. 다음 단계의 최소 FDR 실험 (승인 후)

**사전 단계 (권장안 B, 문서 4 결론 참조):** 학습 마스크 분포를 확정한다.
- C 구조 그대로 Q ∈ {0, 0.15, 0.5}와 "자연 마스크 위 view 탈락"(완전 view가 아니라 자연 마스크에서 view를 지움)을 비교한다.
- 기존 Q 체크포인트를 재사용하고, 필요한 경우만 새로 학습한다.
- 패턴별 위험 곡선을 보고, 이후 실험의 마스크 분포를 하나 고른다.

**FDR 최소 실험:**
- 요인: 디코더 {현재값(C), 완전 지연(FDR)} × 융합 {스칼라, 정밀도}. k = 8, 위에서 정한 마스크 분포.
- 데이터: Lorenz dt ∈ {0.01, 0.05}, p ∈ {0.3, 0.7}.
- seed: 파일럿 1개 → 판정 후 5개.

**측정:**
- 원시 시점 RMSE (past-only와 bidirectional 분리).
- 패턴별 ε 분위수, L̂.
- 같은 상태 쌍의 d_R(주)와 d_z(보조).
- Case A–D 비율 (strict와 loose 둘 다).
- support 내재차원, near-collision.

**Go 기준 (제안):** 분포 안 패턴 쌍에서 FDR의
1. 출력 일치 d_R가 C 이하이고,
2. Case A 비율과 L̂가 seed 간 일관되게 감소하며,
3. past-only RMSE가 seed 변동 범위 안에서 유지될 것.

**No-go:** L̂와 Case A가 줄지 않으면, 디코더 출력 차원으로는 잠재 일관성이 생기지 않는다는 반증이다. 그때는 수학 검토(문서 4의 C 경로)로 돌아간다.
