### A. OOD와 관측 정보량

- **Bayes 위험의 단조성 [Verified, 표준 결과]:** 같은 상태에서 관측 σ-대수가 커지면 (𝔅 ⊆ 𝔅′), 참 조건부 평균 예측기의 기대 제곱오차 E[Var(g | O_𝔅′)]는 E[Var(g | O_𝔅)] 이하다 (분산 분해 / tower).
  - 이것은 **평균에 대한** 진술이다. 개별 상태에서 오차가 커지는 것은 막지 않는다.
  - 학습된 모델은 Bayes 예측기가 아니므로 이 보장이 적용되지 않는다.
- **관찰 [Empirical]:** C, p = 0.7에서 완전 관측 ART:xyz의 상태 오차(0.220)가 자연 마스크(0.095)보다 크다. 이는 "학습된 모델이 추가 정보를 안정적으로 쓰지 못한다"는 증거다. 원인 후보는 넷이고, 이 데이터로는 분리되지 않는다 **[Unresolved]**:

  2. 관측 변수 구성 (세 view 모두 8-lag 완전).
  3. 스칼라 융합의 가중치 w_i = 관측 수가 학습 범위(평균 1.9) 밖의 값(8)을 받음.
  4. 인코더가 관측 수 8의 입력을 학습한 적 없음.

### C. Near-collision의 의미 (참 상태 거리 포함) [Empirical]

출력 최근접 쌍(NATe1 표본 → 다른 시점의 NATe2 표본, d_R < 0.05) 중 참 상태 거리별 분포:

| | C 0.3 | C 0.7 | E 0.3 | E 0.7 |
|---|---|---|---|---|
| 출력 근접 쌍 중 참 상태 < 0.05 | **0.645** | 0.107 | 0.253 | 0.054 |
| 그 쌍들의 d_z 중앙값 | 0.213 | 0.252 | 0.119 | 0.223 |
| 같은 상태·출력 근접 쌍의 d_z 중앙값 | 0.217 | 0.249 | 0.126 | 0.224 |
| 출력 근접 쌍 중 참 상태 > 0.2 | 0.001 | 0.204 | 0.056 | 0.401 |

해석:
- **C, p = 0.3:** 출력이 가까운 쌍의 대부분은 실제로 거의 같은 상태다. 그들의 잠재 거리(0.213)는 같은 상태에 다른 마스크를 준 쌍(0.217)과 같다.
  - → 서로 다른 상태를 같은 출력으로 보내는 "진짜 비단사"의 증거가 아니다. **같은 상태 안에서 마스크에 따라 잠재가 흔들리는 성분(출력에 영향 없는 방향)** 으로 설명된다.
  - Phase 3A의 "near-collision = 디코더 비단사" 해석은 이것으로 수정한다.
- **p = 0.7:** 출력 근접 쌍의 20–40%는 실제로 다른 상태다. 이는 디코더의 비단사가 아니라 **복원 오차**(출력이 상태를 정확히 나타내지 못함)를 반영한다.

## 3. P11′과의 관계

- P11′: ‖z_B − z_B′‖ ≤ 2Lε. 필요 조건은 두 가지다.
  - (i) **점별** 복원 오차 ε (식별 패턴).
  - (ii) 해당 영역에서 R⁻¹의 **Lipschitz 상한** L.
- (i): FDR의 ε는 중앙값 0.34, 90% 분위 0.83 (24차원)로 작지 않다. 최종 lag 오차가 큰 것이 주 기여다. **"정확한 F_all 복원"은 달성되지 않았다 [Empirical].**
- (ii): L의 상한은 측정할 수도 증명할 수도 없었다. 거리 비율, 국소 Jacobian, near-collision은 하한이나 국소 정보일 뿐이다 **[Unresolved]**.
- 그러므로 **FDR이 P11′의 조건을 만족한다고 말할 수 없다.** 관찰된 잠재 분산 감소는 P11′의 예측 방향과 일치하지만, 그 메커니즘(작은 ε × 유한 L)이 작동했다는 증거는 아니다.
- 다른 설명도 가능하다 **[Hypothesis]**:
  - 디코더 출력 차원 증가로 "출력에 영향 없는 잠재 방향"의 수가 줄었다 (16 − 3 = 13차원 → 16 − 24 < 0).
  - 용량 증가 (+1,365 파라미터).
  - 학습 목표 난이도 변화로 인한 다른 최적화 경로.

## 4. 디코더 안정성

- FDR 디코더의 Jacobian은 이번에 측정하지 않았다 **[Unresolved]**.
- Phase 3A에서 C 디코더 (16 → 3)는 support 위에서 계수 3, σ₃ 0.25–0.71이었다. 이것은 국소 정보다.
- FDR 디코더 (16 → 24)는 원리상 계수 16(단사 몰입)이 가능하다. 실제 계수와 최소 특이값은 다음 단계 측정 항목이다.

## 5. 마스크 분포와의 상호작용

- Q = 0.15는 C와 FDR 모두에서 같은 상태의 정확도와 출력 일치를 약간 낮췄다. test RMSE는 낮췄다. 둘이 서로 다른 지표라는 점에 주의해야 한다:
  - test RMSE: 결측 위치만.
  - 상태 오차 e: 관측된 변수의 출력까지 포함.
- FDR 효과(잠재 분산 감소)는 두 Q에서 비슷하다. 상호작용의 증거는 없다 **[Empirical, seed 1]**.

## 6. 주장할 수 있는 것과 없는 것

**주장할 수 있는 것:**
- FDR 구현은 정렬, 누수, 중복도, 인과성, 수치 안정성 테스트를 통과했다. 기존 파이프라인과 비트 단위로 호환된다 **[Verified]**.
- 기존 C의 near-collision은 서로 다른 상태의 충돌이 아니라 같은 상태에서 마스크 의존 잠재 변동이 주원인이다 (p = 0.3) **[Empirical, 3 seed]**.
- 단일 seed에서 FDR은 잠재 분산을 소폭 줄였지만 출력 일치와 정확도는 바꾸지 못했다 **[Empirical]**.

**주장할 수 없는 것:**
- FDR이 공유 상태 일관성을 개선한다는 것 (seed 1, 작은 차이).
- FDR이 P11′의 조건을 만족하거나 단사 디코더를 학습했다는 것.
- 학습된 잠재가 미분동형 상태 표현이라는 것.
- Lorenz 결과가 FDR의 이론적 유용성을 검증한다는 것 (§2.3 of 구현 검증 문서: Lorenz의 현재값은 상태 그 자체).
