## 7. 요약 [Empirical, 단일 seed]

- **FDR vs C (같은 Q):**
  - 같은 상태의 잠재 분산(모델 내 정규화 d_z)이 줄었다: q50 0.39 → 0.34, q90 0.83 → 0.70. 정확한 쌍만 보면 0.35 → 0.30.
  - 척도 정규화와 무관한 kNN 탐침과 근방 겹침도 소폭 나아졌다 (0.183 → 0.170, 0.143 → 0.156).
  - **그러나 좌표 불변 주지표인 lag-0 출력 일치(d_R)와 상태 정확도는 개선되지 않았다** (0.149 vs 0.154, 0.106 vs 0.114).
  - Phase 3B 지침의 결과 C("출력 개선 없이 잠재만")와도 정확히 일치하지 않는다. 출력은 같은 수준, 잠재 지표는 소폭 개선이다.
- **Q 효과:** Q = 0.15는 test RMSE를 C에서 낮췄다 (0.154 → 0.144, FDR은 0.153 → 0.149). 하지만 C0의 epoch 상한 도달과 seed 범위를 고려하면 판단할 수 없다. 같은 상태 일관성과 정확도는 Q로 나빠지거나 비슷했다.
- **상호작용:** FDR의 잠재 개선은 Q = 0, 0.15 모두에서 비슷하다 (0.34). 상호작용의 증거는 없다.
- **seed 한계:** seed 1개. 일관성 지표의 seed 간 변동은 이 조건에서 측정하지 않았다. 기존 dt = 0.01 체크포인트에서 C의 d_z q50 seed 범위는 0.20–0.28 (p = 0.3)이었다.
