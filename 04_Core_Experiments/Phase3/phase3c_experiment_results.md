**FDR − C의 seed별 대응 차이와 test 블록 bootstrap 95% CI** (블록 100스텝 × 30개, 2,000회):

| probe | seed 0 | seed 1 | seed 2 |
|---|---|---|---|
| ridge | +0.033 [+0.011, +0.058] | +0.072 [+0.055, +0.089] | +0.047 [+0.024, +0.068] |
| kNN | **−0.021** [−0.027, −0.014] | **−0.032** [−0.038, −0.026] | **−0.034** [−0.041, −0.027] |
| MLP | **−0.010** [−0.014, −0.006] | **−0.021** [−0.027, −0.014] | **−0.012** [−0.018, −0.005] |

- **비선형 probe(kNN, MLP)에서는 3 seed 모두 FDR 잠재가 y를 더 잘 드러낸다.** 선형 probe에서는 반대다. → "FDR이 y 정보를 더 보존한다"는 **probe 족에 의존**하는 결론이다.
- 블록 CI는 **test 구간의 시간 변동만** 반영한다. 학습 seed 간 변동은 seed 3개의 범위로만 볼 수 있다.
- **블록 길이 근거:** 제곱오차의 자기상관이 lag 1에서 0.43–0.48, lag 5 이후 |ACF| ≤ 0.11 (`eval_acf.csv`). 100스텝은 상관 길이보다 충분히 길다.
- 두 잠재 모두 **같은 MLP probe의 원본 창 특징(0.078)보다 낫다.** 원본 창 probe는 유한 용량이라 정보 상한이 아니다.
- MLP probe의 FDR 잠재(0.035–0.050)는 분석적 2차 유한차분(0.064–0.074, coverage 34%)보다 낮은 오차를 **전체 test 시점에서** 낸다.

## 5. Multi-view 기여: 같은 x 마스크에서 z의 효과 (MLP probe, seed 0 / 1 / 2) [Empirical]

| 조건 | C | FDR | 성격 |
|---|---|---|---|
| xz 모델, 자연 xz 입력 | 0.045 / 0.061 / 0.061 | 0.035 / 0.040 / 0.050 | 분포 안 |
| xz 모델, **z 사후 제거** (x 마스크 동일), probe 재적합 | 0.106 / 0.114 / 0.125 | 0.085 / 0.090 / 0.109 | **OOD** (AE가 z 없는 입력을 거의 본 적 없음) |
| xz 모델, z 제거, 자연 입력 probe를 그대로 적용 | 0.172 / 0.192 / 0.184 | 0.163 / 0.153 / 0.159 | OOD 전이 |
| x-only 모델 (같은 x 마스크), seed 0 | 0.169 | 0.086 | 분포 안, 용량·학습 분포 다름 |
| 원본 창: x만 → xz | 0.116 → 0.078 (3 seed 평균 0.109 → 0.079) | | 같은 probe, 같은 x 마스크 |
| xz 모델, x 제거 (z-only 스트레스) | ≈ 1.00 | ≈ 1.01 | Γ 비식별 (예상대로) |

- **z를 더하면 같은 x 관측에서 y 추정 오차가 대략 절반**으로 줄었다. 확인 경로는 셋이다:
  1. 학습된 xz 모델에서 z 제거 (OOD, 재적합 probe)
  2. 분포 안 x-only 모델 (seed 0)
  3. 원본 창 probe
- 한계:
  - 1은 OOD다.
  - 2는 모델 용량(파라미터 약 절반)과 학습 분포가 다르다.
  - 3만 같은 모델(probe)과 같은 x 마스크다. 3에서도 kNN probe는 오히려 xz가 나쁘다 (0.33 → 0.41, 차원 증가 효과로 보임).
- 관측가능성 감사(`phase3c_observability_audit.md`)와의 관계:
  - 국소 조건수에서는 z가 y 증폭을 줄인다 (1.4 → 0.56).
  - 유한 표본 이웃 지표(깨끗한 참조 창, 완전 kNN)에서는 x 창만으로도 y 이웃 차이가 0.035로 x+z와 같았다.
  - 즉 **정보적으로는 x 창이 이미 y를 거의 결정할 수 있지만, 유한 용량의 학습·추정에서는 z가 실질적으로 돕는다.** [Empirical / Hypothesis 해석]
- **z-only에서 y를 복원하지 못하는 것은 실패가 아니라 Γ 대칭의 올바른 반영이다** [Verified 이론과 일치].

## 7. 실패와 한계 (모두 기록)

1. **평가 버그 (수정):** 첫 `evaluate.py`가 "z 제거" 입력에서 z가 아니라 x 열을 지웠다. 그래서 "z 제거"와 "x 제거" 결과가 같았다 (≈ 1.0). `evaluate.py`를 고쳤고, z 제거 결과만 `multiview_fix.py`로 다시 계산했다 (`eval_probe_zremoved.csv`). `eval_probe.csv`의 `*_zremoved_refit` 행은 **잘못된 값(실제로는 x 제거)** 이므로 쓰지 않는다. x 제거 행은 유효하다.
2. 평가 실행 중 seed 자료형 오류로 첫 평가가 중단됐다. 고친 뒤 처음부터 다시 실행했다.
3. 같은 Lorenz 궤적 하나를 쓴다. seed는 마스크·초기화·배치의 반복이지 독립 궤적이 아니다.
4. x-only 대조군은 seed 0만 있다.
5. 선형 probe는 두 잠재 모두에서 나쁘다 (0.46–0.53). 잠재가 y에 대해 비선형이다.
