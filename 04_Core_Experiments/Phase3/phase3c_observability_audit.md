# Phase 3C — Observability Audit: Lorenz observed through x and z (2026-10-27)

태그: **[Verified]** 증명 또는 정확한 계산 / **[Empirical]** 유한 표본 측정 / **[Hypothesis]** / **[Unresolved]**.

- 코드: `results/extra/phase3c_hidden_state/observability_audit.py`
- 출력: `observability_local.csv`, `observability_global.csv`, `fd_baseline.csv`, `observability_audit.log`
- 데이터: 보관된 Lorenz dt = 0.05 (σ = 10, ρ = 28, β = 8/3, DOP853, rtol 1e−10). 과거 창 m = 8, τ = 1 (시간 폭 0.35).

## 1. 설정

- 상태 s_t = (x, y, z)(t). 관측 함수 h₁ = x, h₂ = z. y는 숨긴다.
- 과거 지연사상 F_xz(s) = (x(t), …, x(t−7), z(t), …, z(t−7)).
- 정규화: 관측은 train 구간 표준편차(x, z)로, 상태는 train 구간 표준편차(x, y, z)로 나눈다. 이 단위에서 계수, 조건수, 오차를 비교한다.

## 2. Γ 대칭과 비식별가능성

- **[Verified]** Γ(x, y, z) = (−x, −y, z)는 흐름과 교환한다 (Phase 2.5 P2). z만 관측하면 z(t − kτ; Γs) = z(t − kτ; s)이므로 z-only 패턴은 s와 Γs를 구별하지 못한다. y는 Γ-홀이므로 z-only로 식별되지 않는다.
- **[Empirical]** 유한 표본 확인: z-only 완전 창의 관측공간 10-NN 중 **50% (90% 분위 70%)가 반대 lobe**(sign x가 다름)다. 이웃의 y 차이 최대값 중앙값은 1.16 (y 표준편차 단위)이다.
- x가 관측되면 Γ-홀 좌표가 들어오므로 대칭은 깨진다. **x를 관측한 모든 패턴의 반대 lobe 비율은 0**이었다.
- **자연 분포에서의 빈도:** p = 0.3에서 길이 8인 x 창이 모두 결측일 확률은 0.3⁸ ≈ 6.6×10⁻⁵다. z-only는 자연 평가 분포의 대표 사례가 아니다. 그래서 **별도 스트레스 테스트**(x 제거)로만 다룬다.

## 3. 국소 관측가능성 (흐름 Jacobian, 2,000개 test 시점) [Empirical, 수치 Jacobian]

d x_j(t−k)/d s(t) = e_jᵀ DΦ_{−kτ}(s_t). RK4 변분방정식 20 하위스텝, `src/observability.py` 재사용.

| 패턴 | 관측 수 | 계수 3 비율 | σ_min q10 / q50 | 조건수 q50 / q90 | y 증폭 ‖e_yᵀJ⁺‖ q50 / q90 |
|---|---|---|---|---|---|
| x 완전 (8) | 8 | 1.00 | 0.28 / 0.77 | 250 / 1641 | 1.04 / 1.77 |
| z 완전 (8) | 8 | 1.00 | 0.33 / 1.09 | 44 / 98 | 0.59 / 2.38 |
| x+z 완전 (16) | 16 | 1.00 | 0.87 / 1.59 | 119 / 526 | **0.43** / 0.89 |
| x 현재값 1개 | 1 | 0 | – | ∞ | ∞ |
| x, z 현재값 2개 | 2 | 0 | – | ∞ | ∞ |
| 자연 MCAR p = 0.3 (x, z) | 11.3 | 1.00 | 0.68 / 1.26 | 105 / 502 | 0.56 / 1.13 |
| 자연 MCAR p = 0.3, x만 (z 제거) | 5.6 | 0.99 | 0.13 / 0.53 | 262 / 2621 | 1.40 / 2.96 |
| 자연 MCAR p = 0.7 (x, z) | 4.8 | 0.92 | 0.06 / 0.55 | 126 / 3077 | 1.23 / 13.2 |

해석:
- **국소적으로** x+z는 x만보다 y를 더 안정적으로 결정한다. y 증폭 중앙값이 1.04 → 0.43 (완전 창), 1.40 → 0.56 (자연 마스크)로 줄어든다. 이것이 Question B(multi-view 기여)의 **국소 이론적 근거**다.
- z-only 창도 국소적으로는 계수 3이다. Γ는 **전역적** 비식별이다 (점 s와 Γs가 멀리 떨어짐). **국소 계수로 전역 식별을 판단할 수 없다는 예다.**
- 관측 2개 이하에서는 3차원 주변공간 계수가 부족하다. 끌개 위의 성질은 별개다 (Phase 2.5 P5′).
- x 완전 창에서 |x| < 2인 시점의 y 증폭 중앙값은 0.88, 그 밖은 1.08이다. "x ≈ 0 근처에서 조건이 나쁘다"는 미분 좌표의 예상(det = −σ²x)은 dt = 0.05의 유한 지연에서 **나타나지 않았다.** 유한 τ에서는 그 근사가 맞지 않는다 (Phase 2.5 수치 2(c)와 같은 방향).

## 4. 전역 모호성 (관측공간 kNN, test 질의 600개 × train 참조 13,993개) [Empirical]

질의 창에서 관측된 좌표만으로 거리를 잰다. 값은 10-NN의 참 상태와 질의 상태의 차이 (y 표준편차 단위).

| 패턴 | 관측 수 | \|Δy\| 중앙값 (q90) | \|Δy\| 최대 중앙값 | ‖Δs‖ 최대 중앙값 | 반대 lobe |
|---|---|---|---|---|---|
| x 완전 | 8 | 0.035 (0.063) | 0.071 | 0.100 | 0 |
| x+z 완전 | 16 | 0.037 (0.083) | 0.075 | 0.114 | 0 |
| 자연 p = 0.3 (x, z) | 11 | 0.037 (0.082) | 0.075 | 0.114 | 0 |
| 자연 p = 0.3, x만 | 6 | 0.035 (0.065) | 0.072 | 0.104 | 0 |
| **x, z 현재값 2개** | 2 | **0.040 (0.098)** | 0.093 | 0.104 | 0 |
| x 현재값 1개 | 1 | 0.385 (0.907) | 1.040 | 2.014 | 0 |
| z 완전 | 8 | 0.219 (2.326) | 1.156 | 2.017 | **0.50** |

**가장 중요한 발견 [Empirical]:**
- **현재값 (x_t, z_t) 두 개만으로도** 이웃의 y가 거의 같다 (중앙값 0.040). 끌개 위에서 y가 (x, z)의 함수에 매우 가깝다는 뜻이다. 끌개는 근사적으로 2차원 곡면이고, (x, z) 사영이 대부분의 영역에서 거의 단사로 보인다.
- **함의:**
  - Model C(현재값 디코더)의 잠재가 (x_t, z_t)만 정확히 담아도, y는 유한 표본 회귀로 거의 복원될 수 있다.
  - 그러므로 "FDR만이 숨은 y 정보를 강제한다"는 Phase 3C의 가설은 **이 관측 설정에서 처음부터 약하다.** y probe 결과의 해석에 이 점을 반드시 반영한다.
  - 다만 이는 **유한 표본·kNN 기준**이다. (x, z) 사영의 전역 단사성은 증명하지 않았다 [Unresolved]. 두 날개가 겹치는 영역에서는 모호성이 있을 수 있다 (q90 0.098).
- x 현재값 하나로는 y를 결정하지 못한다 (0.385). x 완전 창(8개 lag)은 결정한다 (0.035).
- 유한 표본 기준으로는 x 창 하나와 x+z 창의 전역 모호성이 같다 (0.035 vs 0.037). **국소 조건수(§3)는 z가 돕는다고 하지만, 유한 표본 이웃 지표에서는 z의 추가 기여가 보이지 않는다.**

## 5. 숨은 y의 분석적 기준선 (과거 전용 유한차분)

**정확한 관계 [Verified]:** ẋ = σ(y − x) ⇒ y = x + ẋ/σ.

**추정기 (과거 관측만 사용, y와 미래 관측 사용 안 함):**

| 이름 | 식 | 계산 가능 조건 |
|---|---|---|
| bd1 | ŷ = x_t + (x_t − x_{t−1})/(σΔ), Δ = dt | x_t, x_{t−1} 관측 |
| bdnear | 가장 가까운 관측 과거 x_{t−j} (j ≤ 7), Δ = j·dt | x_t 관측, 과거 하나 이상 관측 |
| bd2 (2차 후진) | ŷ = x_t + (3x_t − 4x_{t−1} + x_{t−2})/(2σ dt) | x_t, x_{t−1}, x_{t−2} 관측 |

**계산 불가 시점의 처리:** 추정하지 않는다 (coverage에서 제외하고, coverage를 함께 보고). 다른 정보로 메우지 않는다.

test 구간, p = 0.3 x 마스크, seed 0–2 [Verified 계산]:

| 추정기 | coverage | RMSE (y sd 단위) | MAE |
|---|---|---|---|
| bd1, 결측 없음 (근사오차만) | 1.00 | 0.131 | 0.091 |
| bd1, 마스크 | 0.489 | 0.131 | 0.091 |
| bdnear, 마스크 | 0.697 | 0.198 | 0.126 |

- dt = 0.05에서 1차 후진차분의 **근사오차만으로** RMSE 0.13이다 (y 표준편차 대비).
- 2차 차분은 0.068로 줄지만 coverage가 34%로 떨어진다.
- 학습된 잠재가 "x의 시간 미분 추정"보다 나은지 판단하는 기준선으로 쓴다. 단, coverage가 달라 직접 비교는 해당 부분집합에서만 공정하다.
