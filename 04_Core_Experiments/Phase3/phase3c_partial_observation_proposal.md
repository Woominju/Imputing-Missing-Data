# Phase 3C Proposal — Partial Observation (설계만, 실행하지 않음; 2026-10-27)

## 1. 목적

Lorenz에서는 현재값 (x, y, z)(t)가 상태 그 자체라서, 현재값 디코더와 FDR이 같은 상태 정보를 요구한다 (Phase 3B §2.3). **FDR의 본질적 필요성**은 다음 상황에서만 시험된다: 현재 관측값이 상태를 결정하지 않고, 지연 좌표만이 숨은 상태 정보를 담는 경우.

**핵심 가설 H3C [Hypothesis]:**
- 관측 함수를 {x, z}로 제한하면 현재값 디코더의 목표 (x, z)(t)는 y를 담을 필요가 없다.
- FDR의 목표 (x(t−kτ), z(t−kτ))_{k=0..m−1}는 y를 담아야 정확히 맞출 수 있다. 예: x의 lag 차분 ≈ ẋ = σ(y − x).
- 따라서 **FDR의 잠재가 숨은 변수 y의 정보를 더 많이 보존할 것이다.**

## 2. 설계: Lorenz x,z-only

| 항목 | 규칙 |
|---|---|
| 관측 변수 | x, z만. y는 데이터에서 제거 (모델 입력, 학습 목표, 정규화 통계 어디에도 쓰지 않음) |
| 결측 | x, z에 독립 MCAR (기존 `prepare`를 2변수 배열에 적용) |
| 학습 목표 | x, z의 관측 좌표만 (C: lag-0, FDR: 전체 지연, 1/c 가중) |
| y의 사용 | **사후 평가에만.** 잠재 → y 탐침을 train 구간 잠재로 적합하고 test 구간에서 평가. 탐침족은 선형 + kNN + 작은 MLP. 하이퍼파라미터는 train 안의 교차검증으로 |
| 비교 | C (현재값) vs FDR, 스칼라 융합, k = 16, Q = 0. dt ∈ {0.05} 우선 |
| 대조군 | (a) 무작위 초기화 인코더의 잠재 → y 탐침. (b) 입력 창 원본(마스크 포함, 2 × m × 2차원)에서 직접 y 탐침 (정보 상한 근사). (c) 참 상태 s에서 y (=정답, 탐침 상한) |

## 3. 상태 식별가능성 검토 (사전 CPU 진단)

선험적으로 가정하지 않고 먼저 확인할 것:

1. **Γ 대칭:** Γ(x, y, z) = (−x, −y, z). x는 Γ-홀이므로 x 관측이 있으면 Γ 대칭은 깨질 수 있다. 하지만 **z만 관측된 창**(x 창이 모두 결측)은 y를 식별하지 못한다 (P2). 탐침 평가를 창의 x 관측 수별로 분리한다.
2. **국소 계수:** (x, z) 지연 창의 상태 Jacobian 계수와 최소 특이값. `src/observability.py`의 흐름 Jacobian을 재사용하고, 패턴(관측 위치)별로 계산한다.
   - 미분 좌표에서 det D(x, ẋ, ẍ) = −σ²x이므로 x ≈ 0 근처에서 조건이 나쁘다.
   - z를 더하면 개선되는지 수치로 확인한다.
3. **전역 모호성:** 별도 긴 궤적에서 관측공간 kNN의 참 상태 섬유 지름 (Phase 2.5 로드맵 §4.2). 창 시간 폭(m·τ·dt)별로.
4. **y의 식별 가능성 자체:** y = x + ẋ/σ (P3′). x 지연 창이 충분히 조밀하면 y는 x만으로 거의 결정된다.
   - **주의:** 그러면 "y 정보 보존"은 view 간 공유 상태가 아니라 **x view 하나의 성질**만으로도 달성될 수 있다. 해석 시 x-only 패턴과 x+z 패턴을 분리해 보고, z의 기여를 따로 측정한다.

## 4. FDR과 C의 비교 계획

**주지표:**
1. test 결측 위치 RMSE (x, z, past-only).
2. **잠재 → y 탐침 RMSE** (train 적합, test 평가, 탐침족별).
3. 같은 상태 두 자연 마스크의 lag-0 출력 일치와 잠재 분산 (Phase 3B 지표 그대로).

**보조지표:**
- 창의 x 관측 수별 y 탐침 오차.
- FDR의 전체 지연 ε 분위수.
- 디코더 Jacobian 계수 (16 → 2 vs 16 → 16).

**예측 (반증 조건):**
- H3C가 맞다면 FDR의 y 탐침 오차가 C보다 **seed 간 변동을 넘어** 작아야 한다. 특히 x가 부분 관측된 창에서 그렇다.
- 차이가 없으면, x,z-only Lorenz에서도 FDR 목표가 추가 상태 정보를 강제하지 않는다는 반증이다. 예를 들어 C의 잠재가 이미 y를 담고 있을 수 있다 (인코더 입력에 x 지연이 있으므로).

## 5. Coupled Lorenz 확장 (별도 설계 메모)

- 보관 데이터 `results/data/coupled_lorenz_k{0.0,0.5,2.0}_20000.npz` (6변수).
- 부분 관측 예: {x₁, x₂} 또는 {x₁, z₁, x₂}만 관측하고, 숨은 변수(y₁, y₂, z₂ 등)는 탐침으로만 평가한다.

- x,z-only Lorenz의 결과를 본 뒤에 결정한다.
