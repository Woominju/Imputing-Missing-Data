# Phase 3C — Research Decision (2026-10-27)

## 1. 이번 실험에서 증명되거나 검증된 것 [Verified]

- AE 데이터, 학습, 모델 선택은 y와 독립이다 (테스트: y를 바꿔도 AE 데이터와 짧은 학습 결과가 비트 동일).
- x-only 대조군의 x 마스크, 평가 위치, 정규화가 xz 모델과 동일하다.
- 정확한 관계 y = x + ẋ/σ. z-only 관측은 Γ 때문에 y를 식별하지 못한다. 실험의 z-only probe는 평균 예측기 수준이었다 (일치).
- 8회 학습이 모두 300 상한 전에 patience로 종료됐다. NaN/Inf는 없었다.

## 2. 실험적으로 확인된 것 [Empirical; 같은 궤적, seed 3개, x-only는 seed 1개]

1. **대치:** FDR-xz의 past-only 결측 RMSE가 C-xz보다 3 seed 모두 나쁘다 (+0.004 ~ +0.010).
2. **숨은 y:** 비선형 probe(kNN, MLP)에서 FDR 잠재가 3 seed 모두 낫다 (블록 bootstrap CI가 0을 포함하지 않음). 선형 probe에서는 C가 낫다.
3. **일관성:** 같은 상태 두 자연 마스크에서 FDR의 lag-0 출력 일치(좌표 불변), 관측 변수 오차, 정확한 쌍 비율, y probe 출력 일치, 잠재 분산이 3 seed 모두 낫다.
4. **Multi-view:** 같은 x 마스크에서 z를 더하면 y probe 오차가 약 절반으로 줄었다. 세 경로(OOD z 제거, x-only 모델, 원본 창)에서 같은 방향이었다. 단, 원본 창 kNN probe는 예외였다.
5. **관측가능성:** (x_t, z_t) 현재값 두 개로도 유한 표본 kNN의 y 모호성이 작다 (0.040). x 창만으로도 작다 (0.035).

## 3. 여전히 가설인 것 [Hypothesis]

- FDR의 이점이 "지연 목표가 숨은 상태 정보를 강제"하기 때문이라는 메커니즘. 디코더 기하, 용량, 최적화 차이와 분리되지 않았다.
- 학습된 잠재가 기저 상태와 위상적으로 대응한다는 것 (탐침, 근방 지표는 필요조건의 정황일 뿐).
- z의 기여가 "정보" 때문이 아니라 "추정의 조건수 개선" 때문이라는 해석.

## 4. C와 FDR의 차이 (정리)

| 측면 | 결과 |
|---|---|
| 결측 대치 정확도 | **C가 낫다** |
| 숨은 상태 복원 (비선형 probe) | **FDR이 낫다** |
| 같은 상태 일관성 (출력, 잠재) | **FDR이 낫다** |
| 선형 probe | C가 낫다 |
| 근방 겹침, 1스텝 동역학 | FDR이 낫다 |

→ FDR은 "대치 RMSE"와 "공유 상태 표현"이 **상충**하는 첫 사례를 보였다. AIM의 최상위 기준(공유 상태)으로는 FDR이 유리하다. 하지만 대치 성능 손실을 무시할 수 없다.

## 5. Multi-view의 실제 추가 기여

- **같은 x 관측에서 z 추가 → y 추정 개선**은 세 독립 경로에서 같은 방향이다 [Empirical].
- 그러나 이론적 정보량(완전 kNN 모호성)에서는 x 창만으로도 y가 거의 결정됐다.
- 그러므로 이번 결과는 "z가 x에 없는 정보를 준다"보다 "**유한 데이터·유한 용량 학습에서 z가 추정을 쉽게 만든다**"에 가깝다.
- Lorenz x,z는 진정한 multi-view 필요성(어느 view도 단독으로 상태를 결정하지 못함)을 시험하기에 약한 설정이다.

## 6. Coupled Lorenz로 확장할 근거

- **찬성:**
  - (a) FDR의 일관성 이점이 부분 관측에서 처음 나타났다.
  - (b) Lorenz x,z는 x 하나로도 정보가 거의 충분해서 multi-view 필요성을 시험하지 못한다.
  - (c) Coupled Lorenz는 하위계별 view가 **서로 다른 상태 성분**을 담는다 (k = 0이면 완전히 분리). 그래서 "결합해야만 전체 상태를 식별"하는 상황을 만들 수 있다 (Phase 2.5 P4형).
- **반대 / 선결:**
  - (a) 대치 RMSE 상충의 원인이 미해명이다.
  - (b) C와 FDR 차이의 메커니즘이 분리되지 않았다.
  - (c) seed 3개, 궤적 1개다.

## 7. 다음 아키텍처 수정이 필요한가

- **아직 새 Loss나 구조 변경을 제안하지 않는다.**
- 먼저 대치 RMSE 상충을 진단해야 한다:
  - FDR의 결측 위치 오차가 어떤 lag와 패턴에서 커지는지.
  - lag-0 출력과 lag 통합(양방향) 사이의 관계.
  - 용량을 맞춘 C(디코더 폭을 늘려 파라미터를 FDR과 같게)와의 비교.
- 용량 대조군은 현재 구조의 설정 변경만으로 가능하다 (새 구조 아님).

## 8. 다음 단계에서 가장 중요한 단 하나의 연구 질문

**"FDR의 공유 상태 일관성 이점은 지연 복원 목표 자체 때문인가, 아니면 디코더 용량·출력 차원 때문인가?"**

- 이것이 답해지지 않으면, Coupled Lorenz에서 같은 결과가 나와도 AIM의 핵심 주장("지연 임베딩의 일관된 사상"이 공유 상태를 만든다)을 뒷받침할 수 없다.
- 최소 실험: 같은 Lorenz x,z, p = 0.3에서 **용량을 맞춘 C** (디코더 hidden을 늘려 파라미터를 FDR과 같게)와 **출력 차원만 맞춘 대조 목표** (예: lag-0을 m번 복제 출력하는 디코더. 출력 차원은 같지만 지연 정보가 없음)를 FDR과 seed 3개로 비교한다. 6회. 학습 전 사용자 승인 필요.

## Decisions Requiring Discussion with ChatGPT and the User

1. **AIM 우선순위:** FDR은 공유 상태 일관성과 숨은 상태 복원에서 낫고, 결측 대치 RMSE에서는 나쁘다. 어느 쪽을 주 평가 기준으로 둘지, 아니면 둘을 함께 보고할지.
2. **§8의 메커니즘 분리 실험 승인 여부** (용량 맞춘 C, 출력 차원만 맞춘 대조 목표; 6회).
3. **Coupled Lorenz 진행 시점:** 메커니즘 분리 전에 할지, 후에 할지. 부분 관측 패턴(어떤 변수를 숨길지)의 선택.
4. **probe 족 의존성 보고 방식:** 선형 probe에서 결과가 뒤집히는 것을 주결론에 어떻게 반영할지.
5. **seed와 궤적:** 독립 초기조건 궤적 여러 개로 반복할지 (현재는 궤적 1개).
6. **대치 상충 진단을 별도 단계로 둘지.**
