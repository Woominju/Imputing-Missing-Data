**해석:**
- Phase 3B(전체 관측 Lorenz)와 달리, 이번에는 **좌표 불변 지표인 디코더 출력 일치(d_R)도 FDR이 3 seed 모두 낫다.** 같은 상태의 관측 변수 복원 오차, 정확한 쌍 비율, 두 마스크 사이 y probe 출력 차이도 모두 FDR이 낫다.
- **주의 — 대치 RMSE와의 모순처럼 보이는 점:** test 대치 RMSE(결측 위치만)는 FDR이 나쁘다 (문서 B §3). 같은 상태 오차(관측·결측 포함 lag-0 출력)는 FDR이 좋다.
  - 두 지표는 평가 위치가 다르다. 대치 RMSE는 인위 결측 위치만 보고, 같은 상태 오차는 입력에 관측된 변수의 재출력까지 포함한다.
  - 마스크도 다르다. 같은 상태 실험은 새로 뽑은 자연 마스크이고, 대치는 고정된 데이터 마스크다.
  - FDR이 **관측된 좌표를 더 일관되게 재출력하지만, 결측 위치 예측은 덜 정확**할 수 있다 [Hypothesis]. 둘을 분리하는 진단(같은 상태 쌍에서 결측 위치만의 오차)은 다음 단계 항목이다.
- 정보가 적은 창(x 관측 ≤ 4)에서는 두 모델 모두 일관성이 나빠진다. FDR의 상대적 이점은 유지된다.

## 5. AIM과 직접 연결되는 결론

- **[Empirical]** 부분 관측(x, z) Lorenz에서, 같은 학습 마스크 조건(Q = 0)일 때 FDR은 C보다 다음을 3 seed 모두에서 보였다:
  - (a) 같은 상태의 서로 다른 불완전 관측에 대해 더 일관된 lag-0 출력.
  - (b) 더 작은 잠재 분산.
  - (c) 비선형 probe 기준 숨은 상태 y의 더 좋은 복원.
  - (d) 더 높은 상태 근방 겹침.
  - **이것은 AIM의 "shared latent state consistently mapped"를 지지하는 첫 번째 정량적 증거다.** 단, 대치 RMSE는 더 나쁘다.
- **[Unresolved]** 이것이 다음 중 어떤 이유인지 구분되지 않았다:
  - (i) FDR 목표가 x의 시간 미분(→ y) 정보를 강제한 것인지.
  - (ii) 디코더 출력 차원 증가로 잠재 기하가 제약된 것인지.
  - (iii) 용량 증가(+910 파라미터)인지.
  - (iv) 최적화 경로 차이인지.
  - 관측가능성 감사에서 y가 현재값 (x_t, z_t)로도 거의 결정됐다는 점을 고려하면, (i)이 유일한 설명이라고 볼 근거는 약하다.
- **[Hypothesis로 남김]** 학습된 잠재가 기저 상태와 (위상적으로) 대응한다. 미분동형성은 주장하지 않는다.
