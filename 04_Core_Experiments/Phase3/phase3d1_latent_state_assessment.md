## 1. y-probe 결과의 수학적 의미

**잠재의 정보는 입력 창의 정보를 넘을 수 없다.**
- 잠재 ζ_t = E(창_t)는 마스킹된 입력 창의 결정론적 함수다. 따라서 ζ_t가 y_t에 대해 가진 정보는 창이 가진 정보를 넘지 못한다(data processing) [Verified].
- 두 모델의 차이는 "창의 정보 중 무엇을, 어떤 기하로 남겼는가"에 있다.

**probe 오차는 상한일 뿐이다.**
- probe의 test 오차는 "그 probe 족이 유한 표본에서 달성한 오차"다. 즉 Bayes 오차의 **상한**이다.
- 두 잠재의 probe 오차 차이는 (i) 남은 정보의 차이와 (ii) 같은 정보를 읽기 쉬운 정도의 차이가 합쳐진 것이다. 유한 표본의 probe만으로는 둘을 분리할 수 없다 [Verified, 논리].

**상호정보량 추정은 쓰지 않는다.**
- 결정론적 연속 사상에서는 MI가 발산하거나 추정량이 해상도에 의존한다.
- 그래서 상태 embedding의 증거로 쓰지 않는다.

**해석:**
1. **Ridge 결과로는 정보량을 비교할 수 없다.**
   - 두 잠재 모두 ridge 오차가 0.46–0.53이다. 분산 설명률로 72–79%에 그쳐서, 둘 다 y를 선형으로 담고 있지 않다.
   - C 잠재의 ridge 오차는 참 (x_t, z_t)에 ridge를 쓴 결과(0.458)와 거의 같다. C 잠재가 선형적으로는 "현재 관측값 수준"의 정보만 드러낸다는 정황이다 [Hypothesis].
   - FDR 잠재는 선형으로는 그보다 조금 못하다. 하지만 FDR **디코더 출력**(지연 벡터)에서는 y가 선형으로 잘 읽힌다(0.08).
   - 즉 FDR 잠재와 y 사이는 비선형이고, 디코더가 그 비선형을 풀어 지연 좌표로 내보낸다 [Empirical].
2. **Ridge 악화와 MLP 개선은 동시에 설명할 수 있다.**
   - 같은 정보라도 표현이 선형에서 멀어지면 ridge는 나빠지고, 유연한 probe는 영향을 받지 않거나 좋아진다. 둘은 모순이 아니다 [Verified, 논리].
   - "FDR이 y 정보를 더 많이 가진다"와 "FDR이 비선형 probe에 유리한 기하를 가진다"는 이 결과만으로 구분되지 않는다.
3. **데이터 공간의 같은 형식 비교에서는 FDR이 y 정보를 더 내놓지 않는다.**
   - 보완 시계열에 ridge와 FD2를 쓰면 C가 같거나 낫다. 각 모델이 실제로 내놓는 결측 대치값에 담긴 y 관련 정보에서 FDR의 우위는 없다 [Empirical, 3 seed].
   - 반면 잠재 공간의 비선형 probe에서는 FDR이 낫다 [Empirical, 3/3 seed].
   - 그러므로 **FDR의 우위는 "잠재의 기하 또는 표현"에 있고, 대치 출력의 정보에 있지 않다** [Hypothesis, 가장 일관된 설명].
4. **probe가 두 잠재에 공정하게 적용됐는지:**
   - 같은 probe 족, 같은 하이퍼파라미터 격자, 같은 train/val/test, 같은 train 통계 표준화를 썼다 [Verified].
   - 선택된 kNN k는 두 모델에서 같다.
   - MLP의 best epoch는 128–349로 상한 400에 닿지 않았다.
   - 하지만 **MLP는 초기화 seed가 하나(seed 0)뿐**이다. FDR − C 차이(0.010–0.021)가 probe 초기화 분산보다 큰지는 확인되지 않았다 [Unresolved, CPU로 재구성 가능].
   - 표준화 후 잠재의 참여비(participation ratio)는 C 2.97 / 2.47 / 1.74, FDR 1.88 / 2.22 / 1.98이다. 일관된 순서가 없다. 단순한 "차원 집중" 차이로 kNN 결과를 설명할 수는 없다.
5. **probe 결과만으로 내릴 수 있는 결론:**
   - 학습에 쓰지 않은 y가 두 잠재 모두에서 비선형으로 높은 정확도로 복원된다(MLP 0.035–0.061; 평균 예측 0.99, 무작위 인코더 0.40–0.43) [Empirical].
   - 이것은 상태 식별가능성(I2)의 **필요조건의 정황**일 뿐이다. 상태 embedding(단사성, 위상 보존)의 증거는 아니다.
   - probe 오차 0.035는 test 평균 오차다. 모든 점에서의 단사성을 보장하지 않는다. 근방 겹침 0.23–0.28도 낮다.

## 3. View 간 일관성 (Document A 요약)

- 같은 상태의 두 독립 마스크로 보면 결과가 좌표 종류에 따라 갈린다.
  - **결측 좌표**에서 lag-0 출력은 C가 더 일관적이고 더 정확하다.
  - 관측 좌표에서는 FDR이 더 일관적이다. 하지만 관측 좌표 출력은 두 모델 모두 학습되지 않은 영역이고, 대치에 쓰이지 않는다.
- 잠재 거리 d_z(모델 내부 척도로 정규화)는 FDR이 작았다(Phase 3C).
  - d_z는 좌표계에 의존한다.
  - 같은 상태의 y-probe 출력 차이 |Δŷ|도 FDR이 작았다(0.050–0.061 vs 0.065–0.081). 이것은 y라는 좌표 불변 target을 통한 지표라서 d_z보다 강한 증거다.
  - 정리하면 **"FDR 잠재는 y 관련 방향에서 마스크 불변성이 더 크지만, lag-0 결측 출력은 덜 일관적"**이다 [Empirical].
  - 이 둘을 함께 설명하는 가설: FDR의 lag-0 디코더가 잠재의 작은 차이에 더 민감하다(국소 Lipschitz가 크다) [Hypothesis, 측정되지 않음].

## 5. Coupled Lorenz의 식별가능성 가설 (학습 없음, 설계만)

계 (`src/lorenz.py`): 동일한 Lorenz 두 개가 x를 통해 확산 결합(κ)된다. 상태는 s = (s1, s2) ∈ ℝ⁶이다.

**5.1 κ = 0에서 한 하위계 View로 다른 하위계를 식별할 수 없는 이유 [Verified, 초등적]**
- 관측함수 h = x1은 s1에만 의존한다. 그래서 지연 사상 F_{x1}(s1, s2) = G(s1)는 섬유 {s1} × A2 위에서 상수다.
- 따라서 결합 끌개 A1 × A2에서 단사가 아니다. s2는 view 1의 어떤 함수로도 결정되지 않는다.
- 실제 자료(κ = 0, 같은 궤적)에서 corr(x1, x2) = −0.001이다 (`coupled_sync_check.csv`).

**5.2 결합하면 언제 전체 상태가 식별되는가 [Verified, 조건부]**
- 다변량 지연 사상 Φ(s1, s2) = (G_{x1}(s1), G_{x2}(s2))는 **각 G_{xi}가 Ai에서 단사일 때, 그리고 그때에만** 단사다(곱 사상).
- 하위계마다 Γ 대칭이 있으므로 조건이 붙는다.
  - zi 단독은 Γi 불변이라 단사가 아니다.
  - 각 하위계에 Γ를 깨는 view(xi 또는 yi)가 필요하다.
- view 집합이 (x1, z1, x2, z2)이고 y1, y2가 숨겨진 경우:
  - 각 하위계는 자기 x 창으로 식별된다. 일반 위치를 가정하며, d_box ≈ 2.06이므로 m = 8 > 2·2.06이다.
  - **어느 하위계의 view도 단독으로는 전체 상태를 식별하지 못하고, 결합해야만 식별한다.** Lorenz x, z와 달리 4절의 (c)를 시험할 수 있는 설정이다.

**5.3 모든 view에 결측이 있을 때 필요한 관측량 [Empirical 근거 + 계산]**
- Phase 3C 관측가능성 감사(깨끗한 참조, 잡음 없음, 유한 표본 kNN)에서, 한 창 안에 x 관측이 1개면 y 모호성이 0.27이었고 2개 이상이면 0.03–0.05였다.
- 이 값은 정리(theorem)가 아니라 이 설정에서의 경험적 문턱이다.
- 독립 MCAR(결측률 p)에서 두 하위계의 x 창(m = 8)이 **모두** 관측 2개 이상을 가질 확률 (`mcar_window_obs_prob.csv`):

| p | 한 하위계 | 두 하위계 모두 |
|---|---|---|
| 0.3 | 0.999 | 0.997 |
| 0.5 | 0.965 | 0.931 |
| 0.7 | 0.745 | **0.555** |

  - p = 0.7이면 약 45%의 시점에서 적어도 한 하위계의 상태가 창 안에서 약하게 식별된다. 결측률을 높이면 "부분 식별" 시점이 체계적으로 생긴다.

**5.4 구조적 위험: scalar mean fusion [Verified, 구성적 논증 / Hypothesis, 학습 결과]**
- 현재 fusion은 z = Σ wᵢ zᵢ / Σ wᵢ (관측 수 가중 평균)이다.
- κ = 0이면 view 1의 인코더는 s1만, view 2의 인코더는 s2만 알 수 있다. 평균은 서로 독립인 두 부호를 섞는다.
- 정확한 표현이 **가능은 하다.** 예를 들어 z1 = (a(s1), 1, 0, 0), z2 = (0, 0, b(s2), 1)로 부호화하면
  - z = (α a, α, (1−α) b, 1−α)이고 α = w1/(w1+w2)이다.
  - 디코더는 비율 z₀/z₁ = a(s1), z₂/z₃ = b(s2)를 계산해 두 상태를 복원할 수 있다(α ∈ (0, 1)).
- 하지만 이를 위해서는 **서로 다른 부분공간 배치와 척도 복원**을 학습해야 한다. 학습이 이를 찾는지는 경험적 질문이다.
- 실패한다면 다음과 같은 신호가 예측된다.
  - 하위계 2의 결측 대치 오차가 하위계 1의 관측 비중 α에 의존한다.
  - y2 probe가 y1 probe보다 체계적으로 나쁘다.

**5.5 κ > 0의 경우 [Hypothesis]**
- κ > 0이면 하나의 결합계다. 일반적인 단일 관측함수의 지연 사상이 결합 끌개를 embed할 수 있다(Takens, m > 2D, D는 미지).
- 그러나 κ = 0.5에서는 corr(x1, x2) = 0.15이고 동기화는 없다(상대 거리 < 0.05인 시간 비율 0). x1 안의 s2 정보는 κ(x2 − x1) 항을 통해서만 들어온다. 그래서 **원리상 식별 가능해도 유한 표본에서는 조건수가 매우 나쁠 것**으로 예상한다.
- κ = 2.0에서는 corr(x1, x2) = 0.64이고 시간의 16%에서 거의 동기화된다. view들이 중복되므로 multi-view의 필요성이 약해진다.
- **가장 깨끗한 시험은 κ = 0이다.**
- 기존 coupled 자료는 dt = 0.01이다. Phase 3C와 맞추려면 dt = 0.05 자료를 CPU에서 새로 생성해야 한다.

## 6. Hidden-state recovery와 State Embedding의 차이

| | Hidden-state recovery (지금 보인 것) | State embedding (AIM이 함의하는 것) |
|---|---|---|
| 정의 | 잠재에서 숨은 좌표 y를 test 평균 오차가 작게 예측할 수 있다 | 잠재 사상이 끌개 위에서 단사이고, 역사상이 연속(미분동형)이다 |

| 현재 상태 | [Empirical] 두 모델 모두 확인. FDR이 비선형 probe에서 우수 | **입증되지 않음.** 근방 겹침 0.23–0.28, 역Lipschitz 상한 없음, 결측 좌표 일관성은 C가 더 나음 |

## 7. 현재 공식 AIM에 대해 주장 가능한 범위

주장할 수 있는 것 [Empirical; Lorenz dt = 0.05, 궤적 1개, seed 3개]:
- 완전 관측 변수가 없는 상태(x와 z 모두 MCAR 30%)에서도 delay 기반 multi-view AE가 결측값을 대치한다.
  - C의 past-only 정규화 RMSE는 0.022–0.036이다. 선형 보간은 0.20–0.22, LOCF는 0.52–0.55다.
- 학습에 쓰지 않은 숨은 상태 y를 잠재에서 비선형 probe로 복원할 수 있다.
- 같은 x 관측 아래에서 z view를 추가하면 유한 표본 y 추정이 개선된다.

주장할 수 없는 것:
- "모든 변수의 delay embedding이 공유 잠재 상태로 **일관되게** 사상된다"는 것. 결측 좌표에서 같은 상태 출력 차이는 여전히 0.026–0.049로, 결측 대치 오차와 같은 크기다. 미분동형성과 P11′도 입증되지 않았다.
- "multi-view 결합이 필요하다"는 것. 이 설정은 그 조건이 아니다.
