이번 단계에서는 신규 학습도 GPU 사용도 없었다. 근거 문서는 Document A–C이고, 원자료는 `results/extra/phase3d1_audit/`에 있다.

## 1. 기존 자료만으로 해결한 문제

1. **겉보기 상충의 정체** [Verified와 Empirical]
   - "FDR은 전체 상태 출력이 정확하고 일관적인데 결측 대치는 나쁘다"는 대부분 **지표 구성 효과**다.
   - 두 모델 모두 관측 좌표의 lag-0 출력을 학습하지 않는다. 그런데 C는 이 비감독 영역에서 오차가 2–3배 크다.
   - Phase 3C의 전체 상태 지표는 이 관측 좌표(약 70%)가 지배했다.
   - 결측 좌표(두 마스크 모두 결측)에서는 C가 더 정확하고 더 일관적이다. seed 0, 1은 CI가 0을 포함하지 않는다.
2. **FDR의 lag-0 약점** [Empirical]
   - lag-0은 FDR이 가장 못 하는 출력 중 하나다. lag 7 다음으로 나쁘고, 중간 lag 2–4가 가장 정확하다.
   - 학습 손실에서 lag-0 비중은 11–14%다. gradient 충돌은 없고, 희석만 있다.
   - FDR lag-0은 train 배치에서도 C와 같거나 나쁘다.
3. **FDR 출력의 잠재 능력** [Empirical, 프로토콜이 다름]
   - 사전 정의된 bidir lag 결합(미래 7 step 사용)의 결측 RMSE는 0.0135–0.0175다. C의 past-only(0.022–0.036)보다 낫고, val에서도 같다.
   - 하지만 정보 집합이 달라서 C와 공정하게 비교할 수 없다.
4. **미래 y 경계 누수**: 누수는 있었지만 영향은 2.3e-4 이하이고 결론은 바뀌지 않는다 [Verified].
5. **z-removal 무효 행**: assert로 보호되는 안전 집계 스크립트를 마련했다 [Verified].
6. **Lorenz x, z 결과의 범위**: "두 view가 유한 표본 추정을 돕는다"만 검증했다. multi-view의 필요성은 시험하지 않았다 [Verified, 이론].

## 2. 여전히 미해결인 문제

- **H3 vs H4:** lag-0 약점이 손실 희석 때문인지, 용량이나 최적화 경로 차이 때문인지는 학습 없이 분리할 수 없다.
- **FDR 잠재의 비선형 probe 우위:** 정보가 더 많은 것인지 기하가 다른 것인지 구분되지 않는다. MLP probe 초기화 분산도 측정하지 않았다(CPU로 가능).
- **FDR bidir의 우위:** 이 우위가 FDR 때문인지 미래 정보 때문인지는, 같은 미래 정보를 쓰는 C형 대조군 없이는 알 수 없다.
- **multi-view의 필요성과 fusion 구조의 적합성:** 시험되지 않았다.
- **미분동형성, P11′:** 입증되지 않았다.

## 4. 용량 대조군 6회(Phase 3C 제안)의 기대 정보량

- **원래 목적:** "FDR의 일관성 이점이 지연 목표 때문인가, 용량이나 출력 차원 때문인가"를 가르는 것이었다.
- **3D-1 이후 그 목적의 상당 부분이 사라졌다.** 결측 좌표에서는 설명할 FDR의 일관성 이점이 없다.
- 남은 대상은 두 가지다.
  - (i) 잠재의 비선형 y-probe 우위
  - (ii) lag-0 대치 열세
- 두 대조군 각각의 기대 정보량은 낮다.
  - **용량 맞춘 C:** 파라미터 차이는 910개(3.9%)다. 이 정도 용량 차이가 위 효과를 만들거나 뒤집을 사전 근거가 약하다. 기대 결과는 "C와 거의 같음"이다.
  - **lag-0 복제 출력:** 목표가 C와 같다. 공유층이 받는 gradient가 C의 lag-0 gradient의 척도만 바꾼 형태라 사실상 C의 변형이다. 이것도 "C와 거의 같음"이 예상된다.
- **결론:** 6회 대조군은 "FDR 고유 효과의 존재"는 재확인하겠지만, H3(희석)를 직접 시험하지 않는다. AIM의 핵심 미검증 주장(multi-view 결합, 공유 상태)에 대한 정보도 적다. 우선순위를 낮출 것을 권한다.

## 5. Coupled Lorenz로 확장할 때의 수학적 조건 (상세는 Document C §5)

1. κ = 0에서 하위계 1의 view로는 s2를 식별할 수 없다 [Verified].
2. 결합 view (x1, z1, x2, z2)는 각 하위계에 Γ를 깨는 x 창이 있을 때 결합 상태를 식별한다 [Verified, 곱 사상, 일반 위치 가정].
3. MCAR p에서 두 하위계가 모두 창 안에 관측 2개 이상을 가질 확률은 p = 0.3에서 0.997, p = 0.7에서 0.555다 [계산; 문턱 2개는 경험값].
4. scalar mean fusion으로 결합 상태를 정확히 표현할 수는 있다(부분공간 분리와 척도 복원) [Verified, 구성적]. 학습이 그 해를 찾는지는 [Hypothesis]다.
5. κ = 0.5는 원리상 식별 가능하지만 조건수가 나쁘다. κ = 2.0은 부분 동기화로 view가 중복된다. 가장 깨끗한 시험은 κ = 0이다.

## 6. 다음 단계에 추천하는 단 하나의 실험

**Coupled Lorenz κ = 0, 결합해야만 식별되는 설정에서 C vs FDR (GPU 6회)**

**설정:**
- 자료: dt = 0.05로 새로 생성한다(CPU, `src/lorenz.py`의 기존 함수를 그대로 사용). 길이는 20,000이다.
- view: (x1, z1, x2, z2). y1, y2는 숨긴다.
- 결측: 모든 view에 MCAR p = 0.3을 적용한다. 완전 관측 변수는 없다.
- 그 밖의 설정은 Phase 3C와 같다: m = 8, τ = 1, latent 16, hidden 64, Q = 0, scalar fusion, epoch 상한 300, patience 15.
- 실행: {C, FDR} × seed {0, 1, 2} = 6회. 새 loss와 새 구조는 없다.

**추천 이유:**
- (1) Lorenz x, z로는 AIM의 핵심인 "모든 변수의 delay embedding이 공유 상태로 결합되어야만 식별되는 상황"을 만들 수 없다.
- (2) κ = 0은 그 상황을 이론적으로 보장한다. 그리고 현재 fusion 구조에 대한 **반증 가능한 예측**(§5.4의 α 의존성)을 준다.
- (3) C vs FDR 비교도 함께 얻는다. 단 결측 좌표 기준으로 수정한 프로토콜을 쓴다.
- (4) 용량 대조군보다 AIM에 대한 기대 정보량이 크다.

**사전 등록할 지표** (수정된 프로토콜):
- O1. 하위계별 결측 위치 past-only RMSE. bidir는 "미래 사용"으로 표시해 따로 보고한다.
- O2. **fusion 혼합 검정:** 하위계 j의 결측 항목 오차를 그 시점의 α_j(하위계 j view의 fusion 가중 비중)의 3분위로 층화하고, 최저 분위와 최고 분위의 차이를 block bootstrap CI로 본다.
- O3. 하위계별 "두 마스크 모두 결측" 좌표의 정확도와 출력 차이.
- O4. y1, y2 probe.
  - probe 족: ridge, kNN, MLP. MLP는 초기화 seed 5개.
  - 대조군: 원본 창, 무작위 인코더, 평균 예측.
- O5. **누수 점검:** 하위계 1 view만 관측된 입력에서 y2 probe를 돌리면 평균 예측 수준(≥ 0.95)이어야 한다. 그렇지 않으면 누수로 보고 실험을 중단한다.

**반증 기준:**
- **F (scalar fusion 병목) 가설:**
  - 기각: 두 모델 모두 2/3 seed 이상에서 O2의 분위 차이 CI가 0을 포함하고, y1과 y2의 probe 오차 차이가 probe 분산 안에 있을 때.
  - 지지: 2/3 seed 이상에서 O2의 CI가 0을 포함하지 않고(관측 비중이 낮은 하위계일수록 오차가 큼), y probe에서 하위계 사이 비대칭이 나타날 때.
- **G (FDR이 결합 필요 설정에서 더 나은 공유 상태를 만든다) 가설:**
  - 지지: 2/3 seed 이상에서 FDR이 O3(결측 좌표 일관성과 정확도)와 O4(MLP, probe 분산 초과) **모두**에서 나을 때.
  - 기각: 2/3 seed 이상에서 C가 O3에서 같거나 나을 때. 이는 Lorenz x, z 결과의 재현이 된다.
- **결과에 따른 다음 단계:**
  - F 지지 → Phase 2.5 P8″(행렬 또는 연결형 fusion) 논의
  - F 기각 → scalar fusion을 유지하고 κ = 0.5 또는 실제 자료로 진행
  - G 기각 → 주 모델 후보를 C 계열로 재검토

## 7. 질문별 답

**Q1. FDR이 전체 상태 출력에서는 더 정확한데 결측 대치에서는 왜 부정확한가?**
- 두 모델 모두 관측 좌표의 lag-0 출력을 학습하지 않는다. C는 이 영역에서 오차가 크고(관측 0.054–0.063 vs 결측 0.022–0.036), FDR은 관측 여부와 무관하게 0.035–0.043이다.
- 전체 상태 지표는 관측 좌표가 약 70%라서 FDR이 이긴다. 결측 좌표에서는 C가 이긴다 [Verified 분해, Empirical 3/3 seed].
- FDR이 결측 좌표에서 약한 이유: lag-0은 FDR의 가장자리 출력이다. 손실 비중은 11–14%이고, train 적합도 C보다 같거나 나쁘다 [Empirical]. 인과는 [Hypothesis]다.

**Q2. 관측 위치와 결측 위치를 분리하면 실제로 설명되는가?**
- **예.** 분리하면 상충이 사라진다. 결측 좌표에서는 정확도와 같은 상태 일관성이 모두 C 우위다(일관성은 seed 2에서 CI가 0을 포함) [Empirical].
- FDR의 일관성 우위는 관측 좌표에만 있다 [Verified, 정확한 분해 항등식].

**Q3. FDR 잠재의 개선은 추가 상태 정보인가, 추출하기 쉬운 비선형 좌표 표현인가?**
- 현재 자료로는 **구분할 수 없다** [Unresolved].
- 가장 일관된 설명은 "표현 또는 기하의 차이"다 [Hypothesis]. 근거:
  - (i) 각 모델이 내놓는 보완 시계열에서 같은 선형/해석 readout을 쓰면 C가 같거나 낫다.
  - (ii) ridge는 두 잠재 모두에서 나쁘다.
  - (iii) FDR 디코더의 지연 출력에서는 y가 선형으로 읽힌다.
- MLP probe 초기화 seed가 1개뿐이라 FDR 우위의 견고성도 미확인이다.

**Q4. 미래 예측 평가에 시간 경계 누수가 있었는가? 수정하면 결론이 달라지는가?**
- **있었다.** train과 val의 마지막 D행(D = 1 또는 5)이 다음 split의 y를 target으로 썼다.
- 수정 후 변화는 2.3e-4 이하이고, 선택된 k도 같다. **결론은 바뀌지 않는다** [Verified].

**Q5. 공식 AIM 중 무엇을 달성했고 무엇을 달성하지 못했는가?**
- 달성 [Empirical, Lorenz, 궤적 1개]:
  - 완전 관측 변수 없이 결측값을 대치했다. 선형 보간보다 약 5.5–10배 작은 오차다.
  - 숨은 상태를 잠재에서 비선형으로 복원할 수 있다.
  - 두 번째 view가 유한 표본 추정을 개선한다.
- 미달성:
  - 공유 잠재로의 **일관된** 사상. 결측 좌표에서 같은 상태 출력 차이가 대치 오차와 같은 크기다.
  - 미분동형성과 P11′.
  - multi-view 결합의 **필요성** 시험.
  - Coupled Lorenz와 실제 자료.

**Q6. 다음에 수행할 최소 GPU 실험은?**
- §6의 Coupled Lorenz κ = 0, 4 view, {C, FDR} × 3 seed = **6회**. 사전 등록 지표와 반증 기준을 함께 둔다.
- 그 전에 승인 후 CPU 작업 세 가지(MLP probe seed 반복, 수정 평가 코드, dt = 0.05 자료 생성)를 먼저 한다.
