## 1. Lag 가중치 정의와 원래 FDR과의 관계

**정의**
- 가중치는 w_0 = α, w_k = (1 − α)/(m − 1) (k ≥ 1)이다.
- segment 안의 원본 위치 u마다 A(u) = {k : u가 lag k의 target으로 존재}로 둔다.
- 가중 중복도는 **c_w(u) = Σ_{k∈A(u)} w_k**다.
- 손실은 다음과 같다.

  L_b = Σ_{u,i} H·1{c_w>0} Σ_{k∈A(u)} (w_k / c_w(u)) (x − x̂_k)² / Σ_{u,i} H·1{c_w>0}

**성질** (모두 단위 테스트로 확인)
- [Verified] c_w(u) > 0인 숨김 원본 항목 하나의 총가중은 정확히 1이다(Σ_k w_k/c_w = 1). 즉 "각 원본 시점의 총가중을 일정하게" 하는 정규화다.
- [Verified] α = 1/m이면 w_k/c_w = 1/c(u)가 되어 원래 FDR과 같다.
  - 수치 차이는 원래 구현이 c(u)를 float32로 계산해 생기는 상대 3e-9뿐이다.
  - **α = 1/8로 다시 학습한 seed 0이 Phase 3C FDR 체크포인트와 파라미터까지 비트 단위로 같다**(최대 차이 0.0).
- [Verified] α = 1이면 c_w(u) = 1{u ≥ span}이므로 목적함수가 **C의 `masked_loss`와 같다.**
  - target coverage도 C와 같아진다. 즉 u < span 위치의 target이 사라진다.
  - 따라서 FDR1.0은 "C 목적함수 + FDR 구조"이고, 출력 차원과 파라미터 수가 같은 대조군이다. 사용하지 않는 lag 1–7 헤드는 학습되지 않는다.
- [Verified] segment 내부 위치(모든 lag가 존재)에서 lag k의 몫은 정확히 w_k다.

**분석적 lag 비중** (균일한 H, W = 71)

| α | lag 0 | lag 1–6 | lag 7 |
|---|---|---|---|
| 1/8 | 0.137 | 0.118–0.125 | 0.137 |
| 0.35 | 0.342 | 0.088–0.098 | 0.111 |
| 0.65 | 0.603 | 0.047–0.063 | 0.077 |
| 1.0 | 1.0 | 0 | 0 |

체크포인트에서 측정한 실제 손실 비중의 lag-0 값은 0.115 / 0.246 / 0.414 / 1.0이다. 오래된 lag의 오차가 커서 비중을 더 가져간다.

## 3. 해석

1. **lag-0 가중을 올려도 결측 대치가 C 수준으로 개선되지 않는다** [Empirical, 5 seed].
   - α = 0.35와 0.65는 원래 FDR과 유의한 차이가 없다.
   - α = 1(C 목적함수)에서야 C에 가까워진다. 3/5 seed에서 원래 FDR보다 낫다.
   - seed 3을 빼면 α = 0.65가 C와 원래 FDR의 중간(0.032)이다. 하지만 seed별 검정에서 유의하지 않다 [Hypothesis].
2. **숨은 y 정보의 우위는 지연 목표(lag ≥ 1)에서 나온다** [Empirical, 5/5 seed].
   - FDR1.0은 파라미터 수와 출력 차원이 원래 FDR과 같다. 그런데도 y 우위가 완전히 사라져서 MLP 0.063으로 C(0.056)보다도 나쁘다.
   - Ccap(용량을 맞춘 C)도 우위가 없다.
   - 따라서 **Phase 3D-1의 H4(용량·출력 차원 가설)는 기각되고**, "지연 복원 목표가 y 관련 구조를 잠재에 넣는다"가 지지된다.
   - 다만 이것이 정보량의 증가인지 기하의 변화인지는 여전히 구분되지 않는다(Phase 3D-1 Document C).
3. **관측 위치 출력의 균일성도 지연 목표에서 나온다.** FDR1.0의 관측 위치 오차는 C처럼 크다(0.083) [Empirical].
4. **상충은 개선되지 않았다.**
   - "결측 대치는 좋고 y 정보는 보존하는" α를 찾지 못했다.
   - 대치를 C 수준으로 올린 α = 1은 y 정보를 잃는다.
   - y 정보를 유지하는 α ≤ 0.65는 대치가 C보다 나쁘다.
   - **lag 가중 하나만으로는 이 상충이 풀리지 않는다** [Empirical].
5. **H3(희석 가설)은 지지되지 않는다.** lag-0 비중을 3.6배(0.115 → 0.414)로 늘려도 lag-0 대치가 유의하게 좋아지지 않았다. 희석이 주원인이라는 가설은 이 자료에서 지지되지 않는다 [Empirical].

## 4. 실패와 이상

- **seed 3 조기 종료:**
  - FDR0.35, 0.65, 1.0이 모두 epoch 38(최적 22)에서 patience로 멈췄다. 결측 RMSE는 0.059–0.064다.
  - 이 seed의 val 오차(0.053–0.069)는 다른 seed보다 크다. C s3의 val도 0.058이다.
  - 수치 오류가 아니라 **조기 종료 규칙(patience 15)과 어려운 val 분할이 상호작용한 것**이다.
  - 사후에 규칙을 바꾸지 않았고, seed 3을 포함한 결과와 제외한 결과를 함께 보고했다.
- seed 3, 4의 cfg는 Phase 3C의 s0 cfg에서 seed만 바꾼 것이다. lorenz_C_p0.3_s3/s4 체크포인트는 없다.
- 같은 Lorenz 궤적 하나에서 seed만 바꿨다. seed는 마스크, 초기화, 배치의 반복이지 독립 궤적이 아니다.

## 5. Q1에 대한 답

**Lag-0 가중치를 바꾼 FDR이 결측 대치와 숨은 상태 정보 보존을 동시에 개선할 수 있는가?** — **지지되지 않았다** [Empirical, 5 seed].
- α를 올리면 대치는 C 쪽으로 조금 이동하지만 유의하지 않다.
- α = 1에서 대치를 회복하면 y 정보 우위가 사라진다.
- 동시 개선은 관찰되지 않았다.
- 부수적으로 얻은 확인: **FDR의 hidden-state 이점은 용량이나 출력 차원이 아니라 지연 목표 자체에서 나온다** [Empirical, 5/5 seed].
