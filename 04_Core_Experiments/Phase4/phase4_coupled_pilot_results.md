## 0. 설계와 실행 상태

**학습 설정**
- view는 (x1, z1, x2, z2)이고 y1, y2는 숨긴다. 모든 view에 MCAR을 적용하므로 완전 관측 변수는 없다.
- dt = 0.05, m = 8, τ = 1, latent 16, hidden 64.
- cfg는 `lorenz_C_p0.3_s0`에서 seed만 바꿨다. coupled 자료에서 튜닝하지 않았다.

**조건**
- κ ∈ {0 (음성 대조), 1.0}. κ는 학습 전에 관측가능성만 보고 정했다(`KAPPA_SELECTION.md`).
- p ∈ {0.3, 0.7}.
- 2×2 요인: decoder {C, FDR} × fusion {Scalar (관측 수 가중 평균), Learned (Model F의 mask-aware MLP)}.
- seed 0–2, 궤적은 traj 0 하나다.

**실행 상태 [Verified]**
- 48/48 완료했고 모두 rc = 0, patience 종료다. 최대 epoch는 227로 300 상한에 미달했다.
- NaN, 비유한 파라미터, 비유한 출력은 없다.
- 기록된 test RMSE와 평가 재계산값의 차이는 2.5e-8 이하다.

**평가 원칙**
- 대치 = **최종 시계열**(관측값 유지, 결측은 lag-0 past-only 출력)의 평가용 결측 위치 RMSE.
- 관측 위치의 raw decoder 출력은 따로 보고한다. 학습되지 않는 영역이다.
- FDR bidir는 미래를 쓰므로 따로 표시한다.

**누수 점검 [Verified]**
- κ = 0에서 하위계 1 view만 넣은 잠재로 y2를 예측하면 0.996–1.006으로 평균 예측 수준이다. 반대 방향도 1.01이다.
- 학습 전 누수 테스트 3개(hidden 독립성, train 정규화, 마스크 무시)를 통과했다.

## 2. 요인 효과 (seed별 paired block bootstrap; `*`는 CI가 0을 포함하지 않음)

### Decoder 주효과 (FDR − C)

| 조건 | 결측 대치 | 두 마스크 모두 결측: 오차 | 두 마스크 모두 결측: 출력 차이 |
|---|---|---|---|
| κ = 0, p = 0.3 | +0.008\*, −0.012, +0.007\* | +0.002, +0.004\*, +0.005\* | 0.000, +0.002, +0.003\* |
| κ = 0, p = 0.7 | **−0.026\*, −0.027\*, −0.035\*** | **−0.022\*, −0.040\*, −0.031\*** | **−0.035\*, −0.063\*, −0.060\*** |
| κ = 1, p = 0.3 | +0.007\*, +0.017\*, +0.007\* | −0.008, +0.001, +0.006\* | −0.015, −0.003, +0.003\* |
| κ = 1, p = 0.7 | **−0.022\*, −0.019\*, −0.025\*** | **−0.020\*, −0.027\*, −0.024\*** | **−0.039\*, −0.041\*, −0.043\*** |

- **[Empirical, 12/12 seed-조건] decoder 효과는 결측률에 따라 부호가 바뀐다.**
  - p = 0.3에서는 C의 대치가 낫다. Lorenz x, z 결과와 같다.
  - p = 0.7에서는 FDR이 대치, 결측 좌표 정확도, 결측 좌표 일관성 모두에서 낫다. 6/6 seed-조건에서 CI가 0을 포함하지 않는다.
  - κ에는 의존하지 않는다.
- 가능한 기전 [Hypothesis]: 결측이 많으면 C의 lag-0 감독 신호가 매우 드물어진다(입력 결측 76%). FDR은 숨긴 항목 하나를 여러 anchor에서 target으로 쓰므로 감독이 더 많다.

### Fusion 주효과 (Learned − Scalar)

- **대치:** p = 0.3에서 작은 개선이다(−0.001 ~ −0.005, 6개 seed-조건 중 3개 유의). p = 0.7에서는 일관되지 않다 [Empirical].
- **결측 좌표 일관성:**
  - p = 0.3: 출력 차이는 6개 중 5개에서 유의하게 개선됐다(−0.005 ~ −0.019). 참값 오차는 3개에서 유의하게 개선됐다.
  - p = 0.7: n.s.가 다수다.
- **hidden y (kNN probe):** **12/12 seed-조건, y1과 y2 모두에서 Learned가 낫다**(−0.03 ~ −0.12, 모두 유의) [Empirical].

### 상호작용 (hidden y)

- 대부분 양수이고 유의하다. Learned fusion의 이득은 C에서 크고 FDR에서 작다.
- 즉 **FDR 목표와 Learned fusion은 hidden-state 표현에서 서로를 부분적으로 대체한다** [Empirical].

해석:
- **p = 0.3:** 네 view로 학습한 잠재는 두 하위계의 숨은 y를 **동시에** 복원한다. FDR-Learned는 y1 0.055–0.057, y2 0.041–0.043이다.
  - 이는 자기 하위계 원본 창 MLP(0.078–0.099)와 4-view 원본 창 MLP(0.10–0.11)보다 좋다 [Empirical, 3 seed, 궤적 1개].
  - 무작위 인코더(kNN 0.70–0.77)보다 훨씬 좋다.
- **p = 0.7:** 잠재 probe(0.36–0.54)는 자기 하위계 원본 창(0.37–0.43)과 비슷하거나 나쁘다. 결측이 많으면 학습된 공유 잠재의 이점이 보이지 않는다 [Empirical].
- **probe 족에 따라 순위가 바뀐다.**
  - C-Learned는 ridge와 상태 근방 겹침에서 가장 좋다(겹침 0.68–0.72).
  - FDR-Learned는 MLP에서 가장 좋다.
  - 두 잠재의 기하가 다르다는 Phase 3D-1의 관찰이 coupled에서도 반복된다. "어느 잠재가 상태를 더 잘 담는가"는 probe 족에 의존한다 [Empirical].

## 4. 결측 위치 기반 일관성과 식별가능성 수준 (두 마스크 모두 결측인 좌표)

| 하위계 x_j 관측 수 L_j (두 마스크의 최솟값) | p = 0.7 참값 오차 (4 모델 범위) | 출력 차이 |
|---|---|---|
| L = 0 (Γ_j 미해결) | 0.62–0.75 | 0.81–1.01 |
| L = 1 | 0.26–0.34 | 0.33–0.45 |
| L ≥ 2 | 0.17–0.22 | 0.20–0.25 |

- **[Empirical, 이론과 일치]** 일관성과 정확도는 식별가능성 수준에 따라 단조로 변한다. L = 0에서는 점 일관성이 없는데, 이론상 기대하지 않는 경우다(실패로 보지 않음).
- p = 0.3에서는 L ≤ 1인 좌표가 seed당 0–1개라서 층화할 수 없다.
- FDR은 L = 0, 1, ≥2 모든 수준에서 C보다 출력 차이가 작다(p = 0.7).

## 5. View 결합 vs 개별 view (같은 모델에서 추론 시 view 제거, probe는 같은 패턴으로 재적합)

자기 하위계 y의 MLP probe를 "4 view 전부"와 "자기 하위계 view만"으로 비교했다 (`view_removal_mlp.csv`, probe 초기화 2개).

| 조건 | 4 view가 자기 하위계 view만보다 나은 모델 수 (y1 / y2, 12 = 4 모델 × 3 seed) | 대표 예: FDR-Learned y2 (4 view → 자기 하위계만) |
|---|---|---|
| κ = 0, p = 0.3 | 0 / 0 | 0.043 → 0.038 (자기 하위계만이 나음) |
| κ = 0, p = 0.7 | 0 / 0 | 0.380 → 0.346 |
| **κ = 1, p = 0.3** | **6 / 9** | **0.041 → 0.050 (4 view가 나음)** |
| κ = 1, p = 0.7 | 2 / 0 | 0.358 → 0.327 |

- **κ = 0:** 정보가 없는 상대 하위계 view를 섞으면 자기 하위계 추정이 항상 나빠진다. 손해가 가장 큰 것은 Scalar fusion C(+0.04)다 [Empirical, 이론 예측과 일치].
- **κ = 1, p = 0.3:** Learned fusion과 FDR 모델에서 상대 하위계 view가 자기 하위계 hidden y 추정을 개선했다(y2: 0.003–0.009) [Empirical, 약함].
  - **교란:** "자기 하위계만" 입력은 p = 0.3 학습 분포 밖(OOD)이다. 그래서 그쪽이 불리하게 측정됐을 수 있다.
  - 다만 같은 OOD 조건인 κ = 0에서는 반대 방향이 나왔다. 그러므로 κ = 1의 개선이 OOD만으로 설명되지는 않는다 [Hypothesis].
- **κ = 1, p = 0.7:** 다시 해롭다.

## 6. 동역학

- 잠재로 y_j(t + 1)을 예측하는 kNN(split 경계를 지킨 행 사용):
  - κ = 0, p = 0.3: C-Learned 0.156, FDR-Learned 0.185, C-Scalar 0.323.
  - κ = 1, p = 0.3: C-Learned 0.170, FDR-Learned 0.174.
  - Learned fusion이 Scalar보다 일관되게 낫다.
- 잠재-상태 근방 겹침은 §3과 같다. Learned fusion이 크게 높고(0.42–0.72 vs 0.32–0.46), C-Learned가 가장 높다.

## 7. 실패 사례와 한계

1. **p = 0.7의 대치 오차가 크다(0.33–0.37).** 선형 보간(0.56–0.62)의 약 60% 수준에 그친다.
2. **C-Scalar의 관측 위치 raw 출력 오차가 0.19–0.48로 크다.** 학습되지 않는 영역이다. 최종 대치에는 영향이 없다.
3. **하위계 비대칭**(§1)이 있다. 궤적이 하나뿐이라 원인을 판정할 수 없다.
4. **반복 단위의 한계:** seed 3개는 같은 궤적에서 반복한 것이다. 독립 궤적 반복은 아직 없다(traj 1, 2 자료만 생성됨).
5. **view 제거 비교의 OOD 교란**(§5). 깨끗한 비교에는 단일 하위계 view로 학습한 AE가 필요하다(아직 미실행).
6. 이번에는 FPRM을 실행하지 않았다(원래 FPRM과 수정 FPRM 모두).

## 8. Q2에 대한 답

**실제 Coupled Lorenz에서 불완전한 multi-view delay 관측의 결합이 개별 view보다 기저 상태의 식별가능성과 복원 성능을 개선하는가?**

- **식별가능성 [Verified, 이론과 수치]:** 결합해야만 두 하위계의 상태가 함께 결정된다. 개별 하위계 view는 상대 하위계를 결정하지 못한다(κ = 0에서 rank 3; κ = 1에서 증폭 수백 배, kNN 0.78).
- **복원 성능 — 전체 상태 기준 [Empirical, p = 0.3]:** 4-view 학습 잠재는 y1과 y2를 동시에 0.04–0.06으로 복원한다. 어떤 개별 view 원본 창도 두 하위계를 함께 복원하지 못한다(상대 하위계 ≈ 1.0).
- **복원 성능 — 자기 하위계 기준 [Empirical, 조건부]:**
  - 결합이 개별 view보다 나은 경우는 **κ = 1, p = 0.3에서 Learned fusion 또는 FDR 모델일 때뿐**이고, 효과는 작고 OOD에 교란돼 있다.
  - κ = 0과 p = 0.7에서는 결합이 자기 하위계 추정을 해친다.
- **p = 0.7:** 결합 잠재의 이점이 원본 창 대비 확인되지 않는다.
