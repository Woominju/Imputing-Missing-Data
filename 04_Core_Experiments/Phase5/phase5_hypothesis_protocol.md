## 1. 가설

| ID | 가설 | 성격 |
|---|---|---|
| **H1** | κ = 1, p = 0.7에서 상대 하위계의 마스크 지연 관측 V_j가 자기 하위계 hidden y_j에 대해, 자기 관측 U_j를 넘는 제곱오차 정보를 준다. 즉 R*(U_j) − R*(U_j, V_j) > 0 | 관측 수준. Bayes 위험은 알 수 없으므로 제한된 함수족(MLP)으로 추정한다 |
| **H2 (주 가설)** | 상대 view를 **입력으로 받고 같은 목표(자기 하위계 view)를 복원하도록** 비지도 학습한 encoder의 잠재(Arm B)가, 자기 하위계만 받는 encoder의 잠재(Arm A)보다 y_j를 더 잘 decoding하게 한다 | 학습 표현의 활용 |
| **H3** | 하나의 공유 readout이 허용 마스크(L_j ≥ 2)들에 걸쳐 같은 상태를 정확하고 안정적으로 복원한다 | 공유 상태 일관성. 미분동형성은 시험하지 않는다(MF §7.3) |

**κ = 0 (음성 대조)**
- MF 명제 3에 의해 H1의 Bayes 개선량은 0이다.
- H2의 개선도 0이어야 한다.
- κ = 0에서 B가 A보다 의미 있게 좋다면, 그것은 정보가 아니라 용량, 최적화, 정규화의 인공물이다.

## 2. 주 결과변수와 주 비교
- **주 결과:** test 궤적에서 y_j(정규화 단위, 복제본의 train 궤적 상태 통계 사용)의 MLP probe RMSE.
  - probe는 동결된 잠재에서 학습한다.
  - j = 1, 2의 MSE를 평균한 뒤 제곱근을 취한다.
  - 시험 궤적 10개의 MSE를 동일 가중으로 평균한다.
- **주 비교:** Δ_H2 = RMSE(B_j 잠재) − RMSE(A_j 잠재). 조건은 κ = 1, p = 0.7이다.
- **주 결측 조건 p = 0.7의 근거 (이론에 근거한 사전 선택):**
  - 자기 창의 정보가 줄어들수록 조건부 기댓값이 바뀔 여지가 크다(MF 명제 2).
  - p = 0.3에서는 자기 창에 x_j가 거의 항상 관측된다(P(L_j = 0) = 0.3⁸ ≈ 7e-5).
  - Phase 4 탐색 결과(p = 0.7에서 결합이 해롭다)는 알고 있다. 이 선택은 그 결과에 유리하도록 고른 것이 아니다.

## 3. 복제 단위와 자료 설계
- **복제본 r = 0..7 (κ마다):** 각 복제본은 다음 넷이 묶여 있다. 이 넷의 변동은 분리하지 않고 함께 복제 변동으로 본다.
  - 독립 train 궤적 id r(20,000 표본)
  - 독립 val 궤적 id 100 + r(5,000)
  - 모델 초기화 seed r
  - 학습 마스크 seed
- **학습 seed만의 변동:** 복제본 0에서 Arm A_j와 B_j를 추가 seed 1, 2로 학습한다(κ = 0, 1; p = 0.7; 같은 궤적과 마스크). 따로 보고한다.
- **test:** 독립 궤적 id 200..209(각 5,000 표본)를 모든 복제본과 모든 Arm이 공유한다.
  - test 마스크는 궤적 i마다 seed 9000 + i로 고정한다.
  - H3용 추가 마스크 4개는 seed 9100 + 10i + k(k = 1..4)다.
- **마스크:** 전체 (시간 × 변수) 격자에서 MCAR을 만든 뒤 창을 자른다(MF §1.3). 모든 Arm이 같은 복제본, 같은 κ, 같은 p에서 동일한 마스크 배열을 쓴다.
- **정규화:** 복제본의 train 궤적에서 관측된 항목만으로 계산한다. val, test, sham 궤적에도 이 통계를 그대로 적용한다.
- **hidden 상태:**
  - AE 입력, 목표, 정규화, 손실에 들어가지 않는다.
  - probe 학습(train 궤적 행)과 평가(test 행)에만 쓴다.
  - probe의 조기 종료에는 val 궤적 행을 쓴다.
- **모델 선택(조기 종료):** 참값을 쓰지 않는다(AIM과 맞추기 위함).
  - val 궤적에서 **관측된** 목표 항목의 20%를 고정 seed로 추가로 가린다.
  - 그 항목에서 lag-0 past-only 출력의 RMSE를 기준으로 쓴다.
  - 이것은 기존 프로토콜(평가 결측 위치의 참값 사용)과 다르며, 의도적인 변경이다.
- **겹치는 창을 독립 표본으로 취급하지 않는다.** 통계 단위는 복제본이다. 보조로 test 궤적도 단위로 쓴다.

## 4. Arm (비지도 AE; 구조는 FDR-Learned)

**주 구조: FDR-Learned**
- 구성:
  - view별 encoder: group MLP(2m → 64 → 16)
  - learned fusion: MLP(n_in·16 + n_in → 64 → 16)
  - decoder: 목표 view별로 전체 지연 벡터(m = 8)
- 손실: 다중도 보정 FDR 손실. **목표 열의 숨긴 항목에만** 적용한다.
- 학습 설정: hide 0.2, batch 64, K = 64, step 100/epoch, lr 1e-3, clip 5, patience 15, epoch 상한 300, latent 16, hidden 64.
- 이 구조를 고른 이유:
  - 목표가 **완전 지연 관측 D_j(s)**다. 매장 조건 하에서 D_j(s)는 상태의 위상동형 상이다.
  - 따라서 "마스크 관측에서 완전 지연 관측을 복원한다"가 "지연 좌표에서 상태를 복원한다"는 과제와 정확히 일치한다.
  - C(lag-0 목표)의 목표 x_j(t), z_j(t)는 상태를 결정하지 않는다(y가 숨겨져 있음).
- Phase 4 탐색에서 FDR 계열이 hidden-state probe에서 좋았다는 사실도 알고 있다. 이 선택이 그 결과에 영향을 받았을 수 있음을 밝힌다.

**Arm 정의**

| Arm | 입력 view | 복원 목표 | 비교 목적 |
|---|---|---|---|
| A_j | 자기 하위계 (x_j, z_j) | (x_j, z_j) | 단일 하위계 기준 |
| B_j | 4 view 전부 | (x_j, z_j) | **입력 view 추가의 효과 (주 비교 B − A)** |
| Bcur_j | 4 view. 단 상대 view의 lag ≥ 1은 항상 가림(lag 0만) | (x_j, z_j) | 상대 view의 지연 구조 vs 현재 값 (B − Bcur) |
| C | 4 view | 4 view 전부 | 추가 감독의 효과 (C − B). 입력 정보 비교가 아니다 |
| Sham_j | 자기 view(실제) + 독립 궤적의 상대 하위계 view, 같은 마스크 | (x_j, z_j) | 음성 대조 / 스트레스 시험 |

**Sham의 짝**
- 학습: 복제본 (r + 1) mod 8의 train 궤적.
- 조기 종료: val 궤적 (r + 1) mod 8.
- test: 궤적 200 + ((i + 1) mod 10).
- κ = 0에서는 정확한 대조이고, κ = 1에서는 분포 이동이 있다(MF §3.4).

**남는 교란 (모든 비교에 공통)**
- 모수 수가 다르다(fusion 입력 차원). 함수 용량이 같다고 주장하지 않는다.
- 최적화 경로가 다르다.
- Bcur의 상대 view lag 0은 그 시각에 관측됐을 때만 들어간다.

## 5. 층 (마스크만으로 정의; 결과를 보기 전에 고정)
- **L_j(t):** 자기 창(8 lag) 안에서 관측된 x_j 항목 수.
  - L0: 대칭으로 식별 불가. κ = 0에서는 정확히 식별 불가이고(MF 따름정리 2), κ = 1에서는 미해결이다(따름정리 4).
  - L1
  - L≥2: 허용 마스크(H3).
- **c_j(t):** 상대 x_{3−j}(t)의 현재 시각 관측 여부. B − Bcur 해석에 쓴다(MF §5).

## 6. 분석 방법과 판정 규칙

**주 대비**
- 복제본마다 Δ_r을 구한다.
- 보고: 평균, 95% t-CI(df = 7), 부호 일치 수, Wilcoxon 부호순위 p.
- 민감도 분석: 복제본 × test 궤적의 교차 bootstrap(2,000회)으로 구한 95% CI.

**의미 있는 효과 크기와 동등성 한계: δ = 0.02** (정규화 y 단위; p = 0.7 RMSE 약 0.4의 약 5%)

**H2 주 판정 (κ = 1, p = 0.7)**

| 결과 | 조건 |
|---|---|
| 지지 | 95% CI 상한 < 0 이고 평균 ≤ −δ |
| 검출되지만 미미 | 95% CI 상한 < 0 이고 평균 > −δ |
| 효과 없음과 동등 | 90% CI ⊂ (−δ, δ) (TOST) |
| 반대 | 95% CI 하한 > 0 |
| 결론 불가 | 위 어느 것도 아님 |

**음성 대조 (κ = 0, 같은 대비)**
- 기대 결과는 "효과 없음과 동등"이다.
- κ = 0에서 "지지"나 "검출" 조건을 만족하면, κ = 1의 H2 판정은 **교란으로 표시한다.** 이 경우 κ = 1 − κ = 0의 차이(이중 차이)를 보조로 보고한다.

**H1 (관측 수준)**
- 원 입력 MLP probe로 비교한다. 복제본마다 train 궤적에서 학습하고, 주 probe와 같은 사양을 쓴다.
- 비교 대상:
  - 자기 창 U_j
  - 결합 창 (U_j, V_j)
  - 자기 창 + 상대 현재 값 (U_j, V_j의 lag 0)
  - 현재 값만 (4 view의 lag 0)
- Δ_H1 = RMSE(결합) − RMSE(자기)에 같은 판정 규칙을 적용한다.
- 용량 민감도: train 궤적 8개를 합친 자료로 MLP 폭 64, 256, 1024를 비교한다. 단일 실행이며 탐색적이다.
- 물리 기준 추정기(MF §2.5, 과거만 사용): 완전 관측 자료와 필요 항목이 관측된 행에서 κ 항을 넣은 경우와 뺀 경우를 비교한다. Gate C에서 수행한다.

**보조 대비** (모두 같은 방식으로 보고. 다중성 보정 없이 탐색적으로 표시)
1. p = 0.3에서의 Δ_H2와 Δ_H1
2. B − Bcur (전체, c_j = 1 층, c_j = 0 층)
3. B − A의 L0 층 (MF §5의 경로 D)
4. Sham − A
5. C − B
6. 결측 위치 대치 RMSE (자기 하위계 열, lag 0 past-only)
7. 잠재 probe vs 원 입력 probe (같은 정보 집합). 정보 증가가 아니라 접근성이다(MF 명제 6)

**H3**
- readout: 주 MLP probe 하나(y_j)와 ridge(s_j의 3좌표). train 궤적의 자연 마스크 분포에서 한 번만 학습한다.
- 각 test 궤적에 독립 마스크 5개(주 마스크 1개 + 추가 4개)를 적용한다.
- 층별로 보고한다.
  - (a) readout RMSE
  - (b) 같은 상태 readout 분산: 같은 t에서 L_j ≥ 2인 마스크들 사이의 표준편차의 RMS
- 기준선:
  - 같은 절차를 원 입력 probe(자기 창, 결합 창)에 적용한 값
  - 이론값: κ = 0의 L0 층에서 Bayes 추정은 0이므로 RMSE ≈ sd(y | L0)
- 판정은 서술적으로 한다. "공유 readout이 L≥2에서 원 입력 probe 이하의 오차와 분산을 보이면 H3의 경험적 필요조건을 만족"한다.
  - 이것은 전역 식별가능성이나 미분동형성의 증거가 아니다(MF §7.3).
- 동역학: 잠재 z(t)에서 y_j(t + 5)를 MLP probe로 예측하고 원 입력과 비교한다. 같은 test 궤적 안에서 t + 5 < 길이인 행만 쓴다. 예측 성공을 위상 공액으로 해석하지 않는다.

## 7. 실패 기준과 결론 불가 조건
- 학습 실패: 비유한 step 또는 비유한 출력이 있거나, epoch 상한에 도달한 경우.
  - 해당 실행을 **제외하지 않고** 보고한다.
  - 상한 도달 비율이 10%를 넘으면 그 조건 전체를 "결론 불가"로 표시한다.
- **불리한 seed나 복제본을 사후에 제외하지 않는다.**
- H1이 "효과 없음과 동등"인데 H2가 "지지"라면 모순이다(MF 명제 6). 이 경우 probe 과적합이나 누출을 먼저 의심하고, 결론을 보류한다.
