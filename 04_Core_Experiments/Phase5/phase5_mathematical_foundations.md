## 1. 대상의 정의

### 1.1 상태공간, 흐름, 불변집합

**벡터장** F_κ: R⁶ → R⁶, s = (x1, y1, z1, x2, y2, z2), σ = 10, ρ = 28, β = 8/3, κ ≥ 0.

- ẋ1 = σ(y1 − x1) + κ(x2 − x1), ẏ1 = x1(ρ − z1) − y1, ż1 = x1y1 − βz1
- 하위계 2도 같은 꼴이며, 첫 식의 결합 항만 κ(x1 − x2)로 바뀐다.
- 코드는 `src/lorenz.py:coupled_lorenz_rhs`이고 이 식과 일치한다 [Verified (code)].

**흐름의 존재와 흡수 집합 [Verified (math)]**
- F_κ는 다항식이므로 국소 흐름 Φ^t가 존재하고 C^∞이다.
- 대역적 존재: V(s) = Σ_j [x_j² + y_j² + (z_j − σ − ρ)²]로 두면, 하위계마다의 Lorenz 항은 표준 계산으로 V̇ ≤ −c V + C를 준다(c, C > 0).
- 결합 항의 기여는 2x1κ(x2 − x1) + 2x2κ(x1 − x2) = −2κ(x1 − x2)² ≤ 0이다.
- 따라서 κ ≥ 0에서 유계 흡수 공이 존재하고, 흐름은 모든 t ≥ 0에서 정의된다. 그러므로 콤팩트한 대역 끌개 A_κ ⊂ R⁶가 존재한다(흡수 공의 ω-극한집합).

**주변공간과 불변집합의 구분**
- 상태공간(주변공간)은 R⁶다.
- 자료가 있는 곳은 transient(250 시간단위)를 지난 궤적이 머무는 집합이다. 이것을 끌개 A_κ로 근사한다.
- **A_κ는 매끈한 다양체가 아니다** [Cited, Lorenz 끌개의 프랙탈 구조].
  - κ = 0에서 A_0 ⊇ A_L × A_L이다(A_L은 Lorenz 끌개, box 차원 약 2.06 [Cited]). 곱집합의 box 차원은 약 4.1이다.
  - κ = 1에서 TwoNN 추정은 약 4.0이다 [Empirical, Phase 4].
- **다양체를 전제로 하는 결과(Takens 1981, 매끈한 역함수, 접공간)는 A_κ에 그대로 적용되지 않는다.** 프랙탈 집합용 결과(Sauer–Yorke–Casdagli)를 써야 하고, 그 결론도 "단사 + 콤팩트 부분다양체 위에서 immersion"에 그친다(§4).

### 1.2 자료 생성 분포

**자료 생성 방식**
- 궤적은 무작위 초기조건 s(0)에서 출발해 transient를 버리고 Δt = 0.05 간격으로 표본을 얻는다.
- 학습과 평가는 한 궤적의 시간 표본(서로 강하게 의존함)이나, 여러 독립 궤적을 쓴다.

**목표 분포의 가정 [Hypothesis, 문헌 근거 있음]**
- 시간 평균은 물리적(SRB) 불변측도 μ_κ로 수렴한다고 가정한다.
- κ = 0:
  - 고전 Lorenz 흐름에는 유일한 SRB 측도 μ_L이 있고 [Cited: Tucker 2002 및 후속], 혼합적이다 [Cited: Luzzatto–Melbourne–Paccaut 2005].
  - 혼합은 약혼합을 함의한다. 약혼합계의 곱은 에르고딕이므로 μ_L ⊗ μ_L은 곱 흐름의 에르고딕 측도다.
  - 따라서 Lebesgue-거의 모든 초기조건에서 시간 평균이 μ_L ⊗ μ_L로 수렴한다고 볼 근거가 있다. 이 문서에서 증명하지는 않는다.
- κ = 1: SRB 측도의 존재, 유일성, 대칭성이 알려져 있지 않다 [Unresolved]. 실험에서는 "독립 궤적들의 경험 분포"를 그대로 목표 분포로 정의한다.

### 1.3 관측, 지연 사상, 마스크

**관측과 지연 사상**
- 관측: h = (x1, z1, x2, z2)는 좌표 사영이다. **generic한 관측함수가 아니다.**
- 시간축: m = 8, τ = 1 표본(= 0.05 시간단위). 창 길이는 0.35 시간단위로, Lorenz Lyapunov 시간(약 1.1)보다 짧다.
- 완전 지연 사상: D(s) = [h_i(Φ^{−kτΔt}(s))], i = 1..4, k = 0..7. 즉 D: R⁶ → R³².

**마스크와 관측 사상**
- 전체 시간 격자에서 항목별 MCAR: M[t, i] ~ Bernoulli(1 − p)이며, 상태와 독립이고 항목끼리도 독립이다.
- 시각 t의 창 마스크 m_t ∈ {0,1}^{4×8}는 **같은 전역 마스크에서 잘라낸다.** 창이 겹쳐도 같은 원 항목은 같은 마스크 값을 갖는다(`src/missingness.py` → `delay_embed`) [Verified (code)].
- 관측 사상: O_m(s) = (m ⊙ D(s), m). 학습 encoder는 z = E(O_m(s))다.
- 정규화(train 통계)는 가역 아핀 변환이므로 아래 식별 문제에 영향을 주지 않는다.

**두 관측 집합**
- 자기 하위계 관측 U_j = (m_j ⊙ D_j(s), m_j). D_j는 하위계 j의 (x_j, z_j) 지연 좌표 16개다.
- 상대 하위계 관측 V_j = U_{3−j}.

### 2.1 개념 구분

**주의**
- R⁶에서 rank가 부족해도 저차원 집합 S 위에서는 단사일 수 있다. S는 프랙탈이라 "S 위의 rank"가 정의되지 않는다.
- 이 문서는 rank를 **R⁶ 기준의 충분조건**으로만 쓴다.

### 2.2 명제 1 (결정론적 식별 불가능성) [Verified (math)]

**명제.** s ≠ s′ ∈ S이고 O_m(s) = O_m(s′)이라 하자.
- (a) 임의의 결정론적 encoder E에 대해 E(O_m(s)) = E(O_m(s′))이다.
- (b) 임의의 readout g와 f(s) ≠ f(s′)인 임의의 목표 f에 대해 max{|g(E(O_m(s))) − f(s)|, |g(E(O_m(s′))) − f(s′)|} ≥ |f(s) − f(s′)| / 2이다.
- (c) 따라서 O_m만 받는 표현 E∘O_m은 {s, s′} 위에서 단사일 수 없다. 이 마스크 하나만으로는 두 상태의 "상태 표현"을 동시에 얻을 수 없다.

**증명.**
- (a) E는 함수이므로 같은 입력에 같은 값을 낸다.
- (b) ẑ = g(E(O_m(s)))는 두 상태에서 같은 값이다. 삼각부등식으로 |f(s) − f(s′)| ≤ |ẑ − f(s)| + |ẑ − f(s′)| ≤ 2 max{…}이다.
- (c) (a)의 직접 결과다. ∎

**분포 버전과 점별 버전의 구분**
- 위 명제는 **점별 최악의 경우**를 다룬다.
- 분포 하의 제곱오차 Bayes 위험은 R*(O) = E[(Y − E[Y|O])²] = E[Var(Y | O)]이다.
- 충돌 집합의 측도가 0이면 위험에 기여하지 않는다.
- 반대로 충돌이 **양의 확률로** 일어나고 충돌 상태들의 Y가 다르면 R* > 0이다. 이것이 아래 대칭 명제다.

### 2.3 대칭과 정확한 반례

**보조정리 S [Verified (math), 직접 대입].** Γ(x, y, z) = (−x, −y, z), P(s1, s2) = (s2, s1)로 둔다.
- (i) 모든 κ에서 Γ × Γ와 P는 F_κ와 교환한다(equivariant).
- (ii) Γ × Id는 κ = 0에서만 F_κ와 교환한다.

**증명 (i)**
- ẋ1 성분: −[σ(y1 − x1) + κ(x2 − x1)] = σ(−y1 + x1) + κ(−x2 + x1)다. 이것은 (−x, −y)를 대입한 값과 같다.
- ẏ1: (−x1)(ρ − z1) − (−y1) = −[x1(ρ − z1) − y1].
- ż1: (−x1)(−y1) − βz1 = ż1.
- 하위계 2도 같다. P는 식이 대칭이므로 성립한다.

**증명 (ii)**
- ẋ1 성분에서 Γ × Id를 적용한 F의 값과 F를 적용한 Γ의 값의 차이는 2κx2다.
- 이는 κ ≠ 0이고 x2 ≠ 0이면 0이 아니다. ∎

**따름정리 1 (z-only 마스크의 전역 2:1 충돌) [Verified (math)]**
- 창 안에서 x1, x2가 하나도 관측되지 않은 마스크(z만 관측)를 생각한다.
- 모든 κ에서 Φ^t(Γ×Γ s) = (Γ×Γ)Φ^t(s)이고 z 좌표는 Γ에 불변이다. 따라서 O_m(Γ×Γ s) = O_m(s)다.
- (Γ×Γ)s = s는 x1 = y1 = x2 = y2 = 0일 때만 성립하므로, 끌개의 거의 모든 점에서 s ≠ Γ×Γ s다. 즉 **2:1 충돌**이다.
- 결론: 명제 1에 의해 y1, y2, x1, x2의 부호는 이 마스크에서 결정할 수 없다.

**따름정리 2 (κ = 0, x_j 미관측) [Verified (math)]**
- κ = 0이고 창 안에 x_j 관측이 없으면(자기 하위계에서 z_j만 관측) Γ_j × Id(또는 Id × Γ_j)가 O_m을 보존한다.
- 따라서 **상대 하위계를 얼마나 관측하든** s_j의 부호는 식별할 수 없다.

**따름정리 3 (Bayes 수준의 결과) [Verified (math), 측도 대칭 가정 하]**
- 가정:
  - 대칭 g(Γ×Γ 또는 κ = 0에서 Γ_j × Id)가 자료 분포 μ를 보존한다.
  - 마스크 M은 s와 독립이다.
  - 사건 𝓜_0 = {M ∈ 해당 마스크 집합}에서 O(g s, M) = O(s, M)이다.
  - 목표 f가 f∘g = −f를 만족한다(예: y_j).
- 결론: 𝓜_0 위에서 E[f(s) | O] = 0이고, 그 층의 Bayes 위험은 E[f² | 𝓜_0]다.
- 증명:
  - 임의의 Borel 집합 B에 대해 E[f(s) 1{O(s,M) ∈ B, M ∈ 𝓜_0}]를 생각한다.
  - (s, M)과 (g s, M)의 분포가 같고 O(g s, M) = O(s, M)이므로, 이 기댓값은 E[f(g s) 1{…}] = −E[f(s) 1{…}]와 같다. 따라서 0이다. ∎
- 측도 대칭 조건의 상태:
  - κ = 0: SRB 측도가 유일하면 Γ-대칭이다(Γμ도 SRB이므로) [Cited 근거].
  - κ = 1: 측도 대칭은 가정이다 [Hypothesis]. Gate C에서 경험적으로 점검한다.

**따름정리 4 (κ = 1, x_j 미관측이지만 x_{3−j} 관측) [Unresolved]**
- Γ_j × Id는 대칭이 아니므로 위 논증으로는 식별 불가능성이 나오지 않는다.
- 결합이 x 방정식의 κ(x_j − x_{3−j}) 항으로만 들어오므로, 부호 정보는 상대 하위계의 x 동역학에 약하게 각인될 뿐이다.
- 식별이 가능한지, 가능하다면 조건이 어떤지 열려 있다. 이것은 **순간적 물리 항등식으로 설명되지 않는 상보 정보**의 후보다(§5, 명제 5).

**국소 rank와 전역 단사의 분리 사례 [Verified (math) + Gate C에서 수치 확인]**
- z_j-only 창은 일반적인 점에서 국소 rank가 s_j 방향으로 3일 수 있다(Gate C에서 확인).
- 그러나 Γ_j 때문에 전역적으로 2:1이다.
- Phase 4의 h± 사례와 함께, **국소 Jacobian rank가 전역 단사성을 함의하지 않는다**는 구체적 반례다.

### 2.4 Lorenz의 대수적 관측가능성 (상태를 미분에서 복원하는 식) [Verified (math)]

**단일 Lorenz에서 x로부터의 복원**
- y = x + ẋ/σ
- z = ρ − (ẏ + y)/x (x ≠ 0일 때)
- 따라서 x와 그 1, 2차 도함수가 있으면 x ≠ 0인 곳에서 s가 결정된다. 즉 미분 좌표에서 국소적으로 관측 가능하다.

**z로부터의 복원**
- xy = ż + βz이고, 나머지 식도 x, y에 대해 Γ-대칭이다. 따라서 부호를 결정할 수 없다(따름정리 1과 일치).

**coupled(κ > 0)에서의 식** (지시문 §5의 식)
- y1 = x1 + [ẋ1 − κ(x2 − x1)]/σ
- 이 식에는 **현재 시각의 x2(t)**가 들어간다. 따라서 κ = 1에서는 상대 view의 **현재 값**이 자기 하위계 hidden y1에 대한 정확한 물리 정보를 준다.
- 크기: |κ(x2 − x1)/σ|는 대략 |x2 − x1|/10이다. x 차이는 흔히 10–20이므로 y 단위로 1–2이고, y의 표준편차(약 9)로 정규화하면 0.1–0.2 수준이다.
- 함의:
  - **κ = 1에서 y1 예측이 x2로 개선되어도, 그것은 지연 구조나 공유 상태 복원이 아니라 이 순간 항등식만으로 설명될 수 있다.**
  - 대조군 "자기 창 + 상대 view의 현재 값만"이 필요하다(프로토콜 §4).

### 2.5 표본 간격과 유한차분 오차
- Δt = 0.05에서 ẋ의 후진차분 근사는 다음과 같다.
  - 1차: (x_t − x_{t−1})/Δt, 오차 O(Δt·ẍ).
  - 2차: (3x_t − 4x_{t−1} + x_{t−2})/(2Δt), 오차 O(Δt²·x⃛).
- Lorenz에서 |ẍ|는 10³ 수준까지 커진다. 따라서 물리 기준 추정기의 오차는 Δt에 크게 의존한다. 수치는 Gate C에서 측정한다.
- 결측이 있으면 필요한 항목(x_t, x_{t−1}, x_{t−2}, 상대 x_t)이 모두 관측된 행에서만 이 추정기를 정의할 수 있다. 그 비율은 p에 따라 급격히 줄어든다(p = 0.7에서 (0.3)⁴ ≈ 0.8%).
- **이 추정기는 filtering(과거만)이다. smoothing(미래 사용)과 섞지 않는다.**

## 3. 상보 정보: H1의 수학

### 3.1 명제 2 (L² 사영 항등식) [Verified (math)]

**명제.** Y ∈ L²(Ω, 𝓕, P), 𝓖1 = σ(U) ⊆ 𝓖2 = σ(U, V)라 하자. 그러면
R*(U) − R*(U, V) = E[(E[Y|U,V] − E[Y|U])²] ≥ 0이다.

**증명.**
- E[·|𝓖_i]는 L²(𝓕)에서 닫힌 부분공간 L²(𝓖_i)로의 직교 사영 P_i이고, L²(𝓖1) ⊆ L²(𝓖2)이다.
- Y − P1Y = (Y − P2Y) + (P2Y − P1Y)로 나눈다.
- 둘째 항은 L²(𝓖2)에 속하고, 첫째 항은 L²(𝓖2)와 직교한다.
- 피타고라스 정리로 ‖Y − P1Y‖² = ‖Y − P2Y‖² + ‖P2Y − P1Y‖²이다.
- R*(U) = ‖Y − P1Y‖²이고 R*(U,V) = ‖Y − P2Y‖²이므로 결론이 나온다. ∎

**따름 (엄격한 개선의 조건).** R*(U) − R*(U,V) > 0 ⇔ P(E[Y|U,V] ≠ E[Y|U]) > 0.

**조건부 의존성은 충분하지 않다 [Verified (math), 반례]**
- U를 상수, V ~ N(0, 1), ε를 V와 독립인 Rademacher 변수로 두고 Y = εV로 놓는다.
- 그러면 Y와 V는 종속이다(|Y| = |V|). 따라서 I(Y; V | U) > 0이다.
- 그러나 E[Y | V] = V·E[ε] = 0 = E[Y]이므로 제곱오차 위험의 개선은 0이다.
- 결론: 조건부 상호정보가 양수라는 사실만으로 제곱오차 Bayes 위험이 줄어든다고 결론낼 수 없다.

### 3.2 명제 3 (κ = 0에서 상대 view의 무정보성) [Verified (math), 가정 하]

**가정**
- (A1) 상태 분포가 곱 측도 μ_L ⊗ μ_L이다(§1.2).
- (A2) 마스크 항목이 서로 독립이고 상태와 독립이다(MCAR, 코드에서 확인).

**결론.** Y = y_j(t), U = U_j, V = V_j이면 (Y, U) ⊥ V이므로 E[Y|U,V] = E[Y|U]이고, 명제 2의 개선량은 0이다.

**증명.**
- κ = 0에서 s_j(t)의 궤적은 s_j(0)만의 함수다.
- (Y, U)는 (s_j, M_j)의 함수이고, V는 (s_{3−j}, M_{3−j})의 함수다.
- (A1)과 (A2)에서 두 쌍은 독립이다.
- 독립이면 조건부 기댓값에서 V를 뺄 수 있다. ∎

**한계**
- 한 궤적 안의 시간 표본에서 (A1)은 에르고딕 극한에서만 성립한다.
- 유한 길이 궤적에서는 우연한 상관이 있을 수 있다(Phase 4에서 corr(x1, x2) = 0.004).
- 따라서 κ = 0은 **"정확히 0"이 기대되는 음성 대조**다.
- 경험적으로 0을 "주장"하려면 동등성 한계와 신뢰구간이 필요하다(프로토콜 §6).
- κ = 0에서는 독립 궤적으로 만든 Sham view의 입력 분포가 실제 결합 입력 분포와 **정확히 같다**(가정 A1, A2 하). 그래서 Sham은 κ = 0에서 정확한 대조이고, κ = 1에서는 그렇지 않다(§3.4).

### 3.3 κ = 1에서는 양의 개선이 보장되지 않는다
- 결합이 있다는 사실이 P(E[Y|U,V] ≠ E[Y|U]) > 0을 함의하지 않는다. 예를 들어 U가 이미 Y를 결정하면 개선은 0이다.
- §2.4의 항등식은 다음을 시사한다.
  - U_j가 x_j(t)와 ẋ_j(t)를 정확히 주더라도, y_j를 결정하려면 x_{3−j}(t)가 필요하다.
  - 이 값이 U_j에서 정확히 결정되지 않으면 개선은 양수다.
  - U_j에서 x_{3−j}(t)를 결정할 수 있는지는 κ = 1 단일 view의 조건수 문제다(Phase 4: 증폭 232 → 사실상 결정 불가).
  - 따라서 **양의 개선은 강하게 예상되지만, 이는 Hypothesis이고 Gate C/E의 수치로 확인한다.**

### 3.4 Sham view의 지위 [Verified (math)]
- **κ = 1:** 독립 궤적의 하위계 2 관측을 하위계 1과 짝지은 (s1, s2′)는 결합계의 궤적이 아니다. 결합 분포가 μ_1의 주변분포 곱이 되므로 입력 분포가 실제와 다르다(분포 이동).
- 따라서 Real − Sham의 차이는 "추가 동역학 정보량"의 정확한 추정이 아니다. 다음 효과가 섞인다.
  - 정보의 차이
  - 분포 이동에 대한 학습 반응(Sham으로 학습한 모델은 상대 view를 무시하도록 학습한다)
  - 최적화 차이
- 조건부 무작위화 P(V|U)는 알려져 있지 않다. 추정한 생성기로 표본을 뽑는 방식은 정확한 조건부 무작위화 검정이 아니다. **이번 단계에서는 시도하지 않는다.**

- 단일 Lorenz에서 x 지연은 §2.4의 대수적 관측가능성 덕분에 x ≠ 0인 영역에서 국소적으로 상태를 결정한다 [Verified (math)].
  - 전역 단사성은 정리로 보장되지 않는다. 이는 prevalence 조건이 특정 h에 대해 확인되지 않기 때문이다 [Unresolved].
- 결합계(κ = 1):
  - box 차원이 약 4라면 SYC 조건은 m_total > 8.1 이상의 관측 좌표를 요구한다.
  - 완전 4-view 창(32 좌표)은 충분하다. 자기 하위계 창(16 좌표)도 개수로는 충분하다.

  - 그러나 **개수는 필요조건의 대리일 뿐이다.** 좌표 사영은 generic하지 않고, 정리는 "prevalent h"에 대한 것이다. 관측 좌표 수를 관측가능성과 같게 보지 않는다.
- **어떤 정리도 다음을 함의하지 않는다:**
  - (i) 학습된 E가 단사라는 것
  - (ii) 마스크마다 다른 O_m의 상들이 E를 거쳐 같은 상태 좌표계로 사상된다는 것
  - (iii) 유한 표본에서 전역 미분동형을 확인할 수 있다는 것

## 5. 순간 항등식과 지연 정보의 구분 (명제 5)

**명제 5 [Verified (math)]**
- κ > 0에서 y_j = x_j + [ẋ_j − κ(x_{3−j} − x_j)]/σ다.
- 따라서 정보 집합 𝓘_cur = {x_j(t), ẋ_j(t), x_{3−j}(t)}는 y_j(t)를 정확히 결정한다.
- 이 경우 "상대 view가 y_j 예측을 개선한다"는 사실은 **상대 view의 현재 값만으로** 설명될 수 있다.

**구분해야 할 정보 경로**

| 경로 | 정의 | 대조 |
|---|---|---|
| A. 현재 시각 교차변수 | 자기 창 + x_{3−j}(t), z_{3−j}(t)만 | "Bcur": 상대 view의 lag ≥ 1을 항상 가린 입력 |
| B. 자기 하위계 지연 | 자기 창만 | Arm A |
| C. 다중 하위계 지연 | 자기 창 + 상대 창 전체 | Arm B |
| D. 순간 항등식으로 설명되지 않는 복원 | x_j가 창 안에서 미관측(L_j = 0)인 층. 항등식이 x_j를 요구하므로 적용 불가 | 따름정리 2–4: κ = 0에서는 정확히 0이고, κ = 1에서는 미해결 |

**B − Bcur의 해석에 남는 교란**
- x_{3−j}(t)가 결측일 때, 상대 view의 lag ≥ 1은 x_{3−j}(t)를 **대치**하는 데 쓰일 수 있다.
- 이것은 "지연 구조가 상태를 복원한다"는 뜻이 아니라 "상대 view의 현재 값을 그 과거로 보간한다"는 뜻일 수 있다.
- 두 해석을 가르려면 x_{3−j}(t)가 관측된 행과 결측인 행을 나누어 봐야 한다(사전 등록된 층).

## 6. H2: 학습 표현의 정보 한계

**명제 6 [Verified (math)]**
- z = E(O)가 결정론적이면 σ(z) ⊆ σ(O)다.
- 따라서 명제 2의 같은 논증으로 R*(z) ≥ R*(O)이고, I(Y; z) ≤ I(Y; O)다(자료처리 부등식).

**함의**
- 잠재 probe가 원 입력 probe보다 좋다면, 그것은 **정보의 증가가 아니다.** 유한 표본과 제한된 함수족에서의 **접근성(decodability)** 차이다.
- 사후 지도 probe의 성공은 그 probe 족에 대한 decodability를 보일 뿐이다. 식별 가능한 상태 다양체를 발견했다는 증거가 아니다.

## 7. H3: 공유 상태 일관성의 정의

### 7.1 정의
- 허용 마스크 집합 𝓜_adm: 명제 1과 따름정리 1–3으로 배제되지 않고, 수치 조건이 미리 정한 기준을 만족하는 마스크. 여기서는 층 L_j ≥ 2를 사용한다(프로토콜 §5).
- **ε-일관성:** 다음을 만족하는 **하나의** 측정가능 readout r: Z → R^q가 존재한다.
  - E[‖r(E(O_M(s))) − f(s)‖² | M ∈ 𝓜_adm] ≤ ε
  - f는 상태 좌표(예: s_j 또는 y_j)다.
- **같은 상태 안정성:** 같은 s에 대한 독립 마스크 M, M′ ∈ 𝓜_adm에서 E‖r(E(O_M(s))) − r(E(O_{M′}(s)))‖²를 잰다.
  - 이것은 ≤ 4ε로 위에서 제한된다(삼각부등식과 (a + b)² ≤ 2a² + 2b²).

### 7.2 재매개변수화 불변성 [Verified (math)]
- φ: Z → Z가 전단사이면 E′ = φ∘E, r′ = r∘φ⁻¹에 대해 r′∘E′ = r∘E다.
- 따라서 위 두 양은 잠재 좌표의 선택과 무관하다.
- 반면 잠재 공간의 Euclid 거리나 kNN 겹침은 φ에 불변이 아니다. **H3의 주 지표로 쓰지 않는다.**

### 7.3 속성 사이의 관계

| 속성 | 의미 | 무엇이 함의하지 않는가 |
|---|---|---|
| 같은 상태 안정성 | readout 출력이 마스크에 따라 거의 변하지 않음 | 상태 정확성(일정한 오답도 안정적이다) |
| hidden-state decodability | readout 오차가 작음 | 마스크 사이의 공유 좌표. **마스크별로 다른 readout을 맞추면** 잠재 좌표가 정렬됐다는 증거가 아니다. 그래서 하나의 공유 readout을 쓴다 |
| 동역학 구조 보존 | z(t)에서 s(t + h)를 누출 없이 예측 | 위상 공액. 예측이 좋다고 해서 conjugacy가 함의되지 않는다 |
| 전역 상태 식별가능성 | r∘E∘O_m이 𝓜_adm 위에서 거의 모든 s에 대해 s를 돌려줌 | — 유한 표본으로는 증명할 수 없다 |
| 미분동형 대응 | E∘O_m|_A가 매끈한 역을 갖는 매장 | 유한 표본으로 증명할 수 없다. 필요조건(불연속이나 접힘이 없음)만 점검할 수 있다 |

- 정확한 일관성(r∘E∘O_m = f)은 **잠재의 일치 E(O_m(s)) = E(O_{m′}(s))를 요구하지 않는다.** 잠재가 달라도 같은 r이 같은 상태로 보내면 된다.
- 반대로, 정보가 부족한 마스크(L_j = 0)에서 잠재 일치를 강제하는 것은 명제 1에 의해 불가능하거나(대칭) 해롭다. 그래서 일관성 평가는 𝓜_adm으로 제한한다.

## 8. 미해결 문제 [Unresolved]
1. κ = 1에서 SRB 측도의 존재, 유일성, Γ×Γ 대칭.
2. 좌표 관측 x_j(또는 (x_j, z_j))의 지연 사상이 κ = 1 결합 끌개 위에서 전역 단사인지. 국소 rank 6은 Phase 4에서 수치로 확인했다.
3. 따름정리 4: κ = 1, L_j = 0 마스크에서 s_j의 부호가 원리상 식별되는지, 식별된다면 조건수가 어떤지.
4. 끌개의 정확한 box 차원과, 마스크 창의 관측 좌표 수와의 관계.
5. 학습 encoder의 단사성 또는 Lipschitz 역의 존재. 이론적 보장이 전혀 없다.
6. 유한 표본 위험 추정치와 Bayes 위험 사이의 간극. 함수족과 표본 크기에 의존한다.
