## 2. 정확한 대칭 반례의 수치 확인 (`symmetry_check.csv`)

- 방법: 상태 s와 g(s)를 각각 20 시간단위 적분하고, 등변 잔차 ‖g(Φ^t s) − Φ^t(g s)‖_∞를 쟀다.

| κ | g | 잔차 (t ≤ 1) | 잔차 (t ≤ 20) | z 좌표 차이 (t ≤ 20) |
|---|---|---|---|---|
| 0 | Γ×Γ | 0 | 0 | 0 |
| 0 | Γ×Id | 0 | 0 | 0 |
| 1 | Γ×Γ | 0 | 0 | 0 |
| 1 | **Γ×Id** | **30.2** | 37.8 | 32.7 |

- **[Verified (code), MF 보조정리 S와 일치]**
  - Γ×Γ는 모든 κ에서 정확한 대칭이다. 부호를 뒤집은 적분이 비트 단위로 같다.
  - Γ×Id는 κ = 1에서 1 시간단위 안에 z 궤적이 갈라진다.
- 따라서:
  - z-only 마스크(x 관측 없음)는 **모든 κ에서 정확한 2:1 충돌**을 만든다(MF 따름정리 1).
  - x_j 미관측 마스크는 **κ = 0에서만** 상대 view와 무관하게 정확히 식별 불가능하다(따름정리 2).

## 3. 국소 Jacobian (`local_jacobian.csv`)

**계산 방법**
- 행 ∂O_m/∂s_t는 후진 RK4 변분방정식(step당 50 하위단계)으로 구했다.
- **유한차분 교차 검증:** 중심차분과의 상대오차 ‖J_FD − J‖/‖J‖를 300점에서 쟀다.
  - ε = 1e-3: 중앙값 2.3e-5, 최대 6.1e-4
  - ε = 1e-4: 중앙값 2.3e-7, 최대 6.1e-6
  - ε = 1e-5: 중앙값 4.6e-9, 최대 1.2e-7
  - 오차가 ε²에 비례하므로 Jacobian이 맞다 [Verified (code)].
- 수치 rank: 특이값 > 1e-8·σ_max.
- 증폭: ‖e_{y1}ᵀ J⁺‖은 관측 오차 1단위가 y1 추정에 미치는 국소 선형 증폭이다.
- s1 열만 쓴 결과는 "s2를 알고 있다"는 조건부 국소 분석이고, s6은 전체 상태다.

**표: 각 셀은 "full-rank 비율 / σ_min 중앙값 / y1 증폭 중앙값 (90% 분위수)"**

| 마스크 | κ = 0, s1 | κ = 0, s6 | κ = 1, s6 |
|---|---|---|---|
| 자기 창 (x1, z1) 완전 | 1.00 / 1.54 / 0.44 | **0.00** (rank 3) | 1.00 / **0.027** / 0.61 (1.09) |
| 자기 창 z1만 완전 | **1.00** / 1.16 / 0.59 | 0.00 | 1.00 / 0.0011 / 8.0 (27.8) |
| 자기 창 x1만 완전 | 1.00 / 0.73 / 1.10 | 0.00 | 1.00 / 0.0021 / 15.8 (63.8) |
| 결합 완전 (4 view) | 1.00 / 1.54 / 0.44 | 1.00 / 1.16 / 0.44 | 1.00 / 1.38 / 0.40 (0.76) |
| 결합 z1, z2만 | 1.00 / 1.16 / 0.59 | 1.00 / 0.64 / 0.59 | 1.00 / 0.78 / 0.54 (2.2) |
| 자기 MCAR p = 0.7 | 0.90 / 0.62 / 1.13 | 0.00 | 0.33 / 0.017 / 2.3 (13.7) |
| 결합 MCAR p = 0.7 | 0.93 / 0.56 / 1.13 | 0.85 / 0.37 / 1.11 | 0.93 / 0.40 / 1.19 (5.3) |
| 자기 L0 (x1 없음, z1 MCAR 0.7) | 0.46 / 0.76 / 2.0 | 0.00 | **0.007** / 0.58 / **168** (301) |
| 결합 L0 (x1 없음, 나머지 MCAR 0.7) | 0.45 / 0.00 / 1.9 | 0.41 / 0.07 / 1.9 | 0.78 / 0.10 / **5.4** (84) |
| 결합 L0, x2/z2 완전 + z1 완전 | 1.00 / 1.16 / 0.59 | 1.00 / 0.97 / 0.59 | 1.00 / 1.07 / **0.53** (2.1) |

**해석**

1. **국소 full-rank이지만 전역 비단사인 사례 [Verified (math) + (code)]**
   - z1-only 완전 창은 κ = 0에서 s1에 대해 300/300점이 full-rank이고 증폭도 0.59로 작다.
   - 그러나 Γ 대칭 때문에 전역적으로 2:1이다(§2, §4).
   - **국소 Jacobian 진단만으로 전역 식별을 주장할 수 없다.**

2. **κ = 0에서 자기 창은 s6에 대해 rank 3이다** [Verified (math): 관측이 s2에 의존하지 않음].

3. **κ = 1의 자기 창은 국소적으로 6차원을 관측하지만 조건이 극도로 나쁘다.**
   - 완전 창에서 σ_min은 0.027이다.
   - x1이 없는 L0 마스크에서는 rank 6 비율이 0.7%이고, y1 증폭은 168이다 [Empirical].

4. **κ = 1, L0 층(x1이 창에서 미관측)에서 상대 view가 국소 조건을 극적으로 개선한다.**
   - 상대 view를 완전히 관측하면 y1 증폭이 168에서 0.53으로 떨어진다(MCAR 0.7에서는 5.4).
   - 이것은 MF 따름정리 4(κ = 1 L0)의 **국소 버전**이다. 상대 view가 순간 항등식을 쓸 수 없는 층(x1 미관측)에서도 원리상 y1 정보를 줄 수 있음을 시사한다.
   - **국소 분석은 부호(이산) 모호성에 대해 아무 말도 하지 않는다.** 전역 부호 식별은 미해결로 남는다.
   - 반면 κ = 0의 L0 층에서는 결합 창도 따름정리 2에 의해 전역적으로 부호를 식별할 수 없다. 국소 rank는 대칭 쌍의 각 가지 안에서 성립하므로 이와 모순되지 않는다.

5. **관측 좌표 수와 관측가능성은 다르다.**
   - 결합 z1, z2만(16 좌표): κ = 1에서 국소 증폭이 0.54로 좋다. 그러나 Γ×Γ로 전역 2:1이다.
   - 자기 창 x1만(8 좌표): s1에 대해 국소적으로 충분하다.

## 4. 전역 모호성 탐색 (`global_ambiguity.csv`)

**방법**
- test 창 2,000개(완전 관측)의 관측 좌표에서, train 궤적 8개의 창 16만 개 중 10-NN을 찾는다.
- 이웃들의 참 y와의 차이와, **부호가 반대인 이웃의 비율**을 잰다. 무작위 쌍의 |Δy| 중앙값은 0.89–1.02다.

| κ | view | 대상 | NN 관측 거리 | 10-NN \|Δy\| 중앙값 | 반대 부호 비율 |
|---|---|---|---|---|---|
| 0 | 자기 (x1, z1) | y1 | 0.016 | 0.011 | 0.009 |
| 0 | 자기 (x1, z1) | y2 | 0.016 | 0.93 | **0.50** |
| 0 | z1만 | y1 | 0.008 | 0.044 | **0.49** |
| 0 | z1, z2만 | y1 | 0.21 | 0.23 | **0.50** |
| 0 | 결합 4 view | y1 | 0.40 | 0.11 | 0.07 |
| 1 | 자기 (x1, z1) | y1 | 0.061 | 0.023 | 0.014 |
| 1 | 자기 (x1, z1) | **y2** | 0.061 | **0.61** | **0.30** |
| 1 | z1만 | y1 | 0.023 | 0.086 | 0.49 |
| 1 | z1, z2만 | y1 | 0.24 | 0.23 | 0.49 |
| 1 | 결합 4 view | y1 | 0.40 | 0.11 | 0.06 |

**해석**
- **[Empirical, 이론 예측과 정확히 일치]** z만 보는 view는 관측 거리 0.008–0.02의 근접 이웃 절반이 y의 부호가 반대다. 대칭 Γ(또는 Γ×Γ)의 반례가 유한 표본에서도 그대로 나타난다.
- **[Empirical] κ = 1에서 자기 창은 상대 하위계 y2를 일부 결정한다.**
  - 반대 부호 비율이 0.30으로, κ = 0의 0.50보다 낮다.
  - 결합이 실제로 정보 경로를 만든다는 증거다. 그러나 |Δy2| 0.61은 결합 view(약 0.11)보다 훨씬 나쁘다.
- **유한 표본 해상도의 함정:** 결합 4-view에서 자기 하위계 y1의 이웃 오차(0.11)가 자기 창(0.011–0.023)보다 크다.
  - 정보가 줄었기 때문이 아니다. 결합 끌개가 약 4차원이라 16만 표본에서도 이웃이 멀기 때문이다(NN 관측 거리 0.40 vs 0.016).
  - **kNN 기반 진단은 결합 view의 정보를 과소평가한다.**
- 이 탐색은 "충돌이 없다"는 증명이 아니다. 유한 표본에서 찾을 수 있는 반례만 보여준다. κ = 1의 전역 단사성은 미해결이다.

## 5. 물리 기준 추정기 (`physics_reference.csv`)

**식:** ŷ_j = x_j + (ẋ_j − κ(x_o − x_j))/σ. 완전 관측 test 궤적 10개, 정규화 y 단위.

| κ | 도함수 | κ 항 포함 | κ 항 제외 (x_o 미사용) |
|---|---|---|---|
| 0 | 1차 후진 (과거만) | 0.135 | 0.135 |
| 0 | 2차 후진 (과거만) | 0.072 | 0.072 |
| 0 | 중심차분 (**미래 사용, smoothing**) | 0.037 | 0.037 |
| 1 | 1차 후진 | 0.117 | 0.128 |
| 1 | 2차 후진 | **0.061** | **0.113** |
| 1 | 중심차분 (smoothing) | 0.031 | 0.106 |

**해석**
- **[Verified (code), MF 명제 5와 일치]** κ = 1에서 **현재 시각의 상대 view 값 x_o(t) 하나**를 쓰면 y_j 오차가 0.113에서 0.061로 거의 반으로 준다(2차 후진, 과거만).
  - 이것은 정확한 물리 항등식에서 온 "자명한" 상보 정보다.
  - 이 크기(약 0.05)는 프로토콜의 의미 있는 효과 크기 δ = 0.02보다 크다.
  - 따라서 **κ = 1에서 상대 view가 y_j 예측을 개선하는 것은 지연 기반 상태 복원 없이도 예상되는 결과다.**
- **유한차분 오차가 지배적이다.** Δt = 0.05에서 과거만 쓰는 2차 차분은 0.061–0.072로, smoothing(0.031–0.037)의 약 2배다. 필터링과 smoothing 비교를 섞으면 안 되는 이유다.
- **결측 하의 가용성:** 2차 후진 추정에 필요한 4개 항목이 모두 관측될 확률은 p = 0.3에서 0.24, p = 0.7에서 **0.008**이다.
  - p = 0.7에서 이 해석적 추정기는 실질적으로 쓸 수 없다.
  - 학습 모델이 이 항등식을 결측 하에서 근사하려면, 결측된 x_j(t), x_j(t−1), x_o(t)를 다른 lag에서 보간해야 한다.

## 7. 층과 판정 기준 (결과를 보기 전에 정함)
- L_j 층(L0, L1, L2+)과 c_j 층은 이 감사의 이론(§2–4)으로 정했다. test 결과는 보지 않았다.
- **H3 허용 마스크 = L2+.**
  - L0: κ = 0에서 정확히 식별 불가.
  - L1: 대수적으로는 부호를 정하지만 도함수 정보가 부족하다.
- 이 층들을 L0, L1, L2+로 나눈 것은 이론에 따른 것이다. 수치 조건수 문턱으로 정하지 않았다.
