## Q1. 추가 view는 실제 마스크 분포에서 자기 하위계 상태에 대한 추가적인 Bayes 예측 정보를 제공하는가?

**답: κ = 1에서는 예. 그러나 엄밀히 증명된 부분은 작다. κ = 0에서는 아니오.**

- **[Verified (math) + 통계적 신뢰하한]** κ = 1, p = 0.7:
  - Δ* = R*(U) − R*(U, V) ≥ p⁸ × 0.032 = **0.0019 > 0** (단측 95%, 독립 test 궤적 32개).
  - 근거:
    - 생성기 법칙의 정확한 Γ×Γ 대칭: x_j가 없는 L0 층에서 R*(U|L0) = E[y²]를 정확히 안다.
    - 그러므로 test와 독립인 임의의 예측기가 Δ*_L0의 하한을 준다. **추정 오차에 대한 가정이 필요 없다.**
  - L0 층 자체에서는 Δ*_L0 ≥ 0.032다.
- **[Verified (math)]** κ = 0:
  - L0 층에서 Δ*_L0 = 0이다(Γ_j × Id 대칭).
  - 고정 시각에서 (Y, U) ⊥ V이므로 Δ* = 0이다. 시간 평균에서는 정상성 근사가 필요하다(ER E4).
  - 수치 null(κ = 0, 그리고 κ = 1의 donor V)도 모두 ≤ 0이었다.
- **[Unresolved]** κ = 1의 L1, L2+ 층(전체 시각의 94%)에서 Bayes 개선량이 양수인지는 증명되지 않았다.
  - **[Empirical]** 지도 추정량의 예측 이득은 0.0006–0.003(위험 단위)이다. null보다 크다.
- **[Verified (math) + 수치]** p = 0.7에서 R*(U) ≥ 0.0576이다.
  - 자기 창 Bayes 위험의 73% 이상이 **대칭 모호성(L0)**에서 온다.
  - 추가 view가 줄일 수 있는 위험의 대부분이 이 층에 있다. 그러나 실제로 줄어드는 양은 작다(L0 RMSE 1.00 → 0.98, 부호 오류 0.51 → 0.40).

## Q3. 사용되는 정보는 순간적 물리 항등식으로 설명되는가, 지연 관측으로부터 복원되는가?

**답: 둘 다다. 그러나 순간 항등식으로 설명되지 않는 정보가 존재함이 증명됐다.**

- **[Verified (math) + 통계적 신뢰하한]** L0c0 층에서도 Δ* ≥ 0.027(LCB)이다.
  - 이 층에서는 자기 창에 x_j가 없고 상대 x_o(t)도 결측이다.
  - 순간 항등식 y_j = x_j + (ẋ_j − κ(x_o − x_j))/σ는 x_j와 x_o(t)를 요구하므로 이 층에서는 쓸 수 없다.
  - 따라서 이 정보는 **상대 하위계의 지연 관측**에서 온다.
  - 같은 층에서 현재값만(UVc)은 0을 준다(정의상).
- **[Verified (math) + LCB]** L0c1(x_o(t) 관측)에서는 현재값만으로 0.039(LCB 0.031)를 준다. 지연 창 전체는 0.054다. **현재값 경로가 대부분이다.**
- **[Empirical] AE 수준:**
  - p = 0.3: 상대 view 지연의 추가 이득(B − Bcur = −0.009)이 현재값 이득(Bcur − Aslot = −0.004)보다 크다.
    - 다만 c0 층에서도 지연 이득이 큰 것은 "지연값으로 현재값을 보간"하는 해석과 구분되지 않는다(MF §5의 교란).
  - p = 0.7: 지연의 이득은 L0 층에서만 보인다(B − Bcur = −0.006, B − Sham = −0.018).
- **[Empirical, Oracle 완전 관측 p = 0]**
  - 자기 완전 창만으로 y_j가 거의 결정된다(R = 0.0002).
  - 상대 view의 개선(0.00015)의 절반 이상은 현재값으로 설명된다.

## Q4. 학습된 잠재 표현은 전체 상태에 대응하는 일관된 좌표를 제공하는가?

**답: 아니오 [Empirical, 사전 기준].**
- 공유 6차원 MLP readout에서 사전 기준(RMSE_s6 ≤ 0.2 ∧ 마스크 간 SD ≤ 0.1 ∧ raw보다 우수)을 만족한 AE 잠재(A, Aslot, B)는 **어떤 층에서도 없다.**
- 자기 하위계: p = 0.3에서 근사 복원(s_j RMSE 0.04–0.06, 마스크 간 SD ≈ 0.04)이 된다. p = 0.7의 L2+ 층에서는 0.14–0.16이다.
- 상대 하위계:
  - κ = 0에서 RMSE 1.0이다(정보 0과 일치).
  - κ = 1에서는 B만 일부 담는다(0.42 / 0.92). 자기 목표 AE는 상대 하위계 정보를 대부분 버린다.
- 원시 결합 지연 관측에 같은 readout을 쓰면 6차원 RMSE가 0.08(p = 0.3), 0.37(p = 0.7)이다. **정보는 관측에 있지만, 잠재가 그것을 좌표로 담지 않는다.**
- p = 0.7에서 같은 상태에 대한 출력의 마스크 간 SD(약 0.3)가 오차의 대부분이다. 마스크 불변 좌표가 아니다.
- Global injectivity, homeomorphism, diffeomorphism은 검증할 수 없다 [Unresolved].
  - 프랙탈 끌개이므로 diffeomorphic이라는 표현은 쓰지 않는다.
  - 증거가 있는 최대치는 "p = 0.3에서 자기 하위계의 approximate state recovery"다.
- 6차원 목표 AE(Phase 5의 Arm C 유형)는 Phase 6에서 다시 시험하지 않았다 [Hypothesis: 그 잠재는 다를 수 있다].

## Q6. 가장 강하게 주장할 수 있는 단일 과학적 기여

**주장**
> 결합 Lorenz의 불완전한 다중 지연 관측에서, 생성 법칙의 정확한 대칭으로 Bayes 위험을 **정확히 알 수 있는 관측 층**을 찾아냈다. 이를 이용해 **추정 오차 가정 없이** 다음을 증명하고 통계적으로 확인했다(Δ* ≥ 0.0019, L0 층 ≥ 0.032, 단측 95%).
> - 상대 하위계의 지연 관측이 숨은 상태 y_j에 대해 **엄격히 양의 Bayes 정보**를 준다.
> - 그 정보의 일부는 순간 물리 항등식이나 현재값으로 설명되지 않는다.
> 동시에 "정보가 존재한다"(H1)와 "학습 모델이 그것을 쓴다"(H2)를 분리했다. 표준 AE는 그 정보를 **작게만** 활용한다(Real − Sham ≈ −0.01, 사전 등록 독립 확증). 공유 상태 좌표(H3)는 형성하지 못한다.

**라벨:** 정보 존재는 Verified (math) + 통계적 신뢰하한. 활용 크기와 좌표 부재는 Empirical(사전 등록).

**이 기여가 함의하지 않는 것**
- 학습 모델의 상태 복원
- 미분동형 대응
- 전체 시각(L1, L2+)에서의 Bayes 이득 크기
- 실제 자료에서의 숨은 상태 복원
