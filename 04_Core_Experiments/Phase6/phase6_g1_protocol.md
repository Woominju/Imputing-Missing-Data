# Phase 6 — Gate G1 Protocol: Observation-level Conditional Information (2026-10-28)

**고정:** G1 코드(`experiments/phase6/g1_info.py`)를 실행하기 전, 어떤 G1 수치도 보기 전에 고정했다. 변경은 §8에 기록한다.

**중요한 구분**
- 여기서 학습하는 예측기는 hidden y_j를 **목표로 하는 지도 학습** 추정량이다.
- 이것은 관측 정보의 존재(H1)를 진단하는 **Oracle-level 도구**이고, 비지도 AE(H2)의 성능과 섞지 않는다.

---

## 1. 대상
- (Y, U, V) = (y_j(t), U_j(t), V_j(t)).
  - U_j: 자기 하위계 (x_j, z_j)의 8-lag 마스크 창(값 × 마스크, 마스크).
  - V_j: 상대 하위계 (x_o, z_o)의 같은 창.
- 분포: Phase 6 생성기(독립 초기조건, transient 이후 시각, MCAR 마스크)의 실제 마스크 관측 분포.
- **질문:** κ = 1, p = 0.7에서 Δ* := R*(U) − R*(U, V) = E[(m_UV − m_U)²] > 0을 얼마나 강하게 뒷받침할 수 있는가?
  - m_U = E[Y|U], m_UV = E[Y|U,V].

## 2. 수학 (이 절의 명제는 모두 Verified (math))

**명제 G1.1 (실험 법칙의 정확한 대칭)**
- 생성기 초기분포(`gen6.py`): 하위계마다 x, y ~ U(−15, 15), z ~ U(5, 40)이고 모두 독립이다.
- 이 분포는 다음 변환에 불변이다.
  - Γ×Γ: 두 하위계의 (x, y) 부호를 동시에 반전
  - P: 하위계 교환
  - Γ×Id, Id×Γ
- 보조정리 S에 따라 모든 κ에서 Φ^t∘(Γ×Γ) = (Γ×Γ)∘Φ^t이고 Φ^t∘P = P∘Φ^t다. κ = 0에서는 Φ^t∘(Γ×Id) = (Γ×Id)∘Φ^t도 성립한다.
- **결론:** 모든 t에서 s(t)의 법칙은 Γ×Γ와 P에 불변이다. κ = 0에서는 Γ×Id에도 불변이다. 시각 t를 섞은 혼합 분포도 마찬가지다.
- 마스크는 상태와 독립이다.
- **SRB 측도나 에르고딕성 가정이 필요 없다.** 대상 분포를 생성기의 법칙으로 정의했기 때문이다.
- 따라서 (y_j, U_j, V_j)의 법칙은 j = 1, 2에서 같다. 두 j를 한 문제의 표본으로 합친다.

**따름정리 G1.2 (L0 층에서 R*(U)를 정확히 안다)**
- L0 = {자기 창 안에 x_j 관측이 없음}이라 하자. L0는 마스크만의 함수이므로 σ(U)-가측이다.
- L0 위에서 U_j는 z_j 값과 마스크만 담는다. z는 Γ×Γ에 불변이므로 U_j(Γ×Γ s) = U_j(s)이고, y_j(Γ×Γ s) = −y_j(s)다.
- 명제 G1.1과 MF 따름정리 3의 논증으로 E[y_j | U_j] = 0 (L0 위)이다. 따라서 R*(U_j | L0) = E[y_j² | L0]이다.
- 마스크와 상태가 독립이므로 이 값은 E[y_j²]와 같다.
- κ = 0에서는 Γ_j×Id가 (U_j, V_j)를 모두 보존하므로 E[y_j | U_j, V_j] = 0 (L0 위)이고, **Δ*_L0 = 0이 정확히 성립한다.**
- κ = 1에서는 Γ_j×Id가 대칭이 아니고, Γ×Γ는 V_j의 x_o 부호를 바꾼다. 따라서 이 논증으로는 Δ*_L0 = 0이 나오지 않는다(MF 따름정리 4, 미해결).

**명제 G1.3 (층 분해)**
- S가 σ(U)-가측 층 변수이면 Δ* = Σ_s P(S = s) Δ*_s이고, Δ*_s = E[(m_UV − m_U)² | S = s] ≥ 0이다.
- 따라서 **Δ* ≥ P(L0) Δ*_L0**이다. P(L0) = p⁸은 설계로 정확히 알려져 있다(p = 0.7에서 0.0576).

**명제 G1.4 (L0 인증 부등식)**
- test 자료와 독립으로 정해진 임의의 f ∈ L²(σ(U, V))에 대해 다음이 성립한다.
  Δ*_L0 = E[y_j² | L0] − R*(U, V | L0) ≥ E[y_j² | L0] − R(f | L0) =: G_L0(f).
- 증명: R*(U, V | L0) ≤ R(f | L0)이고, 따름정리 G1.2를 쓴다. ∎
- G_L0(f)는 독립 test 궤적의 표본 평균으로 비편향 추정된다. 그래서 **추정 오차(근사·최적화)에 대한 가정 없이** 통계적 하한(신뢰하한)을 얻는다. f가 나쁘면 하한이 느슨해질 뿐, 틀리지는 않는다.

**명제 G1.5 (witness 부등식; 사용자 지시 §3.1)**
- 임의의 g ∈ L²(σ(U, V)), E[g²] > 0에 대해 Cauchy–Schwarz로 다음이 성립한다.
  |E[(Y − m_U) g]| = |E[(m_UV − m_U) g]| ≤ √Δ* · ‖g‖.
  따라서 Δ* ≥ (E[(Y − m_U) g])² / E[g²]다.
- E[g | U] = 0이면 임의의 h ∈ L²(σ(U))에 대해 E[(Y − m_U) g] = E[Y g] = E[(Y − h) g]다.
- 특히 q = g − E[g|U]로 두면 Δ* ≥ (E[Yq])² / E[q²]이다.

**명제 G1.6 (교차적합 witness의 편향)**
- 정의: q̂ = f_X^A − f_U^A, q̃ = q̂ − r̂^B(U), ε = Y − f_U^B(U). 함수들은 test와 독립인 fold에서 적합한다.
- 그러면 E[ε q̃] − E[(Y − m_U) q̃] = E[(m_U − f_U^B) · (E[q̂|U] − r̂^B)]이다.
- 따라서 |편향| ≤ ‖m_U − f_U^B‖₂ · ‖E[q̂|U] − r̂^B‖₂다. 두 추정 오차의 **곱**이다.
- 증명: ε = (Y − m_U) + (m_U − f_U^B)로 나누고, 둘째 항에서 E[q̃|U] = E[q̂|U] − r̂^B를 쓴 뒤 CS를 적용한다. ∎
- 두 오차를 자료만으로 상계할 수는 없다. ‖m_U − f_U‖² = R(f_U) − R*(U)이고 R*(U)를 모르기 때문이다(L0 층은 예외).

**세 수준의 구분 (사용자 지시 §3.1)**

| 수준 | 내용 | 이 실험에서 |
|---|---|---|
| 1. 정확한 조건부 기댓값 아래의 수학적 하한 | 명제 G1.5 | 정리. 수치 대상은 아님 |
| 2. 교차적합 empirical witness | T = E_n[ε q̃], W = max(T, 0)² / E_n[q̃²] | **Empirical**. 편향은 명제 G1.6의 곱. 정확한 null 대조(아래)로 경험적으로 보정한다. "rigorous lower bound"나 "certificate"라고 부르지 않는다 |
| 3. 추정 오차를 통제한 통계적 하한 | (a) L0 층: 명제 G1.4. R*(U|L0)를 정확히 알기 때문에 추정 오차 가정이 필요 없다. (b) 다른 층: 곱 오차가 b 이하라는 **가정 하에서만** Δ* ≥ (max(0, T_LCB − b))² / E_n[q̃²]_UCB | (a)는 **Verified (math) + 통계적 신뢰하한**. (b)는 가정을 명시한 조건부 진술 |

**정확한 null 대조 (Δ* = 0이 수학적으로 성립)**
- κ = 1, Vs: 독립 donor 궤적의 상대 view. Vs ⊥ (Y, U)이므로 Δ*(U, Vs) = 0이다.
- κ = 0, V: 명제 3. 고정 t에서는 정확하다(ER E4). 시간 혼합에서는 정상성 근사다. L0 층에서는 따름정리 G1.2에 의해 정확히 0이다.
- 이 대조에서 witness T와 인증량 G_L0이 0 근처(G_L0는 기댓값 ≤ 0)여야 한다. 그렇지 않으면 파이프라인 결함이다.

## 3. 자료와 추정량 (`g1_info.py`)

**궤적**
- 새 독립 궤적을 쓴다(G2와 겹치지 않음, gen6 id 7000–8231).
  - fold A: train 7000–7015
  - fold B: train 7016–7031(각 20,000)
  - val: 7100–7107
  - test: **7200–7231, 32개 독립 궤적 = 추론 단위**
  - donor는 같은 길이의 8000/8100/8200번대다.

**입력과 목표**
- 입력 집합
  - U: 자기 창
  - UV: 자기 창 + 상대 창
  - UVc: 자기 창 + 상대 view의 lag 0(현재값)
  - UVs: 자기 창 + donor 상대 창
- 정규화: G2 정규화 풀 상수.
- 목표: y_j / sd(y). 중심화하지 않는다. 명제 G1.1에 의해 E[y_j] = 0이 정확히 성립하기 때문이다.

**마스크**
- 학습: 창 항목마다 매 batch 새로 뽑은 Bernoulli(1 − p) 마스크. 격자 MCAR에서 자른 창의 주변법칙과 같다.
- val: 궤적별 고정 격자 MCAR.
- test: 궤적마다 독립 격자 MCAR 10개. 마스크는 상태와 독립이므로 L0 표본 수를 늘린다. 추론 단위는 여전히 궤적이다.

**추정량**
- MLP 3 × 256 GELU, Adam 1e-3, batch 2048, epoch ≤ 40, patience 5(val MSE).
- fold마다 입력 집합별로 1개씩 학습한다.
- r̂^B: fold B에서 U → q̂를 회귀한다(같은 구조).

**조건**
- κ ∈ {0, 1}, p ∈ {0.3, 0.7}
- Oracle 완전 관측 p = 0(마스크 없음). 실제 마스크 분포가 아님을 명시한다.

**구조 감사 (사용자 지시 §3.2)**
- 같은 U/UV 문제를 세 체제로 학습하고 test 위험을 비교한다.
  - (i) "p5like": train 궤적 1개, 고정 자연 마스크 1개, MLP 2 × 64, patience 20. Phase 5 원시 MLP 설정에 해당한다.
  - (ii) "fixedmask": fold A(16 궤적), 궤적마다 고정 마스크 1개.
  - (iii) 주 체제: fold A, 매 batch 새 마스크.
- 해석 범위:
  - (i) → (ii)의 차이: 표본 수(고차원 입력의 추정 오차).
  - (ii) → (iii)의 차이: 마스크 패턴 다양성(같은 상태에 대한 마스크 증강).
  - 이 비교로 기존 H1 실패의 원인을 분리한다. 단일 seed이므로 탐색적이다.
- 층별 위험: L0, L1, L2+, c0, c1, L0c1, L0c0.
- 부호 오류율: |y| > 0.5에서 sign(f) ≠ sign(y)인 비율. L0에서 U만 쓰면 따름정리 G1.2에 의해 Bayes 예측이 0이다. 부호가 무작위이므로 기대 오류율이 약 0.5다.

## 4. 추론
- 층별 비율 추정량: Σ_궤적,마스크 합 / Σ n.
- 불확실성: **test 궤적 32개에 대한 cluster bootstrap**(10,000회, 백분위).
  - 인증량 G_L0: 단측 95% 신뢰하한(LCB).
  - 나머지: 양측 95% CI.
- **G1 주 진술 (사전 고정):** κ = 1, p = 0.7에서 LCB(G_L0(f̄_UV)) > 0이면 다음과 같이 보고한다.
  - "Δ*_L0 > 0 [Verified (math) + 통계적 신뢰하한, 단측 95%]"
  - "Δ* ≥ p⁸ · LCB > 0"
  - f̄_UV = (f_UV^A + f_UV^B)/2이고, test 전에 고정된다.
- 같은 양을 정확한 null 대조(κ = 1 UVs, κ = 0 UV)에서도 보고한다. 기댓값이 0 이하여야 한다.
- 보조:
  - L0의 UVc 인증량(현재값만으로 증명되는 이득)
  - L0c1/L0c0 분할
  - 모든 층의 교차적합 witness T와 W(null 대조와 비교)
  - 위험 차이 R(f_U) − R(f_UV)(Empirical 예측 이득. Bayes 하한이 아님)
  - 구조 감사

## 5. 해석 규칙
- 인증량 LCB > 0은 **L0 층에서 상대 view가 자기 하위계 y_j에 대한 Bayes 예측 정보를 더한다**는 진술이다. 그 크기의 하한도 준다.
  - L0에서는 순간 물리 항등식(MF 명제 5)이 x_j를 요구하므로 직접 쓸 수 없다.
  - 그러나 x_o(t)의 현재값과 x_j의 통계적 결합(동기화 경향)은 쓰일 수 있다. 이것은 UVc 인증량과 비교해 판단한다.
- L1, L2+ 층에서는 R*(U)를 모른다. 이 층의 진술은 수준 2(empirical witness)와 위험 차이로 제한한다.
- p = 0.3에서는 L0 확률이 0.3⁸ ≈ 6.6e-5다. L0 표본이 거의 없으므로 인증량을 해석하지 않는다.

## 6. 독립성과 선택
- test 궤적은 모델 선택, 조기 종료, 구조 선택에 쓰지 않는다. 조기 종료는 val 궤적으로 한다.
- 모든 사양은 위에서 고정했고, 결과를 본 뒤 바꾸지 않는다.

## 7. 한계
- 인증량은 L0 층에 국한된다. 전체 Δ*의 하한은 p⁸배로 작아진다. 다른 층의 Bayes 수준 진술은 Unresolved로 남을 수 있다.
- witness의 null 보정은 경험적이다. null 분포에서의 편향과 대립 분포에서의 편향이 같다는 보장은 없다.
