## 1. 주 결과: κ = 1, p = 0.7에서 Δ* > 0 [Verified (math) + 통계적 신뢰하한]

**L0 층 인증량** G_L0(f) = E[y² − (y − f)² | L0]이다. 프로토콜 명제 G1.4에 의해 G_L0(f)는 Δ*_L0의 하한이다.

| κ | 예측기 f | G_L0 추정 | **LCB (단측 95%)** | L0 표본 수 | 기대 부호 |
|---|---|---|---|---|---|
| **1** | **f̄_UV (자기 + 상대 창)** | **0.0411** | **0.0322** | 183,019 | > 0 가능 |
| 1 | f̄_UVc (자기 + 상대 현재값) | 0.0109 | 0.0074 | 183,019 | > 0 가능 |
| 1 | f̄_UVs (donor 상대 창, **정확한 null**) | −0.0005 | −0.0041 | 183,019 | ≤ 0 (정리) |
| 1 | f̄_U (자기만, **정확한 null**) | −0.0003 | −0.0017 | 183,019 | ≤ 0 (정리) |
| 0 | f̄_UV (**정확한 null**, 따름정리 G1.2) | −0.0013 | −0.0020 | 183,976 | ≤ 0 (정리) |
| 0 | f̄_UVc / f̄_UVs | −0.0012 / −0.0005 | — | | ≤ 0 (정리) |

**결론**
- **Δ*_L0 ≥ 0.032** (κ = 1, p = 0.7, 단측 95%).
- 명제 G1.3에 의해 **Δ* = R*(U) − R*(U, V) ≥ p⁸ × 0.032 = 0.0019 > 0**.
- 정확한 null 대조 넷이 모두 이론대로 0 이하다. 파이프라인 결함의 증거는 없다.
- 이 하한의 근거는 다음 셋뿐이다. 근사·최적화 오차에 대한 가정은 쓰지 않았다.
  - 생성기 법칙의 정확한 Γ×Γ 대칭: R*(U|L0) = E[y²]
  - test와 독립인 고정 예측기의 위험
  - 독립 test 궤적에 대한 bootstrap
- **답 (Q1의 일부):** 실제 마스크 분포에서 상대 view는 자기 하위계 y_j에 대해 엄격히 양의 Bayes 예측 정보를 준다. 다만 이 엄밀한 하한은 L0 층에서 나온 것이고, 전체 하한은 작다(0.0019).

### 1.1 정보의 경로 (Q3): L0를 상대 x_o(t) 관측 여부로 나눔

c0/c1은 상대 view의 마스크로 정의된다. 이 마스크는 (Y, U)와 독립이므로, 명제 G1.4의 논증이 각 하위층에서 그대로 성립한다(E[y|U, c] = 0 on L0).

| 층 | G(UV) [LCB] | G(UVc) [LCB] | 해석 |
|---|---|---|---|
| L0c1 (x_o(t) 관측) | 0.0544 [0.0427] | 0.0391 [0.0305] | 상대 view의 **현재값만으로** 증명되는 정보가 있다. 지연 창은 약간 더한다 |
| **L0c0 (x_o(t) 결측)** | **0.0353 [0.0274]** | −0.0014 | **현재 x_o가 없는데도 정보가 있다. 상대 view의 지연값(과거 x_o, z_o)에서 온다** |

- L0에서는 순간 물리 항등식 y_j = x_j + (ẋ_j − κ(x_o − x_j))/σ를 쓸 수 없다. 이 항등식은 x_j와 그 도함수를 요구하는데, L0에서는 x_j가 창 안에서 하나도 관측되지 않기 때문이다.
- L0c0에서는 x_o(t)도 없다.
- 따라서 **L0c0의 정보는 순간 항등식으로도, 상대 view의 현재값으로도 설명되지 않는다.** 상대 하위계의 **지연 관측에서 복원된 결합 상태 정보**다(κ = 1에서 x_j와 x_o의 통계적·동역학적 결합).
- 정보량의 크기 [Empirical]: L0의 부호 오류율(|y| > 0.5)은 f_U에서 0.511(이론값 0.5)이고 f_UV에서 0.405다. 상대 view가 대칭 모호성을 **일부만** 깬다. L0의 RMSE는 1.00에서 0.98로 줄 뿐이다.

## 2. L1, L2+ 층과 전체: 교차적합 witness와 위험 차이 [Empirical]

이 층들에서는 R*(U)를 모른다. 진술은 수준 2(empirical witness)와 예측 이득으로 제한한다. 비교 기준은 정확한 null(UVs)이다.

| κ = 1, p = 0.7 | R(f_U) | R(U) − R(UV) [CI] | null: R(U) − R(UVs) | T(UV) [CI] | null: T(UVs) | R(U) − R(UVc) |
|---|---|---|---|---|---|---|
| L1 | 0.0785 | +0.0031 [0.0027, 0.0035] | +0.0007 | 0.0054 [0.0051, 0.0056] | 0.0012 | −0.0011 |
| L2+ | 0.0078 | +0.0006 [0.0005, 0.0006] | −0.0001 | 0.0017 [0.0016, 0.0017] | 0.0002 | −0.0004 |
| 전체 | 0.0785 | +0.0034 [0.0028, 0.0041] | 0.0000 | 0.0047 [0.0043, 0.0051] | 0.0004 | +0.0002 |

- 같은 양의 κ = 0 값(null): R(U) − R(UV)는 L1에서 −0.0010, L2+에서 −0.0005다. T(UV)는 −0.0003 / −0.0001이다.
- 해석:
  - κ = 1에서 실제 상대 view의 이득과 witness는 null보다 크다. **그러나 null 자체도 0이 아니다**(T(UVs) = 0.0012, L1). 이것이 명제 G1.6의 곱 편향 크기에 대한 경험적 단서다.
  - L1, L2+에서 Bayes 개선량의 하한은 이 자료로 **증명되지 않는다** [Unresolved]. 크기는 작다(위험 단위 0.0006–0.003). L2+에서는 자기 창만으로 R ≈ 0.008(RMSE 약 0.09)이다.
  - L1, L2+에서 현재값만(UVc)으로는 위험 이득이 없거나 오히려 음수다. 반대로 c1 층(x_o(t) 관측)에서는 R(U) − R(UVc) = +0.0028 [0.0021, 0.0034]다.

## 3. 마스크 분포에서 정보가 어디에 있는가

**위험의 구성 (κ = 1, p = 0.7, f_U)**

| 층 | P(층) | R(f_U) | 전체 위험 기여 |
|---|---|---|---|
| L0 | 0.0576 (= 0.7⁸) | 0.998 (= R*(U|L0)을 정확히 달성) | 0.0575 |
| L1 | ≈ 0.196 | 0.0785 | ≈ 0.015 |
| L2+ | ≈ 0.746 | 0.0078 | ≈ 0.006 |
| 전체 | | 0.0785 | |

- **[Verified (math)] R*(U) ≥ p⁸ E[y²] = 0.0576이다.** 따름정리 G1.2와 층 분해에서 나온다.
  - 즉 자기 창 Bayes 위험의 **73% 이상이 대칭 모호성(L0)에서 온다.** 추정량의 초과 위험은 ‖m_U − f_U‖² ≤ 0.0785 − 0.0576 = 0.021 이하다.
- **완전 관측 Oracle (p = 0, 실제 마스크 분포가 아님):**
  - κ = 1: R(f_U) = 0.00019, R(f_UV) = 0.00004, R(f_UVc) = 0.00011.
  - 자기 완전 창이 y_j를 거의 결정한다(RMSE 약 0.014). 상대 view는 절대 크기가 매우 작은 개선만 준다(현재값 경로가 그 절반).
  - κ = 0: f_UV가 f_U보다 0.00007 나쁘다. 이는 추정량의 비용이다(정보는 0).

## 4. 구조 감사: Phase 5 원시 MLP가 H1을 검출하지 못한 이유 [Empirical, 단일 seed]

**R(UV) − R(U), 전체 층, p = 0.7** (양수 = joint가 나쁨)

| 학습 체제 | κ = 1 | κ = 0 (정보 0) |
|---|---|---|
| (i) p5like: 궤적 1개(20k), 고정 마스크 1개, MLP 2 × 64 | **+0.0319** [0.0312, 0.0327] | +0.0333 |
| (ii) fixedmask: 궤적 16개, 궤적별 고정 마스크 | +0.0035 [0.0029, 0.0041] | +0.0048 |
| (iii) 주 체제: 궤적 16개, 매 batch 새 마스크 | **−0.0050** [−0.0056, −0.0043] | +0.0011 |

- **Phase 5의 실패가 재현됐다**(i). 원인은 정보 부족이 아니라 **추정량**이다.
  - (i) → (ii) 표본 수: 고차원 입력(64차원)의 추정 오차가 비용의 대부분(약 0.028)을 설명한다.
  - (ii) → (iii) 마스크 증강: 같은 상태에 대한 마스크 다양성이 κ = 1의 부호를 뒤집는다.
- κ = 0에서도 같은 순서로 비용이 줄어(0.033 → 0.005 → 0.001) **추정량 비용을 직접 보여준다.**
- κ = 1 − κ = 0의 차이는 세 체제 모두에서 대략 −0.001 ~ −0.006이다. 체제와 무관하게 정보 신호는 작고, 비용은 체제에 크게 의존한다.
- 층별(체제 (iii) 대 (i)):
  - p5like의 joint 비용은 L0 +0.17, L1 +0.06, L2+ +0.014다(κ = 1).
  - 주 체제에서는 L0 −0.047, L1 −0.006, L2+ −0.002다.
- **결론:** Phase 5 H1의 "검출되지 않음"은 정보 부재가 아니라 추정량 한계였다(Phase 5 해석과 일치). 이번에 추정량을 바꿔 그 해석을 **실증**했다.
