## 1. 질문

**G2 주 질문**
- 같은 입력 채널 수와 아키텍처를 쓰는 Real MV 모델(B_j)이 Sham MV 모델(Sham_j)보다 hidden-state y_j를 더 잘 decoding하는가?
- 이 비교가 평가하는 것: 실제 상대 view의 추가적인 통계적·동역학적 관련성을 학습 모델이 활용하는지.

  - κ = 1에서 Sham은 결합분포를 바꾼다(ER E6, MF §3.4). 따라서 B − Sham은 Bayes 정보량의 추정이 아니다.

**G3 질문**
- 하나의 공유 비선형 readout이 서로 다른 독립 마스크에서 전체 6차원 상태를 정확하고 안정적으로 복원하는가?

## 3. Arm (구조는 Phase 5 FDR-Learned ArmModel, 변경 없음)

| Arm | 입력 slot | 상대 slot | 모수 수 | 목적 |
|---|---|---|---|---|
| A_j | 2 (자기) | 없음 | A 기준 | 원래 H2의 기준 |
| Aslot_j | 4 | **항상 비활성**(lag mask 0) | = B | 용량 통제 own-only |
| B_j | 4 | 실제 상대 view | = B | Real MV |
| Bcur_j | 4 | 실제 상대 view, lag 0만 | = B | 현재값만 (명제 5 경로) |
| Sham_j | 4 | 독립 donor 궤적의 상대 view | = B | Sham MV |

- **같은 총 모수 수가 같은 유효 용량을 보장하지는 않는다.** Aslot은 상대 slot의 encoder 모수를 쓰지 않는다. 즉 학습 가능한 경로가 B보다 적다.
- 학습 설정, 손실, 조기 종료(참값 없음: val의 관측 항목 20% 숨김 재구성)는 Phase 5와 같다(`train6.py`는 `train.py`와 데이터 조립·seed 규칙만 다르다).
- 학습 예산: epoch ≤ 300, patience 15, 100 step/epoch, batch 64.

## 4. 반복 수와 근거 (사전 결정)
- **독립 복제본 n = 24 / κ, p.** test 궤적은 복제본당 8개(총 192개 / κ)이고, 학습 seed는 복제본당 1개다(복제 변동에 포함).
- 근거(검정력, 양측 α = 0.05, paired t):
  - Phase 5 사후 B − Sham의 복제본 SD는 0.012였다. 그러나 순환 donor 때문에 SD가 과소 추정됐을 수 있다. 또 복제본마다 test 집합이 다르므로 궤적 수준 변동이 SD에 더해진다.
  - SD = 0.024(두 배)를 가정하면, 효과 0.015에 대한 검정력은 n = 16에서 0.65, n = 24에서 0.83이다. 효과 δ = 0.02에서는 n = 24에서 0.97이다.
  - SD = 0.012이면 n = 24에서 효과 0.010에도 0.97이다.
- **계산량 때문에 줄이지 않았다.** 학습 960개 = 4 조건 × 24 × 10 Arm.

## 5. 주 결과변수와 판정

**복제본 지표 (Phase 5와 같다)**
- Q_r(Arm) = sqrt(½ Σ_j MSE_j).
- MSE_j는 복제본의 test 궤적 8개에서 합동으로 구하고, MLP probe seed {0, 1}에 대해 평균한다.
- probe 사양은 Phase 5와 같다: MLP 2 × 64 ReLU, Adam 1e-3, batch 512, ≤ 200 epoch, patience 20(val), 동결 잠재, 복제본의 train 궤적에서 학습한다.
- y_j는 정규화 풀의 상태 통계로 정규화한다.

**주 대비 (확증)**
- **S1: Δ_r = Q_r(B) − Q_r(Sham), κ = 1, p = 0.7, n = 24.** 95% 양측 paired t-CI.
- 방향 검출: CI 상한 < 0.

**고정 순서 검정 (FWER ≤ 0.05)** — 앞 단계가 검출되었을 때만 다음 단계를 확증적으로 판정한다.
1. S1 (위)
2. S2: 이중 차이 (B − Sham)_{κ=1} − (B − Sham)_{κ=0}, p = 0.7. Welch 95% CI(복제본은 κ 사이에서 독립). 검출: 상한 < 0.
3. S3: B − Sham, κ = 1, p = 0.3. 검출: 상한 < 0.

**실질 효과 크기 (판정과 분리해 보고, ER E8)**
- δ = 0.02. Phase 5 값이며 사후 결과에 맞춰 줄이지 않는다.
- 다음을 모두 따로 보고한다.
  - 평균
  - 95% CI
  - CI가 −δ보다 작은 쪽에 완전히 있는지(상한 < −δ: "δ 이상 확증")
  - 평균 ≤ −δ인지
  - 표준화 효과 d_z = 평균/SD
  - 음수 복제본 수
  - Wilcoxon p, 부호 검정 p

**음성 대조 (타당성 점검, FWER 족에 포함하지 않음)**
- κ = 0의 B − Sham(p = 0.7, 0.3): ER 명제 E3.1에 의해 **기댓값이 정확히 0**이다.
- 95% CI와 TOST(90% CI ⊂ (−δ, δ))를 보고한다.
- κ = 0에서 95% CI가 0을 제외하면 "파이프라인 비대칭" 경고를 붙이고, S1의 해석을 교란 가능으로 표시한다.

**보조 대비 (서술적, 다중성 보정 없음, 탐색으로 표시)**
- B − A: 원래 H2의 순효과. Phase 5 판정 규칙의 라벨도 함께 보고한다.
- Aslot − A(slot/용량 효과), B − Aslot, Sham − Aslot, B − Bcur, Bcur − Aslot
- 층 L0, L1, L2+, c0, c1(마스크만으로 정함): B − Sham, B − Bcur
- 원시 특징(복제본 수준 H1 추정량): raw_joint − raw_own, raw_owncur − raw_own

**실패 기준**
- 비유한 step이 있거나 상한에 도달한 실행은 제외하지 않고 보고한다. 상한 도달 비율이 10%를 넘는 조건은 "결론 불가"로 표시한다.
- 복제본을 사후에 제외하지 않는다.

## 6. G3 사양 (공유 상태 복원)

**readout**
- 특징 집합마다 **하나의** MLP(2 × 128 ReLU, probe와 같은 학습 규칙, seed 0)를 쓴다. 동결 특징에서 6차원 정규화 상태로 사상한다.
- train 궤적의 자연 마스크 분포에서 학습하고, val로 조기 종료한다.
- 마스크별 readout은 학습하지 않는다.

**특징 집합**
- A_j, Aslot_j, B_j (j = 1, 2)
- 원시 지연 관측 기준선 raw_own_j, raw_joint: 같은 readout 사양을 쓴다.

**평가**
- 각 test 궤적의 같은 실제 상태에 독립 마스크 5개(e = 0..4)를 적용한다.

**지표 (각각 따로 보고. 개념을 섞지 않는다)**
1. Hidden-state decodability: 6차원 readout의 y_j 좌표 RMSE(G2 probe와 별도).
2. Joint-state reconstruction: s6 RMSE(6좌표 평균 MSE의 제곱근). 하위계별로 s1, s2도 보고한다.
3. Same-state mask stability: 같은 시각에서 독립 마스크 쌍의 출력 차이. 지표는 RMS ‖r(M) − r(M′)‖ / √2(마스크 간 표준편차)이고, 두 마스크가 같은 층일 때 그 층에 넣는다.
4. 정확성과 안정성을 함께 본다: 위 2와 3을 같은 층에서 나란히 보고하고, 마스크 평균 출력의 오차도 보고한다.
5. 부호 오류율: |y_j| > 0.5인 점에서 sign(ŷ_j) ≠ sign(y_j)인 비율. 대칭에 의한 전역 모호성의 경험적 지표다.
6. Global injectivity, continuity, homeomorphism, diffeomorphism: 유한 표본으로 증명할 수 없다. **Unresolved로 보고한다.** 위 1–5는 "approximate state recovery"의 경험적 증거로만 쓴다.

**층 (test 결과 전에 고정)**
- 마스크만 사용(추론 시 사용 가능):
  - 결합 층: both_L2+(L1 ≥ 2이고 L2 ≥ 2) / one_L2+ / none_L2+
  - 하위계별 L_j ∈ {L0, L1, L2+}
  - **이 층들은 탐색적 층이며 식별가능 집합이 아니다(ER E5).**
- **Oracle-only** (참 상태 사용, 진단 전용, `jac6.py`):
  - 마스크된 국소 Jacobian ∂(m ⊙ D)/∂s(t)의 σ_min. 정규화 단위이며, 행은 그 특징 집합에 들어가는 view들의 관측 항목이다.
  - 구간: [0, 1e-3), [1e-3, 1e-2), [1e-2, 1e-1), [1e-1, ∞). 관측 행이 6개 미만이면 σ_min = 0이다.
  - 매 5번째 test 시각에서 계산한다.
  - 이 층은 추론에 쓸 수 없다. 마스크만 쓰는 기준과 섞지 않는다.

**경험적 판정 기준 (사전 고정)**
- 특징 집합 F가 층 X에서 "**경험적 근사 상태 복원**"을 보인다고 말하려면 다음 셋을 모두 만족해야 한다.
  - (a) 복제본 평균 s6 RMSE ≤ 0.2(분산의 96% 이상 설명)
  - (b) 마스크 간 표준편차(s6) ≤ 0.1
  - (c) 같은 층에서 raw 기준선(raw_joint 또는 raw_own_j)보다 s6 RMSE가 작음(paired t, 95% CI 상한 < 0)
- 만족하지 못하면 "해당 층에서 공유 상태 복원 증거 없음"으로 보고한다.
- 자기 하위계 y_j만 잘 복원하는 것은 **6차원 공유 상태 복원이 아니다.** 그래서 s6, s1, s2를 따로 보고한다.

## 7. 해석 규칙 (사전 고정)
- S1 검출 시: "κ = 1, p = 0.7에서 Real MV가 같은 구조의 Sham MV보다 y_j를 더 잘 decoding한다(독립 확증)."

- κ = 0 음성 대조가 실패하면(95% CI가 0 제외) S1의 결론을 보류한다.

## 10. 추가 사전 등록 S1R — S1의 독립 재현 (2026-10-28 20:10 KST, S1R 자료 생성·학습 전에 고정)

**동기**
- G2에서 S1(B − Sham, κ = 1, p = 0.7)은 검출됐다(−0.0070). 그러나 같은 p의 음성 대조(κ = 0)가 실패해 사전 규칙에 따라 보류됐다.
- 사후 진단(새 복제본 24개, 결합 적분 J와 분리 적분 S)에서는 κ = 0 대조가 ≈ 0이었다.
  - J: −0.0007 [−0.0060, +0.0046]
  - S: −0.0003 [−0.0054, +0.0047]
- 이 진단 결과는 이미 본 것이다. 그래서 S1의 판정에 쓰지 않고, **새로운 독립 표본으로 S1과 그 음성 대조를 다시 시험한다.**

**설계**
- κ ∈ {1, 0}, p = 0.7, 새 독립 복제본 r = 0..23.
- id 30000번대: train 30000 + r, train donor 30100 + r, val 30200 + r, val donor 30300 + r, test 31000 + 100r + i, test donor 34000 + 100r + i, i = 0..7.
- 생성기, 시드 규칙, 정규화(G2 풀 상수), 학습 루프(train6), probe, 복제본 지표는 G2와 같다.
- Arm은 B1, B2, Sham1, Sham2만 쓴다. 학습은 192개다.

**판정**
- **S1R:** κ = 1의 B − Sham, 95% paired t-CI 상한 < 0이면 검출이다.
- **음성 대조 NC-R:** κ = 0의 B − Sham. 95% CI가 0을 포함해야 하고, TOST(δ = 0.02)도 보고한다.
- 해석:
  - S1R 검출 ∧ NC-R 통과 → "κ = 1, p = 0.7에서 Real MV > Sham MV(y_j decoding)의 독립 확증".
  - S1R 검출 ∧ NC-R 실패 → 결론 보류를 유지한다.
  - S1R 미검출 → S1은 재현되지 않았다.
- δ = 0.02 대비 크기는 따로 보고한다. G2 S1과 S1R을 합친 메타 결과는 보조로만 보고한다.
- 코드: `experiments/phase6/s1r/`. 결과 전에 해시를 고정한다(`results/extra/phase6/s1r/FREEZE.txt`).
