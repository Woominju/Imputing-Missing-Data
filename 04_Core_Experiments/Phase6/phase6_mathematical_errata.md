## E1. 대칭에 의한 충돌: "정확히 2:1" → "적어도 2:1"

**원래 주장** (MF 따름정리 1, OA §2·§3·§8, handover §2)
- "z-only 마스크는 모든 κ에서 전역 **정확한** 2:1 충돌을 만든다."

**정확한 가정**
- Γ×Γ가 F_κ와 교환한다(MF 보조정리 S(i), 직접 대입으로 증명됨).
- 관측 O_m은 창 안의 z 좌표만 쓴다(x 관측 없음).
- 지연 사상이 정의되는 집합 위에서 생각한다(E2).

**증명된 범위 [Verified (math)]**
- O_m(Γ×Γ s) = O_m(s)이고, s ∉ Fix(Γ×Γ) = {x1 = y1 = x2 = y2 = 0}이면 s ≠ Γ×Γ s다.
- 따라서 Fix 밖의 모든 s에 대해 섬유(fiber) O_m⁻¹(O_m(s))는 **적어도 두 점**을 갖는다.
- 이것이 증명된 전부다. 섬유의 크기가 정확히 2라는 진술은 별도 증명이 없다.

**반례·반증 가능성**
- **κ = 0에서는 적어도 4:1이다** [Verified (math)].
  - κ = 0에서는 Γ×Id, Id×Γ, Γ×Γ가 모두 F_0와 교환한다(보조정리 S(ii)는 κ = 0에서 Γ×Id를 허용하고, 같은 계산이 Id×Γ에도 성립한다).
  - 이 셋과 항등원은 Z₂×Z₂를 이루고, z-only 관측은 넷 모두에 불변이다.
  - s1, s2가 각각 자기 하위계의 Fix 밖에 있으면 네 상태가 서로 다르다. 따라서 섬유의 크기는 4 이상이다.
- κ = 1에서도 대칭이 아닌 우연한 충돌(서로 다른 궤도가 같은 z 창을 갖는 경우)을 배제한 증명이 없다. 섬유의 크기는 2보다 클 수 있다.

**수정된 주장**
- "z-only 마스크에서 O_m은 Fix(Γ×Γ) 밖의 모든 점에서 **적어도 2:1**이다(κ = 0에서는 적어도 4:1). 섬유의 정확한 크기는 증명되지 않았다 [Unresolved]."
- 부호 식별 불가능성(명제 1 → y_j의 부호를 정할 수 없음)은 "적어도 2"만으로 성립하므로 **결론은 그대로 유효하다.**

**영향받는 기존 결과**
- 문구만 바뀐다: MF 따름정리 1, OA §2 표 아래 문장, OA §3 해석 1, OA §8 첫 행, handover §2.
- 수치는 영향이 없다. Gate C의 "z-only 이웃 49–50%가 반대 부호"는 적어도 2:1과 모순되지 않는다.

**여전히 유효한 결과**
- 명제 1, 따름정리 2(κ = 0, x_j 미관측 → 부호 식별 불가), 따름정리 3(대칭 측도 하 Bayes 추정 0).
- "국소 full rank ≠ 전역 단사"라는 반례.

## E2. 음의 시간 지연과 전역 과거 흐름의 정의역

**원래 주장** (MF §1.3)
- "완전 지연 사상 D(s) = [h_i(Φ^{−kτΔt}(s))], D: R⁶ → R³²."

**정확한 가정**
- MF §1.1이 증명한 것은 **순방향** 흐름의 대역적 존재다(V̇ ≤ −cV + C → t ≥ 0에서 흡수 공).
- 이 논증은 t < 0에 대해 아무것도 말하지 않는다.
  - 역방향에서는 V̇ ≥ −(…)가 아니라 부호가 뒤집힌다.
  - 소산계의 역방향 해는 부피가 팽창하는 방향으로 간다.
- 따라서 **R⁶의 모든 점에서 Φ^{−t}가 정의된다는 보장은 없다.** 유한 시간 역방향 폭주가 일어날 가능성을 배제하지 않았다.

**증명된 범위 [Verified (math)]**
- F_κ는 다항식이므로 국소 해가 유일하다. 따라서 Φ^t(t ≥ 0)는 단사이고, 그 상 위에서는 역이 정의된다.
- 그러므로 D는 다음 두 집합 위에서는 잘 정의된다.
  - (a) X_T := Φ^T(R⁶), T ≥ (m − 1)τΔt = 0.35. 이 집합의 점 s = Φ^T(s₀)에 대해 Φ^{−t}(s) = Φ^{T−t}(s₀)는 0 ≤ t ≤ T에서 정의된다.
  - (b) 대역 끌개 A_κ. A_κ는 콤팩트 불변집합이다(Φ^t(A_κ) = A_κ, t ≥ 0). 각 점을 지나는 완전 궤도가 A_κ 안에 있으므로 Φ^{−t}가 A_κ 위에서 모든 t ≥ 0에 대해 정의되고 A_κ로 간다.
- 자료의 모든 표본은 transient 250 시간단위 이후의 순방향 상이므로 (a)에 속한다. **실제 계산에는 문제가 없다.**

**반례·반증 가능성**
- R⁶ 전체에서 역방향 흐름이 대역적으로 존재하는지는 이 문서에서 판정하지 않는다 [Unresolved]. 존재하지 않는 점이 있다면 "D: R⁶ → R³²"는 정의되지 않는다.

**수정된 주장**
- "D: X_T → R³² (T ≥ 0.35), 또는 D: A_κ → R³². 국소 Jacobian(R⁶ 기준 rank)은 X_T의 내점(열린 집합)에서 정의되며, Gate C의 계산점은 모두 X_T에 속한다."
- MF §2.1 표의 "R⁶ 기준 rank"는 "열린 집합 X_T 기준 rank"로 읽는다. X_T는 Φ^T가 열린 사상이므로 열린 집합이다.

**영향받는 기존 결과**
- 없음(정의역만 명시).

**여전히 유효한 결과**
- Gate C의 국소 Jacobian 계산: 후진 RK4 변분방정식은 데이터 점(X_T에 속함)에서 0.35 시간단위만 역적분하므로 정의역 안이다.

## E3. Bayes 위험의 명제와 학습 추정량의 기대 차이

**원래 주장**
- PR §1: "κ = 0 (음성 대조) … H2의 개선도 0이어야 한다. κ = 0에서 B가 A보다 의미 있게 좋다면 그것은 … 인공물이다."
- PR §6: "음성 대조(κ = 0)의 기대 결과는 '효과 없음과 동등'이다."
- PR §7: "H1이 '효과 없음과 동등'인데 H2가 '지지'라면 모순이다(MF 명제 6)."
- RES §3.1: "H1이 '음수'라는 주장은 수학적으로 불가능하다."

**정확한 가정과 증명된 범위**
- 명제 2(L² 사영 항등식) [Verified (math)]: Y ∈ L², σ(U) ⊆ σ(U, V)일 때
  R*(U) − R*(U, V) = E[(E[Y|U,V] − E[Y|U])²] ≥ 0.
  - 이것은 **Bayes 최적 위험**(모든 가측함수에 대한 최소 위험)에 관한 명제다.
- 명제 3 [Verified (math), 가정 하]: κ = 0이고 (Y, U) ⊥ V이면 Bayes 개선량은 0이다.
- 명제 6 [Verified (math)]: 결정론적 z = E(O)에 대해 R*(z) ≥ R*(O).
  - 이것도 Bayes 수준의 진술이다.

**반례·반증 가능성 — 왜 추정량에는 적용되지 않는가 [Verified (math)]**
- 학습한 예측기 f̂_A(U), f̂_B(U, V)는 유한 표본과 제한된 함수족, 최적화로 얻는다. 그 위험은 R(f̂) = R* + (근사 오차) + (추정 오차) + (최적화 오차)다.
- κ = 0에서 Bayes 개선량이 0이라도 E[R(f̂_B) − R(f̂_A)]는 0일 필요가 없다.
  - **간단한 반례:** V가 Y, U와 독립인 잡음 차원 d개라도, 같은 표본 수로 학습한 최소제곱 선형 예측기는 기대 초과 위험이 대략 σ²·dim/n만큼 커진다. 따라서 E[R(f̂_B)] > E[R(f̂_A)]이다.
  - 반대로 아키텍처의 정규화 효과 때문에 f̂_B가 더 나을 수도 있다.
- 따라서 "κ = 0에서 B − A = 0이어야 한다"는 **정리가 아니다.** Phase 5의 관측값 κ = 0, p = 0.7에서 B − A = +0.023은 명제 3과 모순되지 않는다.
- 같은 이유로 다음 두 사실도 수학적 모순이 아니다.
  - 원시 MLP probe가 H1을 검출하지 못하거나(심지어 joint가 더 나쁜 것)
  - 잠재 MLP probe가 개선을 보이는 것
  - 두 추정량은 서로 다른 함수족이고, 둘 다 Bayes 위험의 상계일 뿐이다. 상계 두 개의 대소는 Bayes 위험의 대소에 대해 아무 말도 하지 않는다.
- PR §7의 "모순" 조항은 **틀렸다.** 그 조합이 나오면 가능한 설명은 누출이 아니라 "추정량 차이"일 수 있다. 누출을 의심하는 것 자체는 좋은 실무 습관으로 남긴다.

**새로 증명한 사실: 추정량 수준에서 정확히 0인 대조 [Verified (math)]**
- **명제 E3.1 (κ = 0, 독립 donor의 Real–Sham 교환가능성).** 다음을 가정한다.
  - (i) κ = 0
  - (ii) 하위계 초기조건 s1(0), s2(0)이 서로 독립이고 donor 궤적과도 독립이며, 모든 궤적이 같은 초기 분포에서 나온다. `gen_data.py`는 하위계별로 독립 균등 추출을 쓰므로 성립한다.
  - (iii) Real과 Sham에서 마스크, 정규화 규칙, 아키텍처, 학습 seed 분포, probe 절차가 동일하다. 정규화 규칙은 각 열을 그 열을 공급한 계열에서 계산하는 규칙이며, Phase 5와 G2 모두 해당한다.
  - (iv) 각 복제본의 donor가 그 복제본의 실제 궤적과 독립이다.
- **결론:** 복제본 하나에서 Real 학습 자료의 분포와 Sham 학습 자료의 분포가 정확히 같다. test 쌍도 같다. 따라서 학습 결과의 분포가 같고, **E[B − Sham] = 0이 정확히 성립한다**(복제본 분포에 대한 기댓값).
- **증명:**
  - κ = 0에서 s1(·)은 s1(0)만의, s2(·)는 s2(0)만의 결정론적 함수다.
  - Real 쌍은 (s1^a(·), s2^a(·))이고 Sham 쌍은 (s1^a(·), s2^b(·))다.
  - (ii)에 의해 s2^a(0)와 s2^b(0)은 모두 s1^a(0)과 독립이고 같은 분포를 가지므로, 두 쌍의 결합 분포가 같다.
  - 마스크와 seed는 (iii)에 의해 상태와 독립이고 두 Arm에 같은 방식으로 주어진다.
  - 학습 알고리즘은 입력 자료와 seed의 가측함수이므로 결과의 분포가 같다. ∎
- **범위:**
  - "기댓값이 0"이지 "모든 복제본에서 0"은 아니다.
  - Phase 5의 순환 donor((r + 1) mod 8)도 (iv)를 만족하므로 **주변 기댓값은 0**이다. 다만 복제본끼리 독립이 아니다(E6).
  - κ = 1에서는 (ii)의 결론(결합분포 동일)이 성립하지 않는다(MF §3.4). 따라서 이 명제는 κ = 1에 적용되지 않는다.

**수정된 주장**
- κ = 0의 음성 대조는 **B − Sham에 대해서는 추정량 수준에서 정확히 0이 기대되는 대조**다(명제 E3.1).
- **B − A에 대해서는 0이 기대되지 않는다.** 입력 차원과 아키텍처가 다르기 때문이다.
- H1/H2의 "Bayes 수준"과 "추정량 수준"을 모든 문서에서 구분한다.

**영향받는 기존 결과**
- PR §1·§6의 "κ = 0 B − A의 기대 결과 = 동등". 판정 결과(OPPOSITE)는 그대로지만, 그것이 "교란의 증거"라는 해석은 약해진다. 입력 비용이라는 설명과 일관된다.
- PR §7의 모순 조항. 실제로 발동되지는 않았다(H2가 지지되지 않았으므로).
- RES §3.1의 문장은 그대로 맞다. "H1의 Bayes 개선이 음수"는 불가능하고, 추정량 차이는 음수일 수 있다.

**여전히 유효한 결과**
- 명제 2, 3, 6과 그 증명, 명제 2의 반례(조건부 의존 ≠ 위험 감소).
- Phase 5의 수치 전부.

## E4. 명제 3의 곱 측도 가정: 고정 시각에서는 정확, 시간 평균에서는 정상성 필요

**원래 주장** (MF §1.2, §3.2 (A1))
- "상태 분포가 곱 측도 μ_L ⊗ μ_L이다(SRB 측도와 에르고딕 극한 근거)."

**정확한 가정과 증명된 범위 [Verified (math)]**
- 자료 생성은 하위계별 독립 초기조건이다(`gen_data.py:s0_of`).
- 따라서 κ = 0에서는 **각 고정 시각 t에서** (s1(t), s2(t))가 정확히 독립이다. SRB 측도나 에르고딕성이 필요 없다.
- 평가는 여러 시각 t를 섞는다. 공통의 시각 지표 T로 섞으면 (s1(T), s2(T))는 일반적으로 정확히 독립이 아니다. T가 두 하위계에 공통이기 때문이다.
- 정확히 독립이려면 s_j(t)의 주변분포가 t에 의존하지 않아야 한다(정상성). transient 이후의 근사 정상성은 Hypothesis이고, 수치로는 Phase 5의 corr(x1, x2) = 0.010이 이와 일관된다.

**수정된 주장**
- "κ = 0, 고정 t에서 정확한 독립 [Verified (math)]. 시간 평균 위험에서는 근사 정상성 하에서 근사적으로 독립 [Hypothesis + Empirical]."
- **명제 E3.1(Real–Sham 교환가능성)은 시각별 결합 과정 전체의 분포 동일성을 쓰므로 정상성이 필요 없다.**

**영향**
- 명제 3의 결론은 "근사적으로 0"으로 약해진다. κ = 0 대조의 지위는 명제 E3.1(B − Sham)이 더 강하다.

## E5. H3의 "허용 마스크" L_j ≥ 2

**원래 주장**
- MF §7.1: "허용 마스크 집합 𝓜_adm: 명제 1과 따름정리 1–3으로 배제되지 않고 수치 조건이 미리 정한 기준을 만족하는 마스크. 여기서는 층 L_j ≥ 2를 사용한다."
- OA §7: "H3 허용 마스크 = L2+."

**정확한 가정**
- L_j(t)는 자기 창 안에서 관측된 x_j 항목의 **개수**다. 마스크만으로 정해지는 정수다.

**증명된 범위**
- L_j ≥ 1이면 x_j의 부호가 관측되므로 Γ_j 계열 대칭(Γ_j×Id, Γ×Γ)은 그 마스크에서 O_m을 보존하지 않는다 [Verified (math)].
  - 즉 **알려진 대칭 반례가 적용되지 않는다**는 것까지만 증명됐다.
- 다음은 증명되지 않았다.
  - (a) 전역 단사성(대칭이 아닌 충돌의 부재)
  - (b) 국소 rank 6
  - (c) σ_min의 하한
  - (d) 마스크별 상태 추정 위험의 상한

**반례·반증 가능성 [Verified (code/data), Gate C 수치]**
- κ = 0에서는 L_j가 얼마든 s_{3−j}에 대한 정보가 0이다. **6차원 상태에 대해 L_j ≥ 2는 결코 식별 가능 집합이 아니다**(국소 rank 3, OA §3 표).
- κ = 1, 자기 창 완전 관측(L_j = 8)에서도 6차원 σ_min 중앙값은 0.027이다. 국소적으로 6차원을 관측하지만 조건이 극도로 나쁘다.
- 자기 MCAR p = 0.7에서 rank 6 비율은 0.33이다. L_j ≥ 2는 그 안에서 개수만으로 나눈 층이다.
- 즉 L_j ≥ 2는 **관측 개수에 근거한 탐색적 층**이다.

**수정된 주장**
- "L_j ≥ 2: x_j가 창 안에서 두 번 이상 관측된 탐색적 층. 알려진 Γ 대칭 반례를 배제하지만, 상태 식별가능성을 보장하는 집합이 아니다."
- 이후 문서에서는 이 층을 "허용(admissible) 마스크"라고 부르지 않는다. **"L2+ 층"**이라고 부른다.
- G3에서는 다음 넷을 분리해 보고한다(G3 사전 등록 참조).
  - (i) 마스크만으로 정한 층(추론 시 사용 가능)
  - (ii) 참 상태에서 계산한 국소 Jacobian의 rank와 σ_min 층(**Oracle-only 진단**)
  - (iii) 대칭에 의한 전역 충돌(이론)
  - (iv) 마스크별 상태 추정 위험(경험)

**영향받는 기존 결과**
- RES §4의 H3 결론("강한 H3 기각")은 L2+ 층에서 측정한 것이다. "허용 마스크에서의 일관성 실패"가 아니라 **"L2+ 층에서의 일관성 실패"**로 읽어야 한다.
- 수치 자체는 그대로다.

## E6. Sham donor의 독립성 (Phase 5)

**원래 설계** (`core.py:build`, PR §4)
- train Sham donor = 복제본 (r + 1) mod 8의 train 궤적. val donor = 100 + (r + 1) mod 8. test donor = 200 + (i + 1) mod 10.

**확인한 사실 [Verified (code/data)]** (`results/extra/phase6/g0/phase5_sham_donor_map.csv`)
- 모든 train/val donor는 **다른 복제본의 실제 대상 궤적**이다.
  - 복제본 r의 Sham 학습 자료와 복제본 r + 1의 A/B/Bcur/C 학습 자료가 같은 궤적의 하위계 자료를 공유한다.
- 모든 test donor는 **다른 test 대상 궤적**이다.
  - test 궤적 i의 Sham 입력은 test 궤적 i + 1의 실제 하위계 자료다.
- 복제본 대비 d_r = B_r − Sham_r은 순환 1-의존 구조를 갖는다. 즉 d_r과 d_{r+1}이 같은 궤적을 쓴다.

**t-CI의 정당성 [Verified (math)]**
- paired t-CI는 d_1, …, d_n이 독립 동일분포라고 가정한다.
- 순환 1-의존이면 Var(d̄) = (σ²/n)(1 + 2ρ₁)이다(ρ₁ = 인접 상관, 순환이므로 n개의 인접 쌍).
- ρ₁ > 0이면 t-CI는 **너무 좁고**, ρ₁ < 0이면 너무 넓다. ρ₁의 부호는 설계로 정해지지 않는다.

**수치 감도 [Empirical]** (`phase5_bsham_dependence.csv`)

| κ, p | B − Sham 평균 | t-CI (독립 가정) | ρ̂₁ (n = 8, 순환) | ρ = 0.5일 때 CI 상한 |
|---|---|---|---|---|
| 1, 0.7 | −0.0149 | [−0.0251, −0.0048] | **+0.43** | **−0.0006** |
| 1, 0.3 | −0.0133 | [−0.0150, −0.0115] | +0.20 | −0.0107 |
| 0, 0.7 | +0.0033 | [−0.0061, +0.0127] | −0.05 | +0.0166 |
| 0, 0.3 | −0.0003 | [−0.0020, +0.0013] | −0.51 | +0.0020 |

- κ = 1, p = 0.7에서 순환 인접 상관의 추정치는 +0.43이다. n = 8에서 추정한 값이라 매우 불확실하다.
- ρ = 0.5까지 허용하면 CI 상한이 −0.0006으로 0에 거의 닿는다.
- 부호 검정(8/8, p = 0.0078)도 독립을 가정하므로 같은 제약을 받는다.

**수정된 주장**
- Phase 5의 B − Sham t-CI는 **독립 반복에 대한 확증적 추론으로 쓸 수 없다.** 원래 사후 탐색이기도 하다.
- 수치는 그대로 보존한다. 방향(κ = 1에서 음수)은 "독립 표본에서 다시 시험할 가설"로만 쓴다.

**G2 설계로의 반영**
- 복제본마다 서로 겹치지 않는 독립 donor 궤적을 쓴다(train donor, val donor).
- test는 복제본마다 독립 test 대상 궤적과 독립 test donor 궤적을 둔다.
- 결과적으로 복제본 대비가 **정확히 독립**이 된다.

**유지하는 문제 [Verified (math), MF §3.4]**
- κ = 1에서 Sham의 결합 입력 분포는 실제와 다르다.
- 따라서 Real − Sham은 Bayes 정보량의 추정이 아니다. "학습 모델이 실제 결합 관계에서 얻는 이득"과 "분포 차이에 대한 학습 반응"이 섞인 양이다.

## E7. Gate F MV-shift의 시간 정렬

**원래 설계** (`external.py:shift_index`)
- view k를 각 분할 안에서 14k일만큼 순환 이동했다. 위치 t에서 view k는 원래 시각 t − 336k(시)를 보인다(분할 안 순환).
- 감사 문서(`phase5_external_dataset_audit.md` §F.4)는 이를 "view 사이 정렬만 파괴하고 공통 일주기 외력은 통제하는 대조"로 서술했다.

**확인한 사실 [Verified (code/data)]** (`results/extra/phase6/g0/mvshift_time_offsets.csv`)
- 위치 t에서 view k의 목표는 원래 시각 u = t − 336k다. 같은 위치의 view k′ 입력은 원래 시각 u + 336(k − k′)다.
- **k′ < k인 view는 목표보다 미래**(336(k − k′)시간 뒤)의 값이다.
  - 예: NO2(k = 1)의 원래 시각 18000을 예측할 때 PM2.5(k′ = 0)는 원래 시각 18336의 값을 준다(사용자 예시와 일치).
- Beijing test 구간, lag 0 기준으로 target view별 "다른 view 입력이 미래인 비율":
  - PM2.5 0.25, NO2 0.33, CO 0.40, O3 0.47, TEMP 0.54, PRES 0.60, DEWP 0.67, WSPM 0.74
  - Jena: p 0.08 ~ v 0.92
- 분할 안 순환 때문에 **랩 경계를 넘은 다른 view 입력**은 수천 시간 떨어진 값이다(최대 4,924시간).
  - 설계는 **목표 view 자신의 창**이 랩을 넘는 항목만 제외했다. 다른 view의 랩은 제외하지 않았다.
- MV(정렬)와 SV는 원래 시각 기준 past-only다(Phase 5 테스트로 확인).

**수정된 주장**
- MV-shift는 **"원래 시각 기준 past-only 대조군"이 아니다.** 다른 view에서 미래(14일 이상 뒤)와 과거 값이 섞여 들어오는 **시간 정렬 교란 스트레스 실험**이다.
- 해석에 미치는 방향:
  - 14일 이상 떨어진 값의 정보는 약하다(Beijing 대기 변수의 자기상관 시간은 수일).
  - 따라서 이 미래 노출이 MV-shift를 유리하게 했을 수는 있어도, MV − MV-shift < 0이라는 결과를 **만들어냈을 가능성은 낮다** [Hypothesis].
  - 그러나 "정렬 정보의 이득"의 크기를 공정하게 재려면 대조군이 필요하다. 그 대조군은 모든 다른 view가 목표보다 과거에만 있어야 하고, 계절 위상이 보존되어야 한다.
- **공정한 대조군 제안 (Phase 6에서 미실행, 이유: G1–G3 우선):**
  - **목표 view별 지연 대조(MV-lag):** 목표 view k마다 따로 학습한다. 다른 모든 view를 원래 시각 기준 D시간(예: 14일 = 336시간) **과거로만** 이동하고, 목표 view는 정렬을 유지한다. 순환 없이 앞쪽 D시간을 버린다.
  - 대응 기준선은 같은 목표 view별 MV(정렬)다.
  - 이렇게 하면 미래 노출이 0이다. 일주기 위상은 D가 24의 배수라서 보존되고, 계절 위상은 D ≪ 1년이라 근사 보존된다.

**영향받는 기존 결과**
- RES §6의 Gate F 수치는 그대로 보존한다.
- "정렬된 view 통합의 경험적 이득"이라는 해석은 **"정렬을 깬(미래·과거 혼합) 대조보다 낫다"**로 범위를 좁힌다.
- "MV-shift − SV > 0"(정렬이 깨진 view에도 정보가 남는다)는 미래 노출 때문일 수도 있다. 해석을 보류한다.

## E9. 지연 매장 정리 표의 "충분하다"

**원래 주장** (MF §4 "우리 설정에 대한 적용 결과")
- "완전 4-view 창(32 좌표)은 충분하다. 자기 하위계 창(16 좌표)도 개수로는 충분하다."

**수정**
- SYC(1991)의 결론은 prevalent한 관측함수에 대한 것이다. 좌표 사영 h는 prevalent 집합에 속한다는 보장이 없다. z 관측은 실제로 예외다(E1).
- 따라서 "좌표 개수가 SYC의 차원 조건 m > 2·box-dim을 만족한다"는 진술만 맞다. "충분하다"는 **"개수 조건만 만족한다(필요조건의 대리)"**로 고친다.
- MF는 같은 절에서 "개수는 필요조건의 대리일 뿐"이라고 이미 적었다. 앞 문장의 "충분하다"와 상충하므로 앞 문장을 고친다.

## E11. 이 정오표가 바꾸는 Phase 6 설계 요점
1. Sham donor를 복제본마다 독립 궤적으로 둔다. test donor도 test 대상과 독립이다(E6).
2. κ = 0의 B − Sham은 추정량 수준에서 정확히 0이 기대되는 대조다(명제 E3.1). B − A는 그렇지 않다(E3).
3. H1의 정보 하한은 Bayes 위험의 명제와 추정량 결과를 구분한다. 교차 적합 witness에는 추정 오차 분석을 붙인다(G1).
4. H3 층은 마스크만으로 정한 층과 Oracle Jacobian 층을 분리한다. "허용 마스크"라는 용어를 쓰지 않는다(E5).
5. 판정은 방향 검출, 실질 크기, 동등성을 따로 보고한다(E8).
6. Gate F의 MV-shift는 스트레스 실험으로만 인용한다(E7).
