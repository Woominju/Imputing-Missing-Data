## 1. Bayes 위험 하한과 oracle 추정 위험의 관계
- **수학 [Verified (math)]**
  - 임의의 고정 f에 대해 R*_A ≤ R_A(f)(D4)다.
  - 대칭 층에서는 R*_A ≥ LB_A(N1)다.
  - 그러므로 X0와 κ = 0 L_j0에서 LB_A ≤ R*_A ≤ R_A(O_raw)이고, T_A = R_A(O_raw) − LB_A는 oracle 초과위험 R_A(O_raw) − R*_A의 **상한**이다.
  - 그 밖의 층에서는 0 ≤ R*_A ≤ R_A(f)만 알 수 있다.
- **통계:** R_A(f)의 추정은 test 궤적을 합동한 비율 추정량이다. 층의 크기 n_A가 마스크에 따라 무작위이므로 점근적으로 불편하다. 신뢰한계는 복제본(또는 궤적) 단위 t 근사다(유한 표본 보장 아님. 보조로 경험적 Bernstein).
- **코드:** `analyze8.R`(Σ sse / (6n)), T_A = (SSE_f − SSE_sym0[C_A])/(6n)(test 8). sym0 = −μ/σ = 원 단위 0이며, N1의 Bayes 예측과 같다.
- **명확화(반영):** G_tot의 LCB는 **학습 절차의 기대 초과위험** E_r[R(h_r)] − R(O_raw)의 하한이다(oracle 풀 조건부).

## 3. κ = 0 음성 대조의 교환가능성과 동등성 가정
- **교환가능성(P8.3, j별) [Verified (math)]**
  - κ = 0에서 실제 o-하위계 자료와 donor o-하위계 자료는 (자기 자료가 주어졌을 때) i.i.d.다. 초기분포가 하위계 곱이고, 흐름이 비결합이고, donor는 같은 생성기의 독립 궤적이다.
  - Sham_j는 Real이 실제 o-자료를 쓰는 **모든 위치**(train, val, test 입력, readout 목표 S^♯, Fact의 A_o^♯ 학습 자료)에서 donor 자료를 쓴다.
  - 마스크, seed, 정규화(고정 상수), readout 규칙은 같다. 그러므로 맞바꾸면 파이프라인이 정확히 교환된다.
- **코드:** smoke에서 donor := real로 두면 Sham 배열 = Real 배열이다.
- **필요한 추가 가정**
  - GPU 비결정성이 자료와 독립이고 두 실행에 같은 분포다.
  - donor는 각 역할에 한 번만 쓰인다(id 설계로 보장, test 1).
- **평균의 한계:** Real이 j = 1, 2에 공유되므로 j 평균의 분포 대칭은 보장되지 않는다. 기댓값 0만 성립한다. 그래서 정확 부호 검정은 j별로(각 0.025), 평균에는 TOST(t 근사, 정규성 근사)를 쓴다.
- **동등성 판정:** CI가 0을 포함한다는 것을 null 성립으로 보지 않는다. PASS에는 TOST [−0.01, 0.01]이 필요하다. 그 외는 UNDETERMINED이며 확증 보류 라벨을 붙인다(test 9).

## 4. 독립 궤적이 통계적 반복 단위인가
- **복제본 r의 자료는 모두 고유 id이고 서로 독립이다:** train, val, test 8, donor train, val, test 8. κ 사이는 seed가 다르다. 복제본과 풀, 참조는 겹치지 않는다(test 1, 전체 크기).
- **분석 단위는 복제본이다.** test 궤적 × 마스크는 복제본 안에서 합동하며 독립 반복으로 세지 않는다. 시간점도 단위가 아니다.
- **공유 자원(oracle 풀, k-NN 참조, 정규화 상수):** 고정 상수 또는 조건부 진술이다. O_lat은 복제본별이지만 풀이 공유되므로 "풀에 조건부로 독립"이다.
- **p = 0.3과 0.7은 같은 궤적을 쓴다:** p 비교는 대응으로만 하며, 확증 검정은 p = 0.7 하나뿐이다.

## 5. 마스크와 정규화의 공정성
- 복제본의 4열 마스크 배열 하나를 모든 Arm과 특징이 쓴다. Fact와 A_j는 해당 열, donor view는 그 열의 마스크다(test, smoke 확인).
- 평가 마스크 M4(i, e)는 모든 파이프라인(R1, R0, O_raw, O_lat, sym0, 대치)에 같다(`evaluate8` 단일 사전).
- oracle 학습 마스크(풀)는 test 마스크와 다르지만 같은 MCAR(p) 법칙이다. 평가는 같은 test 마스크로 한다.
- 정규화는 모든 곳에서 Phase 6 고정 상수다(자료 의존 정규화 없음). readout의 특징 표준화는 각 파이프라인의 train 특징으로 하며, 같은 규칙이다.
- 의도된 비대칭: R1은 20,000점, O-class는 320만 점으로 학습한다. Family I은 이 차이를 G_rd로 분해하며, 사전에 명시했다.

## 6. Test와 hidden state 누수
- AE에는 y가 들어가지 않는다(입력 OBS만, test와 smoke 확인). 손실, 조기 종료, 정규화에도 y가 없다.
- readout은 y를 train과 val에서만 본다. 선택(조기 종료, ridge λ)은 val로 한다. test는 평가에만 쓴다.
- oracle의 폭 선택은 풀 val로, k-NN의 k는 풀 val로 한다. O_lat 폭은 고정이다. **test로 선택하는 것은 없다.**
- oracle의 자료 접근은 풀 id뿐이다(smoke에서 load 호출 기록으로 확인). 참조 DB는 독립 궤적이다.
- P7 대치 경로는 무작위 가중치로만 시험했다. 고정 전에 P7 결과를 계산하지 않았다.

## 7. α 배분과 고정 순서
- **가족별 α**
  - Family I(단측 0.025): I-1 → I-2 → I-3 → I-4. 각 단계는 앞 단계가 **확증**됐을 때만 같은 α로 검정한다. 이것이 고정 순서 FWER 제어다.
  - IIa(0.0125): IIa-1 → IIa-2
  - IIb(0.0125): IIb-1 → IIb-2
  - 합계 FWER ≤ 0.05다.
- **귀무가설:** I: μ ≤ δ_I, IIa-1: μ ≥ 0, IIa-2: C ≤ 0, IIb-1: Δ ≥ 0, IIb-2: D ≥ 0.
- **게이트:** 확증 라벨을 **제한**만 하므로 FWER를 늘리지 않는다.
- **발견, 수정:** Family I의 "UCB < δ_I(격차 없음)"과 IIb의 "LCB > 0(병치 우위)"는 같은 모수의 **반대 방향** 진술이다. 같은 α로 함께 확증에 쓰면 μ가 경계값일 때 오류율이 2α가 될 수 있다. → **서술적으로 격하했다**(v2 §4.5, §5.3, 코드 열 이름 `descriptive_no_gap_ucb_lt_delta`).
- **미완 셀:** 상한 도달 > 10% 또는 평가 복제본 < 24이면 결론 불가다(코드와 test).

## 8. 결측 위치 대치 평가의 정확한 목표
- **목표:** 관측 변수 view c ∈ {x1, z1, x2, z2}의 실제 값 Õ_c(n)이다(고정 상수로 정규화. 시뮬레이션이므로 무잡음). 대상 위치는 M_{n,c} = 0이고 n ≥ SPAN인 곳이다.
- **추정:** past-only lag-0 출력이다. 창은 n에서 끝나며, 현재 항목은 마스크 0으로 들어간다.
- **방법별 대상 view:** AE는 자신이 decode하는 view만 대상으로 한다(BfullSham은 자기 view, Fact와 A는 자기 view, P7 Bself는 자기 view). 기준선은 0, LOCF(과거 마지막 관측), O_imp(같은 입력, 현재 결측 항목에만 손실)다.
- **층:** 그 view가 속한 하위계의 L_j와 n_obs다. 지표는 view별 RMSE(복제본 평균)다.
- **해석:** 숨은 y는 대치 대상이 아니다(C3).

## 9. CSIA와 GSR의 구분
- **확증 대상:** CSIA(IIa, IIb)다. GSR은 §5.5의 서술 기준 네 개다.
  - 모두 참이어도 "GSR과 양립하는 경험적 증거"일 뿐이다. 단사성, homeomorphism, diffeomorphism은 아니다.
- **해석 금지(§10 #12–13, 16):** RMSE 우위나 비슷한 파라미터 수를 GSR이나 diffeomorphism의 근거로 쓰지 않는다.
