## 1. 설정과 정확한 가정

### 1.1 생성 법칙 P (Phase 6 G1.1과 같음)
- **상태:** s = (x1, y1, z1, x2, y2, z2) ∈ R⁶.
- **흐름 Φ^t:** x로 확산 결합된 두 Lorenz 계(`src/lorenz.py`)다. σ = 10, ρ = 28, β = 8/3, κ ∈ {0, 1}.
  - ẋ_j = σ(y_j − x_j) + κ(x_o − x_j), ẏ_j = x_j(ρ − z_j) − y_j, ż_j = x_j y_j − β z_j
- **초기분포:** 하위계마다 독립으로 x, y ~ U(−15, 15), z ~ U(5, 40)이다(`gen6.s0_of`, 궤적 id별 seed). 적분은 DOP853(rtol 1e-10)이고, dt = 0.05, transient는 5,000 step이다.
- **관측:** O(t) = (x1, z1, x2, z2)(t). y1, y2는 숨겨져 있다.
- **마스크:** M ∈ {0, 1}^{T×4}, 항목마다 i.i.d. Bernoulli(1 − p)이고 상태와 독립이다(MCAR).
- **창:** W_M(t) = {(M_{t−k,i}, M_{t−k,i} O_i(t − k)) : k = 0..7, i = 1..4}. 정규화된 값이고 past-only다.
  - 자기 창은 W_j(t)(i ∈ {x_j, z_j})다.
- **목표:** S = s(t)의 정규화. 좌표 c마다 (s_c − μ_c)/σ_c이고, (μ, σ)는 Phase 6 G2 풀 상수다.
- **위험:** 좌표 평균 제곱오차 R(h) = E‖S − h‖²/6. RMSE = √R다.

### 1.2 대상 분포
- 평가 시각 t의 법칙은 (초기분포, transient 후 시각 지표의 균등 혼합, 마스크 법칙)의 결합 법칙으로 **정의**한다.
- SRB 측도, 에르고딕성, 정상성은 가정하지 않는다.
- 한 궤적 안의 시각들은 독립이 아니다. 독립 단위는 궤적, 그리고 학습된 모델의 복제본이다(§9).

### 1.3 보조정리 (사용하는 사실)

**L1 [Verified (math)] 대칭.** 초기분포는 다음 변환에 불변이다.
- Γ×Γ: (x_j, y_j) → (−x_j, −y_j), j = 1, 2 동시
- P: 하위계 교환
- κ = 0에서 Γ_j×Id

각 변환은 흐름과 가환한다(Γ×Γ와 P는 모든 κ에서, Γ_j×Id는 κ = 0에서). 따라서 모든 t에서 s(t)의 법칙이 이 변환들에 불변이다(G1.1).

**L2 [Verified (math)] 전방 대역 존재와 해석성.**
- V = Σ_j [x_j² + y_j² + (z_j − ρ − σ)²]이라 하자.
- 결합 항은 dV/dt에 −2κ(x1 − x2)² ≤ 0을 더한다. 그래서 단일 Lorenz의 포획 논증이 그대로 적용되고, 모든 초기값에 대해 전방 해가 대역적으로 존재한다.
- 벡터장이 다항식이므로 Φ^t는 초기값에 대해 실해석적이다.
- Liouville 공식으로 det DΦ^t = exp(∫ div) > 0이다. 따라서 Φ^t는 그 상(image)으로 가는 해석적 미분동형이다.

**L3 [Verified (math)] 절대연속.** 초기분포는 Lebesgue 절대연속(a.c.)이다. 따라서 s(t)와 s(t − 7τ)의 법칙도 a.c.다(L2의 미분동형에 의한 push-forward).
- **수치적 주의:** 위상 부피 수축률은 단위 시간당 약 −(2(σ + 1 + β) + 2κ) ≈ −27이다. 그래서 이 밀도는 transient 후 끌개 근방에 지수적으로 집중된다. 아래 L4의 정성적 양성은 **크기에 대해 아무것도 말하지 않는다.**

## 2. 정의: 마스크 조건부 Bayes 위험, 층, 하한, 상한

### 2.1 정의
- **D1 (Bayes 위험):** R*(S | W_M) := inf_f E_P‖S − f(W_M)‖²/6. inf는 모든 가측 f에 대해 잡는다. W_M이 마스크 지시자를 포함하므로 R*(S | W_M, M) = R*(S | W_M)다. 최소화자는 m(W) = E[S | W]다.
- **D2 (층):** A는 **σ(W)-가측**인 사건이다. 예: 마스크만의 함수.
  - R*_A := E[‖S − m(W)‖² | A]/6.
  - **명제 2.1 [Verified (math)]:** A ∈ σ(W)이면 A 위의 최적 예측기도 m(W)다. 층별 예측기를 허용해도 R*_A는 변하지 않는다.
    - 증명: 층 위험 = E[1_A ‖S − f‖²]/P(A)이다. 각 w에서 조건부 최소화자는 E[S | W = w]다. ∎
- **D3 (유효 하한):** 수학적으로 R*_A ≥ LB_A가 증명된 양 LB_A다. 수치는 법칙의 모멘트만 추정해서 얻는다.
- **D4 (oracle 상한):** 학습 자료와 독립인 test 자료에서 평가한 임의의 **고정** 가측 함수 f에 대해 R*_A ≤ R_A(f)다.
  - f는 S를 목표로 지도 학습된 진단 추정기 "oracle"이다.
  - R_A(f)의 test 추정치와 그 상측 신뢰한계(UCB)가 R*_A의 **통계적 상한**이다.
- **D5 (일관 추정치, 상한도 하한도 아님):** 큰 참조 DB에서 같은 마스크를 적용한 1-NN analog 위험의 절반 R̂*_NN이다. Cover–Hart 형 점근적 일관성만 있고(m과 조건부 분산이 연속이라는 가정), 유한 표본 보장은 없다. [Exploratory]
- **D6 (파이프라인 초과위험):** 학습된 파이프라인 h = g∘φ(AE 잠재 φ + readout g)에 대해 E_A(h) := R_A(h) − R*_A ≥ 0이다.
  - **정보 한계 부분** = R*_A
  - **모델 한계 부분** = E_A(h)

### 2.2 기본 부등식 [Verified (math)]
- **(B1)** 임의의 oracle f에 대해 E_A(h) ≥ R_A(h) − R_A(f). 모델 한계의 **하한**이다.
- **(B2)** R*_A ≥ LB_A ⇒ (정보 한계 비율) R*_A / R_A(h) ≥ LB_A / R_A(h).
- **(B3, DPI)** 임의의 φ에 대해 R*(S | φ(W)) ≥ R*(S | W)다.
  - 그리고 R*(S | φ(W)) ≤ R(g'∘φ)가 임의의 readout g'에 대해 성립한다.
  - **R(g'∘φ) − R(f_raw)는 R*(S | φ) − R*(S | W)의 하한이 아니다.** g'가 최적이 아닐 수 있기 때문이다.
  - 그래서 "잠재가 정보를 잃었다"는 Bayes 진술은 이 비교로 증명되지 않는다. 증명되는 것은 "같은 readout 부류·자료량에서 잠재로부터 접근 가능한 위험이 raw보다 크다"뿐이다. 이것을 **F-접근 가능 위험(F-accessible risk)**이라 부른다.
- **(B4, 차원 병목의 부재)** φ*(W) := m(W) ∈ R⁶ ⊂ R¹⁶이면 R*(S | φ*(W)) = R*(S | W)다.
  - 따라서 **잠재 16차원은 Bayes 수준의 정보 병목이 아니다.** Bfull의 손실은 목표, 최적화, 연속성·귀납 편향의 문제이지 차원의 문제가 아니다.
  - 주의: m은 불연속일 수 있다. AE는 연속 함수다. 연속성 제약하의 병목은 Unresolved다.

### 2.3 마스크 분산 항등식 [Verified (math)]
- T를 전체 상태 궤적이라 하고, 마스크 M, M′이 T가 주어졌을 때 i.i.d.라 하자(MCAR). 임의의 h(W_M)에 대해 h̄ := E[h | T]로 둔다.
  - E‖h − S‖² = E‖h − h̄‖² + E‖h̄ − S‖²
  - ½ E‖h(W_M) − h(W_M′)‖² = E‖h − h̄‖²
- 증명: S는 σ(T)-가측이므로 교차항이 0이다(tower). 두 번째 식은 조건부 i.i.d.에서 나온다. ∎
- **결과:** MSE = (마스크 분산) + (마스크 평균 편향)이고, 안정성 SD² ≤ MSE다.
- **Bayes 예측기 m(W_M)도 일반적으로 마스크 분산 > 0이다.** 마스크마다 정보가 다르기 때문이다. 그러므로 "마스크 의존 변동이 크다"는 것 자체는 모델 실패의 증거가 아니다. oracle의 같은 분해와 비교해야 한다.
- 이 항등식은 σ(T)-가측 층(예: all)에서만 성립한다. 마스크로 정의한 층에서는 선택이 마스크에 의존하므로 성립하지 않는다.
- 예시(P7, κ = 1, p = 0.7, Bfull): SD² = 0.0727, MSE = 0.0940 → 마스크 평균 편향² ≈ 0.021이다.

## 3. 식별가능성: 증명된 조건과 반례

**정의**
- 마스크 m과 집합 K ⊂ R⁶에 대해 D_m: s(t − 7τ) ↦ W_m의 관측 항목을 정의한다. 이것은 Φ의 전방 성분들로 이루어진 해석적 사상이다.
- **(K, m)-식별가능** ⇔ D_m이 K 위에서 단사다. 마스크 층 A가 식별가능하다는 것은 P(A)-거의 모든 m에 대해 끌개 지지 집합 위에서 단사라는 뜻이다.

**L4 (양성; 정성적) [Verified (math), 증명 스케치]**
- m의 관측 항목 수 n_obs(m) < 6이면 E[Var(S | W) | M = m] > 0이다.
- 스케치:
  1. Var = 0이라 하자. 그러면 S = h(W) a.s.이다. S와 s(t − 7τ)는 미분동형으로 대응한다. 그래서 D_m은 양의 Lebesgue 측도 집합 E 위에서 단사다(L3).
  2. D_m은 해석적이므로 rank가 최대값 r ≤ n_obs < 6을 갖지 않는 점들은 고유 해석적 부분집합(측도 0)이다.
  3. rank가 상수인 열린 집합에서 상수 rank 정리와 Fubini를 쓰면, E가 양의 (6 − r)차원 측도의 섬유를 가진다. 이는 단사에 모순이다. ∎
- **한계:** L3의 수치적 주의 때문에 크기 하한은 주지 않는다.
- 설계 확률(p = 0.7): P(n_obs < 6) = 0.051.

**L5 (κ = 0 자기 하위계) [Verified (math)]**
- κ = 0이고 n_own,j(m) < 3이면 R*(s_j | W, M = m) > 0이다(정성적).
- 근거: κ = 0에서 (s_j, W_j)는 (s_o, W_o)와 독립이고, W_j는 3차원 a.c. 상태의 해석적 함수다. L4를 3차원으로 적용한다.
- 설계 확률(p = 0.7): P(n_own < 3) = 0.099.

**N1 (대칭에 의한 비식별, 정량적) [Verified (math)]**
- **결합 x-맹 층** X0 := {창 안에 x1, x2 관측 없음}이다.
  - Γ×Γ가 W를 보존하고 법칙을 보존한다(L1). 그래서 E[x_j, y_j | W] = 0(원 단위, j = 1, 2, 모든 κ)이다.
  - 따라서 LB_X0 = Σ_{c ∈ {x1, y1, x2, y2}} E[s_c²]/(6σ_c²)이다. 정규화 목표에서 Bayes 예측은 −μ_c/σ_c이고, 오차는 비중심 2차 모멘트다.
  - 크기는 약 4/6 ≈ 0.67이다(RMSE ≥ 약 0.82). P(X0) = p¹⁶ = 0.0033(p = 0.7).
- **자기 x-맹 층(κ = 0)** L_j0 := {창 안에 x_j 관측 없음}이다.
  - Γ_j×Id가 W(W_o 포함)와 법칙을 보존한다. 따라서 LB = [E x_j² + E y_j²]/(6σ²)이다(약 2/6). P = p⁸ = 0.0576.
- **자기 x-맹 층(모든 κ, 자기 창만)**
  - R*(y_j | W_j, L_j0) = E[y_j²]이고, R*(x_j | W_j, L_j0) = E[x_j²]이다(G1.2).
  - 이것은 **자기 창만 쓰는 추정기**의 하한이며, §6 인증에 쓴다.
- κ = 1의 L_j0에서는 Γ×Γ가 x_o의 부호를 바꾸므로 이 논증이 성립하지 않는다(G1: 정보가 있음, Empirical LCB).

**C1 (반례: L_j ≥ 2는 충분조건이 아님) [Verified (math)]**
- κ = 0에서 L_j = 2이고 창 안에 z_j 관측이 없는 마스크를 생각하자. n_own = 2 < 3이므로 L5에 의해 R*(s_j | W) > 0이다.
- 이 사건의 확률은 C(8, 2)(0.3)²(0.7)⁶ × 0.7⁸ ≈ 0.017(p = 0.7) > 0이다.
- 따라서 "L_j ≥ 2 ⇒ 식별가능"은 거짓이다. Phase 6/7의 L 층은 **서술 층**이며 식별가능 집합이 아니다(ER E5 유지).

**C2 (국소 ≠ 전역) [Verified (math)]**
- dD_m(s)가 full rank(σ_min > 0)이면 역함수 정리로 s의 근방에서 D_m이 단사다. 전역 단사나 미분동형은 따라오지 않는다.
- 예: z-only 창의 2:1(ER E1). 그리고 Γ×Γ 궤도의 두 점은 국소적으로는 정칙일 수 있으나 전역적으로 구별되지 않는다(X0).
- 그래서 oracle σ_min 층은 국소 조건화의 서술로만 쓴다.

**C3 (좋은 imputation ⇏ 상태 복원) [Verified (math)]**
- κ = 0, L_j0 층에서 z_j는 Γ_j-불변이다. 그래서 z_j 결측의 대치는 정확할 수 있다.
- 그러나 N1에 의해 R*(y_j | W) = E y_j²/σ²(약 1, 정규화)다.
- 따라서 관측 변수 대치 정확도는 숨은 좌표의 복원 가능성을 함의하지 않는다.

**C4 (안정성 ≠ 식별) [Verified (math)]**
- 상수 함수는 마스크 분산 0이지만 R = Var(S)다. P7 Bself의 상대 하위계가 실제 예다.

**증명되지 않은 것 (Unresolved)**
- **충분조건이 하나도 없다.** n_obs ≥ 6, L_j ≥ 2, both_L2+ 같은 조건 중 어느 것도 끌개 위의 단사를 보장하지 않는다.
  - Takens / Sauer–Yorke–Casdagli 정리는 **generic(prevalent)** 관측함수에 대한 것이다. 고정 좌표 관측 + Γ 대칭에는 바로 적용되지 않는다. 실제로 X0가 위반 사례다.
- n_obs ≥ 6인 층에서 R*_A가 0인지 양수인지는 알 수 없다.

**정리 (Q-I의 원리적 한계) [Verified (math), 위 L3–L4와 B1–B2에서]**
> 이 무잡음 결정론 계에서 **정량적** 정보 한계(R*_A ≥ c > 0)는 정확한 비식별 증거(대칭)가 있는 층에서만 인증된다. 그 밖의 층에서는 R*_A ∈ [0, R_A(f_oracle)]만 알 수 있다. 따라서 Phase 8은 (i) 모든 층에서 **모델 한계의 하한**(B1)을, (ii) 대칭 층에서만 **정보 한계의 하한**(B2)을 인증할 수 있다. 그 밖의 층에서 "정보 부족"이라는 결론은 **Hypothesis**로만 남는다.

## 4. 실험 Family I — 정보 한계 대 모델 한계 (Q-I)

### 4.1 자료 (모두 새 독립 궤적, 이전 모든 id·seed와 비중첩; 테스트로 확인)
- **AE 복제본(Family II와 공유):** id 50000+, r = 0..23 × κ{0, 1} × p{0.3, 0.7}.
  - 복제본마다 train 1(20,000), val 1(5,000), test 8(5,000)이다.
  - **p = 0.3과 0.7은 같은 궤적을 공유**하고 마스크는 다르다. p 비교는 복제본 대응으로 한다. κ 사이는 seed가 다르므로 독립이다.
- **Oracle 풀(κ별):** id 60000+.
  - oracle-train 40 궤적 × 20,000, oracle-val 8 × 5,000이다.
  - 마스크는 epoch마다 p에 맞게 새로 뽑는다(MCAR 법칙을 알므로 무제한 증강이 가능하다).
  - **oracle은 AE test 궤적을 보지 않는다.**
- **참조 DB(D5용):** id 70000+, 50 × 20,000(κ별).

### 4.2 추정기
- **O_raw (oracle 상한, 지도 학습)**
  - 입력: raw W(64차원 = 값 × 마스크 32 + 마스크 32). 출력: S(6차원).
  - 구조: MLP, 깊이 4, 폭 ∈ {256, 512, 1024}. Adam 1e-3, batch 1,024, epoch ≤ 200, patience 20.
  - **폭은 oracle-val 위험으로만 선택한다**(test 금지).
  - (κ, p)마다 하나의 고정 함수다.
- **O_lat(φ):** O_raw와 같은 부류, 같은 풀, 같은 선택 규칙으로 동결 잠재 φ(W) → S를 학습한다. 특징 집합 × 복제본마다 학습한다.
- **R1 (P7 readout):** `evaluate6.mlp_fit` 2 × 128을 복제본 train 궤적 20,000점에서 학습한다(P7와 동일).
- **O_own,j (자기 창 oracle):** 입력 W_j만 쓰고, s_j와 y_j를 목표로 한다. 자기 창만의 상한이며, κ = 1 교차 정보의 추정량 수준 진단이다.
- **포화 진단 (서술):** 선택된 폭에서 oracle-train 궤적 수를 {10, 20, 40}으로 바꿔 oracle-val 위험 곡선을 본다. 곡선이 계속 감소하면 "oracle 상한이 느슨함"으로 보고한다.
- 이 oracle들은 **진단 도구**이며 AIM의 모델이 아니다. AE 구조나 손실은 바꾸지 않는다.

### 4.3 층 (사전 고정; 마스크만, 추론 시 계산 가능)
- **H (주 어려운 층):** none_L2+ = {L1 ≤ 1 ∧ L2 ≤ 1}. P = 0.065(p = 0.7). p = 0.3에서는 사실상 공집합(4e-6)이므로 Family I은 **p = 0.7만**이다.
- 그 밖: one_L2+, both_L2+, n_obs 구간 {< 6, 6–9, 10–13, ≥ 14}, 대칭 층 X0(모든 κ)과 L_j0(κ = 0의 LB 층, κ = 1의 인증 층).
- Oracle σ_min 층은 서술 전용이다(C2).

### 4.4 대비 (MSE, 좌표 평균, s6; 복제본 r의 test 8 궤적 × 마스크 5 합동)
- **G_tot(A) := R_A(R1∘φ_Bfull) − R_A(O_raw):** 파이프라인 전체의 모델 한계 하한(B1)
- **G_lat(A) := R_A(O_lat∘φ_Bfull) − R_A(O_raw):** 같은 강한 readout에서 잠재의 F-접근 가능 위험 격차
- **G_rd(A) := G_tot − G_lat:** readout 부분(서술)
- **T_A := R_A(O_raw) − LB_A(대칭 층만):** oracle의 초과위험 상한. 작으면 oracle이 그 층에서 Bayes에 가깝다. 점별 불편 추정량 ‖S − f‖² − Σ_{xy 좌표}(S̃_c + μ_c/σ_c)²를 쓴다.
- **정보 한계 비율 하한:** LB_A / R_A(R1∘φ_Bfull)(대칭 층만)

### 4.5 주 결과와 판정 (Family I, 고정 순서, 단측 α_I = 0.025)
- **I-1:** κ = 1, p = 0.7, H에서 G_tot. **LCB_97.5 > δ_I = 0.02**(MSE)이면 "B-full 파이프라인의 H층 오차 중 적어도 δ_I는 관측 정보의 한계가 아니다(모델 한계)"로 판정한다.
- **I-2:** 같은 조건에서 G_lat. LCB > δ_I이면 "강한 readout을 써도 B-full 잠재에서 접근 가능한 위험이 raw보다 크다(잠재 표현 수준의 한계; F-접근 가능 의미)"로 판정한다.
- **I-3:** κ = 0, H에서 G_tot. **I-4:** κ = 0, H에서 G_lat.
- **δ_I = 0.02의 근거:** P7 H층 Bfull MSE(약 0.26)의 약 8%이고, p = 0.7 all 층 MSE(0.094)의 약 20%다. 결과 전에 고정한다.

**추론**
- O_raw는 고정 함수다. G_r는 복제본 r의 test 궤적 위에서 대응 차이로 계산한다.
- n = 24의 단측 t-LCB를 쓰고, 보조로 정확 부호 검정을 쓴다.
- 결론은 **oracle 풀에 조건부**다(B1은 임의의 고정 f에 대해 성립하므로 조건부여도 유효하다).
- CI의 coverage는 점근적 근사다.
- 유한 표본 판(예측을 포획 집합 상자로 clip + 궤적 평균 손실에 경험적 Bernstein)은 포획 상수 C_V를 계산해서 고정한 뒤 보조로 보고한다(과제 M-1).

**반증 / 결론 규칙**
- I-1 UCB_97.5 < δ_I: "H층에서 B-full은 이 oracle 부류보다 δ_I 이상 나쁘지 않다." 이것은 **정보 한계의 증명이 아니다.** 정보 한계는 대칭 층의 T_A와 LB로만 말한다.
- I-1 LCB > δ_I, 그리고 I-2 UCB < δ_I: 실패는 주로 **readout(R1)의 한계**다.
- I-2 LCB > δ_I: 잠재 수준의 접근성 한계다. 단, B3에 따라 잠재가 Bayes 정보를 잃었다는 증명은 아니다.
- 포화 진단에서 oracle 곡선이 계속 감소하면, 모든 "격차 없음" 결론을 "oracle 부류 기준"으로 약화한다.

**보조 (서술, 사전등록)**
- 모든 층과 κ에서 G_tot, G_lat, G_rd, T_A, LB 비율, R̂*_NN(D5)을 보고한다.
- §2.3 분해: O_raw, O_lat∘φ, R1∘φ의 마스크 분산과 편향(all 층)을 보고한다.
  - "B-full의 마스크 분산 ≫ O_raw의 마스크 분산"이면 마스크 의존 변동이 모델 기인이다 [Empirical].
  - 둘이 같은 크기이면 정보의 마스크 의존성이 내재적이라는 뜻이다(마스크 분산의 Bayes 하한이 아니라 같은 부류의 비교).

## 5. 실험 Family II — 진정한 공유 상태 표현의 통제 검증 (Q-II)

### 5.1 수학적 기초

**P8.1 (κ = 0 인수분해) [Verified (math)]**
- κ = 0에서 (s1, W1)과 (s2, W2)는 독립이다. 하위계별 독립 초기조건, 비결합 흐름, 열별 독립 MCAR 때문이다.
- 따라서 E[s_j | W] = E[s_j | W_j]이고, R*(S | W) = ½ Σ_j R*(s_j | W_j)다(좌표 평균).
- **결과:** κ = 0에서 결합 표현이 병치 표현보다 나은 이유는 **교차 정보일 수 없다.** 차이는 추정, 용량, 최적화 효과("병치 비용")뿐이다.

**P8.2 (병치 충분성) [Verified (math)]**
- 임의의 φ_j에 대해 R*(S | φ1(W1), φ2(W2)) ≥ R*(S | W)다.
- (φ1, φ2)가 W_j 위에서 단사이면(더 약하게, 결합 충분이면) 등호가 성립한다.
- **결과:** 손실 없는 자기 view AE의 병치에 충분히 강한 readout을 쓰면 Bayes 수준에서 B-full과 같다. 따라서 B-full과 Fact의 차이는 (a) 인코더의 정보 손실 차이이거나 (b) **고정 readout 부류에서의 접근성** 차이다.
  - "진정한 공유 상태"의 조작적 의미는 (b)다. 결합 정보가 **고정된 약한 readout으로 접근 가능한 형태**로 잠재에 형성되었는가를 묻는다.

**C5 (주변 충분성 ⇏ 결합 충분성) [Verified (math), 반례]**
- W1 = (a, b), W2 = c, s1 = a, s2 = b·c라 하자.
- φ1(W1) = a는 s1에 대해 충분하다. 그러나 φ1이 b를 버리므로 (φ1, φ2)는 s2에 대해 충분하지 않다.
- 따라서 "각 자기 표현이 자기 상태에 충분"하다는 것만으로는 병치가 결합 정보를 보존한다는 결론이 나오지 않는다.

**P8.3 (Sham 교환가능성) [Verified (math), E3.1의 확장]**
- 상대 view를 독립 donor 궤적(같은 κ, 같은 법칙)의 상대 view로 바꾼 것을 W_o^♯라 하자.
- κ = 0에서는 자기 자료가 주어졌을 때 (W_o, W_o^♯)가 i.i.d.다. 같은 seed와 같은 마스크로 학습·평가하면 (Real_r, Sham_r)은 교환 가능하다.
  - 그러므로 임의의 파이프라인 F에 대해 CG_F,r := R(y_j | F_real) − R(y_j | F_sham)의 분포는 0에 대해 대칭이다. **정확 부호 검정이 유효하다.**
- κ = 1에서 Sham은 결합만 끊고 주변 법칙은 보존한다.

**P8.4 (자기 L0 인증) [Verified (math); G1.2 + G1.4 적용]**
- 모든 κ에서 R*(y_j | W_j, L_j0) = E[y_j²]다(원 단위; 정규화에서는 E[(S̃_y + μ_y/σ_y)²]).
- 따라서 test와 독립으로 학습된 **임의의** 특징 F(W)와 readout g에 대해 다음이 성립한다.
  - C_F := E[y_j² − (y_j − g(F))² | L_j0] > 0 ⇒ g∘F는 **σ(W_j) 밖의 정보(상대 view)**를 쓴다.
- κ = 0에서는 E[y_j | W, L_j0] = 0(N1)이므로 모든 F에 대해 C_F ≤ 0이다. **수학적 음성 대조**다.
- 이것이 "비지도 표현이 교차 정보를 담는다"를 **readout이 성공했다는 사실만으로가 아니라 하한 논리로** 인증하는 유일한 경로다. 다만 인증되는 대상은 g∘F 파이프라인이다. F가 g 없이 무엇을 "안다"는 진술이 아니다.

**IIb — 결합 인코딩 대 병치**

**κ = 0의 해석 규칙 (사전 고정)**
- κ = 0에서 D_0 := RMSE_s6(Bfull) − RMSE_s6(Fact8)는 **병치 비용 / 결합 학습의 추정 효과**로만 보고한다. 교차 정보나 공유 상태로 해석하지 않는다(P8.1).
- κ DiD (D_1 − D_0, Welch)는 서술 전용이다. 두 κ는 동역학 자체가 다르므로 상호작용을 결합 정보로 귀속할 수 없다.

**반증 기준**
- IIa-1이 검출되지 않으면(UCB ≥ 0) "B-full의 잠재와 R1 readout은 κ = 1에서 실제 상대 view로부터 자기 숨은 상태에 대한 이득을 얻는다"가 이 설계에서 지지되지 않는다.
- IIb-1 UCB ≥ 0이면 "결합 잠재는 병치보다 결합 정보를 더 잘 활용한다"가 지지되지 않는다. Δ_JF > 0(CI 하한 > 0)이면 반대 방향(병치가 우월)으로 보고한다.
- 게이트 실패는 해당 하위 가족의 결론을 보류한다.

**보조 (서술, 사전등록)**
1. p = 0.3에서 같은 대비
2. Fact16, O-class, R0 readout에서 같은 대비
3. 하위계별 s_j, s_o와 층별(L_j, n_obs, X0, H)
4. 자기 view만의 oracle O_own,j 대비: κ = 1 교차 정보의 추정량 수준 크기, R(O_own,j) − R(O_raw)
5. P8.4 인증을 Fact8, BfullSham(기댓값 ≤ 0이어야 함), O_raw(G1 재현)에 적용
6. §2.3 분해
7. 학습 진단

## 6. Family III — 결측 위치 대치 평가 (Q-III; 서술, 사전등록)

**정의:** 마스크 M_{t,i} = 0인 위치(t ≥ SPAN)에서 past-only lag-0 출력 x̂_i(t)와 실제 값의 RMSE(정규화 단위)를 잰다.
- view별, 자기 층 L_j ∈ {L0, L1, L2+}별, n_obs 구간별로 잰다. test 8 × 마스크 5이고 복제본이 단위다.

**대상**
- P8 Arm: Bfull, BfullSham(자기 view), Fact8과 Fact16(각 A_j는 자기 view)
- **P7 checkpoint(추가 학습 없음):** Bfull(4 view), Bself_j(자기 view만. 비활성 head는 학습되지 않았으므로 평가하지 않음), P7 test 자료와 마스크(e = 0..4)
  - 이것은 **Phase 7에 대한 사후 평가**이지만 이 프로토콜에서 결과 전에 고정한다.

**기준선**
- 0(평균)
- LOCF(past-only, 마지막 관측값)
- **O_imp:** 지도 oracle 대치기. O_raw 부류이고, 입력은 W, 목표는 현재 4 view 값이다. 대치 Bayes 위험의 상한이다.

**관계 분석 (서술)**
- 복제본 간 Spearman(대치 RMSE, 상태 RMSE_s6)을 Arm마다 구한다.
- 같은 층에서 "대치 ≈ oracle인데 y_j 오차 ≫ oracle"인 경우를 표로 보고한다(C3의 경험적 대응).
- **해석 제한:** 대치는 관측 좌표(x, z)의 추정이다. 숨은 좌표에 대해 아무것도 함의하지 않는다(C3).

## 7. Family IV — Readout 없는 잠재 진단 (탐색적)
- **마스크 민감도 비율:** ρ_φ = ½ E‖φ(W_M) − φ(W_M′)‖² / tr Cov(φ). 같은 상태에 독립 마스크 두 개를 쓴다.
- **잠재 이웃 상태 불일치:** test 점마다 잠재 공간의 k-NN(다른 마스크, 시각 포함)을 찾고 그 참 상태의 6차원 거리 분포를 본다. 근사 단사성의 경험적 지표다.
- **분석 범위:** 지도 readout의 성공을 비지도 AE 자체의 상태 복원으로 취급하지 않기 위한 보완이다. 그래도 **전역 단사성의 증명이 아니다**(C2).

## 9. 통계적 추론 단위
- **단위 = 독립 복제본 r**(n = 24 / (κ, p)).
  - 복제본마다 독립 train, val, test 궤적과 독립 마스크 seed를 쓴다. AE와 R1은 복제본마다 새로 학습한다.
  - 한 복제본 안의 Arm은 같은 자료, 마스크, (해당 시) 초기 가중치를 쓴다 → **대응 비교**다.
- **test 궤적 8 × 마스크 5:** 복제본 안에서 합동한다(SSE 합 / n). 독립 반복으로 세지 않는다.
  - 시간점은 단위가 아니다(시간 상관).
  - 분산 성분(복제본 / 궤적 / 마스크)은 서술로 보고한다.
- **고정 oracle(O_raw, O_imp):** 결론은 oracle 풀에 조건부다. O_lat은 복제본마다 학습하지만 풀은 공유한다 → 풀에 조건부로 복제본이 독립이다.
- **κ 사이:** 독립(seed가 다름) → Welch.
- **p 사이:** 같은 궤적 → 복제본 대응.
- **j(하위계):** 복제본 안에서 평균한다. 두 j를 독립 반복으로 세지 않는다.
- **다중성**
  - Family I: α = 0.025(단측)
  - Family II: α = 0.025(IIa 0.0125, IIb 0.0125, 각 고정 순서)
  - 합계 FWER ≤ 0.05
  - 그 밖은 모두 서술적이다.
- **검정력 근거:** P6 S1R 효과(−0.010, d_z 약 2)에서 n = 24이면 검정력이 0.99 이상이다. 기대 효과가 작아도 n은 줄이지 않는다.
- **실패 처리**
  - 비유한 실행이나 상한 도달은 제외하지 않고 보고한다. 어떤 셀에서 상한 도달 > 10%이면 그 셀은 결론 불가다.
  - 마감 전에 끝나지 않은 셀은 미실행으로 보고한다.

## 10. 해석 규칙 (사전 고정; 금지된 추론)
1. 낮은 readout RMSE ≠ 전역 단사성이나 homeomorphism, diffeomorphism.
2. 지도 readout의 성공 ≠ 비지도 AE 자체의 상태 복원. 모든 상태 진술에는 "readout 부류 F, 자료량 n에서 접근 가능"을 붙인다.
3. L_j ≥ 2, both_L2+, n_obs ≥ 6 ≠ 식별가능(C1, §3 미해결).
4. p = 0.3 all 층의 평균 성공 ≠ 모든 마스크에서의 성공. 층별 최악값을 함께 보고한다.
5. 국소 σ_min > 0 ≠ 전역 단사(C2).
6. 마스크 안정성 ≠ 식별가능성(C4). 마스크 분산은 oracle과 비교해서만 모델 기인으로 해석한다(§2.3).
7. 좋은 imputation ≠ 숨은 상태 복원(C3).
8. oracle과의 격차가 없음 ≠ 정보 한계. 정보 한계는 대칭 층 LB로만 진술한다(§3 정리).
9. κ = 0의 Bfull 우위 ≠ 결합 또는 공유 상태(P8.1).
10. 통계적 검출 ≠ 실질 효과. δ 기준을 따로 보고한다.
11. 결과를 이 구조, 이 시스템 밖으로 일반화하지 않는다.

## 11. 실행 계획 (고정 후)
0. 독립 검토 → 이 문서 수정 → 해시 고정
1. **코드 + CPU 테스트**(학습 전)
   - id·seed 비중첩
   - Arm 동일성(마스크, 초기 가중치, Sham donor의 독립과 1회 사용)
   - hidden y 비사용
   - A_j 입력이 자기 view만인지
   - 비활성 head gradient 0
   - oracle이 test 궤적을 쓰지 않는지
   - LB 공식(Γ×Γ로 W 불변) 단위 테스트
   - 마스크 층 확률이 §설계값과 일치하는지
2. 자료 생성: AE 복제본, donor, oracle 풀, 참조 DB
3. AE 학습. GPU 예약 확인(`labres-check`). 셀당 BfullSham 포함 Arm 6개 → 24 × 4 × 6 = 576 학습
4. Oracle 학습: O_raw, O_imp, O_own(κ, p별), O_lat(특징 × 복제본)
5. 평가 → 6. 사전등록 분석(자동) → 7. 보고와 handover

**사전 수학 과제 (고정 전에 완료하거나 Unresolved로 명시)**
- **M-1:** 포획 집합 상수 C_V(결합 Lyapunov 함수)를 계산한다. 유한 표본 경험적 Bernstein 판의 손실 상한에 쓴다.
- **M-2:** LB_X0, LB_{L_j0}의 2차 모멘트를 oracle 풀(test와 독립)에서 추정하는 방식과, 점별 불편 추정량의 수식을 확정한다.
- **M-3:** D5(1-NN analog)의 점근 일관성 가정(m과 조건부 분산의 연속성)이 대칭 경계에서 깨질 수 있다는 점을 명시한다.
