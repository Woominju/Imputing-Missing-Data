## 3. 검토 과정에서 새로 발견해 v2에 반영한 설계 수정

1. **[수학] j 평균 CG의 대칭성:** Real 파이프라인이 j = 1, 2에 공유되므로 j 평균의 분포 대칭은 보장되지 않는다. j별 대칭과 평균의 기댓값 0만 성립한다. 그래서 정확 검정은 j별로, 평균에는 t 검정을 쓴다(P8.3 주의).
2. **[설계] Fact8Sham의 정확 교환가능성:** v1은 Fact8Sham의 상대 인코더로 Real의 A_o를 그대로 썼다. 그러면 Real ↔ Sham 교환이 정확하지 않다(A_o의 학습 자료가 바뀌지 않음). v2는 donor 하위계로 학습한 **A_o^♯(A1_8d, A2_8d)**를 추가했다. 학습 수는 셀당 7 → 9, 총 864다.
3. **[설계] BfullSham은 j별 두 Arm**(BfullSham1, BfullSham2)이다. readout 목표는 S̃^♯(실제 s_j, donor s_o)다.
4. **[설계] O_lat 폭:** O_raw의 선택 폭으로 고정한다(계산 예산). 사전 고정한다.
5. **[설계] oracle 풀 마스크:** 궤적당 K = 4개 고정 추출(epoch별 재추출 대신)이다. 결정적이고 재현 가능하다.
6. **[범위] oracle σ_min 층 제거**(국소 진술, 판정 무관, P7에 존재).
7. **[범위] Family I은 p = 0.7만**(p = 0.3에서 P(H) ≈ 1.7e-6).
