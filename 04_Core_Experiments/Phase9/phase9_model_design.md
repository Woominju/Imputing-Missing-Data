## B1. 출발점: B-full과 Fact8의 정확한 구조

**구조 (`experiments/phase5/core.py:75–104`, `experiments/phase8/core8.py`, `train8.py`)**
- **B-full:** ArmModel(입력 4 view, 출력 4 view, 잠재 16)
  - view별 group MLP 인코더 → 마스크 인식 학습 fusion(관측 없는 view의 코드는 0, 관측 비율을 덧붙임) → 공유 잠재 Z ∈ R¹⁶ → view별 디코더가 **전체 지연 벡터**(8 lag)를 출력
  - 손실은 FDR이다. **숨김 관측 항목 H에서만** 계산하고, H는 매 step 다시 뽑는다(h = 0.2).
  - 입력은 B = O − H다. O는 궤적마다 고정된 MCAR 마스크다.
  - 조기 종료는 val의 숨김 관측 항목 lag-0 RMSE로 한다.
- **Fact8:** 하위계별 ArmModel(입력·출력 2 view, 잠재 8) 두 개를 연결한 것이다. 같은 손실이고, 인코더는 상대 view를 보지 못한다.

**조건별 평가**

| 조건 | B-full | 근거 |
|---|---|---|
| 여러 view 정보 활용 | 한다(IIa-1, IIa-2) | Phase 8 |
| 공통 잠재 | 구조상 하나의 Z | 코드 |
| 같은 상태의 cross-mask 일관성 | **강제하지도 유도하지도 않는다.** readout 수준 마스크 분산이 Fact8보다 크다 | 손실 정의, Phase 8 §2.3 |
| 상태 구별성 | 측정만 했다(잠재 NN). Fact8 대비 우위가 없다 | Phase 8 감사 S2 |
| 결측 위치 대치 | 손실 목표가 **원래 결측 위치(u ∉ O)에 하나도 없다.** 그 위치는 숨김 관측 위치에서 일반화해야 한다 | A4.1, 코드 |
| 미분동형 대응 | 보장하지 못한다. 목적의 최적해가 조건부 기댓값이고, 마스크 간 결속이 없으며, 단사성이 미측정이다 | A3 말미 |

**정확한 부족 조건 (A3 말미, A4)**
- B-full 목적의 모집단 최적해는 이미 조건부 기댓값 f*다(A4.1). 따라서 실패는 **추정 대상의 문제가 아니라 유한 용량·표본에서의 추정 문제**다. 다음 세 가지가 있다.
  1. **감독 희소성:** p = 0.7에서 student의 비입력 항목 중 참값 목표가 있는 비율은 r = 0.079뿐이다. 나머지 92%(원래 결측 위치)에는 목표가 없다.
  2. **공변량 이동:** 학습 입력 밀도는 0.24, test 입력 밀도는 0.30이다.
  3. **마스크 간 결속 부재:** 같은 창에 대해 마스크가 다를 때 출력이 일관될 이유가 손실에 없다.

**이전 기법과의 관계 (프로젝트 기록 조사)**
- **무조건 정렬 ‖E_i − E_j‖²:** 제안됐으나 실행하지 않고 기각했다(`aim_architecture_candidates.md:136`, P7). Gate A의 A2.2가 그 이유를 정리로 만든다. **재도입하지 않는다.**
- **View dropout(Model E, Phase 3A/3B):** 단일 view 일관성은 좋아졌지만 다변량 정확도가 모든 Q에서 나빠졌다(`AUTO_RESULTS.md` §6, §10). 이 방법은 입력 분포를 바꾸는 방식이다. **P9는 입력 분포를 바꾸지 않는다.**
- **P10 tower KL:** 분포 수준 KL(q_𝔅 ‖ q_𝔅′ 혼합)로 제안됐고 기각됐다(`aim_architecture_candidates.md:173–182`). 기각 이유는 두 가지였다.
  - (a) 상수 사후분포에서 0이 된다(붕괴).
  - (b) 최적점에서 자동으로 성립한다.
  - Phase 2.5 감사는 이 비교가 섬유 평균이지 같은 상태 비교가 아니라고 지적했다(`phase25_mathematical_audit.md:254–275`).
- **P9가 위 기각 사유와 다른 점**
  - (a)에 대해: 참값 holdout 항목을 고정해 두었다(r_min > 0). A4.3이 상수해를 배제하고 고정점이 유일함을 증명한다.
  - (b)에 대해: 맞다. **최적점에서는 추정 대상이 바뀌지 않는다**(A4.3). P9의 가설은 오직 유한 용량에서의 효과이며, Phase 8 자료(위 1–3)가 그 필요성을 보인다.
  - 섬유 평균 문제에 대해: P9는 **같은 창**에서 student 입력 B ⊂ teacher 입력 O를 비교하는 회귀다. 섬유를 몬테카를로로 근사할 필요가 없다.
  - **이 프로젝트에서 이 형태의 일관성 손실을 학습한 적은 없다**(코드 검색: `experiments/`, `src/`에 distil/teacher/consistency 항 없음).
- **문헌:** teacher가 student 입력의 상위집합을 보는 자기 증류는 알려진 기법이다(CD4LM, MaskSub, ViT self-distillation; Gate A §A5). **기법 자체의 새로움은 주장하지 않는다.** 이 문맥에서의 기여는 다음 세 가지다.
  - 조건부 기댓값 추정 대상의 보존(A4.3)
  - 비식별 마스크에서 거짓 일관성을 만들지 않는 성질
  - 그 경험적 검증

## B2–B3. 선택한 단일 메커니즘: 중첩 마스크 tower 일관성 (P9-MVAE)

**해결하려는 단 하나의 수학적 문제**
- B-full 목적은 원래 결측 위치(u ∉ O)에 감독 신호가 없다.
- 그리고 같은 창의 서로 다른 마스크 출력 사이에 결속이 없다.
- 이 상태에서 조건부 기댓값 추정 대상을 바꾸지 않고, 그 위치들에 **추정 대상과 일관된 목표**를 공급한다.

**수식**
- 구간 X_s, 원래 마스크 O, 숨김 H, student 입력 B = O − H, teacher 입력 O라 하자. 둘 다 같은 창이고 FDR 창 구성(마스킹 후 창 만들기)을 따른다.
- 앵커 t, lag k의 출력 Ŷ^S_{t,k} = f(W_B)_{t,k}, Ŷ^T_{t,k} = sg[f(W_O)]_{t,k}라 하자. 같은 네트워크이고 gradient를 차단한다.
- 손실:
  - L_P9 = L_rec + λ L_tow, **λ = 1**
  - L_rec = FDR(Ŷ^S, X, H): **B-full과 비트 단위로 같다.**
  - L_tow = Σ_{t,k,i} D_{t−k,i} w(t−k)(Ŷ^T_{t,k,i} − Ŷ^S_{t,k,i})² / Σ D·1{c > 0}
  - D := 1 − O이다(원래 결측 위치). w = 1/c는 FDR과 같은 중복도 가중이다.
- **λ = 1의 근거:** 두 항이 모두 항목 평균 MSE이고 단위가 같다. A4.3에 의해 임의의 λ > 0에서 고정점이 같다. λ는 조정하지 않는다. **결과를 보고 바꾸지 않는다.**
- **구조, 잠재 차원, 데이터, 학습 예산, 조기 종료 규칙은 B-full과 같다.** λ = 0이면 B-full이다.

**필요성**
- A4.3의 붕괴 반례에 의해 L_rec(참값 항목)는 필수다.
- A2.2에 의해 잠재 등식 대신 출력 공간의 조건부 기댓값 목표가 필요하다.
- teacher를 O로 두는 이유는 두 가지다.
  - test 입력과 같은 밀도다(공변량 이동 완화 가설).
  - B ⊆ O이므로 tower 성질이 성립한다.

**증명된 충분조건 (Verified (math), A4.3)**
- MCAR, holdout 독립, 0 < h, p < 1이면 무한 용량에서 유일한 고정점은 f*이고 붕괴해가 없다.
- 고정점에서는 f(W_B) = E[f(W_O) | W_B]다. 식별 마스크에서는 출력이 같고, 비식별 마스크에서는 조건부 평균만 일치한다.

**미증명 가정 (Hypothesis)**
- H1: 유한 용량에서 L_tow가 대치 오차를 줄인다(감독 희소성 완화).
- H2: 같은 상태의 마스크 간 잠재 일관성과 구별성(cross-mask 상태 검색)이 개선된다.
  - 잠재 공간에는 직접적인 항이 없다. 출력 일관성에서 잠재 일관성으로 가려면 디코더의 국소 단사성이 필요하며, 이는 미증명이다(A3.2).
- teacher 오차가 전파되지 않는다(축약 상수 약 0.92이므로 위험이 있다).

**붕괴 반례:** λ → ∞이거나 L_rec를 제거하면 상수 f가 L_tow = 0인 고정점이다. P9는 L_rec를 그대로 두므로 이 반례에 해당하지 않는다. 유한 표본에서의 부분 붕괴는 검색 비율로 감시한다.

**비식별 마스크 반례:** X0(student 창에 x가 없음)에서 teacher O가 x를 볼 수 있다. 그래도 student 목표의 조건부 기댓값은 E[f(W_O) | W_B]다. γ₁₂ 대칭이므로 x, y 성분은 0 쪽이다. **P9는 X0에서 teacher의 x 값을 그대로 복사하라고 요구하지 않는다.** 모집단에서는 조건부 평균만 요구된다. 단 유한 표본에서는 표본 수준 회귀이므로 분산이 커진다(경험적 감시 대상).

**B-full, Fact8과의 차이**
- B-full과의 차이는 L_tow 항 하나뿐이다.
- Fact8과는 구조(결합 인코더)가 다르다. P9 대 Fact8은 "메커니즘 + 결합 구조"의 비교다.

**반증 가능한 핵심 가설 (사전등록에서 정량화)**
- P9가 B-full보다 대치 RMSE가 낮지 않으면 → H1 반증(이 n에서)
- P9의 cross-mask 상태 검색이 B-full, Fact8보다 낫지 않으면 → H2 반증
- P9가 Fact8 대비 비열등하지 않으면 → "공유 표현 + 메커니즘이 실용적"이라는 주장 반증
