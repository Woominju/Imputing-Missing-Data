## 1. 모델과 비교군
- **P9:** B-full 구조(ArmModel 4 → 4, 잠재 16)에 손실 L_rec + λL_tow(λ = 1)를 쓴다(설계 B2–B3). 그 밖은 모두 B-full과 같다.
- **Bfull:** Phase 8 B-full이다. 동결된 구현(ArmModel, FDR, train8 루프)과 같다.
- **Fact8:** [A1_8(W₁), A2_8(W₂)]
- **보조**
  - Fact16 = [A1_16, A2_16]
  - self-only AE(Fact8의 각 인코더가 자기 view만 쓰는 AE이므로 따로 학습하지 않는다)
  - zero, LOCF(과거만)
  - **지도 진단:** Phase 8 고정 oracle O_imp, O_raw(P8 oracle 풀로 학습, Phase 9 test와 독립; 같은 생성 법칙과 정규화). 진단 전용이다.
- **학습 예산:** 모든 AE에 같다. epoch ≤ 300, 100 step/epoch, batch 64, lr 1e-3, patience 15, clip 5, h = 0.2. 조기 종료는 val 숨김 관측 lag-0 RMSE로 한다.
  - P9는 step마다 teacher 순전파(gradient 없음)가 1회 추가되어 계산량이 약 1.5배다.
  - Fact는 최적화가 2개이므로 총 step이 최대 2배다.
- **초기화 seed**
  - P9와 Bfull은 같은 seed다(main 9000 + r, pilot 9500 + r). H 표집 난수 흐름도 같아서 대응이 가장 엄밀하다.
  - A_j_8: 9100 + r / 9600 + r
  - A_j_16: 9200 + r / 9700 + r

## 2. 자료 (새 독립 궤적; Phase 1–8과 겹치지 않음)
- **생성기:** gen6/gen8과 같다(DOP853, dt = 0.05, transient 5,000 step).
  - s0 = s0_of(κ, id)로, rng(SEED6 + 100000κ + id)이고 하위계마다 x, y ~ U(−15, 15), z ~ U(5, 40)이다.
  - **id ∈ [200000, 299999]:** κ = 0의 seed는 SEED6 + [200000, 300000), κ = 1의 seed는 SEED6 + [300000, 400000)이다. 이전의 모든 seed(< SEED6 + 200000)와 겹치지 않는다.
- **main 복제본 r = 0..23:** train 200000 + r(20,000 step), val 200100 + r(5,000), test 200200 + 10r + i(i = 0..7, 각 5,000)
- **pilot 복제본 r = 0..5:** train 210000 + r, val 210100 + r, test 210200 + 10r + i
- **p = 0.3과 p = 0.7은 같은 궤적을 공유하고 마스크는 다르다.**
- **마스크:** 항목별 i.i.d. MCAR이다.
  - seed_of("p9train" | "p9val" | "p9valhide", stage, κ, p, r)
  - test: seed_of("p9test", stage, κ, p, r, i, e), e = 0..4
- **정규화:** Phase 6 풀 900–903의 고정 상수다(P8과 같다).
- **숨은 y:** 입력, 목표, 정규화, 손실에 쓰지 않는다(테스트). readout 목표, 층, 검색 평가에만 쓴다.

## 3. 평가 (복제본마다; test 8궤적 × 마스크 5, n ≥ 7)
- **대치 RMSE:** 원래 결측 위치 M_{n,i} = 0에서 과거 창 lag-0 출력과 참값의 정규화 RMSE다.
  - **주 지표는 4 view 합동**(Σ SSE / Σ n)이다. view별 지표와 단순평균도 보고한다.
  - 층: 자기 L_j(L0, L1, L2+), n_obs 구간 4개(Phase 8 정의)
- **cross-mask 상태 검색 (주 지표, 일관성과 구별성을 함께 잰다)**
  - 특징 F ∈ {P9, Bfull, Fact8, Fact16}마다, 복제본의 모든 test 잠재(8궤적 × 마스크 5, n ≥ 7)로 평균과 공분산을 구하고 **백색화**한다(Σ^{−1/2}, 고윳값 하한 1e-8·max).
    - 잠재의 가역 아핀 변환에 불변이다. 비선형 재매개화에는 불변이 아니다.
  - 궤적 i마다 질의 1,000개를 뽑는다(마스크 e = 0, 시각은 seed로 균등 비복원 추출).
  - DB는 같은 궤적의 마스크 e = 1..4 잠재 전체(4 × 4,993)다.
  - 백색화 공간에서 유클리드 10-NN을 찾는다.
  - **ρ_ret** := Σ‖S̃_q − S̃_{NN}‖ / Σ‖S̃_q − S̃_{rand}‖
    - S̃는 정규화 6차원 참 상태(숨은 y 포함; 평가 전용)다.
    - rand는 같은 DB에서 균등하게 고른 10개다.
    - 궤적 8개와 질의를 합동한다.
  - 낮을수록 좋다.
    - 같은 상태의 다른 마스크 잠재가 가깝고(일관성), 다른 상태가 멀어야(구별성) 낮아진다.
    - **붕괴하면 약 1이 된다.**
  - 보조(서술): 정확 시각 적중률, 동일 시각/무작위 쌍의 백색화 거리 비, 질의 층별 ρ_ret
- **R1 상태 decodability (서술):** P7 readout 규칙(core8.fit_mlp; 복제본 train 궤적, seed 0)으로 RMSE_s6과 y_j RMSE를 층별로 잰다. P8 고정 O_raw를 진단으로 함께 잰다.
- **readout 마스크 분산, 백색화 ρ_φ (서술)**

## 4. 확증 가설 (main 단계, κ = 1, p = 0.7; 단위 = 복제본, n = 24; 대응 차이)
**고정 순서 P-1 → P-2 → P-3 → P-4를 따른다. 각 단계는 단측 α = 0.025이고 FWER는 0.025다.** 앞 단계가 실패하면 뒤 단계는 검정하지 않는다(서술만 한다).

| 단계 | 대비 d_r | 판정 | 실질 기준(따로 보고) |
|---|---|---|---|
| P-1 | 대치 RMSE(P9) − 대치 RMSE(Bfull) | t-UCB_{97.5%} < 0 | δ_imp = 0.01 |
| P-2 | ρ_ret(P9) − ρ_ret(Bfull) | UCB < 0 | δ_ret = 0.02 |
| P-3 | 대치 RMSE(P9) − 대치 RMSE(Fact8) | **비열등:** UCB < η = +0.01 | — |
| P-4 | ρ_ret(P9) − ρ_ret(Fact8) | UCB < 0 | δ_ret = 0.02 |

- 보조로 정확 부호 검정(단측)을 함께 보고한다.
- **기준값 근거 (Phase 8 자료, Phase 9 결과 전)**
  - P8 κ = 1, p = 0.7에서 대치 RMSE는 Bfull 0.312(복제본 SD 0.006), Fact8 0.296이다. Fact8 − Bfull = −0.016(SD 0.009)이다.
  - δ_imp = 0.01은 RMSE의 3%이고, Fact8 격차의 약 60%다.
  - η = 0.01은 P9가 Fact8 격차의 3분의 1 이상을 메워야 비열등이 되는 엄격한 수준이다.
  - P8의 잠재 NN 비는 약 0.25(백색화 없음)이고, Bfull − Fact8의 복제본 SD는 약 0.04다. δ_ret = 0.02는 그 비의 8%다.
- **성공 판정**
  - **S3(대치 효용):** P-1 확증 ∧ P-3 비열등
  - **S2(공유 상태 증거):** P-2 ∧ P-4 확증
  - **S1(수학적 타당성):** 문서 감사로 판정한다.
  - **AIM 진전 주장:** S1 ∧ S2 ∧ S3가 모두 필요하다. 하나라도 실패하면 그대로 보고한다.
- **해석 제한**
  - ρ_ret는 P에 대한 평균이다. 비식별 마스크(X0 등)의 질의는 원리적으로 완전 검색이 불가능하다(A2).
  - ρ_ret 개선은 전역 단사성, 식별성, 미분동형의 증거가 아니다.
  - 낮은 RMSE는 상태 재구성의 증거가 아니다.

## 5. 이차 분석 (모두 서술)
- κ = 0과 p = 0.3 셀의 같은 대비(음성 대조의 의미)
  - κ = 0에서 P9의 효과는 결합 특이가 아니다. 메커니즘이 결합과 무관한 추정 메커니즘이기 때문이다.
  - 결합 특이 정보(Real/Sham)는 P9에 대해 수행하지 않는다. **CSIA를 주장하지 않는다.**
- 층별 결과(H, X0, L_j0, n_obs)
- R1 decodability, O_raw/O_imp 진단
- 마스크 분산, ρ_φ, 정확 시각 적중률
- 학습 진단: L_tow 궤적, epoch, best_val

## 6. Pilot (Gate D; 개발 seed·자료; 결론 없음)
- **범위:** 4셀 × 6 복제본 × 6 arm = 학습 144개 + 평가 24개
- **통과 기준 (모두 충족해야 main으로 간다; 구현 타당성만 본다)**
  - G-P1: 모든 학습 valid(유한, 상한 도달 0)
  - G-P2: P9의 L_tow가 모든 run에서 유한·양수로 기록되고, step당 teacher 목표 항목 수가 > 0이다.
  - G-P3: 붕괴 없음. 모든 셀에서 P9 복제본 평균 ρ_ret < 0.8이고 잠재 공분산 trace > 0이다.
  - G-P4: 파국 없음. 모든 셀에서 평균 대치 RMSE(P9) ≤ 평균(Bfull) + 0.02이다.
  - G-P5: 무결성 테스트 통과(§8)
- **pilot 결과를 보고 λ, 구조, 손실, 평가를 바꾸지 않는다.** 실패하면 본 실험을 하지 않고 원인을 보고한다.

## 7. 실제 자료 (이차, 서술; main 다음에 실행)
- **자료:** Jena(`Data/external/jena/processed/jena.npz`, 70,127 × 5: p, T, rh, u, v; 시간 단위). 시간순으로 train 70% / val 15% / test 15%로 나눈다.
  - 정규화는 train의 관측 항목으로 한다.
  - 자연 NaN(0.13%)은 입력과 평가 모두에서 미관측으로 처리하고, 평가 목표에서 제외한다.
- **인공 MCAR:** p ∈ {0.3, 0.7}, 마스크 seed 8개. 복제본 = (초기화 seed, 마스크 seed)이고 **같은 계열이므로 독립 자료가 아니다.** 따라서 추론하지 않고 서술만 한다.
- **arm:** P9, Bfull(5 view, 잠재 16), SelfV(변수별 자기 AE, 잠재 4 × 5 = 20), zero, LOCF
- 실제 자료에는 상태 정답이 없으므로 식별성의 증거로 쓰지 않는다.

## 8. 무결성 테스트 (CPU, pilot 전)
1. λ = 0이면 P9 손실이 Phase 8 FDR 손실과 비트 단위로 같다.
2. teacher 입력 ⊇ student 입력이고, tower 목표는 원래 결측 위치(1 − O)에서만 쓰며, teacher는 gradient가 없다.
3. 숨은 y(열 1, 4)는 입력과 손실 어디에도 없다.
4. Phase 9 id, seed가 이전 모든 자료와 겹치지 않는다(첫 상태 해시 비교).
5. test 마스크 seed가 train/val과 다르고, 층 정의는 Phase 8과 같다.
6. 평가가 결측 위치만 대상으로 하고 n ≥ 7이다.
7. 학습 행 기록이 smoke와 실제를 구분한다.

## 9. 실패 처리
- 무효 학습(비유한)은 완료 표지 없이 실패 기록만 남기고, 재시도하지 않는다. 그 복제본은 미평가로 남는다.
- 셀의 평가 복제본이 24개 미만이면 그 셀은 결론 불가다.
- 마감으로 중단된 작업은 실패가 아니며 재개한다.
- 모든 출력 표지는 원자적으로, 마지막에 쓴다.

## 10. GPU와 실행 환경
