## 1. FPRM 알고리즘 요약

### 1.1 실제로 계산하는 것 (코드 기준)
```
X_i(t) = [x_i(t), x_i(t+τ), …, x_i(t+(E-1)τ)]     # PhaSpaRecon: 미래 방향 지연 (t 이후 값 사용)
행 t ∈ {1, …, l-(E-1)τ}; 무작위 holdout(cvpartition, 비율 r) → 결측 행, 나머지 → 학습 행
Z = zscore(X_i[학습 행])  (학습 행의 평균·표준편차로 예측변수만 표준화)
GP = fitrgp(Z, x_j[학습 행])                        # MATLAB 기본 설정
x̂_j(t) = predict(GP, (X_i(t) − μ)/σ),  t ∈ 결측 행
평가: RMSE/std(정답), Pearson ρ, MAE
```
- **입력**: 완전 관측 기준 변수 i의 E차원 *미래 방향* 지연벡터 하나. **출력**: 불완전 변수 j의 현재 값
  x_j(t) 하나(스칼라). 불완전 변수마다 별도의 GP를 학습함 [논문 Discussion 한계 항목].
- **Full reconstruction** = 완전 변수의 지연 행렬 M(x_i) (식 6). **Partial reconstruction** = 불완전 변수의
  지연 행렬 M(x_j) (식 9). 실제 학습 대상은 M(x_j)의 **첫 열**뿐이고 (식 13–14), 나머지 열은 쓰지 않음.
  따라서 "full → partial 다양체 사상"은 구현상 **x_j(t)에 대한 스칼라 회귀 x_i 지연벡터 → x_j(t)** 임.
- **학습·평가 데이터 범위**: 같은 시계열 안에서 관측된 행으로 학습하고 같은 구간의 결측 행을 채움
  (**transductive**). 시간순 train/val/test 분할 없음. 결측은 지연 행렬의 행 단위로 무작위 지정되므로
  마지막 (E-1)τ개 시점은 평가 대상이 아님.
- **GPR** [논문 식 15–18]: squared-exponential 커널, 스케일 θ는 "예측변수 표준편차의 평균으로 결정".
  [코드]는 `fitrgp` 기본값을 그대로 사용. MATLAB 기본 동작(기저 함수, 초기값, 주변우도 최적화, 큰 n에서의
  근사 방법)은 버전에 따라 다르므로 **[불명확: R2024b 문서로 확인 필요]**. 논문의 θ 설명은 초기값을 말하는
  것으로 보이며, 최적화 후 값이 논문과 다를 수 있음.
- **E, τ** [SI Table S1]: FNN(E)과 mutual information(τ)으로 선택. 3D Lorenz는 E=3, τ=3;
  120D 결합 Lorenz는 E=4, τ=3. [코드] 예시는 `PhaSpaRecon(y(:,2),3,5)`, 즉 τ=3, **E=5**로 Table S1과 다름.
- **지표**: ρ와 정규화 RMSE. [논문 식 19]는 √(MSE/σ_예측)로 적혀 있으나 [코드]는 √MSE / std(정답).
  **코드 정의를 따름** (식 19는 오기로 판단).
- **반복**: 200회, `rng('shuffle')`로 시드를 고정하지 않음. 정확한 수치 재현은 불가능하고 분포 수준의
  재현만 가능.

### 1.4 변형과 비교 방법
- **Lag-FPRM** [논문 Discussion, SI Fig. S15–S17]: 모든 변수가 같은 시점에 결측일 때 "어긋난(staggered)
  유효 구간과 불완전 구간"으로 재구성하는 방법. **그림 설명만 있고 알고리즘 명세와 코드가 없음.**
  검사한 설정도 변수당 결측 7개와 14개뿐임. → **재현 불가, 이번 비교에서 제외.**
- S-map/MVCM [SI 노트 1–2]: 완전 기준 변수 하나로만 지연 라이브러리를 구성. θ ∈ {1,5,9,15,25,35,45}.
  MVCM은 lag 범위 [1,20]의 view 조합 중 상위 n개를 사용. **θ와 n은 "정답과 대치값의 Pearson 상관을
  최대화"하도록 선택함 → 평가 정답으로 하이퍼파라미터를 고른 것(누수)**. 우리 프로토콜에서는 검증 구간으로
  선택해야 함.

### 1.5 우리 연구와 관련된 이론상의 주의점
- FPRM이 이론적 근거로 삼는 문장("각 변수의 재구성이 원래 끌개와 미분동형이므로 서로 일대일 사상이 있다")은
  **기준 변수의 지연사상이 끌개 위에서 단사일 때만** 성립함. Lorenz z는 Γ(x,y,z)=(−x,−y,z) 대칭 때문에
  모든 E, τ에서 단사가 아님 (math_review 2(b); `aim_crossview` v1에서 z만 넣으면 예측이 원래 시계열과
  Γ 시계열에서 정확히 같음을 확인). 따라서 **z를 기준으로 한 FPRM의 x·y 복원은 이론적으로 실패해야 함**
  (부호 정보 없음 → RMSE ≈ std 수준, 두 정답 차이로 정해지는 하한 존재).
- "partial reconstruction이 원 시스템과 미분동형"이라는 서술은 결측이 채워졌을 때의 지연사상에 대한
  것이며, 결측 자체가 임베딩을 보존해 주는 것은 아님.
- FPRM의 출력도 x_j(t) 스칼라임. 따라서 우리 Model C와 마찬가지로, **회귀 성능은 F_j∘F_i⁻¹ 학습을 직접
  검증하지 않음.** 두 방법 모두 "현재 값 복원 능력"으로 비교해야 함.

## 3. 비교 실험 설계

공통 [우리]: Lorenz 20000점(dt=0.01, DOP853), 시간순 70/15/15 분할, train의 관측값으로 정규화,
seed 0/1/2, 결측률 0.1/0.3/0.5/0.7, `prepare()`와 같은 난수 흐름.
평가 대상 = test 구간에서 인위적으로 숨긴 항목(eval_mask=1). 지표 = 우리 RMSE(train z-score 단위), MAE,
FPRM식 nRMSE(RMSE/std(정답)), Pearson ρ. **모든 방법을 같은 대상 집합에서 계산.**
불확실성 = 시간 블록(100 step) bootstrap + seed 3개 (seed 3개의 한계를 함께 명시).

### 3.1 조건 A: FPRM의 전제가 성립하는 환경 (기준 변수 하나만 완전 관측)
- **마스크**: 기존 `prepare(p, seed)`의 M을 그대로 쓰되 기준 열 r만 1(M_orig)로 바꿈. 이렇게 하면
  r이 아닌 변수의 결측 위치와 평가 대상이 메인 프로토콜과 **정확히 같은 부분집합**이 되어 결과를
  재사용할 수 있음. 평가 대상은 r 이외 변수의 test 결측 항목뿐.
- **기준 변수**: r ∈ {x, y, z}. **r = z는 이론적 대조군**: x·y 대상은 부호를 식별할 수 없어야 함.
  Γ 쌍 하한을 함께 보고(`aim_crossview`의 방법 재사용). z 대상(r = x 또는 y)은 정상 비교.
- **추가 결측률**: 원 논문의 주요 설정은 r=0.9이므로, 조건 A에 한해 p=0.9를 추가 실험으로 두는 것을
  권장(새 마스크, 별도 표기).
- **비교 대상과 재사용 가능성**

| 방법 | 조건 A에서의 처리 | 기존 결과 재사용 |
|---|---|---|
| mean, locf, linear | 대상 변수의 열만 사용 → 메인 예측과 동일 | **가능** (메인 예측을 대상 부분집합으로 제한) |
| B | 자기 변수만 사용 → 동일 | **가능** |
| A | 시점 t의 다른 변수를 사용 → 기준 열이 바뀌므로 입력이 달라짐 | 불가: 재평가 필요. 학습 분포와 달라지므로 진단용 |
| C (기존 체크포인트) | 기준 View가 항상 완전 → 학습 때 입력 분포(모든 변수 결측률 p+0.2(1−p))와 다름 | **진단용으로만** (OOD 표시) |
| C (조건 A 재학습) | 같은 구조·loss, 학습 마스크만 "기준 열 완전 + 나머지 MCAR + hide" | 새 학습 필요 → **공정 비교의 본 결과** |
| FPRM (Python 이식) | 원 설정 그대로 적용 가능 | 신규 |

- **공정 재학습이 필요한가**: **필요함.** 기존 C는 기준 View가 완전한 입력을 학습 중 거의 보지 못함
  (완전 View 확률: p=0.1에서 0.07, p=0.7에서 1e-5; `aim_crossview/v1/exp1_training_frequency.csv`).
  `aim_crossview`에서 확인했듯이 C는 학습 때 드문 입력 패턴에서 성능이 크게 떨어짐(자기 View만 넣은 C
  0.18–0.42 vs 같은 정보의 B 0.01–0.04). 따라서 기존 체크포인트 결과로 C와 FPRM의 우열을 판단하면 안 됨.
- **FPRM의 학습 범위 (두 가지로 나눠 보고)**:
  - A-T (원 논문과 같은 transductive): 전체 시계열에서 *관측된* (X_r(t), x_j(t)) 쌍으로 GP를 학습하고 test
    결측을 대치. 평가 정답은 학습에 들어가지 않음. 단 test 구간의 관측값을 학습에 씀. linear도 test
    관측을 쓰므로 같은 "오프라인" 범주.
  - A-I (inductive, 우리 신경망과 같은 조건): train 구간 쌍으로만 학습, val 구간에서 E·τ·근사 크기 선택,
    test에 적용.
- **E, τ**: (i) 원 논문 값 E=3, τ=3 (단, 원 논문의 τ는 비균일 샘플링 기준이므로 시간 단위가 다를 수 있음)
  (ii) 우리 train 구간에서 FNN과 MI로 다시 선택. 두 결과를 모두 보고.

### 3.2 조건 B: AIM 환경 (모든 변수 MCAR, 완전 기준 변수 없음)
- **원래 FPRM의 직접 적용 가능성**: **불가.** GP의 입력 X_r(t)는 완전한 지연벡터여야 하는데, 기준 변수에도
  결측이 있으면 학습 행과 대치 행 모두에서 입력이 정의되지 않음. 논문도 이를 한계로 명시함 [논문
  Discussion]. 이는 **적용 범위의 구조적 한계이지 성능 비교에서 진 것이 아님.** 조건 B에서 "FPRM의 RMSE"는
  보고하지 않음.
- **Adapted FPRM 후보** (원래 FPRM이 아님을 이름에 명시):
  - **AF-interp**: 기준 변수 r의 결측을 r의 *관측값만* 사용한 선형 보간으로 채운 뒤 FPRM 적용. 보간에는
    r의 관측 항목만 쓰고, 평가 정답과 test의 숨긴 값은 사용하지 않음(입력 마스크 M 기준). 보간 오차가
    입력 오차로 전파됨. r 자신의 결측은 다른 기준 변수로 채움(대상별로 r을 바꿈).
  - **AF-complete-rows**: 기준 지연벡터가 우연히 완전한 행만 사용(보간 없음). 대치 가능한 대상 비율이
    (1−p)^E로 제한됨 (E=3: 0.73, 0.34, 0.125, 0.027). **적용 범위(coverage)를 함께 보고**하고, RMSE는
    같은 부분집합의 C와만 비교.
  - (선택) 기준 변수를 바꿔 가며 앙상블하는 MVCM 유사 방식은 원 논문 설정과 더 멀어지므로 후순위.
- **비교 대상**: 기존 메인 결과(mean/locf/linear/A/B/C)는 조건 B와 **같은 마스크·대상이므로 그대로 재사용**.
- Lag-FPRM: 알고리즘이 명세되지 않아 구현하지 않음. 구현하지 않았다는 사실 자체를 보고.

## 4. 입력 정보와 평가 조건 비교표

| 방법 | 대치 시 사용하는 관측 | 미래 정보 | 학습 데이터 | 하이퍼파라미터 선택 | 분류 |
|---|---|---|---|---|---|
| mean | train 평균 | 아니오 | train | 없음 | 기준선 |
| locf | x_j의 t 이전 마지막 관측 | 아니오 | 없음 | 없음 | 과거만(온라인) |
| linear | x_j의 t 전후 관측 | **예** | 없음 | 없음 | 오프라인 |
| A | 모든 변수의 시점 t | 아니오 | train | val | 현재만 |
| B | x_j의 t−7…t | 아니오 | train | val | 과거만 |
| C | 모든 변수의 t−7…t | 아니오 | train | val | 과거만 |
| D | 모든 변수의 t−7…t+7 | **예** | train | val | 오프라인 |
| FPRM (A-T) | 기준 변수 r의 t…t+(E−1)τ | **예** | 전체 시계열의 관측 쌍 (transductive) | 원 논문: 고정 E·τ, GP는 주변우도 | 오프라인 |
| FPRM (A-I) | 기준 변수 r의 t…t+(E−1)τ | **예** | train | val | 오프라인 |
| AF-interp | 보간된 r의 t…t+(E−1)τ (보간 자체가 r의 과거·미래 관측 사용) | **예** | A-T/A-I와 동일 | val | 오프라인, 변형 |

**보고 원칙**: 같은 표 안에서도 "과거만 사용하는 방법"(locf, B, C)과 "오프라인 방법"(linear, D, FPRM,
AF)을 구분해 표시. C가 FPRM 또는 linear보다 나쁘더라도 미래 정보 접근 차이를 함께 적음. 필요하면 이후에
(재학습이 필요한) 양방향 창 C를 별도 실험으로 둠.

## 5. 데이터 누수 방지 점검

1. 평가 대상(eval_mask=1)의 값은 어떤 방법의 입력·학습·보간·하이퍼파라미터 선택에도 쓰지 않음
   (코드에서 assert로 확인: `X*M` 형태의 입력만 전달).
2. 조건 A의 기준 열은 평가 대상에 포함하지 않음(기준 열의 평가 마스크를 0으로).
3. 정규화 통계는 train 관측값만 사용 (FPRM 이식에서도 MATLAB `zscore`의 학습 행 통계 사용).
4. 원 논문처럼 정답과의 상관으로 θ, n, E, τ를 고르지 않음 → val 구간 또는 학습 데이터 내부 기준.
5. A-T의 transductive 학습은 test 구간의 *관측값*을 사용함. 이는 누수가 아니지만 정보 조건이 다르므로
   별도 행으로 보고.
6. AF-interp의 보간은 입력 마스크 M 기준으로만 수행. 보간 함수가 받는 배열에 숨긴 값이 남아 있지 않은지
   assert로 확인(기존 `baseline_impute(X*M, M)` 관례 사용).
7. FPRM 지연벡터는 t+(E−1)τ까지 사용하므로, test 끝의 (E−1)τ 구간 대상은 정의되지 않음. 모든 방법의
   평가 대상을 같은 공통 부분집합으로 제한하고 제외 개수를 보고.
8. Γ 대조군 시계열은 평가에만 사용하고 학습에는 쓰지 않음.

## 7. 현재 주장할 수 있는 것과 없는 것

**주장 가능 (현재 결과 기준, Lorenz, seed 3개)**
- 모든 변수에 MCAR이 있는 조건(AIM 조건)에서 Model C는 과거 정보만으로 B·A보다 정확하게 복원함.
  완전한 기준 View가 없는 대상에서도 마찬가지임(aim_rescue v1/v1_abc).
- C는 시점 t의 정보가 전혀 없을 때도 지연 입력으로 복원함(지연 정보가 실질적으로 기여).
- 원래 FPRM은 조건 B에 그대로 적용할 수 없음(논문이 명시한 구조적 전제). 이는 적용 범위의 차이이지
  성능 비교 결과가 아님.
- Lorenz에서 z만으로는 x·y를 복원할 수 없음(증명 + C에서 확인). FPRM의 z 기준 설정에도 같은 한계가 예상됨.

**아직 주장 불가**
- C가 FPRM보다 낫거나 나쁘다는 어떤 주장도 (조건 A·B 모두 실험 전).
- C가 미분동형 대응을 학습했다는 주장; View 코드가 같은 좌표계라는 주장(반대 증거 있음: aim_latent v1).
- linear 보간보다 낫다는 주장: 높은 p와 일부 실제 데이터에서 linear(미래 정보 사용)가 더 좋음.
- Coupled Lorenz와 실제 데이터로의 일반화(이번 FPRM 비교 설계는 Lorenz 중심).
- Adapted FPRM 수치를 원래 FPRM의 성능으로 해석하는 것.
