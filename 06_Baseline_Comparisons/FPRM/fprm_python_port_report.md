### 2.1 공식 코드와 일치시킨 항목 (코드 근거)

| 항목 | 공식 MATLAB | Python 이식 |
|---|---|---|
| 지연 방향 | `PhaSpaRecon(s,tau,m)`: 행 k = s(k), s(k+τ), …, s(k+(m−1)τ) (미래 방향) | 동일, 1-기반 문자 그대로 옮긴 함수와 배열 동일성 테스트 |
| 인자 순서 | `(s, tau, m)` → `PhaSpaRecon(y,3,5)` 는 **τ=3, E=5** | 동일 (E, τ는 호출자가 지정) |
| Full / Partial reconstruction | M(x_i) = 완전 변수의 지연 행렬, M(x_j) = 불완전 변수의 지연 행렬 | 동일 |
| 학습 대상 | `Ytrain = Y(idxTrn,1)` — Partial reconstruction의 **첫 열** x_j(k) 하나 | 동일 |
| 결측 단위 | `cvpartition(N,'Holdout',r)` — 지연 행렬 **행** 단위 무작위 | 동일 (`holdout_rows`) |
| 예측변수 표준화 | `zscore(Xtrain)` (N−1), `tr_sigma==0 → 1`, test는 학습 통계로 변환 | 동일 |
| 목표 표준화 | 없음 (`Standardize` 기본 false) | 없음 |
| GP 기저 | `fitrgp` 기본 `'constant'` (β 추정) | 상수 β를 GLS로 프로파일 |
| 커널 | `'squaredexponential'`, 길이척도 1개 | 동일 |
| 초기값 | σ_L0 = mean(std(X)), σ_F0 = std(y)/√2, σ0 = std(y)/√2, σ 하한 1e−2·std(y) | 동일 (논문 "θ는 예측변수 표준편차의 평균"은 이 **초기값**과 일치) |
| 학습 방식 | n ≤ 2000 exact, 그 이상 subset-of-data(활성 집합 1000) | 동일 규칙 |
| 지표 | `LL = sqrt(loss)/std(Ytest)` (N−1), `corr`, MAE, 상대오차(YFit 기준) | 동일 (`official_metrics`) |
| 경계 | 마지막 (E−1)τ 시점은 지연 행이 없어 학습·대치 불가 | 동일, 모든 방법의 평가에서 동일하게 제외하고 개수 기록 |
| transductive | 같은 시계열의 관측 행으로 학습 → 결측 행 예측 | `FPRM-T` (공식). 비교용 `FPRM-I`(train 구간만 학습)는 **우리 변형**으로 별도 표기 |

### 2.2 공식 코드와의 차이 (모두 코드 주석에도 기록)

| ID | 차이 | 영향 |
|---|---|---|
| D1 | 최적화기: fminunc(quasi-Newton) 대신 scipy L-BFGS-B + 해석적 기울기 | 같은 목적함수·초기점. 최종 하이퍼파라미터가 약간 다를 수 있음 |
| D2 | 잡음 하한을 log σ 박스 제약으로 처리 | 최적점이 하한에 있을 때 동일. 내부 매개변수화 차이 |
| D3 | n > 10000에서 MATLAB은 반복법 'bcd' 예측; 우리는 정확한 Cholesky 해 | 'bcd'가 근사하려는 값을 직접 계산 |
| D4 | 'sd' 적합 후 β·α를 전체 n에서 GLS로 다시 계산 | MATLAB 내부 처리 미공개 → 불확실 |
| D5 | 활성 집합·holdout 난수는 numpy (MATLAB과 다른 난수열); 공식은 `rng('shuffle')`라 원래도 재현 불가 | 분포 수준 비교만 가능 |
| D6 | 초기점에서 L-BFGS-B가 비정상 종료하면 고정된 대체 초기점 2개에서 재시작, 최소 NLL 선택 | 실제 사례: Lorenz x→y(E=3,τ=3)에서 NLL −2444(정체) → −3570. 목적함수 동일 |
| D7 | 커널 비유한값/Cholesky 실패 시 NLL=+∞ 반환 | 극소 학습 집합(l=100, r=0.9)에서 overflow로 전체 실행이 죽던 문제 해결. 박스 제약 방식은 L-BFGS-B를 초기점에 멈추게 해서 폐기 |
| D8 | 최종 예측용 Cholesky 실패 시 최소 대각 jitter (σ_F²·10^k) 추가 후 기록 | n≈16000 조밀 표본에서 발생. **관측 사례 jitter=0.0028 은 잡음분산(1e−4)의 약 28배** → 그 실행은 사실상 더 큰 잡음으로 예측함. 결과 행에 `jitter` 열로 표시 |
| D9 | `cvpartition` holdout 크기: round(r·N) 사용 (MATLAB 반올림 규칙 미확인) | 최대 1행 차이 |

### 2.3 논문·SI·코드 사이의 불일치 (공식 코드를 구현 근거로 사용)

1. E: 코드 예시 E=5, τ=3 / SI Table S1: 3D Lorenz E=3 τ=3, 120D 결합 Lorenz E=4 τ=3 → 둘 다 실행해 보고.
2. 식 19 nRMSE = √(MSE/σ_예측) vs 코드 √MSE/std(정답) → 코드 정의 사용.
3. 논문 "θ = 예측변수 표준편차 평균"은 고정값이 아니라 `fitrgp` 초기값이며 이후 주변우도로 최적화됨.
4. 결합 Lorenz 초기값: 본문 "0.3에서 0.03씩 증가" vs 코드 `0.3:0.3:…` → 두 초기값 모두 실행.
5. 3D Lorenz 생성 스크립트·데이터 길이 l은 공개되지 않음; `Coupled Rossler system.mlx`는 실제로 결합 Lorenz를 적분.
6. S-map/MVCM 비교(SI 노트)는 정답과의 상관으로 θ·n을 고름 → 우리 프로토콜에서는 사용하지 않음.

## 5. 조건 A (기준 변수 1개 완전 관측) — 우리 Lorenz (dt=0.01), `v2/cond_a/`

설정: `prepare(p, seed)` 마스크에서 기준 열만 완전 관측. 평가 = test 구간의 숨긴 항목(비기준 변수 2개), 마지막 (E−1)τ
시점은 모든 방법에서 제외. p ∈ {0.1, 0.3, 0.5, 0.7}, seed 0–2, (E,τ) ∈ {(3,3), (5,3), (3,1), (3,6)}. 실행 576개
(ref×p×seed×Eτ), **오류 0, 비유한 0**, D8 jitter 사용 행 16개 (`jitter` 열).
FPRM-T = 공식 transductive, FPRM-I = train 구간만 학습 (**우리 변형**).

### 5.1 test RMSE (2개 대상 통합, seed 평균), E=3, τ=3 (SI Table S1 값)

|---|---|---|---|---|
| FPRM-T | 기준 변수의 미래 지연만 (예측 시) | .052/.048/.053/.053 | .203/.205/.206/.208 | 1.006/1.010/1.009/1.069 |
| FPRM-I | 〃 | .053/.059/.058/.059 | .211/.211/.213/.216 | 1.013/1.034/1.063/1.116 |
| C 조건A 재학습 (GPU) | 기준 변수 + 대상 변수의 부분 관측, 과거만 | .010/.014/.020/.050 | .008/.010/.017/.044 | .008/.008/.017/.104 |
| C 원래 체크포인트 (OOD 진단) | 〃 | .008/.015/.040/.173 | .008/.014/.035/.186 | .007/.015/.034/.172 |
| linear | 대상 변수의 과거·미래 관측 | .008/.015/.033/.088 | .006/.012/.025/.064 | .006/.011/.026/.073 |

검증 기준(E,τ 4개 중 val RMSE 최소)으로 고르면 FPRM-T: x 기준 .037/.034/.038/.039, y 기준 .063/.065/.096/.079
(z 기준은 그대로 ≈1.01). **FPRM은 (E,τ) 선택에 민감**하다. 예: E=5,τ=3 에서 x→y 는 RMSE 0.0002–0.0004.

### 5.2 해석
1. **z 기준 → x, y: nRMSE ≥ 0.998 (개별 실행 범위 0.998–1.383, 모든 E,τ), ρ −0.27…0.10 (개별 실행)**. 명제 1(대칭 하한)과 정확히
   일치. FPRM-T와 FPRM-I 모두 같음. 3000점 짧은 구간 스모크에서 보였던 ρ≈0.79는 짧은 test 구간의 표본 비대칭에서
   생긴 현상이었음 (전체 데이터에서는 사라짐).
2. **x → y 가 매우 정확한 이유 (도출)**: Lorenz 식 ẋ = σ(y − x) 에서 y = x + ẋ/σ. y는 x와 그 도함수의 명시적
   함수이므로 x의 지연벡터(유한차분)로 거의 결정됨.
3. C가 FPRM보다 낮은 오차를 보이는 것은 **정보 접근 차이를 포함**함: C는 대상 변수 자신의 부분 관측(MCAR 1−p)도 입력으로
   씀. FPRM은 예측 시 기준 변수만 씀. 따라서 이 표는 "같은 정보에서 알고리즘이 더 낫다"는 증거가 아님.
   예측 시점 정보를 맞춘 비교(기준 view 하나만 입력)는 §7.
4. C 원래 체크포인트(모든 변수 MCAR로 학습)는 p≥0.5 에서 재학습 C보다 크게 나쁨 (p=0.7: 0.17 vs 0.04–0.10) →
   프로토콜에서 예상한 학습/평가 분포 불일치가 실제로 확인됨. 조건 A 비교에는 재학습 결과를 써야 함.

## 6. 조건 B (모든 변수 MCAR, AIM 조건) — **원래 FPRM 적용 불가, Adapted FPRM만**

원래 FPRM은 예측변수 지연벡터가 완전해야 하므로 조건 B에 적용할 수 없음 (구조적 전제; 성능 패배가 아님).
Adapted FPRM: AF-interp(기준 변수 결측을 자기 관측값으로만 선형보간 → FPRM), AF-complete(기준 지연벡터가 완전한 행만).
AF-interp-T-valsel = 대상별로 val RMSE가 가장 낮은 기준 변수 선택. AF-interp-T-avg = 두 기준의 평균(**우리 확장**).

## 7. 정보를 맞춘 비교: 기준 view 하나만 입력 (dt=0.01, `aim_autonomous_20261027/eval_views`)

예측 시 x 지연만 주어질 때 다른 변수 복원 (test, 2개 대상 통합, 3 seed):
FPRM-I(x 기준, E=3,τ=3) ≈ 0.053–0.059 vs C(원래) 0.23–0.46 vs E(view-dropout) 0.15–0.39 (`fig4_views_C_vs_E.png`).
→ **같은 단일 view 정보에서 FPRM(GP)이 C의 view별 경로보다 훨씬 정확**. C의 단일 view 경로가 약한 것은 식별 불가능성
때문이 아님 (x view는 y를 거의 결정함; §5.2-2). 학습 분포에 단일 view 입력이 거의 없고(p=0.3에서 확률 ~6e−6),
평균 융합 구조 때문일 가능성이 큼 (종합 보고서 C절).

## 8. 결론: FPRM을 정식 기준 모델로 쓸 수 있는가

- **조건부로 예.** 공식 코드의 연산을 항목별로 이식했고, 누수·정렬·재현성 테스트를 통과했으며, 대칭 대조군에서 이론과 일치하는
  결과를 냈다. 비교 실험의 기준선으로 쓸 수 있다.
- 단, 다음 한계를 함께 적어야 한다: (1) MATLAB 실행 결과와의 직접 대조가 없음; (2) 논문 수치를 재현하지 못함 (표본 간격
  가설만 지지됨); (3) D6–D8 수치 처리, 특히 D8 jitter가 일부 n≈16000 실행에서 잡음 크기를 바꿈; (4) 결과가 (E,τ)에
  민감하므로 보고 시 선택 규칙(val 기반)을 명시해야 함.
- 아직 부족한 검증: MATLAB(또는 Octave+동등 함수) 환경에서의 동일 입력 수치 대조, 원 논문 데이터(Figshare 실제 데이터 5종)에
  대한 재현, 'bcd' 예측과 jitter의 차이 정량화.
