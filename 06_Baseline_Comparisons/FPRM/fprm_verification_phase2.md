**`test_d8_jitter.py` (신규)**
- 최적화기를 고정 결과로 바꾸고 `cho_factor`를 k번 강제로 실패시켜 D8 루프를 결정론적으로 실행한다.
- 확인 항목:
  1. 실패가 없으면 jitter = 0.
  2. n번 실패 후 기록된 jitter = σ_F²·10^(−12+n−1), 그리고 실제로 더해진 대각값이 그 값과 같음 (부동소수점 허용오차 내).
  3. k = −4까지 모두 실패하면 `LinAlgError`가 발생.
- 첫 작성 때 허용오차를 상대오차 1e−9로 잡아 실패했다. 원인은 ~0.64 크기 대각 원소끼리 뺄셈할 때 생기는 정밀도 손실이었고, GP 코드 결함이 아니었다. 허용오차를 `eps × 대각 크기` 기준으로 고쳤다.

### 3.4 MATLAB `fitrgp`와의 차이가 미쳤을 수 있는 영향

| 차이 | 이번 문제와의 관련 | 가능성 |
|---|---|---|
| D1 최적화기 (fminunc quasi-Newton vs L-BFGS-B) | 종료 판정과 line search가 다르다. 같은 초기점에서 fminunc도 정체 해에 빠지는지는 **알 수 없다**. MATLAB에는 "실패 플래그" 개념이 따로 노출되지 않는다 | 정체 국소해의 발생 빈도가 MATLAB과 다를 수 있음 |
| D3 n > 10,000에서 bcd vs exact | 조건 A의 거의 모든 적합(n ≈ 10k–18k)이 MATLAB이었다면 bcd 예측을 썼을 것이다. jitter가 필요한 나쁜 조건수에서 bcd는 반복 수렴 문제가 생길 수 있다 | jitter 행의 예측값은 MATLAB과 다를 가능성이 큼 |
| D4 'sd' 후 β, α를 전체 n으로 재계산 | 국소해 여부와는 무관하다. 예측 평균에 영향 | 정량화 안 됨 |
| D5 활성 집합 난수 | 정체 해 발생이 활성 집합에 의존 (§3.3) | MATLAB에서는 다른 seed가 정체에 빠질 것 |
| 재현 차이 (ρ 0.997 vs 0.90) | 수치 문제를 포함하든 빼든 ΔnRMSE ≤ 0.0002 | **설명 불가.** 데이터 조건(표본 간격, 잡음) 쪽이 남은 가설 |

- 보존 위치: `third_party/fprm_paper/` (2026-10-27 10:12 KST 다운로드)

  - `FPRM_SI_MOESM1_ESM.pdf` (21쪽): MD5 `e4ad5ff2…`, SHA-256 `62e53faa…`
  - 전체 해시는 `PROVENANCE.md`에 있다.
- 기본 FPRM (Methods Eq. 6–14):
  - Full reconstruction M(x_i)의 행 = (x_i(t), x_i(t+τ), …, x_i(t+(E−1)τ)), 즉 **미래 방향**이다 (Eq. 6).
  - 매핑 대상은 partial reconstruction의 **첫 열** x_j(k)다 (Eq. 13–14).
  - "contemporary known values"로 학습한다.
  - → 이식 코드(`delay.py`, `fprm.py`)와 **일치**한다.
- 논문 서술의 수학적 단서 (우리 해석):
  - 논문은 결측이 있는 partial reconstruction M(x_j)도 원 끌개와 미분동형이라고 쓴다 (Eq. 10).
  - 그러나 결측 원소가 있는 행렬은 상태 공간의 점 집합으로 정의되지 않는다. 실제 알고리즘이 쓰는 것은 결측이 없는 full reconstruction에서 **스칼라 x_j(k)로 가는 함수**뿐이다.
  - 따라서 FPRM에서 이론적으로 필요한 것은 "F_i가 A 위에서 단사"라는 조건 하나다 (doc 2 P1).
- "Merit and limitation"에 저자들이 명시한 한계:
  1. 변수마다 별도 매핑이 필요하다.
  2. 일부 실제 데이터에서는 특정 변수만 다른 변수를 복원할 수 있다.
  3. 완전 관측 변수가 필요하다 → Lag FPRM으로 "일부 경우" 완화.
  4. 길고 연속된 동시 결측 구간에서는 누적된 동역학 예측 편차가 생긴다.

## 6. Lag FPRM 조사

### 6.1 출처

- **본문 Discussion** ("Merit and limitation" 마지막 문단):
  > "for scenarios where all variables suffer from simultaneous missing entries at identical time points, our framework can be extended to a lag FPRM variant. This variant employs a segment-wise cross-reconstruction strategy for synchronous missing data. It builds dynamical mappings between attractors reconstructed from staggered valid and incomplete segments of paired time series … (Supplementary Fig. S15). … there remains room for further improvement handling extensive long continuous, synchronous missing segments across all variables, as gradually accumulated dynamic prediction deviations may impair the overall imputation performance."
- **SI Fig. S15**: 개념도와 행렬식 (e).
- **SI Fig. S16, S17**: 그림만 있다. 모델 계(ecology, 3D Lorenz, 120D coupled Lorenz, 120D coupled Rössler)와 실제 데이터(도로, EEG, 환율, 풍속)에서 **결측 7점 또는 14점짜리 단일 구간**의 정답과 대치값을 선으로 비교한다. 패널당 변수 하나다.
- **SI 본문에는 Lag FPRM 절이 없다** (12절은 S15 캡션뿐). 알고리즘 단계, p 선택 규칙, 기준 변수 선택 규칙, 반복 횟수, 집계 지표가 모두 없다.
- **공식 코드에는 구현이 없다**: Figshare v3의 `.mlx` 4개와 `.m` 2개를 확인했다. `FPRM mian code.mlx`는 기본 FPRM (`PhaSpaRecon`, `cvpartition`, `fitrgp`)뿐이고 lag나 shift 인자가 없다.
- **결론: Lag FPRM은 논문과 SI에만 개념으로 설명돼 있다.**

### 6.2 알고리즘 (SI Fig. S15(e)에서 재구성)

그림 (e)의 행렬식:

```
F [ x_i(1)     x_i(1+τ)     …  x_i(1+(E−1)τ)          ]   [ x_j(p)     x_j(p+τ)    … x_j(p+(E−1)τ) ]
  [ x_i(2)     x_i(2+τ)     …  x_i(2+(E−1)τ)          ] = [ x_j(p+1)   …                            ]
  [   ⋮                                               ]   [   ⋮                (음영 = 결측)         ]
  [ x_i(m−p)   x_i(m−p+τ)   …  x_i(l−p)               ]   [ x_j(m)     x_j(m+τ)    … x_j(l)        ]
```

- 그림 (b): x_i는 앞쪽 구간(결측 없음), x_j는 lag p만큼 뒤로 민 구간(뒤쪽에 결측 포함).
- 그림 (2행)에는 x_j(p+1), x_j(p+τ)로 적힌 오타로 보이는 부분이 있다.

정식화 (기본 FPRM과 같은 "첫 열 대상" 규칙을 적용했다는 **우리 해석**):

  x̂_j(k+p) = F_{j←i,p}( x_i(k), x_i(k+τ), …, x_i(k+(E−1)τ) ),  k = 1, …, m−p

- 학습: 입력 창이 모두 관측되고 x_j(k+p)도 관측된 행으로 GP를 적합한다.
- 예측: x_j(k+p)가 결측이지만 입력 창은 모두 관측된 행에 적용한다.

**시간 구조에서 나오는 제약 (우리 도출):**
- 동시 결측 구간을 [g, g+L−1] (길이 L)이라 하자. 구간 안의 모든 t를 복원하려면 입력 창 {t−p, …, t−p+(E−1)τ}가 구간 앞에 있어야 한다.
- 따라서 **p ≥ L + (E−1)τ**.
- 입력의 마지막 관측 시점에서 대상까지의 거리 = p − (E−1)τ ≥ L.
- 즉 Lag FPRM은 결측 구간 길이 이상의 **변수 간 직접 다단계 예측**(direct multi-step cross-prediction)이다.
- 혼돈계에서는 오차가 대략 e^{λ₁·(p−(E−1)τ)·dt}로 커진다. 이것은 저자들이 쓴 "accumulated dynamic prediction deviations"와 맞는다.
- (구간 뒤쪽 창을 쓰는 음의 p, 즉 backcast도 원리상 가능하지만 논문에는 서술이 없다.)

### 6.4 변수별 독립 MCAR(조건 B)에서 일반화한 Lag FPRM의 가정과 한계 (우리 분석)

결측률 r, 변수 n개, 창 크기 E인 독립 MCAR을 가정한다.

- **A1 (입력 창 완전성):** 특정 (i, p)에서 창이 완전할 확률은 (1−r)^E다. 예: r=0.3, E=3이면 0.343, r=0.7이면 0.027.
  - 후보 (i, p)를 여럿 허용하면 적어도 하나가 완전할 확률은 1 − Π(1−(1−r)^E)다. 창끼리 겹치므로 실제로는 독립이 아니고, 이 식은 근사다.
  - 이렇게 하면 coverage는 크게 늘지만, 대상 시점마다 다른 (i, p) 모델을 쓰게 된다.
- **A2 (학습 표본):** (i, p)별 학습 행 비율은 (1−r)^{E+1}이다. r=0.7, E=3이면 0.8%다. T=20,000이면 ≈ 160행. GP에는 충분할 수 있으나 p가 커지면 매핑이 복잡해진다.
- **A3 (예측 지평):** MCAR에서는 결측이 대개 짧아서 작은 |p|로도 완전한 창을 찾을 수 있다. 그래서 동시 결측 구간보다 **유리**할 수 있다. 반대로 p ≥ (E−1)τ+1이면 순수 예측이 되고, 혼돈계에서는 오차가 지평에 따라 커진다.
- **A4 (기준 변수의 식별력):** 고른 x_i가 대상 x_j를 결정해야 한다. Lorenz z 기준은 Γ 대칭 때문에 어떤 p에서도 x, y를 결정할 수 없다 (doc 2 P2). Coupled Lorenz(결합 약함)에서 다른 하위계 변수도 마찬가지다.
- 따라서 "모든 변수 결측에 FPRM이 적용되지 않는다"고 단정할 수 없다. 반대로 "Lag FPRM이 MCAR을 해결한다"는 근거도 없다.
  - 저자들의 검증은 동시 결측 구간 7–14점, 정성적 그림뿐이다.
  - MCAR 일반화는 coverage, 표본 수, 예측 지평의 3중 상충을 안고 있다.
  - 이 상충이 실제 성능에서 어떻게 나타나는지는 **실험으로 확인해야** 한다 (§6.6).
- 기존 우리 결과와의 관계: 조건 B의 AF-complete(p=0, 기준 창이 완전한 행만 사용)는 이 일반화의 **p = 0 특수 경우**다. coverage가 (1−r)^3으로 줄어든다는 것은 이미 관찰했다.

### 6.6 비교 프로토콜 설계 (구현하지 않음)

1. **결측 체계 두 가지**를 같은 데이터와 같은 시간순 분할에서 비교한다.
   - (S) 논문 체계: 모든 변수에 동시 결측 구간. 길이 L ∈ {7, 14, 28, 56}, 구간 수 고정, 구간 위치는 seed로 무작위.
   - (M) 우리 체계: 변수별 독립 MCAR, r ∈ {0.1, 0.3, 0.5, 0.7}, 기존 `prepare(p, seed)` 마스크 재사용.
2. **방법:**
   - Lag-FPRM-paper: 기준 변수 i와 p = L + (E−1)τ를 고정하고, i는 **validation 구간**의 성능으로 고른다.
   - Lag-FPRM-multi (우리 확장): 대상 시점별로 창이 완전한 (i, p) 중 val 오차가 가장 낮은 모델을 고른다. |p| ≤ P_max.
   - 비교 대상: C, F, linear, locf, Adapted FPRM.
   - 모든 FPRM 계열에 FPRM-T(transductive)와 FPRM-I(train만)를 둘 다 둔다.
3. **선택 규칙:** E, τ, i, p는 val 구간에서만 고른다. 논문의 S-map/MVCM 비교처럼 정답 상관으로 고르는 것은 금지한다.
4. **평가:** 같은 평가 위치를 쓴다. 어떤 방법이 정의되지 않는 위치(coverage 밖)는 그 방법의 "미정의"로 따로 집계하고, 공통으로 정의된 위치에서 RMSE를 비교한다. coverage 자체도 지표로 보고한다.
5. **표본 간격:** dt ∈ {0.01, 0.05, 0.1}. 예측 지평 효과는 dt에 따라 크게 달라진다.
6. **GP 수치 표시:** 모든 GP 적합에 대해 `opt_success`, `opt_restarts`, `jitter`, `sigmaL`, NLL을 저장한다. §3.3의 정체 해(σ_L > 100) 여부를 표시한다.
7. **정체 해 대응** (구현 전에 결정할 일): 결과를 조용히 바꾸지 않도록, 기존 결과는 그대로 두고 **새 버전에서만** "성공 판정과 무관한 고정 다중 시작점(D6′)"을 도입하는 것을 제안한다. 결정은 사용자에게 맡긴다.
