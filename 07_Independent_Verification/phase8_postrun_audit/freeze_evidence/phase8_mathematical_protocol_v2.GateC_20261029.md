### 1.3 보조정리

**L1 (대칭군) [Verified (math)]** — 검토 3에 따라 표기를 수정했다.
- **반전과 교환:** Γ: (x, y, z) ↦ (−x, −y, z)는 한 하위계의 반전이다.
  - 동시 반전 γ₁₂ := Γ×Γ
  - 개별 반전 γ₁ := Γ×Id, γ₂ := Id×Γ
  - 하위계 교환 π
- **(a) 초기분포 불변:** Π₀는 γ₁₂, γ₁, γ₂, π **모두**에 불변이다(모든 κ). 하위계별 독립과 대칭 균등분포 때문이다.
- **(b) 흐름 가환(등변성)**
  - 모든 κ에서 Φ^t∘γ₁₂ = γ₁₂∘Φ^t이고, Φ^t∘π = π∘Φ^t다.
    - 근거: 벡터장 F가 F(γ₁₂ s) = γ₁₂ F(s)를 만족한다. 결합 항 κ(x_o − x_j)가 동시 반전에서 부호를 바꾸기 때문이다. π에 대해서는 결합이 대칭이다.
  - **κ = 0에서만** 추가로 Φ^t∘γ_j = γ_j∘Φ^t가 성립한다.
    - κ ≠ 0이면 F(γ₁ s)의 ẋ₁ 성분은 σ(x₁ − y₁) + κ(x₂ + x₁)이고, −ẋ₁ = σ(x₁ − y₁) − κ(x₂ − x₁)과 같으려면 2κx₂ = 0이어야 한다. 따라서 성립하지 않는다.
- **(c) 결론:** 모든 n에서 경로 (s(n − 7), …, s(n))의 법칙이 다음 군에 불변이다.
  - κ > 0: G_κ = ⟨γ₁₂, π⟩(위수 4)
  - κ = 0: G₀ = ⟨γ₁, γ₂, π⟩(위수 8)
  - 시각 지표의 혼합 P에서도 마찬가지다. 마스크는 경로와 독립이므로 (경로, M)의 결합 법칙도 (g·경로, M)에 대해 불변이다.

**L2 (포획과 해석성) [Verified (math); 검토 10 재검산]**
- **포획 함수:** V := Σ_j [x_j² + y_j² + (z_j − c)²], c := ρ + σ = 38이라 하자.
- **항등식(기호 계산으로 확인):**
  (−2V + 2βc²) − dV/dt = 2(σ − 1)Σ_j x_j² + (β − 2)Σ_j (z_j − c)² + βΣ_j z_j² + 2κ(x₁ − x₂)²
- σ ≥ 1, β ≥ 2, κ ≥ 0이므로 우변 ≥ 0이다. 따라서 **dV/dt ≤ −2V + 2βc²**다.
- **Grönwall:** V(t) ≤ V(0)e^{−2t} + βc²(1 − e^{−2t}) ≤ max(V(0), βc²)다.
  - Π₀의 상자에서 V(0) ≤ 2[15² + 15² + (5 − 38)²] = **3078**이다.
  - βc² = 8/3 × 1444 = **3850.667**이다.
  - 따라서 **모든 t ≥ 0에서 V(t) ≤ 3850.667**이다. 검토 10의 주장과 일치하며, 독립적으로 재검산했다.
- **더 좁은 상수 [Verified (math)]**
  - 하위계마다 dV_j/dt + 2V_j = −2(σ − 1)x_j² − (2β − 2)z_j² + (2βc − 4c)z_j + 2c² − 2κ-항 ≤ sup_z[…] = 3080.533이다(z* = 7.6, κ-항 ≤ 0).
  - 따라서 dV/dt ≤ −2V + 2·3080.533이고, **V(t) ≤ max(3078, 3080.533) = 3080.533**이다.
- **수치 확인 [Verified (code/data)]:** P7 궤적 480개에서 max V는 κ = 0에서 2,513.8, κ = 1에서 2,550.7이다.
- **좌표 상한:** |x_j|, |y_j| ≤ √3080.533 = 55.50이고, |z_j − 38| ≤ 55.50이다. M-1 유한 표본 판에서 손실 상한으로 쓴다(§4.5).
- **해석성:** 벡터장이 다항식이므로 Φ^t는 초기값에 대해 실해석적이다. 대역 존재는 위 포획에서 나온다.
- **미분동형:** det DΦ^t = exp(t·div F) > 0이다. div F = −2(σ + 1 + β) − 2κ는 상수다. 따라서 Φ^t는 상(image)으로 가는 해석적 미분동형이다.

**L3 [Verified (math)]**
- **(a) P는 절대연속이다(A-ac).** Π₀가 Lebesgue a.c.이고, Φ^t가 상으로 가는 미분동형이므로 μ_P는 a.c.다. s(n − 7)의 법칙도 마찬가지다.
- **(b) 콤팩트 불변집합은 Lebesgue 측도 0이다.** K = Φ^t(K)이면 vol(K) = e^{t·div F} vol(K)이고, div F < 0이므로 vol(K) = 0이다.
  - 따라서 콤팩트 불변집합에 지지된 ν는 Lebesgue에 대해 **특이**하다. A-ac가 ν에서는 거짓이다.
- **(c) 수치적 주의:** 부피는 e^{div·T₀} ≈ e^{−6800}(κ = 0 기준) 비율로 수축한다. 그래서 μ_P의 밀도는 끌개 근방에 극단적으로 집중된다.
  - (a)에 기댄 정성적 양성은 크기에 대해 아무것도 말하지 않는다.
  - 배정밀도 시뮬레이션에서는 수치적으로 검증할 수도 없다.

## 2. Bayes 위험, 층, 하한, 상한

### 2.1 정의
- **D1:** R*(S | W) := inf_f E_P‖S̃ − f(W)‖²/6(가측 f). 최소화자는 m(W) := E_P[S̃ | W]다. W가 마스크 지시자를 포함하므로 R*(S | W, M) = R*(S | W)다.
- **D2 (층):** A ∈ σ(W), P(A) > 0이다.
  - R*_A := E_P[‖S̃ − m(W)‖² 1_A] / (6P(A))이고, 좌표별 R*_{A,c}도 같은 방식으로 정의한다.
  - 이 프로토콜의 층은 모두 σ(M) ⊂ σ(W)다(마스크만의 함수).
  - **명제 2.1 [Verified (math)]:** A ∈ σ(W)이면 A 위의 최적 예측기도 m(W)다. 층별 예측기를 허용해도 R*_A는 변하지 않는다.
- **D3 (유효 하한):** P에 대해 R*_A ≥ LB_A가 **증명된** 양이다. LB_A의 수치는 모집단 모멘트에 의존하며, 그 추정은 통계량이다(§2.4).
- **D4 (oracle 상한):** 학습 자료로 정해진 뒤 **고정된** 임의의 가측 f에 대해 R*_A ≤ R_A(f)다.
  - 수학적으로는 무조건 성립한다.
  - R_A(f)의 test 추정과 그 상측 신뢰한계는 통계량이다. f가 test와 독립이어야 불편이다.
- **D5a (k-NN oracle; D4의 특수 경우) — 검토 1**
  - 참조 표본 𝓡 = {(s_q, 창_q)}_{q ≤ N_REF}를 고정한다.
  - 각 마스크 m에 대해 f_kNN(W)는 W의 관측 항목과 같은 위치에 m을 적용한 참조 창들 사이의 Euclid 거리로 k개 최근접을 찾고, 그 S̃_q를 평균한다. 동률은 seed로 고정한 무작위 섭동으로 깬다.
  - **𝓡과 k가 고정되면 f_kNN은 W의 고정 가측 함수다. 따라서 R*_A ≤ R_A(f_kNN)가 유한 표본에서 정확히 성립한다.** 상한의 타당성에는 일관성 정리가 필요 없다.
  - **조임에 대한 근거만 Stone 정리로 댄다:** 고정 m마다 (D_m(s_q), S̃_q)가 **i.i.d.**이고, E‖S̃‖² < ∞(L2로 유계), k_N → ∞, k_N/N → 0, 동률은 무작위로 처리한다.
    - 그러면 E‖f_kNN − m‖² → 0이고, R_m(f_kNN) → R*_m이다. 분포 무관 약 일관성이다(Stone 1977; Györfi–Kohler–Krzyżak–Walk 2002, Ch. 6).
    - **유한 N에서 조임 정도는 보장되지 않는다.**
  - **i.i.d.의 확보(설계):** 참조점 q마다 **독립 궤적 하나**에서 시각 n_q ~ Unif{SPAN..N_TEST − 1} **하나만** 뽑는다(§4.1).
    - 그러면 (s_q, 창_q)는 정확히 P에서 i.i.d.이고, 시간 의존성이 없다.
    - **연속 창(한 궤적의 여러 시각)을 참조로 쓰는 판은 만들지 않는다.** P가 정상 과정의 주변분포가 아니라서 혼합 조건하의 k-NN 정리도 적용 근거가 없다.
  - k는 oracle-val 점(test와 독립)에서 {5, 10, 20, 50, 100} 중 위험이 최소인 것으로 고른다. 선택 후 고정된 함수이므로 D4가 유지된다.
- **D5b (½·1-NN 잔차분산 통계량; 점 추정) [Exploratory]**
  - R̂*_NN,m := (1/(2N)) Σ_q ‖S̃_q − S̃_{NN_m(q)}‖²/6. NN_m(q)는 𝓡 안에서 m을 적용한 거리로 q를 제외한 최근접이다.
  - 이것은 **예측기가 아니다.** 1-NN **예측기**의 위험은 (연속성 조건 아래) 2R*로 가며, Bayes 일관적이지 않다.
  - ½·통계량이 R*의 일관 추정량이 되는 조건은 문헌에 있다(Devroye–Györfi–Lugosi–Walk 2018 등). 그러나 **정리 번호와 조건은 원문 대조 전이므로 Unresolved**다.
  - 상한도 하한도 아니며, 어떤 판정에도 쓰지 않는다.
  - 층 A에 대해서는 P(M | A)에서 **정확히** 뽑은 창 마스크 100개의 평균을 쓴다. (L₁, L₂)는 Binomial(8, 1 − p)²을 A로 제한해 정규화한 분포에서 뽑고, 주어진 개수에서 x 위치는 균등, z 열은 i.i.d.로 뽑는다. 기각 추출을 쓰지 않으므로 P(X0) ≈ 4e-9(p = 0.3)에서도 정확하다.
- **D6 (파이프라인 초과위험):** h = g∘φ(AE 잠재 φ + readout g)에 대해 E_A(h) := R_A(h) − R*_A ≥ 0이다.

### 2.2 기본 부등식 [Verified (math)]
- **(B1)** 임의의 고정 f에 대해 E_A(h) ≥ R_A(h) − R_A(f)다(D4). 모델 한계의 **하한**이다.
- **(B2)** R*_A ≥ LB_A이면 R*_A / R_A(h) ≥ LB_A / R_A(h)다. 정보 한계 비율의 하한이다.
- **(B3, DPI)** 임의의 φ에 대해 R*(S | φ(W)) ≥ R*(S | W)다. 그리고 임의의 g'에 대해 R*(S | φ(W)) ≤ R(g'∘φ)다.
  - 따라서 R(g'∘φ) − R(f_raw)는 **실제로 학습된 두 함수의 위험 차이**일 뿐이다.
  - 이것은 R*(S | φ) − R*(S | W)(인코더의 Bayes 정보 손실)의 하한도 상한도 아니다.
  - 또한 두 함수족의 최적 위험 차이 inf_{g ∈ 𝓕} R(g∘φ) − inf_{f ∈ 𝓕} R(f)도 아니다(학습이 최적이라는 보장이 없다). — 검토 8
- **(B4) 가측 수준의 차원 비병목:** φ*(W) := m(W) ∈ R⁶ ⊂ R¹⁶이면 R*(S | φ*(W)) = R*(S | W)다.
  - 이것은 **가측 함수 수준**의 진술이다.
  - m은 불연속일 수 있다. 연속(또는 Lipschitz) 인코더 제약하에서 16차원이 병목인지는 **Unresolved**다.
  - 그러므로 "B-full의 손실은 차원 문제가 아니다"라고 단정하지 않는다.

### 2.3 마스크 분산 항등식 [Verified (math)]
- **가정:** T = 상태 경로 전체, M과 M′은 T가 주어졌을 때 i.i.d.(MCAR)이고, h = h(W_M)이며 h̄ := E[h | T]다.
- **결론**
  - E‖h − S̃‖² = E‖h − h̄‖² + E‖h̄ − S̃‖²
  - ½E‖h(W_M) − h(W_M′)‖² = E‖h − h̄‖²
  - 따라서 안정성 SD² ≤ MSE다.
- **증명:** S̃는 σ(T)-가측이므로 tower 성질로 교차항이 0이다. 둘째 식은 조건부 i.i.d.에서 나온다. ∎
- **범위:** σ(T)-가측 사건(예: all) 위에서만 성립한다. 마스크로 정의한 층에서는 선택이 마스크에 의존하므로 성립하지 않는다.
- **명제 2.2 (Bayes 예측기의 마스크 분산은 양수) [Verified (math)]**
  - E_P‖m(W_M) − m̄(T)‖² > 0이다.
  - **증명**
    1. 사건 B₁ := {M_{n,x₁} = 1}에서는 x₁(n)이 W에 정확히 들어 있다. 그래서 m의 x₁ 성분은 S̃_{x₁}다.
    2. X0(§3 N1) 위에서는 그 성분이 상수 −μ_{x₁}/σ_{x₁}다.
    3. B₁과 X0는 T와 독립이고, 서로 소이며, 둘 다 양의 확률을 가진다.
    4. 그런데 P(x₁(n) = 0) = 0이다(μ_P가 a.c.).
    5. 따라서 T가 주어졌을 때 m의 x₁ 성분이 양의 확률로 마스크에 따라 다르다. ∎
  - **결과:** 마스크 의존 변동이 크다는 것 자체는 모델 실패의 증거가 아니다. oracle의 같은 분해와 비교해서만 해석한다.

### 2.4 모멘트 추정의 불확실성 (검토 4)
- LB 수치는 모집단 모멘트 m_c := E_P[s_c²]의 함수다. 정규화 상수 σ_c는 고정되어 있다.
- **추정:** oracle 풀의 train 궤적 q = 1..40(test와 독립, 서로 독립)에서 궤적별 평균 m̂_{q,c} = 평균_n s_c(n)²를 구한다(n은 P의 시각 지표 범위).
  - L̂B_A = (1/6) Σ_{c ∈ C_A} [평균_q m̂_{q,c}] / σ_c²
  - 신뢰구간은 궤적 단위 t-구간이다(궤적별 합 Σ_c m̂_{q,c}/σ_c²를 단위로 함).
  - 궤적 안의 시각은 독립이 아니다. 그래서 궤적만 단위다.
- **점별 불편 대안 (T_A용, §4.4):** 같은 test 점 위에서 (S̃_c + μ_c/σ_c)² = s_c²/σ_c²를 쓴다. 이 경우 모멘트를 따로 추정할 필요가 없다.
- **설계 단계 확인 [Verified (code/data), 결과 자료 아님]:** P7 **train** 궤적 24개/κ에서 E[s_c²]/σ_c²는 다음과 같다.
  - κ = 0: x 1.0014 ± 0.0004, y 0.9982 ± 0.0007
  - κ = 1: x 1.0045 ± 0.0029, y 0.9992 ± 0.0015
  - 따라서 LB_X0는 0.6667(κ = 0), 0.6677 [0.6673, 0.6682](κ = 1)이다.
  - 확증 수치는 Phase 8 oracle 풀에서 다시 추정한다.

## 3. 식별가능성: P에서의 결과, 대칭 하한, 반례

**정의 (P 기준)**
- D_m: s(n − 7) ↦ (W의 관측 항목)은 Φ의 전방 성분들로 이루어진 해석적 사상이다.
- 마스크 m이 **P-식별가능** ⇔ μ_P-전측도 Borel 집합 E가 있어서 D_m|_E가 단사다.
- **L4′ (특성화) [Verified (math)]:** R*_m = 0 ⇔ m이 P-식별가능하다.
  - (⇐) 가측 역사상을 쓴다.
  - (⇒) S̃ = m(W) a.s.이므로 h := s(n − 7)의 함수 표현이 존재한다.
  - 같은 특성화는 임의의 법칙(ν 포함)에서 성립한다. 다만 **식별가능 여부는 법칙에 따라 다르다.**

**L4 (P에서의 정성적 양성) [Verified (math); 가정 A-ac(= L3a); 판정에 쓰지 않음]**
- **명제:** n_obs(m) < 6이면 R*_m > 0(P 기준)이다.
- **증명 스케치**
  1. S̃ = h(W) a.s.라 하자. 그러면 D_m은 μ_P-전측도 집합 E 위에서 단사다. A-ac에 의해 Leb(E) > 0이다.
  2. D_m은 해석적이므로 rank가 최대값 r ≤ n_obs < 6이 아닌 점들은 고유 해석적 부분집합이고, 측도 0이다.
  3. rank가 상수인 열린 집합에서 상수 rank 정리와 Fubini를 쓰면, E ∩ (그 열린 집합)이 양의 (6 − r)차원 측도를 가진 섬유를 포함한다. 이는 단사에 모순이다. ∎
- **범위:** A-ac가 핵심이다. **ν(끌개 불변측도)에서는 A-ac가 거짓이므로(L3b) 이 명제를 ν로 확장하지 않는다.**
  - ν에서는 n_obs < 6이어도 D_m이 끌개 위에서 단사일 수 있다. Sauer–Yorke–Casdagli형 결과는 prevalent 관측 사상에 대한 것이고, 우리 고정 좌표 관측에 바로 적용되지 않는다. 그래서 ν에서의 식별 여부는 **Unresolved**다.
- **크기:** L3c에 의해 R*_m의 크기는 이 명제로 알 수 없다.
- **용도:** n_obs 구간은 서술 층으로만 쓴다. 설계 확률은 P(n_obs < 6) = 0.0510(p = 0.7)이다.

**L5 (κ = 0 자기 하위계; P에서) [Verified (math); A-ac]**
- κ = 0이고 n_own,j(m) < 3이면 R*(s_j | W, M = m) > 0(P 기준)이다.
- 근거: κ = 0에서 (s_j, W_j)는 (s_o, W_o)와 독립이고, 3차원 a.c.이며, L4의 3차원판이다.
- ν로 확장하지 않는다. 설계 확률은 P(n_own < 3) = 0.0994다.

**C1 (P에서의 형식적 반례) [Verified (math); A-ac; 크기 무의미]**
- κ = 0, L_j = 2이고 창 안에 z_j 관측이 없으면 n_own = 2 < 3이다. 그래서 L5에 의해 P에서 R*(s_j | W) > 0이다.
- 이 마스크 사건의 확률은 28 × 0.3² × 0.7⁶ × 0.7⁸ ≈ 0.0171(p = 0.7)이다.
- **해석:** "L_j ≥ 2 ⇒ P-식별가능"은 거짓이다.
- **ν에 대해서는 L_j ≥ 2의 충분성이 증명되지도 반증되지도 않았다(Unresolved).**
- 어느 경우든 L 층은 **서술 층**이며 식별가능 집합이 아니다.

**N1 — 대칭에 의한 정량적 하한 (검토 3, 4)**

**N1-X0 [Verified (math)]**
- **가정**
  - (i) L1: γ₁₂가 (경로, M)의 결합 법칙을 보존한다. 모든 κ다.
  - (ii) M은 상태 경로와 독립이다.
  - (iii) n ≥ SPAN이다.
  - (iv) 정규화 상수 (μ_c, σ_c)는 고정되어 있다.
- **층:** X0 := {M_{n−k, x₁} = M_{n−k, x₂} = 0, k = 0..7} ∈ σ(M)이다. z 열은 임의다.
- **대상 좌표:** C_X0 := {x₁, y₁, x₂, y₂}다.
- **증명**
  1. X0 위에서 W는 (z 관측 항목, M)의 함수이므로 W∘γ₁₂ = W다.
  2. c ∈ C_X0에 대해 s_c∘γ₁₂ = −s_c다.
  3. 따라서 임의의 Borel B에 대해 E_P[s_c 1_B(W) 1_X0] = −E_P[s_c 1_B(W) 1_X0] = 0이다. s_c는 유계(L2)다.
  4. 그러므로 E_P[s_c | W] = 0 a.s.(X0 위)이고, E_P[S̃_c | W] = −μ_c/σ_c다.
  5. 좌표별 조건부 Bayes 위험: R*_{X0,c} = E_P[s_c² | X0]/σ_c² = **m_c/σ_c²**다. 둘째 등호는 X0 ⊥ 상태(ii)에서 나온다.
  6. 합치면 R*_X0 = (1/6)[Σ_{c ∈ C_X0} m_c/σ_c² + Σ_{c ∈ {z₁, z₂}} R*_{X0,c}] ≥ **LB_X0 := (1/6) Σ_{c ∈ C_X0} m_c/σ_c²**다. ∎
- **2/3의 조건:** 대칭으로 E_P s_c = 0이므로 m_c = Var_P(s_c)다.
  - **LB_X0 = 2/3 ⇔ C_X0의 네 좌표에서 σ_c² = Var_P(s_c)일 때(분산 일치)**다.
  - 실제 σ_c는 풀 표본 SD다. 그래서 2/3은 근삿값이고, 설계 단계 추정은 0.6667–0.6677이다(§2.4).
  - RMSE 하한 √LB_X0(약 0.816)도 같은 조건부다.
- **확률:** P(X0) = p¹⁶ = 0.00332(p = 0.7)다.

**N1-L_j0 (κ = 0만) [Verified (math)]**
- **가정:** κ = 0(γ_j가 흐름과 가환; L1b), 그리고 위 (ii)–(iv)다.
- **층:** L_j0 := {M_{n−k, x_j} = 0, k = 0..7}이다. 상대 하위계 열은 임의다.
- **대상 좌표:** {x_j, y_j}다.
- **증명:** W∘γ_j = W다(W_o는 불변이고, W_j는 z_j와 마스크뿐). 나머지는 위와 같다.
- **하한:** LB_{L_j0} := (1/6)[m_{x_j}/σ_{x_j}² + m_{y_j}/σ_{y_j}²]다. **1/3 ⇔ 두 좌표에서 분산 일치**일 때다.
- **확률:** P(L_j0) = p⁸ = 0.0576이다.
- 이 하한은 **전체 W**(상대 view 포함)에 대한 하한이다.
- κ = 1에서는 성립하지 않는다. γ₁₂가 x_o의 부호를 바꾸므로 W가 불변이 아니다. G1에 따르면 κ = 1에서는 정보가 있다(Empirical LCB).

**N1-own (모든 κ, 자기 창만) [Verified (math)]**
- **가정:** γ₁₂(모든 κ)와 (ii)–(iv)다.
- σ(W_j)로 조건을 제한하면 L_j0 위에서 W_j∘γ₁₂ = W_j다.
- 그러므로 E_P[s_c | W_j] = 0(c ∈ {x_j, y_j})이다.
- **좌표 하나의 위험:** R*(y_j | W_j, L_j0) = m_{y_j}/σ_{y_j}²(정규화 단위, /6 아님)다. x_j도 같다.
- §5 P8.4 인증의 기준이다.

**검토 11 — H와 X0의 관계 [Verified (math), 설계 확률]**
- X0 ⊂ H(= none_L2+)이고, P(X0 | H) = 0.00332 / 0.0652 = **0.0509**다.
- 따라서 **정확한 대칭 하한이 적용되는 것은 H의 약 5.1%뿐이다.**
- X0 하한을 H 전체의 정보 부족에 대한 증명으로 확대하지 않는다.
- H∖X0(H의 94.9%)에서는 R*에 대한 정량적 하한이 없다. 따라서 그곳의 "정보 부족"은 Hypothesis다.

**C2 (국소 ≠ 전역) [Verified (math)]**
- dD_m(s)가 full rank이면 s의 근방에서 단사다(역함수 정리). 전역 단사나 미분동형은 따라오지 않는다.
- 예: z-only 창의 2:1(ER E1), γ₁₂ 궤도(X0).

**C3 (좋은 imputation ⇏ 숨은 상태 복원; κ = 0) [Verified (math)]**
- κ = 0, L_j0 층에서 z_j는 γ_j-불변이다. 그래서 z_j 결측의 대치는 정확할 수 있다.
- 그러나 N1-L_j0에 의해 R*_{y_j} = m_{y_j}/σ_{y_j}²(분산 일치에서 약 1)다.

**C4 (안정성 ≠ 식별) [Verified (math)]:** 상수 예측기는 마스크 분산 0이지만 R = Var(S̃)다.

**방법론적 원칙 (v1 §3 "정리"의 정정; 라벨 없음)**
- 이 프로토콜의 도구 중 **정량적** 정보 한계 하한을 주는 것은 N1(대칭) 뿐이다.
  - L4/L5는 P에서 양성만 주고 크기를 주지 않는다.
  - ν에 대해서는 아무것도 주지 않는다.
- 다른 비식별 증거(새로운 정확한 대칭, 섬유의 해석적 구성)가 존재할 가능성은 배제하지 않는다. "**대칭 층에서만 가능하다**"는 정리가 아니다.
- 따라서 Phase 8의 인증 범위는 다음과 같다.
  - 모든 층: 모델 한계의 **하한**(B1)
  - X0, κ = 0 L_j0: 정보 한계의 **하한**(B2)
  - 그 밖: R*_A ∈ [0, R_A(f_oracle)]만 알 수 있다.

**Unresolved:** 어떤 층(n_obs ≥ 6, L_j ≥ 2, both_L2+)에 대해서도 P-식별가능성이나 ν-식별가능성의 충분조건은 증명되지 않았다.

- **포화 진단(서술):** 선택된 w에서 O_raw의 풀 train 궤적 수를 {10, 20, 40}으로 바꿔 풀 val 위험을 본다.
- **sym0:** 모든 좌표에서 원 단위 0을 예측한다(= −μ_c/σ_c). LB와 P8.4 계산에 쓴다.
- oracle들은 S̃를 목표로 학습한 **지도 진단 도구**다. AIM의 모델이 아니며, AE 구조나 손실은 바꾸지 않는다.

### 4.3 층 (사전 고정; 마스크만)
- **H := none_L2+** = {L₁ ≤ 1 ∧ L₂ ≤ 1}. L_j는 창 안의 x_j 관측 수다. P(H) = 0.0652(p = 0.7)다.
  - p = 0.3에서 P(H) ≈ 1.7e-6이므로 **Family I은 p = 0.7만** 다룬다.
- 서술 층
  - X0(H의 5.1%), H∖X0
  - one_L2+, both_L2+
  - L_j ∈ {L0, L1, L2+}
  - n_obs ∈ {< 6, 6–9, 10–13, ≥ 14}
- v1의 oracle σ_min 층은 Phase 8에서 **제거**했다. 국소 진술이고 판정에 쓰지 않으며, P7에 이미 있다. 변경 사유는 crosswalk에 기록했다.

### 4.4 대비 (복제본 r; test 8 궤적 × 마스크 5 합동; 좌표 평균 MSE)
- **G_tot(A) := R_A(R1∘φ_Bfull) − R_A(O_raw)**
  - 실제로 학습된 B-full 파이프라인과 실제로 학습된 O_raw의 위험 차이다.
  - B1에 의해 B-full 파이프라인의 모델 한계 E_A의 하한이다(O_raw는 oracle 풀에 조건부로 고정된 함수).
- **G_lat(A) := R_A(O_lat∘φ_Bfull) − R_A(O_raw)** — 검토 8
  - **실제로 학습된 O_lat과 O_raw의 위험 차이**다.
  - "같은 MLP 부류·학습 규칙·풀에서, 잠재를 입력으로 했을 때 얻은 함수가 raw를 입력으로 했을 때 얻은 함수보다 위험이 크다"는 진술이다.
  - **인코더의 Bayes 정보 손실도, 함수족의 최적 위험 차이도 아니다**(B3).
- **G_rd(A) := G_tot − G_lat:** 서술이다.
- **T_A (대칭 층만; 검토 5)**
  - 점별 양 τ_i := (1/6)[Σ_{c=1}^{6} (S̃_{ic} − f_c(W_i))² − Σ_{c ∈ C_A} (S̃_{ic} + μ_c/σ_c)²]
  - T̂_A = 평균_{i ∈ A} τ_i이고, E[τ_i | A] = R_A(f) − LB_A다(불편).
  - (S̃_c + μ_c/σ_c)² = s_c²/σ_c²이고, 그 기댓값이 m_c/σ_c²다.
  - **1/6 정규화를 포함한다.**
  - T_A ≥ R_A(f) − R*_A ≥ 0이므로 oracle 초과위험의 상한 추정치다.
  - 계산에는 sym0의 xy 좌표 SSE를 쓴다.
- **정보 한계 비율 하한:** L̂B_A / R_A(R1∘φ_Bfull)(X0, κ = 0 L_j0). L̂B_A는 §2.4의 풀 추정치이고 CI를 함께 보고한다.

## 5. Family II — 결합 특이 정보 접근성 (CSIA)

### 5.0 용어 구분 (검토 6, 12) [방법론]
- **CSIA (Coupling-specific Information Accessibility)**
  - 정의: 고정된 유한 모델·readout 파이프라인이 **결합 동역학을 통해서만 존재하는** 상대 view의 정보(κ = 1의 교차 정보; κ = 0에서는 0, P8.1)를 실제로 실현하는 정도다.
  - 측정: Real 대 Sham 대비(CG)와 P8.4 인증으로 잰다.
  - Family II의 확증 대상이다.
- **GSR (Genuine Shared-state Representation)**
  - 정의: AIM이 뜻하는 "모든 view의 지연 매장이 일관되게 사상되는 공유 잠재 상태"다.
  - Phase 8에서 GSR은 **확증 대상이 아니다.**
  - §5.5의 다중 서술 기준을 모두 만족해도 "GSR과 양립하는 경험적 증거"일 뿐이다. 상태공간과의 단사성, homeomorphism, diffeomorphism은 주장하지 않는다.
- **어떤 Family II 결과도 다음의 직접 증거로 쓰지 않는다**
  - B-full이 Fact8보다 RMSE가 낮다는 것
  - 파라미터 수가 비슷하다는 것
  - Δ_JF < 0
  - 잠재 좌표의 일관성, 단사성, 미분동형성

### 5.1 수학적 기초

**P8.1 (κ = 0 인수분해) [Verified (math)]**
- κ = 0에서 (s₁, W₁) ⊥ (s₂, W₂)다. 하위계별 독립 초기조건, 비결합 흐름, 열별 독립 MCAR 때문이다.
- 따라서 E_P[s_j | W] = E_P[s_j | W_j]다.
- R*(S | W) = ½ Σ_j R*(s_j | W_j)이고, 여기서 R*(s_j | ·)는 **3좌표 평균**이다.
- **결과:** κ = 0에서 결합 표현과 병치 표현의 차이는 교차 정보일 수 없다(추정·용량·최적화 효과).

**P8.2 (병치 충분성) [Verified (math)]**
- R*(S | φ₁(W₁), φ₂(W₂)) ≥ R*(S | W)다.
- (φ₁, φ₂)가 W 위에서 결합 충분이면(예: 각 φ_j가 W_j 위에서 단사이면) 등호가 성립한다.

**C5 (주변 충분성 ⇏ 결합 충분성) [Verified (math)]**
- W₁ = (a, b), W₂ = c, s₁ = a, s₂ = b·c라 하자.
- φ₁ = a는 s₁에 대해 충분하다. 그러나 (φ₁, φ₂)는 s₂에 대해 충분하지 않다.

**P8.3 (Sham 교환가능성) [Verified (math)]**
- **가정**
  - (i) donor 궤적은 같은 κ의 같은 생성 법칙에서 나온 독립 궤적이다. 각 donor(train, val, test)는 해당 역할에 **한 번만** 쓰인다.
  - (ii) Real과 Sham_j는 같은 초기화 seed, 같은 마스크 배열, 같은 학습·평가 절차를 쓴다.
  - (iii) GPU 비결정성은 자료와 독립이다.
  - (iv) Sham_j의 readout 목표는 S̃^♯ := (실제 s_j, donor의 s_o)다.
  - (v) Fact8Sham_j의 상대 인코더 A_o^♯는 **donor train 궤적의 하위계 o view로 학습**한다(Real의 A_o와 같은 seed와 규칙).
- **결론**
  - κ = 0에서는 자기 자료가 주어졌을 때 (실제 o-자료, donor o-자료)가 i.i.d.다(train, val, test 동시).
  - 두 자료를 맞바꾸면 Real ↔ Sham_j 파이프라인이 정확히 교환된다. 따라서 **j별로** CG_{F,j} := RMSE(y_j | F_real) − RMSE(y_j | F_sham,j)의 분포가 0에 대해 대칭이다. Δ_JF,j(아래)도 마찬가지다.
- **주의:** Real 파이프라인이 j = 1, 2에 공유되므로 **j 평균 CG의 대칭성은 보장되지 않는다.** 다만 j별 대칭에 의해 **기댓값은 정확히 0**이다(유계).
  - 그래서 정확 부호 검정은 j별로만 쓴다. j 평균에는 t 기반 검정(점근)을 쓴다.
- **κ = 1의 해석:** CG는 학습과 추론 전체 파이프라인의 차이다. 추론 시 정보량만의 차이가 아니다.

**P8.4 (자기 L0 인증) [Verified (math)]**
- 임의의 동결 특징 F(W)와, F만 입력으로 test와 독립으로 학습된 readout g에 대해 다음을 정의한다.
  - C_{F,j} := E_P[(S̃_{y_j} + μ_{y_j}/σ_{y_j})² − (S̃_{y_j} − g_{y_j}(F))² | L_j0]
- 그러면 다음이 성립한다.
  - (a) C_{F,j} > 0 ⇒ g∘F는 σ(W_j) 밖의 정보를 쓴다(N1-own).
  - (b) **C_{F,j} > 0 ⇒ L_j0 위에서 F(W)는 W_j의 a.s. 함수가 아니다.**
    - 증명: F가 W_j의 함수라면 g∘F는 σ(W_j)-가측이다. 그러면 N1-own에 의해 C ≤ 0이다. ∎
  - (c) κ = 0이면 모든 F에 대해 C_{F,j} ≤ 0이다(N1-L_j0). BfullSham_j는 모든 κ에서 C ≤ 0이다(donor ⊥ (y_j, W_j)).
- **범위:** (b)는 잠재 자체에 대한 진술이다. 그러나 "잠재가 공유 상태 좌표다"는 아니다.

  - CG_Bfull := ½ Σ_j CG_{Bfull,j}
  - 검출: UCB_{1−0.0125} < 0. 실질 기준 δ_y = 0.02를 따로 보고한다.
- **IIa-2:** (IIa-1 검출 시) κ = 1, p = 0.7, P8.4 인증
  - Ĉ_Bfull := ½ Σ_j Ĉ_{Bfull,j}이고, readout은 O_lat∘φ_Bfull의 y_j 성분이다.
  - 검출: LCB_{1−0.0125} > 0이면 P8.4(b)의 진술이 인증된다.

**IIb — 결합 인코딩 대 병치(CSIA 비교)**
- **IIb-0 (게이트):** κ = 0, p = 0.7, R1, Δ_JF,j := CG_{Bfull,j} − CG_{Fact8,j}(j별 정확 대칭, P8.3)와 그 평균
- **IIb-1:** κ = 1, p = 0.7, R1, Δ_JF := ½ Σ_j Δ_JF,j. UCB < 0이면 다음을 뜻한다.
  > "readout R1에서, 결합 인코딩 파이프라인은 병치 파이프라인보다 실제 결합에서 오는 자기 y_j 이득을 더 크게 실현한다."
  - 이것은 **CSIA**이며 GSR이 아니다.
- **IIb-2:** (IIb-1 검출 시) κ = 1, p = 0.7, R1에서 D₁ := RMSE_s6(Bfull) − RMSE_s6(Fact8). UCB < 0을 보고, δ₆ = 0.05를 따로 보고한다.

**구별 불가능한 다른 설명 (IIb 결과의 범위)**
- IIb-1 검출은 다음 둘을 구별하지 못한다.
  - (i) 결합 인코딩이 교차 정보를 R1-접근 가능한 형태로 만들었다.
  - (ii) Fact8 인코더가 교차 관련 성분을 버렸다(C5).
- 함수 부류와 최적화 step의 차이도 섞여 있다.

**κ = 0 해석 규칙:** D₀ := RMSE_s6(Bfull) − RMSE_s6(Fact8)(κ = 0)는 병치 비용이나 추정 효과로만 보고한다. κ DiD는 서술 전용이다.

**반증 기준**
- IIa-1 UCB ≥ 0 → "κ = 1에서 B-full + R1이 실제 상대 view로부터 자기 y_j 이득을 얻는다"는 지지되지 않는다.
- IIb-1 UCB ≥ 0 → CSIA 우위가 지지되지 않는다. LCB > 0이면 병치 우위를 **서술적으로** 보고한다(반대 방향, α 예산 밖).
- 게이트 FAIL → 해당 하위 가족 보류. UNDETERMINED → 라벨을 붙인다.

## 7. Family IV — readout 없는 잠재 진단 (탐색적)
- **마스크 민감도:** ρ_φ := ½ E‖φ(W_M) − φ(W_M′)‖² / tr Cov(φ). Bfull, Fact8, Fact16에 대해 계산한다.
  - 같은 상태에 서로 다른 마스크 쌍을 쓰고, 공분산은 test 잠재로 계산한다.
- **잠재 이웃 상태 불일치:** test 궤적 i ∈ {0, 1}, 마스크 e = 0의 점 1,000개를 질의로 삼는다. 같은 궤적의 마스크 e = 1..4 잠재에서 표준화 잠재 공간 10-NN을 찾고, 그 참 상태와 질의 상태의 정규화 6차원 거리 평균을 무작위 이웃 기준선 대비로 본다.
- 근사 단사성의 **경험적** 지표이며, 전역 단사성의 증명이 아니다(C2).

## 9. 통계적 추론 단위
- **단위 = 독립 복제본 r**(n = 24 / (κ, p)).
  - 한 복제본 안의 Arm은 같은 자료와 마스크를 쓴다 → 대응 비교다.
- **test 궤적 8 × 마스크 5:** 합동한다(SSE/n). 독립 반복으로 세지 않으며, 시간점은 단위가 아니다.
- **j:** 복제본 안에서 평균한다. j별 정확 검정은 게이트에서만 쓴다.
- **고정 oracle(O_raw, O_own, O_imp, f_kNN):** 결론은 oracle 풀(또는 참조 DB)에 조건부다. O_lat은 복제본마다 학습하지만 풀은 공유한다 → 풀에 조건부로 복제본이 독립이다.
- **κ 사이:** 독립(Welch). **p 사이:** 같은 궤적이므로 복제본 대응.
- **다중성:** Family I α = 0.025(단측, 고정 순서), Family II α = 0.025(IIa 0.0125, IIb 0.0125, 각 고정 순서). **FWER ≤ 0.05.** 게이트는 다중성 예산 밖의 사전 조건이다. 그 밖은 모두 서술적이다.
- **실패 처리**
  - 비유한 실행이나 상한 도달은 제외하지 않는다. 셀의 상한 도달 > 10%면 그 셀은 결론 불가다.
  - **무효 AE 실행**(비유한 step·파라미터·검증)은 완료 표지와 checkpoint를 남기지 않고 실패 기록만 남긴다. 그러면 그 복제본의 O_lat과 평가가 시작되지 않는다.
    - 그 복제본은 미평가로 남고, 셀의 평가 복제본이 24개 미만이면 결론 불가다.
    - 무효 실행은 분석에 보고하며(`p8_invalid_runs.csv`, 셀 표), 조용히 제외하지 않는다.
    - 같은 seed로 자동 재시도하지 않는다.
  - 마감 전에 끝나지 않은 셀은 미실행으로 보고한다.
  - smoke 모드 산출물은 분석에서 거부한다(코드 검사).

## 10. 해석 규칙 (금지된 추론)
1. 낮은 readout RMSE ≠ 전역 단사성, homeomorphism, diffeomorphism.
2. 지도 readout의 성공 ≠ 비지도 AE 자체의 상태 복원. 상태 진술에는 "readout 부류, 자료량"을 붙인다.
3. L_j ≥ 2, both_L2+, n_obs ≥ 6 ≠ 식별가능(C1은 P에서. ν에서는 미해결).
4. p = 0.3 all 층의 평균 성공 ≠ 모든 마스크에서의 성공. 층별 최악값을 보고한다.
5. 국소 rank ≠ 전역 단사(C2).
6. 마스크 안정성 ≠ 식별가능성(C4). 마스크 분산은 oracle과 비교해서만 해석한다(명제 2.2).
7. 좋은 imputation ≠ 숨은 상태 복원(C3).
8. oracle과의 격차 없음 ≠ 정보 한계. 정보 한계는 X0와 κ = 0 L_j0의 LB로만 말하며, **X0는 H의 5.1%**다.
9. κ = 0의 Bfull 우위 ≠ 결합 또는 공유 상태(P8.1).
10. 통계적 검출 ≠ 실질 효과. δ를 따로 보고한다.
11. 이 구조, 이 시스템 밖으로 일반화하지 않는다.
12. 비슷한 파라미터 수 ≠ 같은 용량·귀납 편향.
13. Δ_JF < 0, D₁ < 0, CSIA ≠ GSR, 잠재 좌표 일관성, diffeomorphism.
14. G_lat > 0 ≠ 인코더의 Bayes 정보 손실 또는 함수족의 최적 위험 차이.
15. κ = 0 대조의 CI가 0을 포함 ≠ null 성립. 동등성(TOST)으로만 말한다.
16. P(평가 법칙)의 결과(L4/L5/C1) ≠ ν(불변측도)의 결과.
