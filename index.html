A. Research Overview

Official AIM (원문)

We aim to develop a dynamics-informed imputation framework that reconstructs missing values in multivariate time series without requiring any fully observed variable. It does so by learning a shared latent state to which the delay embeddings of all variables are mapped consistently, as implied by Takens' embedding theorem.

가장 강하게 정당화되는 기여

  • 참조 없는 학습의 수학적 근거: MCAR, holdout, 양성 조건에서 숨긴 관측 항목 손실의 최적해가 조건부 기댓값이다(Fisher 일관성; Phase 9 A4.1). 증명
  • 무조건 cross-mask 정렬의 불가능성(Lorenz 대칭 반례; P7, A2.2). 증명
  • 상대 view의 숨은 상태 정보 존재와 부분 활용(Phase 6, Phase 8 IIa, 독립 복제본 24). 확증·인증
  • 모델 한계 ≥ 0.041 MSE(Phase 8 I-1)와 X0층 정보 한계 ≥ 83%. 인증

아직 해결되지 않은 핵심 문제

  • 결합 공유 잠재(B-full)가 병치(Fact8)보다 낫다는 증거가 없다. p=0.7 대치와 6차원 decodability에서는 병치가 낫다(Phase 8과 9에서 재현). 부정적
  • Phase 9의 수학적으로 정당한 메커니즘(tower 자기 증류)도 개선하지 못했다(P-1 실패). 부정적
  • 학습된 잠재와 기저 상태의 대응(단사성, 미분동형)은 미입증이다. 미해결
  • FPRM과의 같은 정보 조건 공정 비교는 수행되지 않았다. 미평가
